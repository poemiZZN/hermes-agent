# 《我的废柴老公是狼王》写作手法·AI漫剧模板

> 来源：一卡5.26版，10集短剧。主攻动作/表情/冲突的写法，不记忆故事。
> 亮点：高强度物理动作+肌肉级情绪外显+快节奏反转。非常适合AI漫剧的视觉可视化。

---

## 一、格式约定

### 1. 标注符号体系
| 符号 | 用途 | 示例 |
|------|------|------|
| ▲ | 动作/物理行为（类似△） | ▲Elara猛地将一把带血的匕首砸在木桌上。 |
| 【字幕：】 | 角色介绍字幕 | 【字幕：Elara，落魄采药女】 |
| （VO） | 内心独白/画外音 | Elara（VO）：该死…… |
| （OS） | 内心独白/画外音，**可内嵌眼神·神情微动作** | 伊莎贝拉OS（垂眸）：他每一世都记得。 |
| ▲（加粗拟声词） | 强调特定音效 | ▲啪！一只大手猛地按在柜台上！ |

### 2. 对话内嵌情绪
```
格式：角色名（情绪+微表情+身体反应）：台词
```
**不单独写△动作行，而是把表演提示直接嵌入对话行**。这是该模板与用户常规模板的核心差异。

> **OS 同理**：内心独白行（`人名OS（…）：台词`）也可内嵌 1 个眼神 / 神情 / 表情微动作，让内心戏可视化、给表演与绘图支点。OS 与对话同受「把握度铁律」约束——单句 ≤ 1 个表情微动作 + 1 个语气词，不重复罗列、不堆砌无关微表情。

## 二、动作描写核心技法

### 1. "肌肉级"情绪外显（核心技法）

不只是写"生气"或"愤怒"，而是写**具体的肌肉反应和生理变化**：

| 情绪 | ⭐高级写法（狼王模板） | ❌平庸写法 |
|------|----------------------|-----------|
| 愤怒 | 因愤怒而**指甲暴长**，将白骨王座扶手**捏得粉碎** | 他很生气 |
| 害羞 | **耳尖以肉眼可见的速度红透** | 脸红了 |
| 紧张 | **指关节因用力而发白** | 手攥紧了 |
| 震惊 | **瞳孔骤然收缩** | 愣住了 |
| 暴怒 | **额头青筋暴起**，声音低沉如同**野兽咆哮** | 大喊 |
| 恐惧 | **后背瞬间被冷汗浸透** | 害怕 |
| 兴奋 | 眼神里多了一丝**危险的玩味** | 眼睛亮了 |
| 温柔消失 | 嘴角的笑意**瞬间凝固** | 笑不出来了 |

### 2. 动作递进链（三拍递进）

每场冲突的动作不是孤立一句，而是**A→B→C 递进**：

```
示例（Kael发现被拉黑）：
① Kael嘴角的笑意瞬间凝固（第一拍：情绪冻结）
② 他死死盯着那行红字，因愤怒而指甲暴长（第二拍：生理升级）
③ 将白骨王座的扶手捏得粉碎！（第三拍：暴力释放）

▲底下的暗影卫队吓得瞬间伏地，大气都不敢喘（侧面渲染）
```

### 3. 暴力动作具象化

禁忌：不写"打了一架"、"教训了他"
做法：写**具体武器、具体身体部位、具体伤害**：
- "用金属刀鞘**狠狠砸在Todd的肩膀上**"
- "骨头**碎裂的声音清晰可闻**，Todd双腿一软，重重跪倒在地"
- "一刀**劈穿了阁楼的木门**，木屑飞溅"
- "一把**掐住脖子**，**单手提到半空**"

### 4. 视角轮换（展示者/观看者）

同一事件要从**两个角色的视角**分别描写：
```
▲Kael猛地一拳砸碎了白骨王座扶手（Kael视角）
▲暗影队长Jax单膝跪地，肩膀剧烈抖动，拼命憋着笑（旁人视角）
▲底下的暗影卫队瞬间伏地，大气都不敢喘（群体视角）
```

### 5. 环境/物品参与冲突

不让角色在真空中打架，**让环境参与叙事**：
- "符石表面**弹出一行红色警告**：对方已单方面**抹除**您的精神印记"（符石"说话"）
- "月色洒下，兜帽滑落，**露出一张冷若冰霜的脸**"（月色+兜帽配合亮相）
- "木屋墙壁缝隙里不断灌进冰冷的夜风，**发出呜呜的哭泣声**"（风"哭"了）

## 三、情绪描写高频词汇库

### 眼部
瞳孔骤缩 / 瞳孔地震 / 眼眶通红 / 眼泪夺眶而出 / 眼中闪过一丝不忍 / 眼睛微微发红 / 死死盯着

### 面部
脸色瞬间惨白 / 脸色发白 / 脸色发青 / 脸色阴鸷 / 冷若冰霜 / 面部扭曲 / 面带狞笑

### 手部
指关节因用力而发白 / 手背上青筋暴起 / 手指颤抖 / 死死攥住 / 粗暴地扣住手腕 / 指甲暴长

### 身体
浑身颤抖 / 身体剧烈抖动 / 后背瞬间被冷汗浸透 / 双腿一软瘫坐在地 / 浑身一震 / 膝盖被捏得粉碎 / 大口喘着粗气

### 声音
声音低沉沙哑 / 声音颤抖 / 尖酸刻薄 / 冰冷彻骨 / 如同野兽咆哮 / 声音不大却清晰入耳

### 嘴部
咬着下唇 / 死死咬住 / 啐了一口唾沫 / 朝地上吐了一口 / 嘴角勾起一抹弧度 / 笑容凝固

## 四、台词与动作的配合模式

### 模式A：动作打断台词
```
Silas（惊恐地往后退）：……你这个连魔力都没有的废物，怎么可能——
▲Kael一言不发，缓缓拉开衣袖，露出一道闪烁的血誓烙印。
Silas（瞳孔骤缩，尖叫）：血誓？！你居然跟她结契了？！
```

### 模式B：台词触发动作
```
Kael：只要守好那间木屋，别让Logan的狗杂碎碰她一根头发。
▲Kael一边说着，一边用手指摩挲着符石。
▲突然，符石剧烈颤抖，蓝色光芒"啪"地一声彻底熄灭。
Kael嘴角的笑意瞬间凝固。
```

### 模式C：动作先行·台词压轴
```
▲Kael一把掐住Silas的脖子，单手提到半空！
▲Silas双腿在空中乱蹬，拼命拍打着Kael的手臂。
Kael（一字一顿，声音冰冷彻骨）：嘴巴放干净点。
```

### 模式D：多角色接力反应
```
▲全员反应链：
Todd（脸色发白，往后退）：这眼神……怎么回事……
Silas（惊恐地后退）：你是……什么人？
Kael（冷冷扫视全场）：我来接我的妻子。挡路者，死。
▲全场死寂。
```

## 五、冲突节奏：每场=1个核心冲突+3拍动作

每场（一个场景）拆解为：
1. **触发事件**（1个△）
2. **主角反应**（1-2行对白+内嵌情绪）
3. **反作用/升级**（1-2个△+对白）
4. **顶点手势**（1个暴力或强视觉△收束）
5. **侧面渲染**（可选：旁人反应△）

示例：
```
触发：▲整扇木门被一脚踹开！Todd拎着斧头冲进来！
反应：Elara（脸上血色褪尽，身体止不住地颤抖）：不要……
升级：▲Todd一把揪住Elara的头发。Todd（面部扭曲）：今晚谁也救不了你！
顶点：▲一根金属刀鞘狠狠砸在Todd肩膀上，骨头碎裂声清晰可闻。
侧面：▲Silas脸色惨白，瘫倒在地。
```

## 六、角色区分度写���

### 弱→强的过程写法
- 女主柔弱时：咬着下唇 / 死死攥紧衣角 / 眼眶微红但咬牙不语 / 声音颤抖但仍把话说完
- 女主反击时：眼神狠绝 / 一把揪住对方衣领 / 高高举起手腕亮出血誓 / 一字一顿 / 冷笑
- 男主对外：面无表情 / 眼神一凛 / 冷冷俯视 / 声音冰冷彻骨 / 像丢垃圾一样
- 男主对女主：耳尖泛红 / 有些手足无措 / 慌乱地切断通话 / 语气生硬却放缓语调 / 嘴角勾起宠溺笑意

### 反派区分
- 残暴型（Logan/Todd）：面部扭曲 / 朝地上吐痰 / 啐了一口唾沫 / 贪婪淫邪的眼神
- 阴险型（Silas/Vivian）：脸色阴鸷 / 冷笑 / 慢条斯理 / 虚伪做作 / 两面三刀
- 懦弱型（Myra）：躲在门后 / 浑身发抖 / 却尖酸刻薄地诅咒

## 七、改编为△格式的转换规则

狼王模板的▲符号在用户的常规模板中对应△。台词内嵌情绪（括号里的表演提示）在用户模板中保留。核心差异是：

| 维度 | 狼王模板 | 用户常规模板 |
|------|---------|-------------|
| 动作标记 | ▲ | △ |
| 情绪位置 | 嵌入对话行括号内 | 嵌入对话行括号内（一致） |
| 角色介绍 | 【字幕：】 | 人物：行 |
| 暴力细节度 | 极高（骨头碎裂声、指甲暴长） | 中（可借鉴升级） |
| 多人反应链 | 标配 | 可借鉴增强 |
| 环境参与冲突 | 标配 | 可借鉴增强 |

**用户模板可直接借鉴移植的部分**：
1. "肌肉级"情绪外显词汇库
2. 三拍动作递进链
3. 视角轮换（展示者+旁观者）
4. 环境/物品参与冲突
5. 暴力具象化（具体身体部位+具体伤害效果）
