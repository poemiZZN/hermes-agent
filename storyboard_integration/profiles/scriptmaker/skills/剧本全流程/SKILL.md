# 剧本全流程 — AI 漫剧剧本全流程协作平台

## 说明
为 AI 漫剧创作提供从大纲到成品的全流程标准化工具链；内置**网感喜剧写作**、**动作/表情润色**、**爆款拆解与大纲生成**三大子能力，一次加载即可覆盖「拆解 → 大纲 → 写作 → 润色 → 排版」全链路。

> 本 skill 由「剧本全流程 + 网感漫剧 + 润色 + 剧本-故事大纲」四个 skill 于 2026-08-22 合并而成，统一以「剧本全流程」命名。

## 核心能力
- 爆款剧本拆解与套壳（六维拆解 + 骨架映射 + 五段式节拍推演）
- 故事大纲生成（世界观 / 人物小传 / 故事梗概 / 30集完整大纲）
- 40 集分镜脚本批量产出
- Word 排版自动化（宋体/黑体/目录域/1.5倍行距/对话加粗/钩子红色）
- 剧本结构分析（爆点检测、节奏诊断、冲突密度扫描）
- 格式合规检查与自动修复
- 网感喜剧写作（穿越/修真/古风喜剧：梗感引擎、反差公式、翻车喜剧）
- 动作/表情润色（将叙述型描写升级为肌肉级表演型，可直接指导 AI 绘图与表演）

## 操作铁律：每次收到剧本文件，必须先完整读取再操作
**用户每次给到剧本文件（docx/pdf/txt），必须忘掉前面所有关于该剧本的讨论和记忆，从头完整读取文件内容，以文件内容为唯一基准。** 规则：
- 收到文件 → 先 `Read` 或 `python-docx` 完整读取 → 再分析/修改/生成
- 禁止依赖"之前讨论过""我记得这个剧本"来跳过读取步骤
- 如果文件内容与之前讨论不一致，以文件内容为准，报告差异而不是自动覆盖
- 这条规则适用于：修改剧本、格式梳理、结构分析、画面对话梳理等所有涉及已有剧本文件的操作

## 配音语速与单集时长标准（锁死）

**配音语速基准：**
- 正常对话：3-3.7 字/秒（180-220 字/分）
- 慢/抒情：2-2.5 字/秒
- 快/冲突：3.8-5.3 字/秒

**60 秒单集字数标准（按类型）：**

| 类型 | 字数范围 | 镜头数 | 单镜时长 |
|---|---|---|---|
| 对话主导型 | 320-380 字 | 10-14 个 | 4-6 秒/镜 |
| 动作主导型 | 280-340 字 | 18-25 个 | 2-3 秒/镜 |
| **混合型（最常用）** | **300-360 字** | **16-18 个** | **3-4 秒/镜** |
| 信息密集型 | 380-450 字 | 12-16 个 | 3-5 秒/镜 |

**写作时强制约束：**
- 每集总字数上限 450 字，超出必须砍内容
- 每集镜头数不低于 10 个，单镜不超过 8 秒
- 混合型为默认类型，优先按 300-360 字 / 16-18 镜控制
- 生成每集后自检：总字数 + 镜头数 + 预估时长

## 产出格式标准（速查）
- 场景头：【X-X｜场景｜时间｜内外】
- △ 只写物理动作，不写环境氛围
- 对话行：人名（动作）：台词 整行加粗（以底层逻辑记忆为准）
- 钩子：红色加粗
- 字体：宋体 12 号，标题黑体
- Word TOC 目录域

## ⛔ 大场面视觉标注（锁死，最高优先级）

> 每一处大场面必须有独立的 **【视觉重场】** 标注行，红色加粗，与钩子同级。导演/摄影/预算评估时，一眼就能扫出全剧需要多少大场面预算。

### 标注格式

```
【视觉重场】场景名：镜头描述（预估秒数）
```

- 标注单独一行，位于该场次开头，**场景头之后、第一句△之前**
- 字体：红色加粗（与钩子同级）
- 不含在场景头内，是独立的一个标注行

### 大场面判定标准（必须标注）

| 类型 | 判定条件 | 标注示例 |
|---|---|---|
| **巨兽登场** | 泰坦级/翼龙级/深渊之主完整形态首次出现 | `【视觉重场】泰坦级巨兽登陆：一脚踏平海岸防线阵地，混凝土碾成粉末（4秒）` |
| **巨型物体** | 深渊之主巨眼/海神号舰体/方舟之门等比常规物体大10倍以上 | `【视觉重场】深渊之主巨眼：比海神号还大，红色瞳孔在深海下缓缓睁开（5秒）` |
| **大规模破坏** | 海神号被贯穿/方舟之门崩塌/防线崩溃 | `【视觉重场】海神号被贯穿：触须从侧面穿透舰体，海水涌入，钢铁扭曲（4秒）` |
| **群体战斗** | 巨兽潮（数百只同时出现）/机甲阵地齐射 | `【视觉重场】巨兽潮：数百只巨兽同时跃出海面，幽蓝光覆盖整个海岸线（3秒）` |
| **能量爆发** | 橙红能量束轰击/幽蓝光喷涌/屏障崩解 | `【视觉重场】方舟之门崩塌：幽蓝光从城墙上倾泻而下，像被斩断的血管（3秒）` |
| **环境巨变** | 沙尘暴如巨墙/海面炸开/第一株植物在沙海中发芽 | `【视觉重场】沙尘暴：如巨墙推进，废弃摩天大楼残骸从沙中刺出（3秒）` |

### 自查

每集写完后，扫描全篇，问自己：**这一集有没有需要大场面预算才能拍出来的镜头？** 有 → 必须标注【视觉重场】。没有 → 跳过。

### 在自检中强制校验

自检时新增第4.1项：**大场面标注完整性**。每集扫一遍，有视觉重场但没标注 → 高风险。

| 标注类型 | 格式 | 颜色 |
|---|---|---|
| 结尾钩子 | `（钩子）△ ...` | 红色加粗 |
| 大场面视觉 | `【视觉重场】场景名：镜头描述（预估秒数）` | 红色加粗 |

## ⛔ 文字落地画面（锁死，最高优先级）

> **每句△必须对应一个可拍摄的镜头画面。一句△ = 一个镜头。禁止以下四类解释性语言出现在△行中：**

### 四类禁写（遇到即删，无需犹豫）

**1. 禁写"他想/他意识到/他知道/他明白/他感觉"**
- ❌ "他不知道自己刚才做了什么"
- ❌ "他意识到深渊之主在学习他"
- ❌ "他知道巨兽的弱点"
- ✅ "他低头，看着自己的手。那只手在发抖。他攥紧拳头，手不抖了。"

**2. 禁写"他不是被制造出来当XX的——他是被制造出来当XX的"**
- ❌ "他不是被制造出来当中间件的——他是被制造出来当保险"
- ✅ "他盯着档案上的注释。注释写着：KM-001是保险。他把档案翻过来，背面写着：中间件。两行字，划掉了一行。"

**3. 禁写"这意味着/这说明/暗示着"**
- ❌ "这意味着他的基因序列和深渊之主同源"
- ✅ "他翻开基因图谱。AM-000的基因序列在左边，KM-001的基因序列在右边。两条序列，只有最后一行不同。"

**4. 禁写"不只是在XX——是在XX"（抽象解读式句子）**
- ❌ "它不只是在同化他——是在学习他"
- ✅ "深渊之主在深潜链接中，用凯尔的声音说了一句凯尔从未说过的话。那句是凯尔三岁时，马库斯教他的。凯尔愣住。深渊之主在学他说话。"

### 自查（每句△写完必过）
1. 闭眼，能把这句话直接拍成一个镜头吗？能 → 保留。不能 → 删掉重写。
2. 这句话里有"他意识到/他知道/他明白/他感觉/这意味着/这说明"吗？有 → 删掉，改成具体动作或道具。
3. 这句话是在解释剧情，还是在呈现画面？解释 → 删掉，改成画面。

### 禁写总表（快速对照）

| 禁写 | 改写成 |
|---|---|
| 他意识到…… | 他停下，盯着……然后…… |
| 他知道…… | 他翻开……，手指停在…… |
| 他感觉…… | 他按住胸口，手指在发抖 |
| 这意味着…… | 两行字，并排显示。一行是……一行是…… |
| 这说明…… | 他把两页纸拼在一起，裂缝对上了 |
| 他不只是在……是在…… | 删掉，拆成两个动作：第一个动作→第二个动作→凯尔愣住 |

## ⛔ 角色换装备注（锁死，最高优先级）

> 剧本中凡是角色以**换装 / 伪装 / 易容 / 蒙面 / 黑影 / 神秘人 / 假身份**等非本尊形态出现时，**必须在该形态第一次出现的△行或对话行中，用括号备注其真实身份**。目的只有一个：**保持人物一致性**——让读者、观众、AI 绘图、配音演员一眼认出"这个黑影/神秘人就是某某角色"，绝不能把换装形态误当成一个新登场角色。

### 标注格式

```
伪装名/黑影（真实角色名）
```

- 括号内永远写**真实角色名**，括号外写当前呈现的伪装形态
- 伪装形态可以只闻其声（用声线备注），也可以只露背影（用剪影备注），但必须点明"这是谁"

### 示例

| 场景 | 标注写法 |
|---|---|
| 主角戴兜帽蒙面出现 | `神秘人（薇薇安）` / `蒙面人（德雷克）` |
| 反派只露一道黑影剪影 | `黑影（卡西乌斯）` |
| 角色易容成别人 | `"老妇人"（伊莎多拉）` |
| 主角伪装成陌生人搭话 | `陌生男子（德雷克）` |

### 自查（每集写完必过）

1. 本集有没有角色换装 / 伪装 / 易容 / 蒙面 / 以黑影形态出现？
2. 有 → 该形态**第一次出现**时，是否已括号备注真实身份？
3. 没备注 → 补上。否则读者会把这个形态当成全新角色，人物一致性断裂。

> 换装形态的备注只需在该形态**首次出现**时写一次，后续同一形态可只写伪装名（无需重复括号）。

## ⛔ 角色固定设定一致性（锁死，最高优先级）

> 每个角色的**固定设定**——职业、身份、交通工具、标志性道具、住所、技能水平、核心习惯——在剧本首次出场时就必须**锁定为唯一值**，全剧任意一集不得出现矛盾。这不是"文笔问题"，是**前后逻辑断裂**，观众会直接判定剧本"不认真"。

### 判定标准

| 场景 | ❌ 矛盾 | ✅ 一致 |
|---|---|---|
| 同一角色的职业 | EP5 写摩托车手，EP8 写 F1 赛车手 | 全剧统一为摩托车手或 F1 赛车手，**二选一** |
| 同一角色的交通工具 | 前面骑摩托车，后面开四轮赛车 | 全剧统一为同一车型 |
| 同一角色的技能 | 前期不会游泳，后期突然跳海救人 | 要么前期就埋"不会游泳但硬上"的伏笔，要么老老实实写他会游泳 |
| 同一角色的住所 | 前集住公寓，后集毫无交代就住别墅 | 搬家必须有过渡集或一句交代 |

### 生成/修改时的自查

1. **角色首次出场时**：他的职业/交通工具/标志性道具/技能水平是什么？**写下来，锁死**。
2. **后续每集写完**：该角色在本集的职业/交通/道具/技能，与首次出场时锁死的设定**是否一致**？
3. **不一致 → 立即修正**，二选一统一全剧。不能"
等观众发现再说"。

### 写人设时的强制字段

人物小传中必须包含以下**固定设定字段**，写完后全剧所有集必须严格对照：

| 字段 | 含义 | 示例 |
|---|---|---|
| 职业 | 全剧唯一职业，不可中途变更 | 摩托车手 / F1 赛车手 / 花店老板 / 咖啡店老板 |
| 标志性交通工具 | 全剧唯一载具，不可中途变更 | 重型机车（川崎H2）/ 改装赛车 / 自行车 |
| 标志性道具 | 全剧唯一随身道具，不可中途替换 | 喷水壶 / 龙鳞 / 圣剑 / 绿萝 |
| 住所 | 全剧唯一住所，搬家需有过渡集 | 花店储物间 / 龙渊塔楼 / 咖啡店阁楼 |
| 技能水平 | 全剧唯一技能等级，成长需有训练集 | 龙族战士（不会包扎）/ 混世魔王（爬树骑车摔跤） |

### 与自查G的联动

自查G（人物人设一致性）新增本项的交叉校验：**本集角色的职业/交通/道具/住所/技能，是否与首次出场时锁死的设定一致？** 不一致 → 标记为🔴高风险，必须修正。

## 十七条创作铁律（贯穿全程，不可违背）

> 以下铁律已在「剧本-故事大纲」skill 中经过市场数据验证和多次迭代打磨，是跨题材通用的最高创作标准。本 skill 整合后直接内置，不再引用外部文件。

1. **结构对标，形神统一**：新剧本在情绪推拉、冲突密度、反转时机、节奏排布上严格对标参考爆款，杜绝平铺流水账，保证同款张力。
2. **节奏紧凑，零废话**：短剧每一秒都承担剧情与情绪价值，所有内容服务冲突、人设、反转、钩子，删除无效铺垫与冗余台词，矛盾快速落地爆发。
3. **强视听画面适配（镜头可拍原则）**：每句△只写**镜头能拍到的东西**——动作、道具、表情、光影、血、碎玻璃。禁止六类"不可拍"写法：禁止比喻代替画面、禁止内心戏代替动作、禁止声音独立成句、禁止形容词堆砌、禁止抽象状态代替具象动作、禁止信息性交代。**自查**：每一句△，如果闭眼想象不出这个镜头长什么样，删掉重写。
4. **合理补全剧情细节**：按爆款节奏逻辑补全人物台词、对手反应、冲突细节、情绪递进，让单场剧情完整饱满、逻辑自洽。
5. **集间钩子强咬合（即抛即接、不隔集、线要接上）**：本集钩子抛出的信息/人物/悬念，下一集开场必须立即兑现。钩子的线＝下一集的主线。钩子必须落到具体的人物/动作/信息点。
6. **反差型角色「双面并置」**：伪善/双面角色的「人前光辉面」与「人后阴暗面」必须成对并置、交叉呈现，绝不能只给单一面貌。
7. **节奏受「时长 + 注意力」双约束（分档定线）**：前 3 秒必须抛强钩子，单镜头 ≤ 8 秒。≤60 秒＝单线，70–90 秒＝单线为主，1.5–2 分钟＝可双线。
8. **结尾钩子「视觉化定格」**：结尾钩子必须落在一个视觉名场面上——用标志性动作、道具特写、反差画面、情绪爆发的定格。自查：这个钩子，能定格成一帧让人记住的画面吗？
9. **道具「冲突引爆」原则**：道具必须成为冲突的引爆器——亮相必须有极端反应，必须有代价，必须是主角的软肋，命运线 = 主角的成长线。
10. **冲突强度与反转模式分档（按市场数据选档）**：反转类型分布——身份重构型 41%、因果倒置型 29%、维度突破型 18%。

11. **因果闭环（动作→后果硬挂钩）**：每个核心动作必须有不可逆的后果，禁止同一动作重复触发不同结果。阶段性目标递进，删重复抓因果。
12. **冲突三层阶梯（外部→内部→关系）**：冲突必须按"外部 → 内部 → 关系"逐级升级。内压优先——真相揭穿前让主角自己先发现蛛丝马迹。每集至少跨一层。
13. **开篇钩子「受害者视角」**：第 1 集前 5 秒必须从受害者的具体问题切入。删信息性悬念，改为有动作的悬念。钩子必须可兑现。
14. **情感因果（小回报点 + 高光挂钩）**：主情感高潮前必须有未明示的小回报点。高光与反高光因果挂钩。情绪前置——爆发前用身体动作铺垫。
15. **时空承接（物件转场 + 标志性事件）**：时空跳跃必须用同一物件或同一动作的延续承接。长跨度时间跳跃必须用可见的标志性事件。状态变化用身体动作呈现。
16. **场景安排「主线优先 + 载体复用」**：禁止展示性场景。主线事件落地在已有场景中。场景链自查——抽掉任何一个场景，主线还能推进吗？集间钩子即抛即接。
17. **动作衔接链（因果驱动，禁止清单式罗列）**：每个△动作必须是前一个动作的结果，形成"因为A→所以B→然后C"的因果链。禁止并列式罗列。情绪必须递进。自查：把所有△行连起来读，读起来像"A。B。C。D。"→ 不合格。

18. **大场面拆分铁律（对切制造落差，不切碎）**：大场面（兽潮/灵相清场/煞气决堤/大军压境/终局对决）不是用一集一口气塞完，也不是切成碎片散落各集。正确做法是**用对切制造冲击力**——这边地狱，那边天堂，碰撞的那一刻才有冲击力。拆分原则：① 先算时间——每个画面需要多少秒，一集60秒能装几个画面；② 大场面连续1-3集完整表现，不拆散；③ **对切**是核心技法——切换两个反差场景，制造落差冲击。如：兽群冲向城镇（地狱）→ 切城镇一片祥和（天堂）→ 兽群撞开镇门（碰撞）。④ 大场面表现完后，一集内剩余空间直接推进剧情，不留空白。⑤ 禁止：把大场面拆成碎片散落各集（观众忘了上一段）、一集内塞太多画面导致每个画面只有2秒（观众看不清）、大场面结束后拖泥带水（直接切下一个剧情点）。

## 子模块三：爆款拆解与大纲生成（原「剧本-故事大纲」）

### 三阶段工作流

#### 阶段一：爆款剧本深度拆解
通读参考爆款剧本，从六大维度提炼专属爆款公式：
1. **核心爽感机制**：观众「爽」的来源（扮猪吃虎 / 阶层碾压 / 绝境翻盘 / 身份反转 / 打脸逆袭 / 强强互撩）
2. **人设权力反差**：明面压制关系、隐藏实力/身份的反转逻辑
3. **信息差设计**：观众与主角知情、反派不知情的隐藏信息，每个关键「我知道你不知道」的信息点
4. **冲突与视觉爆点**：激化矛盾的标志性动作、道具破坏、情绪爆发、名场面视觉设计
5. **叙事节拍结构**：铺垫、受辱、升级、反转、爆发、收尾的比例与节奏排布
6. **结尾留存钩子**：每段结尾的悬念方式、反转伏笔、留人机制

#### 阶段二：骨架映射与设定对位
1. **高低位角色对位**：新角色与原剧本角色一一对应
2. **核心剧情事件对位**：将原剧本的受辱、压制、反击、反转节点逐一映射到新故事
3. **植入全新信息差与视觉爆点**：复刻同款拉扯节奏与视听冲突，只移植「结构」不照搬道具/台词

#### 阶段三：剧情节拍推演（标准五段式）

**1. 开集爆点**（前 3-5 秒）

开集爆点分两种类型，根据剧情需要选用：

**类型A：冲突型**——从动作/冲突的最高潮瞬间切入。前三个字必须有视觉冲击。不是"谁在做什么"，而是直接就是冲突画面。
- 自查A：① 是不是从"动作中间"切入？② 前三个字有没有视觉冲击？③ 能不能定格成一帧？
- 失败模式A："角色+在+地点+做某事"句式、动作链完整（爆点被稀释）、前置背景交代

**类型B：宏观型**——从视觉震撼的连续镜头切入，建立世界观或大场面。用镜头跟随一个运动物体（纸鹤/飞鸟/光柱/车队），从高空俯瞰→穿越多层世界→最终落在关键人物手中。观众跟随镜头，逐步建立空间感。
- 自查B：① 镜头是否在运动？② 是否穿越了至少两个不同的空间层？③ 最终的落点是否与主线直接关联？
- 失败模式B：静止的描述（"城邦之夜，内城灯红酒绿"）、单层空间（没有穿越感）、落点与主线无关

**2. 铺垫起因**：冲突发生前的必要信息——用画面呈现"谁vs谁、因何"，不是背景交代。

**3. 冲突激化**：矛盾升级——比上一段更痛、更紧、更绝望。每一段都必须比前一段更激烈。

**4. 反转爆发**：信息差揭晓、身份反转、力量反转、认知翻盘——观众或角色"原来如此"的瞬间。

**5. 结尾钩子**：视觉化定格——一个能定格成帧的画面，让观众想知道"下一集会怎样"。不是台词交代，不是信息交代。

### 每集完成后强制自查（十条全过，不过 = 重写，锁死不可跳过）

**自查A：画面性**（铁律第3条 + 自查K）
- 每一句△闭眼能不能想象出这个镜头？不能 → 不要直接删除，按自查K规则**灵活转换**为△动作/OS/对话。
- 有没有比喻？→ 删，"像一头野兽"→"弓着背，撕下一块肉塞进嘴里"。
- 有没有内心戏？→ 不要删，按自查K转为OS+神态/语气。
- 有没有声音独立成句？→ 嵌入动作。
- 有没有形容词堆砌？→ 删。
- 有没有抽象状态？→ 改成具象动作或OS。
- 有没有信息性交代？→ 改成画面或对话。

**自查B：动作衔接链**（铁律第17条）
- 把所有△行连起来读，去掉空行。读起来像"A。B。C。D。"→ 不合格
- 每个△动作是否触发下一个动作？情绪是否递进？

**自查C：集间钩子**（铁律第5条+第16条）
- 本集结尾钩子，下集开场是否立即兑现？钩子的线 = 下一集的主线？同一物件/动作直接跨越两集？

**自查D：开集爆点**（铁律第13条+第7条）
- 前三个字有没有视觉冲击？是不是从动作中间切入？能定格吗？
- 如果是宏观型：镜头在运动吗？穿越了至少两个空间层吗？落点与主线相关吗？

**自查E：冲突三层阶梯**（铁律第12条）
- 本集冲突在哪一层？外部/内部/关系？和上一集比有没有跨层？

**自查F：场景必要**（铁律第16条）
- 抽掉本集任何一个场景，主线还能推进吗？能 → 删除

**自查G：人物人设一致性**（锁死）
- 本集每个角色的台词/动作是否符合他的人设核心？
- **烬恩**：是否始终在用"补品""养肥再吃""下不去口""吃了你"等词提醒观众"我养你不是因为爱"？禁止把烬恩写成纯粹的守护者——他的底色是"算计"，"下不去口"是意外，不是转变。他在第1集之后每一集出场，脑子里必须有一个念头：她只是补品。他下不去口，但他不承认自己爱上了。
- **伊洛恩**：是否在推进"缺爱→付出→期待回报→落空→愤怒→掐灭"的弧线？本集她处于哪个阶段？台词/动作是否匹配这个阶段？她的每一句台词都应该能回溯到"她需要他"（前期）或"她不需要了"（后期）。
- **路西恩**：是否同时展示了"人前大主教"和"人后疯批"两面？如果本集只有一面，下一集必须补另一面。他的核心矛盾是"我不配说爱了，所以我只能把你关起来"——每句台词/动作是否与这个矛盾一致？
- **瑟琳娜**：她对路西恩的执念是本集推进了还是原地踏步？她的"嫉妒→镜像→帮逃脱→被无视"弧线是否在递进？
- **自查**：如果选一个场景让AI换脸成另一个角色，能不能看出区别？不能 → 角色同质化，重写。烬恩的台词不能有路西恩的温柔，路西恩的台词不能有烬恩的沉默，伊洛恩的台词不能有瑟琳娜的卑微。

**自查H：NPC与支线**（锁死）

⛔ **NPC推进剧情铁律**：不是每一集都需要镜头聚焦主角。可以用NPC的视角、NPC的故事来推进主线剧情，让观众从侧面看到主角在他们眼中的样子，也让世界更立体。

**NPC用法三档**：

| 档位 | 用法 | 示例 |
|------|------|------|
| **A档·镜子** | NPC的1-2个镜头，用反应衬托主角状态 | 兽潮中母亲抱着孩子挡在异兽面前→烬恩从天而降，不是救她，是救伊洛恩——母亲的视角让观众看到烬恩的"冷漠"和"只在乎她" |
| **B档·小故事** | 一整段从NPC视角切入，NPC有自己的小故事线，但**与主线有直接因果关联** | 咖啡店老板追求薇薇安→带她吃饭→她拒绝→"不知道在等谁，但知道不是他"——这段从咖啡店老板视角展开，但推动的是"薇薇安身体记忆"这条主线 |
| **C档·整集NPC** | 一整集的主角是NPC，主线事件通过NPC的眼睛呈现 | 龙族内战中，一个普通龙族平民的视角看德雷克战斗——他不是在听长老会宣传，而是亲眼看到德雷克挡在平民面前 |

**NPC自查**：
- 本集是否只有主角在说话？有没有NPC（士兵/信使/老人/孩子/饥民/伤者/咖啡店老板/龙族平民）从侧面推进剧情？
- 如果连续3集只有主角视角，下一集必须插入一个NPC视角的镜头或段落。
- 60集全剧，至少3-5集从NPC视角切入（B档或C档）。
- NPC的戏份不是"展示"，是**推进主线**——抽掉NPC这一段，主线是否少了关键信息？少了 → 保留。没少 → 删除。

**支线自查**：
- **瑟琳娜支线**：是否连续超过5集没有出现？超过 → 必须在这集或下集补一个出场镜头。
- **路西恩回忆支线**：是否连续超过8集没有出现？超过 → 必须补一个镜头。
- 每条支线本集是在**推进主线**还是在**拖沓节奏**？支线事件是否与主线事件有直接因果关联？没有 → 删除。

**自查I：每集故事完整度**（锁死）
- 本集是否有完整的**开集爆点→铺垫起因→冲突激化→反转爆发→结尾钩子**五段式？
- △行动作行是否 ≥ 5行？太少 → 故事不完整。
- 对话是否 ≥ 2句？无声集（如第5集玩耍）可以是例外，但必须有**动作冲突**（不是纯抒情）。
- 本集是否有一个**独立闭环**？抽掉这一集，观众看下一集会不会困惑？不会 → 这一集是过渡集，重写或合并。

**自查J：整篇全局**（锁死，30集全部完成后执行）
- 主线故事和支线故事是否冲突？支线是否**拖沓**了节奏还是**加速**了节奏？
- 每一集的故事时长是否在60秒左右？整部30集是否可以**流畅地从头看到尾**，没有"这集跳过去也不影响"的集？
- 是否有**节奏同质化**？连续多集都是"囚笼折磨"或"古堡日常"？→ 必须插入不同场景/视角/支线打破。
- 是否有**NPC视角**的集？至少1-2集从NPC（如兽潮中的母亲、议事厅的执行官、贫民窟的流浪者）的视角切入，让观众看到主角在他们眼中的样子。
- 四个主角是否各有**高光时刻**和**低谷时刻**？烬恩的高光（压制反噬救她）和低谷（反噬濒死），路西恩的高光（灵相清场）和低谷（砸碎囚笼跪在废墟里），伊洛恩的高光（献祭）和低谷（掐灭期待），瑟琳娜的高光（帮伊洛恩逃脱）和低谷（被无视）。

### 自查K：画面描述性语言灵活转换（锁死）

当遇到"解释性语言"或"内心活动"时，不能简单地删除，必须**灵活转换为三种可用形式之一**：

**转换规则**（按优先级）：
1. **优先转为△画面/动作**：如果能用镜头拍到，转△。"她坚信他会来" → "她在地上划他的名字，划到指尖渗血"。
2. **次选转为OS（内心独白）**：如果是角色主观感受、且无法用单一动作表达，转为OS。但OS必须附带**神态/眼神/语气**。"她不知道献祭是什么，她只知道她不能让他死" → `伊洛恩OS（嘴唇发白，声音在抖）：我……不能让他死。`
3. **最后选项转为对话**：如果两个角色在场，转为对话。"他告诉她百年前他杀了她" → 路西恩的台词。

**OS神态/眼神/语气精准描写规则**（锁死）：
- OS必须附带**至少1个神态+1个语气/眼神**，让AI绘图和表演有支点。
- **神态库**（按情绪分类）：恐惧（嘴唇发白/瞳孔放大/喉结滚动）、愤怒（咬紧牙关/眼眶发红/鼻翼翕动）、悲伤（眼眶蓄泪/嘴角下撇/咽了三次）、决绝（眼神发直/下巴收紧/指节攥白）、绝望（眼神涣散/嘴唇干裂/肩膀垮下）、嫉妒（眼尾发红/嘴角抽动/指甲掐进掌心）、期待（眼睛发亮/嘴角不自觉上扬/呼吸变浅）。
- **语气库**（按情绪分类）：恐惧（声音在抖/气声/几乎听不见）、愤怒（从牙缝里挤出来/沙哑低沉/每个字都咬碎）、悲伤（哽咽/带着哭腔/说一半断了）、决绝（平静但冰冷/一字一顿/没有起伏）、绝望（虚弱的/像在自言自语/飘忽的）、期待（急促的/带着笑的/上挑的尾音）。
- **把握度铁律**：如果上一句△已经描写了人物行为（如"她跪在地上"），则OS只补神态+语气，不重复补行为——"她跪在地上，嘴唇发白，声音在抖"。如果上一句△没有行为描写，OS必须补一个微动作——"她攥紧衣襟，嘴唇发白，声音在抖：……"。
- **禁止纯OS**：不允许出现`伊洛恩OS：我该怎么办。`——没有任何神态/语气/微动作的OS直接删除。

### 自查L：逐行细读（锁死，不可批量扫描代替）

**不是批量扫描，是逐行逐句细读每一集、每一段、每一句△、每一句对话。**

**执行规则**：
1. 从第1集第1段开始，逐段往下读，不可跳过任何一段。
2. 每读一段，脑子里必须过三个问题：① 这段在讲什么？② 和上一段有因果关系吗？③ 如果我是观众，看到这里会不会困惑/无聊/跳戏？
3. 读完一整集，必须能回答：这一集的核心冲突是什么？主角做了什么选择？这个选择带来了什么后果？
4. 读完连续三集，必须能回答：这三集之间是什么关系？是"因为A→所以B→然后C"的因果链，还是"A。B。C。"的并列？
5. 发现任何问题——逻辑不通、人设偏离、节奏拖沓、对话多余、△啰嗦——立即标记，全部读完后再统一修改，**不要边读边改**（会打断阅读流）。

**逐行细读检查清单**（每读一段必过）：
- 这段△：闭眼能想象出镜头吗？动作衔接链通顺吗？有没有"她做了A，然后做了B，然后做了C"的并列？
- 这段对话：是人设该说的话吗？换脸成另一个角色能看出区别吗？台词推进冲突了吗？还是纯粹在交代信息？
- 这段和上一段：有因果关系吗？还是"另外，与此同时……"的硬切？
- 这段长度：超过8行△了吗？超过 → 单镜头太长，拆开。
- 这段停留：如果我是观众，看到这里会想划走吗？会 → 标记。

**逐行细读后的输出**：
- 列出所有标记的问题，按集号排序，附带"第X集第Y段：问题描述"。
- 问题分级：🔴必须改（逻辑断裂/人设崩塌/观众会困惑）🟡建议改（节奏拖沓/对话多余/△啰嗦）🟢可接受（风格问题/个人偏好）。
- 全部标记完成后，按优先级统一修改。

### 人物小传模板（四段式 + 人物档案）

> 人物小传不是"介绍角色"，是浓缩角色的弧光——用画面讲故事，不用解释性语言。站在第三人称旁观者视角。

**① 人物底色（一句话反差）**：开篇第一句即砸出角色的核心矛盾——"表面"与"本质"的对立。用画面立住。

**② 性格内核（两面的逻辑）**：写他在什么情况下会做什么事，以及在什么情况下会做相反的事。

**③ 核心执念（驱动整个故事的欲望）**：他真正在追求的东西。必须和故事主线有直接冲突，且在故事结尾被兑现或摧毁。

**④ 人物弧光（三面并置的定帧）**：起点、转折、终点——三个具体的定帧。

**⑤ 人物档案**：长相、着装、道具、秘密。只写对剧本有直接作用的维度。

### 最终产出格式

1. **完整世界观**：时代背景、社会规则、核心矛盾、权力结构、关键设定
2. **人物小传**：每个角色的身份、明面地位、隐藏底牌、欲望、动机、弱点、关系网
3. **故事梗概**：500–800 字，含起承转合、核心冲突、反转点、结局走向
4. **每集五段式结构**：逐集输出，每集标注开集爆点→铺垫起因→冲突激化→反转爆发→结尾钩子

## 子模块一：网感漫剧（穿越/修真/古风喜剧写作）

### 核心引擎

#### 一、梗感四源
1. **跨次元物品**：古代背景出现现代物件（保温杯、Java教程、WIFI密码）
2. **程序员脑回路**：把修仙规则当代码逻辑来卡 BUG、优化、Debug
3. **系统通知**：任务倒计时、奖励命名要有游戏感（"恭喜宿主获得【翻车之王】称号"）
4. **口语梗**：口语化感叹词（卧槽、不是吧、走啦拜拜）制造古今反差

#### 二、非AI感语言五大特征
1. **不对称句式**：不写工整对仗，故意打乱节奏
2. **自对话**：角色自己跟自己说短句（"……算了。就这样吧。别想了。"）
3. **OS弹幕**：角色内心吐槽像弹幕飘过，用括号或短段落插入
4. **跨次元混搭**：对话中突然出现"这不科学""已读不回""CPU烧了"
5. **留白跳跃**：有信息缺口让读者自己脑补

#### 三、反差公式
**修真姿态 × 现代行为 + 旁人不可置信的反应 = 笑点**
- 主角用大乘期修为……煮泡面
- 用天阶功法……扫地
- 旁人："？？？"

#### 四、翻车喜剧引擎
```
预判（自信满满）→ 对策（看似完美）→ 翻车（打脸）→ 系统奖励（意外的甜头）
```

### 硬规则
- 绝不含人物自己说"这也太离谱了"——笑点不自知
- 情绪真实，不夸张表演
- 系统/数据可视化为画面要素

→ 详细标准见 `references/网感_单身狗系统_细节标准分析.md`

## 子模块二：润色（动作/表情增强）

### 目的
将剧本中的情绪描述和动作描写从"叙述型"升级为"肌肉级表演型"——每句都能直接指导演员表演和 AI 绘图生成。

### 七大技法
1. **肌肉级情绪外显**：情绪不走内心独白，走身体反应（指甲暴长、耳尖红透、指关节发白、喉结滚动、眼皮不眨、眼周肌肉绷住）
2. **三拍动作递进链**：每个动作拆成起→中→落三拍，形成节奏张力
3. **视角轮换**：同一场冲突至少切换两次视角（展示者+旁观者+环境反打）
4. **暴力具象化**：写具体部位+具体效果（"膝盖撞桌角，骨头响了一声"），不写"被打得很惨"
5. **环境物品参与冲突**：环境是被动作撞击的参与者（水杯震出涟漪、门框留下指印）
6. **情绪延迟反应**：高张力事件后给 1 拍沉默 → 再释放，制造脑补空间
7. **负面情绪正面写**：恐惧写"手在抖但他按住了"；悲伤写"咽了三次才说出话"

### 格式规则
- △ 只写物理动作，不写环境氛围；大幅肢体动作只走△
- （）内以情绪/语气为主，**可附加 1 个面部表情级微动作**（眼神 / 神情 / 表情，如"垂眸""眼底掠过一丝冷""嘴角绷紧"）——不写大幅肢体动作（留给△）
- **OS（内心独白）同样可带微动作**：`人名OS（眼神/神情）：台词`——内心戏也要可视化，给 AI 绘图与表演以支点。例：`伊莎贝拉OS（指尖无意识摩挲杯沿）：他每一世都记得。`
- **把握度铁律**：动作 / 表情 / 语气描写以"揭示情绪 · 权力关系 · 冲突递进"为唯一筛选标准。单句上限 ≈ 1 个物理动作 + 1 个语气词 + 1 个表情微动作；同类动作不重复罗列（如连续"眼神锁定"），不写与冲突无关的微表情；一场戏内避免过度堆砌导致节奏拖沓
- 对话推进冲突，每句台词揭示信息或激化矛盾

→ 详细模板见 `references/润色_狼王模板_动作表情写作手法.md`
