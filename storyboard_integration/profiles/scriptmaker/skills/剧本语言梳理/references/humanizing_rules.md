# 四层递进式语言打磨详细规则

## 第 1 层：去机械化 — 详细操作指南

### 1.1 AI 写作常见特征（需要消除的）

| AI 特征 | 示例 | 真人写法 |
|---------|------|---------|
| 过度工整的排比 | "他愤怒，他绝望，他崩溃" | "他气得浑身发抖。然后——绝望。最后整个人都垮了。" |
| 模板化开场 | "在这个充满挑战的时代..." | 直接切入，不铺垫 |
| 完美对称的句式 | "一边是光明，一边是黑暗" | "光明在这边，另一边——全是黑的。" |
| 过度使用破折号 | "他——终于——明白了" | "他终于明白了。" 或 "他，终于，明白了。" |
| 三段式总结 | "首先...其次...最后..." | 自然过渡，不刻意编号 |
| 空洞的升华 | "这不仅仅是一次胜利，更是..." | 直接说发生了什么，不拔高 |
| 过度使用的连接词 | "然而""此外""与此同时" | 用短句自然过渡，减少连接词 |
| 完美闭环的段落 | 每段都有开头-中间-结尾 | 允许段落不完整、戛然而止 |

### 1.2 口语化改造技巧

**加入语气词：**
- 陈述句末尾加"的"、"了"、"呢"
- 疑问句加"吗"、"吧"、"啊"
- 感叹句加"啊"、"嘛"、"啦"

**制造不规整感：**
- 刻意让相邻句子长度不同（长-短-短-长-短）
- 偶尔使用不完整句子（说半句、省略主语）
- 允许重复（"我真的...我真的不知道"）
- 加入修正/改口（"不，不是那样，我是说——"）

**对话特有技巧：**
- 不同人物有不同的口头禅和说话节奏
- 紧张时句子变短、变碎
- 放松时句子可以稍长、带语气词
- 情绪激动时允许语法不完整

### 1.3 第 1 层示例对照

**原文（AI 风格）：**
> 林悦站在门口，她的眼神中充满了复杂的情绪。她既愤怒又悲伤，既想冲进去质问，又想转身离开。这一刻，她感到前所未有的迷茫。

**打磨后：**
> 林悦站在门口，没动。
> 眼神很复杂——愤怒，悲伤，全搅在一起。她想冲进去问个清楚，脚却像钉在地上。走？不走？
> 她从来没这么迷茫过。

**改动说明：**
- "她的眼神中充满了复杂的情绪" → "眼神很复杂"（去书面化）
- 打破"既...又...既...又..."的工整排比
- 加入"没动""走？不走？"的短句制造节奏变化
- "她感到前所未有的迷茫" → "她从来没这么迷茫过"（口语化）

## 第 2 层：增强感染力 — 详细操作指南

### 2.1 词汇替换对照表

| 平淡词汇 | 升级选项（根据场景选） |
|---------|---------------------|
| 看 | 盯着、扫了一眼、凝视、瞥见、死死地看 |
| 说 | 低声道、吼出来、冷笑一声、吐出几个字、从牙缝里挤出来 |
| 走 | 冲出去、拖着步子、晃进来、疾步、踉跄着 |
| 生气 | 炸了、脸都青了、手指攥得发白、眼底烧着火 |
| 害怕 | 腿发软、后背发凉、心提到嗓子眼 |
| 高兴 | 嘴角压不住、眼睛亮了、心跳漏了一拍 |
| 难过 | 喉咙发紧、眼眶发酸、胸口像被什么东西堵住了 |
| 想/思考 | 脑子里闪过、一个念头冒出来、反复琢磨 |
| 非常/很 | 用具体描写替代，不叠加强度副词 |
| 突然 | 用动作直接表现，少用"突然"这个词本身 |

### 2.2 句式节奏优化

**长短句交替原则：**
- 紧张/冲突场景：短句为主（5-10 字），制造急促感
- 抒情/内心独白：适当中长句（15-25 字），但不超过 30 字
- 关键情绪爆发点：2-5 字超短句，制造冲击力
- 对话与叙述交替，避免连续 3 句以上同类型句式

**避免的句式：**
- 连续"XX 地"副词修饰（"愤怒地""绝望地""痛苦地"）
- 连续"一边...一边..."并列结构
- 连续"不仅...而且..."递进结构
- 过度使用"仿佛""似乎""宛如"等模糊词

### 2.3 第 2 层示例对照

**原文（第 1 层结果）：**
> 林悦站在门口，没动。眼神很复杂——愤怒，悲伤，全搅在一起。她想冲进去问个清楚，脚却像钉在地上。走？不走？她从来没这么迷茫过。

**打磨后：**
> 林悦站在门口，手指攥得发白。
> 愤怒，委屈，不甘——全搅在胸口，烧得她喉咙发紧。她想冲进去，想把所有话砸在他脸上，腿却像灌了铅。
> 走？不走？
> 她活了二十八年，头一回不知道该往哪迈。

**改动说明：**
- "没动" → "手指攥得发白"（视觉化情绪）
- "眼神很复杂" → "愤怒，委屈，不甘——全搅在胸口，烧得她喉咙发紧"（分层递进情绪）
- "问个清楚" → "把所有话砸在他脸上"（更有冲击力）
- "像钉在地上" → "像灌了铅"（更沉重、更有画面感）
- "从来没这么迷茫过" → "活了二十八年，头一回不知道该往哪迈"（更具体、更有记忆点）

## 第 3 层：梳理结构 — 详细操作指南

### 3.1 句子拆分规则

- 任何超过 40 字的单句必须拆分
- 每个句子只承载一个核心信息
- 因果、转折、递进关系各占一句，不糅合
- 拆句后检查信息流是否自然（从已知到未知）

### 3.2 段落拆分规则

- 每个段落聚焦一个核心要点
- 段落长度控制在 2-4 句（剧本场景描写可稍长）
- 不同情绪/节奏的内容分属不同段落
- 空行表示情绪转折或场景切换

### 3.3 小标题添加规则

当内容涉及多个逻辑板块时，可添加小标题：
- 小标题用简短短语（3-8 字），不用完整句
- 小标题风格与全文一致
- 小标题之间逻辑平行或递进
- 剧本场景中用小标题标注场景转换

### 3.4 第 3 层示例对照

**原文（第 2 层结果）：**
> 林悦站在门口，手指攥得发白。愤怒，委屈，不甘——全搅在胸口，烧得她喉咙发紧。她想冲进去，想把所有话砸在他脸上，腿却像灌了铅。走？不走？她活了二十八年，头一回不知道该往哪迈。

**打磨后：**
> **站在门口**
>
> 林悦手指攥得发白。
>
> 愤怒，委屈，不甘——全搅在胸口，烧得她喉咙发紧。她想冲进去，把所有话砸在他脸上。
>
> 腿却像灌了铅。
>
> **走还是不走**
>
> 走？不走？
>
> 活了二十八年，头一回不知道该往哪迈。

**改动说明：**
- 拆分为两个板块：「站在门口」和「走还是不走」
- 每个板块聚焦一个核心情绪状态
- 超短句独立成行，强化节奏感
- 删除了"她"的重复使用，部分句子省略主语更自然

## 第 4 层：语气适配 — 详细操作指南

### 4.1 语气风格对照表

#### 正式庄重
- 用词：完整正式词汇，避免口语化
- 句式：结构完整，适当使用复合句
- 语气词：极少使用
- 适用：法庭陈词、官方声明、仪式致辞

#### 日常随意
- 用词：生活化词汇，允许俚语、网络用语
- 句式：短句为主，允许不完整句
- 语气词：大量使用（呢、吧、啊、嘛）
- 适用：朋友聊天、日常家庭、街头场景

#### 专业严谨
- 用词：行业术语适度使用，定义清晰
- 句式：逻辑严密，因果关系明确
- 语气词：几乎不使用
- 适用：医疗诊断、法律分析、技术讨论

#### 亲切温和
- 用词：柔和、正面词汇为主
- 句式：中等长度，节奏舒缓
- 语气词：温和语气词（呢、哦）
- 适用：亲子对话、恋人低语、安慰场景

#### 权威干练
- 用词：果断、直接，少修饰
- 句式：短句为主，命令式/陈述式
- 语气词：不用
- 适用：上级指令、专家判断、决策场景

#### 励志鼓舞
- 用词：正面、有力、具象化
- 句式：节奏感强，适当使用排比（控制在 2-3 组）
- 语气词：感叹语气
- 适用：演讲、赛前动员、逆境反击

#### 紧张压迫
- 用词：短促、尖锐、具冲击力
- 句式：极短句（2-8 字），断句多
- 语气词：极少
- 适用：对峙、追击、倒计时、突发事件

#### 浪漫深情
- 用词：具象化感受，少用抽象形容词
- 句式：中等长度，有韵律感
- 语气词：温柔语气
- 适用：告白、离别、重逢、回忆

### 4.2 术语密度控制

- **大众受众**：专业术语不超过 5%，必须使用时附带自然解释
- **行业受众**：术语可占 10-20%，无需解释
- **混合受众**：术语占 5-10%，首次出现时用上下文暗示含义

### 4.3 句式复杂度控制

- **紧张/快节奏**：平均句长 5-15 字，简单句为主
- **日常对话**：平均句长 10-20 字，混合句式
- **抒情/独白**：平均句长 15-25 字，可适当使用复合句
- **正式/专业**：平均句长 15-30 字，结构完整

### 4.4 第 4 层示例对照

**原文（第 3 层结果，现在适配"紧张压迫"风格）：**

> **站在门口**
>
> 林悦手指攥得发白。
>
> 愤怒，委屈，不甘——全搅在胸口，烧得她喉咙发紧。她想冲进去，把所有话砸在他脸上。
>
> 腿却像灌了铅。
>
> **走还是不走**
>
> 走？不走？
>
> 活了二十八年，头一回不知道该往哪迈。

**打磨后（适配"紧张压迫"风格）：**

> 手指攥得发白。
>
> 胸口在烧。
>
> 愤怒。委屈。不甘。全堵在喉咙里——她想冲进去，把所有话砸在他脸上。
>
> 腿动不了。
>
> 走。
>
> 不走。
>
> 心跳砸在耳膜上。二十八年，头一回不知道该往哪迈。

**改动说明：**
- 句式进一步缩短，加重紧迫感
- 删除小标题（紧张场景不需要分段标记）
- 用"胸口在烧""心跳砸在耳膜上"增强生理感受
- "走。不走。"各独立成句，制造停顿对峙感
- 删除"像灌了铅"等比喻，改为更直接的"腿动不了"

## 整体注意事项

1. **四层递进关系**：每层在前一层基础上优化，不是独立操作。第 4 层的结果包含了前 3 层的所有改动。
2. **保留核心内容**：原文的剧情、信息、人物关系全程保留，只打磨语言形式。
3. **适配载体**：所有打磨服务于 AI 竖漫剧本，优先考虑画面感和对话节奏。
4. **避免过度打磨**：去 AI 化的目标是"像真人"，不是"像文学大师"。日常对话保留适当的粗糙感。
5. **大声朗读验收**：打磨完成后，大声朗读一遍，听感是否自然是最直接的检验标准。
