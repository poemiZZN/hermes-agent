# 剧本语言梳理

## Overview

这是一个专门为 AI 漫剧剧本设计的四层递进式语言打磨流程。从"去机械化"到"语气适配"，层层递进，
确保最终产出的文字自然、真实、有感染力，且完全保留原文核心内容。

## 触发场景

当用户提出以下任一需求时触发此 skill：
- "帮我把这段剧本对话去 AI 化"
- "这段文字读起来像机器写的，帮我改得像真人"
- "口语化这段对话"
- "打磨这段文字，增强感染力"
- "梳理这段剧本结构，更易读"
- "把这段文字改成XX风格/语气"
- 任何涉及剧本语言润色、去机械化的请求

## 核心原则

1. **只打磨语言，不改剧情** — 原文核心内容、剧情走向、人物关系全程保留
2. **四层递进，层层叠加** — 每层在前一层基础上进一步优化，不是独立操作
3. **先出原稿再出打磨稿** — 每次输出都先展示原文，再展示打磨后的结果，方便对比
4. **适配漫剧载体** — 所有打磨服务于 AI 竖漫剧本的对话节奏和画面感

## 四层递进打磨流程

执行时按以下顺序逐层进行，每层完成后在下一层基础上继续优化：

### 第 1 层：去机械化 — 像真人写的

目标：消除 AI 写作痕迹，让文字读起来像真人自然说出或写出的。

核心操作：
- 打破工整对称的句式，适当制造不规整感
- 加入口语化语气词（呢、吧、啊、嘛、了、的等）
- 句子长短交错，避免连续使用相同句式结构
- 适当使用省略、倒装、重复等真人说话的自然特征
- 加入少量"不完美"表达（如语气停顿、改口、说半句）
- 杜绝模板化开场和过度工整的排比

验收标准：大声朗读时，听起来像真人日常说话，而非背诵或朗读稿件。

### 第 2 层：增强感染力 — 精准生动

目标：在第 1 层口语化基础上，提升文字的张力和吸引力。

核心操作：
- 将平淡/模糊词汇替换为精准、有画面感的表达
- 优化句式节奏，长短句交替形成韵律感
- 强化情绪动词，让动作描写更有冲击力
- 统一全篇文风，确保前后语气一致
- 修正细微语法、用词不当之处
- 对话中增加符合人物性格的口头禅或习惯用语

验收标准：读完能感受到文字的情绪张力，关键句有记忆点。

### 第 3 层：梳理结构 — 清晰易读

目标：在第 2 层基础上，优化阅读体验，让内容层次分明。

核心操作：
- 拆分超过 40 字的长句，每个句子只承载一个核心信息
- 大段落拆解为 2-3 句的短小板块
- 删除含糊不清、绕来绕去的表述，全部改为直白明确
- 按逻辑板块添加小标题（如需要），每个板块只讲一个核心点
- 用空行或分隔符区分不同情绪/节奏段落
- 确保信息流动自然，从已知到未知、从铺垫到高潮

验收标准：扫读一遍就能抓住核心信息，不需要反复阅读理解。

### 第 4 层：语气适配 — 精准调性

目标：在第 3 层基础上，根据具体场景和受众调整整体语气。

支持的语气风格：
- **正式庄重** — 适用于法庭、仪式、权威场合
- **日常随意** — 适用于朋友聊天、家庭场景、日常互动
- **专业严谨** — 适用于医疗、法律、金融等专业场景
- **亲切温和** — 适用于亲子、恋爱、治愈类场景
- **权威干练** — 适用于上级对下级、专家发言
- **励志鼓舞** — 适用于演讲、赛前动员、逆境反击
- **紧张压迫** — 适用于对峙、追击、倒计时场景
- **浪漫深情** — 适用于告白、离别、重逢场景

核心操作：
- 根据用户指定的场景/受众，调整用词正式程度
- 控制专业术语密度，适配受众理解能力
- 调整句式复杂度匹配场景节奏（紧张场景短句为主，抒情场景可适当长句）
- 确保情绪传递与场景氛围一致

验收标准：读者能明确感受到该场景应有的情绪氛围，不会出戏。

## ⛔ 角色换装备注（锁死，最高优先级）

> 剧本中凡是角色以**换装 / 伪装 / 易容 / 蒙面 / 黑影 / 神秘人 / 假身份**等非本尊形态出现时，**必须在该形态第一次出现的△行或对话行中，用括号备注其真实身份**。目的：**保持人物一致性**——让读者、观众、AI 绘图、配音一眼认出"这个黑影/神秘人就是某某角色"，绝不能把换装形态误当成新角色。

### 标注格式

```
伪装名/黑影（真实角色名）
```

- 括号内永远写**真实角色名**，括号外写当前呈现的伪装形态
- 换装形态的备注只需在**首次出现**时写一次，后续同一形态可只写伪装名

### 示例

| 场景 | 标注写法 |
|---|---|
| 主角戴兜帽蒙面出现 | `神秘人（薇薇安）` / `蒙面人（德雷克）` |
| 反派只露一道黑影剪影 | `黑影（卡西乌斯）` |
| 角色易容成别人 | `"老妇人"（伊莎多拉）` |
| 主角伪装成陌生人搭话 | `陌生男子（德雷克）` |

### 打磨时的自查

1. 打磨过程中遇到换装 / 伪装 / 易容 / 蒙面 / 黑影形态的角色出场，是否已括号备注真实身份？
2. 没备注 → 补上。否则读者会把这个形态当成全新角色，人物一致性断裂。

## 输出格式

每次打磨完成后，按以下格式输出：

```
【原文】
（展示用户提供的原始文字）

---

【第 1 层：去机械化】
（展示第 1 层打磨结果）

【第 2 层：增强感染力】
（展示第 2 层打磨结果）

【第 3 层：梳理结构】
（展示第 3 层打磨结果）

【第 4 层：语气适配 — XX风格】
（展示第 4 层打磨结果）

---

【打磨说明】
- 第 1 层：简述主要改动（如：打破 3 处排比、加入口语语气词、调整句式长短）
- 第 2 层：简述主要改动（如：替换 X 个平淡词汇、优化 X 处句式节奏）
- 第 3 层：简述主要改动（如：拆分 X 个长句、重组为 X 个板块）
- 第 4 层：简述主要改动（如：调整为 XX 风格、控制术语密度、统一句式复杂度）
```

## 快捷模式

如果用户只需要其中某几层或只要求最终结果，可以跳过中间展示，直接输出最终打磨稿。
此时仍需在内部按四层递进执行，但只展示用户需要的层级结果。

用户常见简化指令：
- "只要第 1 层" → 只做去机械化
- "直接给我最终版" → 四层全部执行，只展示最终结果
- "前两层就行" → 执行第 1、2 层，展示对应结果
