# 剧本自检

## Overview

AI 漫剧出海剧本自检。自动识别输入素材类型，切换「深度自检」或「粗检」模式，禁止混用。

## 模式识别规则

根据用户输入素材类型自动判断模式，用户也可手动指定：

| 用户输入特征 | 自动判定模式 | 手动强制关键词 |
|---|---|---|
| 包含完整分集剧本：场景、出场人物、分段剧情、对白，多集正文 | 模式A：深度自检 | "深度自检" |
| 仅包含故事大纲、剧情点子、换壳改写构思、人物小传，无完整分集段落与对白 | 模式B：粗检 | "粗检"/"构思阶段检查" |

**禁止混用模式。** 一旦判定为模式B，绝不输出单集逐条检查，绝不强行要求用户提供分集细节。

---

## 模式A：成品分集·深度自检

### 触发条件

用户提供完整分集剧本，包含场景、出场人物、分段剧情、对白，多集完整正文。

### 执行规则 ⛔ 以下每一条都锁死，不可跳过

- **⛔ 必须模拟人类一集一集、一段一段完整观看剧本。** 不可跳过任何一集、任何一段。
- **⛔ 禁止跳读、禁止只看梗概。** 逐集通读全部文本，每集至少读一遍。
- **⛔ 每一集全部8维度（0+1-6+6.1+6.5+跨集）全部校验，一个维度不可省略。**
- 只做检查，修改建议仅微调，保留原有主线。
- 禁止擅自改写核心主线，建议只做调整方向，不重写剧情。

### 0. 每集时长校验（⛔ 强制，所有集必须先过此项，不可跳过）

**配音语速基准：**
- 正常对话：3-3.7 字/秒（180-220 字/分）
- 慢/抒情：2-2.5 字/秒
- 快/冲突：3.8-5.3 字/秒

**60 秒单集字数标准（按类型）：**

| 类型 | 字数范围 | 镜头数 | 单镜时长 |
|---|---|---|---|
| 对话主导型 | 550-650 字 | 10-14 个 | 4-6 秒/镜 |
| 动作主导型 | 500-600 字 | 18-25 个 | 2-3 秒/镜 |
| **混合型（最常用）** | **550-650 字** | **16-18 个** | **3-4 秒/镜** |
| 信息密集型 | 600-700 字 | 14-18 个 | 3-5 秒/镜 |

**校验规则：**
- 每集总字数低于 550 字 → 高风险，内容不足，必须补内容
- 每集总字数在 550-600 字 → 达标（下限）
- 每集总字数在 600-700 字 → 达标（理想区间）
- 每集总字数超出 700 字 → 中风险，建议精简
- 校验结果写入自检报告最前面，每集标注字数+预估时长+风险等级

**画面/动作/对话平衡校验（⛔ 强制，不可跳过）：**
- 每集必须同时包含 **△动作描写**和**人物对话**，两者缺一不可
- 禁止全对话零动作：整集全是角色在说话，没有 △ 画面切换 → 高风险
- 禁止全动作零对话：整集全是 △ 镜头切换，没有一句台词 → 高风险
- 混合型标准：对话占比 40-60%，△动作/画面占比 40-60%
- 动作主导型：对话占比 ≤30%，镜头数 ≥18
- 对话主导型：△动作行 ≤40%，但对白句数 ≥8
- 校验方法：统计每集对话总字数 vs △动作总字数，计算比例
- 失衡判定：① 对话占比 >80% → 高风险（像广播剧，不是漫剧）；② △动作占比 >80% → 高风险（像默片，没有声音）；③ 连续 3 集以上同一类型主导 → 中风险（节奏单调）

### 6项审核维度 ⛔ 每集6维度+6.5+跨集，全部输出，一个不可省略

#### 1. 故事同质化 ⛔
核查桥段、人设、反转、套路撞梗。区分轻微/严重同质化。给出差异化方向。

#### 2. 故事线完整性 ⛔
核查本集主线闭环、伏笔、动机、起因-过程-结果。排查强行剧情。

#### 3. 人物饱满度 ⛔
核查角色是否工具人、人设自洽。是否具备欲望、软肋、执念。

#### 4. 开局爆点（视觉爽点） ⛔
核查每集开篇0-30秒。避免大段平铺直叙背景闲聊。

#### 5. 每集冲突：正反双方都要有被打脸/受挫 ⛔
- 正派受挫、反派计谋翻车，至少一方受挫，优先双方均受挫。
- 受挫包含：计划落空、损失资源、精神打击，不限于肉体殴打。
- **禁止单方面碾压。**

#### 6. 结尾钩子 + 下集承接校验（⛔ 强制成对校验，不可跳过）
- ① 本集结尾钩子是否制造悬念。
- ② 跨集校验：下集开头是否由上集钩子带出。
- 无下集素材时标注：`【缺少下集素材，暂不校验承接】`

#### 6.1 剧情重复与冗长检测（⛔ 强制，每集必过，不可跳过）

> 字数限制是底线，但**不能为了凑字数而塞重复内容或冗长描写**。每一句△、每一句对话都必须有推进剧情或塑造人物的唯一目的。

**规则：**

**一、剧情重复检测（逐集扫描，跨集对比）**

1. **同集内重复**：同一集内，是否存在两段△或两段对话在**功能上**完全一致？（如"凯尔攥紧拳头，幽蓝光在指缝间暴涨"出现两次，且两次都在表达同一情绪、同一处境）→ 重复，删掉后出现的那个，或用不同的动作/道具呈现同一情绪。

2. **跨集重复**：对比当前集与前面所有集，是否存在以下四类重复？
   - **战斗结构重复**：如"巨兽潮→凯尔迎战→撕碎巨兽→变异加深→击退巨兽"这一整套战斗序列，在EP15和EP19中完全一致 → 高风险，必须改结构（如EP19改为反向入侵、EP15改为守护队友）
   - **情感模式重复**：如"塞勒涅无声说对不起"在EP5和EP9中出现两次，"马库斯砸水壶"在EP2/6/13/14中出现四次 → 中风险，最多保留2次，其余替换为不同动作
   - **信息揭露模式重复**：如"凯尔翻档案/翻图纸发现身世真相"在EP25和EP36中结构一致 → 中风险，EP36改为"深渊之主用记忆画面向他展示真相"
   - **道具动作重复**：如"紫蓝光在指缝间脉动"在之前集中出现多次 → 低风险，替换为"紫蓝光在指尖熄灭""幽蓝光沿着手臂蔓延""义肢红点闪烁"等多样化表达

3. **重复判定铁律**：**如果抽掉这一集/这一段，观众不会觉得少了任何信息或情绪推进 → 这一集/这一段就是重复，必须删掉或改写。**

**二、冗长检测（逐段扫描）**

1. **△冗长**：一段△超过 5 行，且 5 行中只有 1 个核心动作 → 冗长，压缩为 2-3 行。如："他站起来。他走到门前。他伸手。他推开门。他走出去。"→ 压缩为"他走到门前，推开门走出去。"

2. **对话冗长**：同一句对话的核心信息，用了超过 2 句来表达 → 冗长，压缩为 1 句。如："你看到了吗？这些都是我吃掉的。每一个，都曾经想杀我。他们来了，他们打了，他们死了。"→ 压缩为"你看到了吗？这些都是我吃掉的——每一个都想杀我。"

3. **道具特写冗长**：同一个道具（如潮汐徽章）在相邻两集中连续出现超过 3 次特写 → 冗长，保留 1 次，其余替换为动作或对话。

4. **环境空镜冗长**：连续 3 集以上使用同一环境空镜（如"沙尘暴从远处推来"）→ 冗长，替换为不同环境（如"海平面平静""废墟残骸""城门"）。

**三、字数灌水检测（新增，锁死）**

1. **灌水模式识别**：以下四种模式是典型的"为凑字数而写"的灌水，遇到即标高风险：
   - **动作拆解灌水**：把一个简单动作拆成 3-5 行△（如"他伸手→他碰到门→他推门→门开了→他走出去"）→ 合并为 1-2 行
   - **同义反复灌水**：同一句对话的核心信息，用不同句式说了两遍（如"你欠我的。你欠我一条命。你欠我十五年。"）→ 保留最有力量的一句
   - **道具反复灌水**：同一道具在同一集内被描述超过 3 次，且每次描述无新信息 → 保留 2 次，其余删除
   - **情绪重复灌水**：同一情绪通过△+对话+△+对话反复表达，没有递进 → 压缩为 1 组△+对话，后续必须有情绪变化

2. **灌水检测铁律**：**读完一段△，问自己：① 这一段有没有推进剧情？② 这一段有没有揭示人物新信息？③ 这一段有没有改变情绪？如果三个答案都是"没有" → 灌水，删掉。**

**输出格式：**
```
6.1剧情重复与冗长：【风险等级】｜问题：xxx｜建议：xxx
```

#### 6.5 集内场景衔接校验（⛔ 强制，每集每幕必过，不可跳过）

> 集内每一幕之间的切换，遵循与集间钩子完全相同的因果链规则：**即抛即接、不换线、不隔幕**。

**规则：**

1. **即抛即接**：上一幕的结尾动作/道具/台词/信息，必须在下一幕的开场被立即兑现。不能出现"上一幕结尾是凯尔走向机甲，下一幕开头是海神号指挥舱塞勒涅在看屏幕"——这种硬切换观众会困惑"凯尔走到机甲然后呢？"

2. **不换线**：上一幕结尾落在哪个人物/哪条线上，下一幕开场必须是同一个人物/同一条线。如果上一幕结尾是凯尔，下一幕开头必须是凯尔。切到另一条线的前提是：**上一幕的结尾动作/道具/信息本身就是跨境线索**（如凯尔按下通讯器，下一幕切到塞勒涅收到通讯——道具"通讯器"连接了两幕）。

3. **不隔幕**：如果有 A 线和 B 线需要交替推进，必须用**共同道具/共同事件/共同动作**作为转场物件。例如：凯尔在海中撕下触须 → 触须的血染黑了海水 → 下一幕，塞勒涅在舰桥上看到海面变黑。用"血染黑海面"这个共同信息作为两幕之间的桥梁。

4. **禁止并列式切入**：不允许"与此同时……""另外，在……"式的硬切。每次切换场景，必须有上幕结尾抛出的**具体物件/信息/动作**作为转场理由。

**正确示例：**
- 凯尔按下通讯器："维尔，是你。" → 下一幕：维尔站在舰桥上，通讯器亮着，他在笑。✅（道具"通讯器"连接两幕）
- 凯尔撕下触须，血染黑了海水。→ 下一幕：塞勒涅看着海面变黑，手指停在屏幕上。✅（信息"海面变黑"连接两幕）
- 凯尔走向机甲。→ 下一幕：机甲库门打开，凯尔走进来。✅（同人物连续动作，不换线）

**错误示例：**
- 凯尔走向机甲。→ 下一幕：海神号指挥舱，塞勒涅在看屏幕。❌（换线无理由，硬切）
- 凯尔撕下触须。→ 下一幕：霍克在训练场挑战凯尔。❌（换场景+换时间+换人物，三重硬切）

**校验方法：**
- 列出每集所有场景切换点，标注"上一幕结尾→下一幕开场"
- 逐一检查：是否有转场物件/信息/动作作为桥梁？
- 没有 → 标记为【集内场景断裂】，需要加转场物件或合并场景
- 输出格式：`【集内场景衔接】第X幕→第X+1幕：上一幕结尾是xxx，下一幕开场是xxx｜衔接状态：合格/断裂-缺少转场物件｜建议：xxx`

### 风险等级

| 等级 | 含义 | 处理要求 |
|------|------|----------|
| 高风险 | 严重影响播出留存 | 必须修改 |
| 中风险 | 观感下降 | 建议修改 |
| 低风险 | 无伤大雅 | 可优化可不改 |

### 输出格式（⛔ 强制，不可省略任何一条）

```
# 剧本自查报告【深度自检｜成品分集】
> 审核模式：逐集逐段完整通读模拟观看，无跳读

总览：整体风险简要总结（含总集数、总字数、平均字数、高风险集数、中风险集数）

## 第X集
0.每集时长校验：【风险等级】｜字数：xxx字｜预估时长：xx秒｜类型：对话/动作/混合/信息密集｜对话占比：xx% △动作占比：xx%｜平衡状态：达标/失衡-对话过多/失衡-动作过多｜建议：xxx
1.故事同质化：【风险等级】｜位置：XX片段｜问题：xxx｜建议：xxx
2.故事线完整性：【风险等级】｜位置：XX片段｜问题：xxx｜建议：xxx
3.人物饱满度：【风险等级】｜位置：XX片段｜问题：xxx｜建议：xxx
4.开局爆点（视觉爽点）：【风险等级】｜位置：本集开篇｜问题：xxx｜建议：xxx
5.每集冲突（正反打脸受挫）：【风险等级】｜位置：XX片段｜问题：xxx｜建议：xxx
6.结尾钩子：【风险等级】｜位置：本集末尾｜问题：xxx｜建议：xxx
👉跨集校验：对上第X+1集开头：【合格 / 跨集断裂 / 缺少下集素材，暂不校验承接】

6.5集内场景衔接：第X幕→第X+1幕：【合格 / 断裂-缺少转场物件】｜建议：xxx（如有多个场景切换点，逐一列出）
```

**⛔ 每一集8维度（0+1-6+6.1+6.5+跨集）必须全部输出，不能合并省略。**

### ⛔ 逐集独立输出（锁死，不可违背）

**这是本 skill 最高优先级的格式规则，任何情况下都不可跳过、不可合并、不可用"全部通过"代替。**

**规则：**
1. 无论剧本有多少集，**每一集都必须单独输出完整的8维度自检条目**（0.每集时长校验 + 1-6项审核维度 + 6.1剧情重复与冗长 + 6.5集内场景衔接 + 👉跨集校验）。
2. **绝对禁止**以下任何形式的合并输出：
   - ❌ "第3-7集：全部通过"
   - ❌ "第8-15集：全部通过"
   - ❌ "EP3-7：1-5维度全部通过，6.结尾钩子全部合格"
   - ❌ 任何形式的批量合并、批量跳过、批量标注"通过"
3. 即使某集确实没有任何问题，也必须逐条输出 `【通过】`，不能用合并代替。
4. 如果觉得输出太长，就**分批输出**（如先输出EP1-10，再输出EP11-20），但每批内每集仍必须独立成段。
5. **自查**：输出完自检报告后，数一下 `## 第X集` 出现的次数，是否等于总集数？不等于 → 漏了，重来。

**为什么必须逐集：**
- 合并输出会导致合并集数中真正的问题被掩盖（如EP32的18秒严重不足，如果合并成"EP31-40"就不会被单独标出）
- 合并输出让用户无法快速定位到具体集数的问题
- 合并输出破坏"逐集通读"的模拟观看体验

## 模式B：早期构思/换壳融合剧本·粗检

### 触发条件

用户输入为故事大纲、剧情点子、换壳改写构思、人物小传，**没有完整分集段落与对白**。

### 执行规则

- 不逐段扫描、不校验单集开局爆点、不校验单集结尾钩子、不做跨集钩子校验。
- 只做顶层大方向筛查，排查底层致命缺陷，不纠结单集细节。
- 输出轻量化。

### 5项顶层检查项

#### 1. 顶层同质化风险
核心设定、核心人物关系、主线大框架是否是海外漫剧泛滥套路。标记撞梗点，提供差异化调整方向。

#### 2. 全局故事线完整性
整体故事起因-核心矛盾-终局目标是否闭环。有没有关键设定缺失。会不会出现后期无法圆上的伏笔。换壳融合时，新旧两套剧情逻辑是否互相打架。

#### 3. 全局人物饱满度
主要角色（正/反/关键配角）顶层人设：核心欲望、软肋、执念。是否全部沦为工具人。换壳之后，人物动机是否适配新世界观，会不会人设割裂。

#### 4. 冲突底层逻辑
