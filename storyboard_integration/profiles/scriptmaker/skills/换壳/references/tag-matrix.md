# 标签换壳变换矩阵 — US AI Short Drama Tag Transformation Matrix

## 核心规则

- **每次换壳至少改 3 个标签**
- **硬换壳（Hard Swap）优先**：改 1 个标签 = 触发连锁变化 ≥ 5 个故事元素
- **故事线改编率 ≥ 60%**，前 3 集必须完全不同

---

## 七大标签维度

### 1. Genre 类型标签

| 原标签 | 硬换壳目标 | 触发连锁变化 |
|--------|-----------|-------------|
| Mafia/Crime 黑道 | Royal Court 皇室宫廷 / Corporate 商战 | 权力结构从暴力→权谋/资本；武器从枪→毒/合同 |
| Romance 爱情 | Thriller 悬疑 / Action 动作 | 核心驱动力从感情→谜题/生存；对白从情话→信息博弈 |
| Revenge 复仇 | Redemption 救赎 / Rise 崛起 | 主角动机从毁灭→重建；结局从清算→和解/成功 |
| Action 动作 | Horror 恐怖 / Psychological 心理 | 冲突从外部打斗→内部恐惧；场景从开阔→封闭 |
| Comedy 喜剧 | Dark Drama 暗黑 | 叙事基调彻底反转；角色命运从幸运→残酷 |
| Sci-Fi 科幻 | Fantasy 奇幻 / Historical 历史 | 技术逻辑→魔法/权力逻辑；道具从科技→神秘物品 |

## 换壳强度分级

### Level 1：轻度换壳（不推荐，改编率可能不足60%）
- 改 3 个标签，但没有触发时代/主角硬换壳
- 例：仅改 关系 + 冲突 + 基调 → 故事框架相似度过高

### Level 2：标准换壳（推荐基线）
- 至少 1 个 Era/Setting 硬换壳 + 至少 1 个 Protagonist 硬换壳
- 例：Modern→Medieval + CEO→Assassin + Revenge→Power Grab
- **改编率确保 60%+，前3集确保全新**

### Level 3：深度换壳（最优，改编率80%+）
- Era/Setting 硬换壳 + Protagonist 硬换壳 + Core Conflict 硬换壳
- 剧名、场景、台词、人物关系全面翻新
- 仅保留最底层故事骨架（如"一个人失去一切后重新崛起"）

## 换壳决策树

```
输入：原剧 7 标签
↓
Step 1: 选 1 个 Era/Setting 硬换壳（必须）
Step 2: 选 1 个 Protagonist 硬换壳（必须）
Step 3: 选 1-2 个其他维度换壳（冲突/关系/基调/特殊元素）
Step 4: 检查变更标签数 ≥ 3
Step 5: 生成新标签组合 → 进入故事适配引擎
```
