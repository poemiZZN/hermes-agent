# 质量核验清单 — Quality Control Checklist

## 目的：每次出本后自动跑一遍，减少人工审核时间

---

## A 级检查（必须全部通过，否则打回重写）

### A1. 标签变更检查
- [ ] 变更标签数 ≥ 3 个（7 标签中至少改 3 个）
- [ ] 至少包含 1 个 Era/Setting 标签变更（硬换壳）
- [ ] 新标签组合与原文标签组合**无逻辑矛盾**（如 Medieval + Cyberpunk = 矛盾）

### A2. 前 3 集独立性检查
- [ ] 第 1 集场景/人物/冲突与原文第 1 集完全不同
- [ ] 第 2 集延续新故事线，未出现原文第 2 集的相同桥段
- [ ] 第 3 集冲突升级路径与原文不同
- [ ] 前 3 集台词不能有超过 3 句与原文相同或高度相似

### A2+. 床戏标记检查（强制）
- [ ] 全剧 40 集，第 5、10、15、20、25、30、35、40 集的床戏场次整段红色加粗标注
- [ ] 共 8 处，不多不少

### A3. 改编率检查
- [ ] 主角身份/职业已置换
- [ ] 核心冲突触发方式已改变
- [ ] 至少 3 个关键道具已替换
- [ ] 主要场景地点已重设
- [ ] 结局走向与原文不同（happy→dark / open→closed / revenge→redemption 等）

### A4. 美剧风格合规
- [ ] 暴力描写直给（枪战/打斗有正面的血/伤口特写；枪战不标注特殊颜色）
- [ ] 亲密戏不遮挡不暗示（接吻/暧昧场景）
- [ ] **床戏占位已用红色加粗标注，含占位标记**（强制）
- [ ] 对白为短句/碎片化/直接，无"隐喻式威胁"
- [ ] 至少 1 处角色做出"不道德但合理"的选择
- [ ] 无道德说教/正能量总结

---

## B 级检查（影响观感，必须修复）

### B1. 冲突密度
- [ ] 每集 ≥ 3 个冲突事件（开场冲突 + 中间升级 + 结尾钩子）
- [ ] 没有连续 2 集以上无肢体冲突（枪战/打斗/追逐）
- [ ] 第 11 集有爽点（观众需要定期多巴胺）
- [ ] 第 20 集有全剧最大高潮

### B2. 钩子密度
- [ ] 每集结尾必须有钩子（悬念/反转/新威胁/选择困境）
- [ ] 前 5 集钩子至少有 1 个是"美剧型"（枪口悬念/尸体发现/背叛反转）
- [ ] 没有连续 2 集使用相同类型钩子

### B3. 角色行为一致性
- [ ] 主角行为不违背其设定身份/能力（CEO 不会亲自格斗除非设定他有军事背景）
- [ ] 反派不会突然"良心发现"洗白
- [ ] 女性角色不会"等男人来救"

---

## C 级检查（加分项，非强制）

### C1. 节奏优化
- [ ] 全剧冲突/温情比约 8:2（80% 冲突驱动）
- [ ] 纯温情/治愈连续不超过 3 集
- [ ] 每 5-7 集有一个爽点
- [ ] 后半段（23-40集）至少 2 个独立情绪高峰

### C2. 视觉化
- [ ] 关键证据/武器/道具/伤口有特写镜头描述
- [ ] 每集至少 1 个"AI 绘图友好"的视觉重点（单人近景/双人对峙/道具特写）

### C3. 格式合规
- [ ] 使用固定分镜模板：【集数 - 场次｜场景】
- [ ] 无品牌名称出现
- [ ] 对白使用英文（海外市场）
- [ ] △ 只写物理动作，不写环境氛围
- [ ] 床戏场景红色加粗标注；枪战不标注特殊颜色
- [ ] 40 集 × 1 分钟，每集约 250 字

---

## 快速审核流程（5 分钟版）

```
Step 1: 对比原剧和新剧的 7 标签 → 检查变更数 ≥ 3？  （1 分钟）
Step 2: 阅读新剧第 1 集 → 和原剧第 1 集完全不同？     （1 分钟）
Step 3: 随机抽查第 11/20/30 集 → 爽点和高潮在不在？    （2 分钟）
Step 4: 抽查一集暴力/亲密戏 → 是否直给不遮挡？        （1 分钟）

全部通过 → 合格。
任何一步不通过 → 指出问题，定向修改。
```
