# 故事适配引擎 — Story Adaptation Engine

## 核心原则

当标签改变时，故事不是"换皮"而是"重构"。
改编率 ≥ 60% 意味着：人物名字、场景地点、冲突触发方式、关键道具、甚至结局走向都可以不同。

## 一、时代背景替换全表

| 警察 | 骑士团/卫兵 | 执法方式从调查取证→武力镇压 |
| 监控摄像头 | 暗哨/眼线/密探 | 信息获取从技术→人际网络 |
| 银行账户/钱 | 金币/地契/粮食 | 财富形态变化 |
| 社交媒体 | 谣言/公告/市集流言 | 舆论战方式变化 |
| 法律/合同 | 血誓/婚约/领土协议 | 约束力来源从法律→荣誉/武力 |

|---------|------------|---------|

## 六、改编率自检公式

```
改编率 = (改变的人物数/总人物数 × 0.2
       + 改变的场景数/总场景数 × 0.2
       + 改变的冲突触发方式/总冲突数 × 0.2
       + 改变的对白风格 × 0.15
       + 改变的结局走向 × 0.15
       + 改变的核心道具 × 0.1) × 100%

目标：≥ 60%
```

### 快速判断法（无需计算）：
- ☑ 前3集场景/冲突/人物关系与原文完全不同？→ 基础合格
- ☑ 至少2个主要角色的身份/职业/立场被置换？→ 改编率45%+
- ☑ 至少1个核心冲突的触发方式和解决路径完全不同？→ 改编率60%+
- ☑ 结局走向改变（悲剧→喜剧，团圆→开放等）？→ 改编率70%+
