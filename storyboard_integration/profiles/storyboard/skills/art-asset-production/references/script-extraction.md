# 剧本资产提取

## 提取原则

通读用户指定的完整剧本范围，按角色、场景和道具建立去重清单。不能只抽取主角或高频场景。

- 同一角色的不同称谓应合并，并保留别名。
- 群演、路人和无名角色若需要独立形象，应列入清单并标记优先级。
- 同一空间在不同时间、布置或剧情状态下差异明显时，拆成场景版本。
- 同一道具在完好、破损、沾血、打开等剧情状态下，拆成状态版本。
- 原文没有年龄、颜色或材质时，标记“待设计”，不要伪装成剧本事实。

## 人物资产表

推荐字段：

| 字段 | 内容 |
|---|---|
| 人物名 | 标准名字与别名 |
| 年龄/性别 | 剧本明示；没有则标记待定 |
| 剧情身份 | 职业、关系、阵营和气质 |
| 面部与发型 | 可识别的骨相、五官、肤色、发型 |
| 体型 | 身高感、肩腰比例、体态 |
| 服装版本 | 按剧情阶段拆分，通常不超过 3 套主服装 |
| 关键道具 | 与该人物绑定的手持或身份道具 |
| 首次/重要出场 | 集数或场次 |
| 设计状态 | 剧本明确、导演确认、待设计、待审核 |

一套服装至少写清：廓形、层次、主色、面料、领口/袖口、鞋、饰品、磨损程度和适用剧情。

## 场景资产表

推荐字段：

| 字段 | 内容 |
|---|---|
| 场景名 | 唯一、可搜索的名称 |
| 内外景/时间 | 室内或室外，日/夜及具体时段 |
| 地域与年代 | 国家、城市、文化和时代 |
| 空间功能 | 场景用于什么剧情行为 |
| 空间结构 | 出入口、走廊、楼梯、桌面、窗户等关键位置 |
| 固定陈设 | 应直接生成在场景中的普通道具 |
| 关键道具 | 需要单独出图或特写的道具 |
| 光源 | 主光方向、色温、自然光/实景灯 |
| 场景版本 | 正常、凌乱、破坏后、昼夜等 |
| 首次/重要出场 | 集数或场次 |

## 道具资产表

仅当道具满足以下至少一项时默认单独出图：

- 被角色手持、交接或使用
- 有近景、特写或信息读取镜头
- 包含剧情关键文字、Logo、数据或符号
- 具有角色身份识别功能
- 存在重要状态变化

推荐字段：道具名、持有人、剧情用途、尺寸、形状、材质、颜色、文字内容、状态版本、所在场景、首次出场。

## 交付给编剧和导演

正式制作前，把资产表中不确定项集中成一轮确认，不要散落成大量重复问题。优先确认：

1. 角色脸部方向与服装版本
2. 场景时代、地域和空间功能
3. 剧情关键道具及其文字信息
4. 项目统一风格、画幅和审核优先级

确认后的内容标记来源，例如“剧本事实”“导演确认”“美术设计”，方便后续追责和修改。

## 海外项目补充

- 保证地域、语言、交通规则和生活方式符合目标市场。
- 欧美场景中的可读信息默认使用英文，除非剧情另有规定。
- 驾驶座位置、道路方向、插座、货币、制服等必须符合故事发生地。
- 不用单一刻板印象代替角色设计；题材气质只能作为设计方向，仍需结合人物经历和剧情功能。
