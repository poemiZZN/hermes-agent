# 场景与道具资产

## 通用场景结构

场景提示词按以下模块组合：

```text
场景事实：[地点、年代、地域、时间、天气、剧情状态]。
空间结构：[机位看到的区域、出入口、前中后景、关键位置关系]。
陈设与材质：[固定家具、地面、墙面、玻璃、金属、织物等]。
构图：大全景或超广角，结构清楚，主体区域明确，保留可供角色表演的空间。
光源：[主光方向与高度]，光源数量克制，符合窗户、灯具和时间。
画面控制：大色块优先，细节疏密有节奏，材质统一，不堆砌假细节。
限制：无人物；车辆、文字、Logo 和临时杂物按剧情需要决定是否出现。
画幅：16:9。
```

默认以 45 至 70 度方向的主光、室内顶光或侧光中的一种为主，不要同时堆叠多个无来源光源。

地面和墙面应保持结构与材质变化，但避免重复碎纹理。先确定空间大关系，再补充小物件。

## 动画场景模板

```text
[场景名字与剧情描述]。
通透的日系院线动画场景，细腻二维绘制结合克制的三渲二质感，电影级广角构图。
冷色环境基调中有来自真实光源的暖光，天空、玻璃、金属、石材和植物具有统一的材质语言。
空气透视自然，前中后景清楚，透视准确，边缘不过度锐化，画面干净，无人物、无文字、无 Logo，16:9。
```

用户明确指定某种画风时保留其选择；没有指定时，不擅自套用动画风格。

## 矢量卡通场景

```text
2D 矢量卡通插画，统一粗细的深色轮廓，纯色平涂，简洁几何结构，高饱和但受控的撞色。
使用大面积色块和清楚的前后层级，不使用复杂渐变、写实纹理或不一致阴影。
```

## 反打镜头

先定位原图中的反打机位，再推导空间，而不是镜像原图：

```text
摄像机移动到[原图中的墙面/壁画/门口位置]并朝相反方向拍摄。
保留原场景的空间尺度、建筑语言、材质、时间、色温和固定陈设。
反打内容必须符合原图出入口、墙体和家具的位置关系，不增加人物和无关物品，16:9。
```

若原图没有足够空间信息，说明需要补充平面图、另一角度或文字布局。

## 场景编辑

使用局部修改合同：

```text
修改区域：[明确对象和变化]。
保持不变：机位、构图、空间结构、家具位置、主色调、光源和所有未点名内容。
质量修复：去除噪点、黑斑、杂色和水印；墙地面保持干净；边缘柔和但结构清楚。
物理要求：文字形态、光影方向、透视、材质和颜色关系正确。
```

涉及屏幕、文件和招牌时，明确文字语言和准确内容。不要只写“文字正确”。

## 场景中的道具

普通陈设直接写入场景。以下道具单独生成：

- 手持或交接道具
- 特写道具
- 承载信息的文件、屏幕、标牌、饰品
- 角色专属识别道具
- 有前后状态变化的剧情道具

## 单体道具模板

```text
[道具名称与用途]，[时代、地域与使用者]。
[形状、比例、结构、材质、颜色、磨损和文字信息]。
单件道具居中，完整可见，中性证件照式全光源，白色背景，无手、无人物、无支架、无无关物品。
竖向道具使用 9:16，横向或宽幅道具使用 16:9。
```

批量生成时，每件道具保持独立画面和独立提示词，不拼成一张杂乱合集，除非用户明确要求资产板。

## 人物融入场景

分别锁定：

- 场景参考：机位、透视、家具位置、光源和背景。
- 人物参考：身份、服装、身体结构和识别细节。
- 动作参考：姿势和接触关系，不继承人物身份。

提示词应说明人物坐、站或接触何物，手脚放在哪里，哪些场景物品不能移动。最终检查人物比例、落地关系、接触阴影、色温和画风是否与场景统一。
