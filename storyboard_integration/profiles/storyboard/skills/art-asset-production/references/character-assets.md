# 人物资产

## 角色一致性锚点

在生成任何人物提示词前，先整理一段不可随意改变的身份锚点：

```text
身份锚点：年龄段、性别呈现、族裔/地域特征、脸型与骨相、眉眼、鼻唇、肤色、发型发色、体型、显著标记。
服装锚点：廓形、主色、面料、领型、袖型、腰线、鞋、首饰和磨损状态。
```

全身图、特写、三视图和剧情图重复使用同一锚点，只改变构图、动作和景别。

## 真人全身图

组合顺序：

```text
[角色身份锚点]。[服装锚点]。
真人写实摄影，真实皮肤与服装材质，正面全身站姿，人物直立，双手自然下垂，双脚完整入画。
身体比例自然修长，肩颈、腰腿关系清晰；服装装饰集中在主要视觉区域，疏密有节奏。
中性浅灰或白色纯净背景，柔和均匀的正面棚拍漫射光，低对比、无强烈投影。
面部和服装准确对焦，商业人物设定照，9:16。
```

“九头身、大长腿、宽肩、瘦腰”等夸张比例只在项目明确需要时使用，不能覆盖角色的年龄、职业和体型事实。

## 真人面部特写

从已有全身图生成特写时，先写：

```text
严格保持参考人物的脸部身份、年龄、发型、肤色和服装领口不变，只把景别改为正面头肩特写。
```

写实皮肤模块：

```text
半哑光真实皮肤，毛孔克制可见，鼻梁和额头仅有自然微光泽，保留轻微自然肤色差异。
眉毛和头发有原生毛流与重量感，眼睛有湿润自然反光，五官骨骼清晰但不过度锐化。
50mm 人像镜头感，柔和正面漫射棚灯，面部准确对焦，背景干净。
```

按剧情添加汗、泪、尘土、伤痕或疲惫，不要把这些状态写成所有角色的默认皮肤。

常用限制：

```text
避免过度磨皮、塑料假皮、油光满面、网红滤镜、畸形五官、数字噪点、过度锐化和不合理妆容。
```

## 三视图

```text
生成同一人物的正面、严格侧面和背面全身三视图，三栏等宽排版，人物头顶线和脚底线对齐。
三视图保持同一脸部身份、身体比例、发型、服装结构、颜色、材质、鞋和配件。
中立站姿，双手自然下垂，不遮挡服装结构；白色背景，无文字、无多余道具、无透视变形，16:9。
```

若用户同时提供特写与全身图：

- 特写图负责脸部身份、肤色和发型细节。
- 全身图负责身体比例、服装、鞋与配件。
- 排版参考只负责栏位与姿势，不继承其中人物。

## 卡通与动画人物

先锁定线条、上色和光影规则，再写角色细节：

```text
保持参考图的线条粗细、轮廓语言、色块边界、明暗层级和高光方式。
白色背景，画面整洁，人物全身完整，结构和站姿清楚，不添加文字、Logo 或无关配件。
```

不要同时要求“纯色平涂无阴影”和“厚涂渐变高光”。两者冲突时，以用户的主要参考图为准。

## 换装、换色与元素融合

使用“改变项/不变项”格式：

```text
改变项：把服装替换为[服装描述]。
不变项：脸部身份、年龄、发型、肤色、身体比例、姿势、机位、背景和光源保持不变。
```

换色时列出具体部位，不要写“整体改成蓝色”：

```text
身体主色改为中蓝色；头顶结构改为浅蓝色；翅膀改为浅蓝色。
眼睛、喙、领带、轮廓线、姿势和所有结构保持不变。
```

多参考图融合示例：

```text
参考图1只负责画风、线条和高光处理。
参考图2负责角色结构、三视图角度、肢体位置和颜色分区。
保留项：背鳍、脚部分叉、身体中线和全部识别结构。
禁止项：缺失肢体、结构错位、比例漂移、偏色、额外配件、额外角色、文字和 Logo。
```

## 群像

明确人数、站位顺序、每人的身份锚点和遮挡关系。需要资产设定图时：

```text
人物从左到右依次排开，脚底线对齐，完整全身，不互相遮挡，统一棚拍光和背景。
```

不要让模型自行决定“几个人”或用相似脸替代不同角色。
