# 美术资产创作

把剧本和创作需求转成可审核、可复用、可交付的美术资产清单与生图提示词。优先保证叙事准确、角色和空间一致，再追求画面丰富度。

## 工作模式

先判断用户需要哪种结果：

1. **资产提取**：从剧本或分镜中提取人物、场景、关键道具。
2. **资产规划**：整理给编剧、导演或美术确认的资产需求表。
3. **提示词编写**：为一个或一批资产生成提示词。
4. **参考图编辑**：换装、换色、融合角色与场景、生成特写或三视图。
5. **资产质检**：检查一致性、透视、材质、杂物、水印、命名和交付结构。

用户只要求其中一项时，不要强行执行完整流程。

## 最少确认项

优先从会话、剧本、页面上下文和参考图中读取已知信息，只询问真正缺失且会改变结果的内容。不要一次抛出冗长问卷。

- **资产对象**：人物、场景、道具，或三者全部。
- **目标风格**：真人写实、3D 国漫、2D 动漫、卡通矢量、游戏 CG，或用户指定风格。
- **用途**：全身图、特写、三视图、大全景、反打、单体道具、编辑图等。
- **画幅**：人物与竖向道具通常用 `9:16`；场景与三视图通常用 `16:9`。用户或项目已有设置时，以已有设置为准。
- **参考图角色**：每张参考图负责身份、服装、结构、姿势、场景、色彩、光影或画风中的哪一项。

如果用户已经给出完整需求，直接产出，不再重复确认。

## 核心流程

### 1. 建立资产事实

从剧本和用户要求中区分三类信息：

- **明示事实**：角色年龄、服装、时代、地点、剧情道具等，必须保留。
- **合理设计**：原文未规定但制作必须补齐的视觉信息，可以提出设计方案。
- **禁止臆造**：会改变剧情、身份、品牌或空间逻辑的内容，不得擅自添加。

执行剧本提取时读取 [剧本资产提取](references/script-extraction.md)。

### 2. 生成资产清单

先整理清单，再写批量提示词。至少记录：

- 人物：名字、年龄/性别、剧情身份、面部、体型、发型、服装版本、随身关键道具。
- 场景：名称、内外景、时间、空间结构、固定陈设、光源、重要剧情位置。
- 道具：名称、剧情用途、持有人、材质、形状、文字信息、是否需要单独出图。

普通杯子、桌椅等环境陈设应直接进入场景；只有手持、传递、特写、承载关键信息或影响剧情的道具才默认单独出资产。

### 3. 编写提示词

按以下顺序组织自然语言提示词：

1. 资产类型和主体
2. 项目风格与时代地域
3. 构图、视角、景别、姿势
4. 身份特征、空间结构或道具结构
5. 材质、色彩、服装和表面细节
6. 光源、环境与背景
7. 一致性要求和参考图职责
8. 画幅与质量要求
9. 必要的负面限制

不要堆砌互相冲突的风格词。`8K`、`4K` 等可以表达细节目标，但实际输出分辨率应使用生图工具的 `resolution` 参数控制。

按资产类型读取：

- 人物、特写、三视图、换装与群像：[人物资产](references/character-assets.md)
- 场景、反打、场景修改、道具与融合：[场景与道具资产](references/scene-and-prop-assets.md)

### 4. 管理参考图

为每张参考图声明单一主职责，并明确不应迁移的内容。例如：

```text
参考图1：只参考脸部身份和发型，不继承服装与背景。
参考图2：只参考服装结构、材质和配色，不改变人物脸部。
参考图3：只参考场景透视、机位和光源，不复制其中人物。
```

多图融合时使用职责描述，不依赖模糊的“参考一下”。确需权重时给出相对权重，并同时写清结构性不变项。

### 5. 质检与交付

生成前检查提示词，生成后检查结果。读取 [质检与交付](references/quality-control.md)。

关键验收顺序：

1. 剧情和身份是否正确
2. 人物、服装、道具和场景是否连续
3. 结构、透视、比例和光源是否合理
4. 是否存在多余人物、车辆、文字、Logo、水印或杂物
5. 材质、皮肤、边缘和噪点是否符合目标风格
6. 文件名、版本号和文件夹归档是否可追踪

## 输出格式

### 资产清单

默认使用 Markdown 表格。资产较多且用户要求文件时，再生成 Excel/CSV。

### 单个提示词

输出：

```text
资产名称：
用途：
正向提示词：
负面限制：
建议画幅：
参考图职责：
```

没有参考图时省略“参考图职责”。负面限制只保留容易发生且会破坏结果的问题。

### 批量提示词

每个资产独立编号，保留统一的项目风格块和资产自己的差异块。不要用一条含糊提示词让模型自行拆分多个资产。

## 行为约束

- 不把文档中的示例角色、品牌、办公室或服装误当成所有项目的默认内容。
- 不把人物特写、全身图和三视图分别设计成不同的人。
- 不用“高级、震撼、精致、电影感”替代可观察的构图、光线和材质。
- 不为了细节密度填满画面；保持疏密关系、大色块、留白和单一视觉焦点。
- 不承诺参考图中无法确认的细节；看不到图片时明确请求图片或可访问路径。
- 用户要求调用生图工具时，把最终提示词和参考图上下文交给可用的生图工具；本 Skill 本身不伪造生成结果。
