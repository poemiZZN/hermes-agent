# 短剧场景模板库（wan3.0-video）

每个模板给 **推荐形态 / 建议参数 / 可套骨架 / 一条完整示例 / 该场景专属注意**。
方括号 `[ ]` 是待填槽位，交付时必须替换掉且**不保留方括号**。

**全库统一遵守的基准口径**（详见 [`wan3-formulas.md`](wan3-formulas.md)）：

- 参考对象一律写 `@图片1` / `@视频1` / `@音频1`（**带 @、用全称**，图片/视频/音频各自从 1 起编号，同一对象可多次 @）
- 人声写**六要素**：`"说话内容"` + 情绪 + 语调 + 语速 + 音色 + 口音
- 音效写**三段**：音源材质 + 行为 + 环境音；BGM 写**两段**：背景音乐/配乐 + 风格
- 不要台词写「**全片无台词**」，不要配乐写「**无背景音乐**」，不要切镜写「**生成单镜头**」或「**一镜到底**」——不写模型就自己发挥
- 不写"不要"（`negative_prompt` 已废弃，全部转正向排除）；有参考图不复述外观；空间写死

### 多素材先写一段职责声明

素材超过一个（多角色图、角色图 + 场景图、图 + 视频）就在正文开头先声明每份素材的职责，四要素齐全：**素材编号 + 正向职责 + 生效时段 + 禁止迁移项**。缺了"禁止迁移项"，模型很容易把 A 图的背景、服装、道具带到 B 身上。

```
@图片1 提供男主的五官与服装，全片生效；图中原有背景与手持物不参与生成。
@图片2 提供女主的五官与服装，全片生效；图中妆容以外的场景元素不参与生成。
@图片3 只提供客厅的陈设与光线氛围，全片生效；图中出现的人物不进入画面。
@视频1 只提供运镜节奏与走位路线，全片生效；原片的角色、服装与字幕不参与生成。
```

写法细则与更多例子见 [`prompt-craft-discipline.md`](prompt-craft-discipline.md) §2。

## 1. 双人对话（正反打 / 过肩）

**形态**：全能参考 `reference_image` ×2 + 各挂 `reference_voice`
**参数**：duration 8–12 / 720P / 9:16 或 16:9 / audio=true

骨架：
```
[光线] + [景别] + [双人镜头/过肩镜头角度拍摄] + [焦段] + [色调] + [运镜]。
@图片1 的[角色A]在画面[左/右]侧、朝向[方位]，@图片2 的[角色B]在画面[另一侧]、[坐/站]姿朝向[方位]，两人相距约[距离]。
@图片1 的[动作与表情变化过程]；@图片2 的[回应动作与表情变化过程]。
@图片1 说："[台词]"，[情绪]，[语调]，[语速]，[音色]，[口音]。
@图片2 说："[台词]"，[情绪]，[语调]，[语速]，[音色]，[口音]。
[环境音效]，[BGM 或"无背景音乐"]。
两人五官与身形比例全程稳定，朝向与相对位置保持不变，画面干净无字幕叠加，机位与焦距全程不变。生成单镜头。
```

示例：
```
柔光，侧光，室内实用光，中近景，双人镜头，过肩镜头角度拍摄，中焦距，冷色调，固定镜头。
@图片1 的男人站在画面左侧、身体朝向右前方，@图片2 的女人坐在画面右侧的餐桌旁、侧身抬头面向他，两人相距约一米五。
@图片1 把一份文件推到桌面中央，指尖在纸面上停了一秒才松开，眉头由平缓收紧；@图片2 的目光先落在文件上，随后缓慢上移与他对视，手中的杯子放回桌面。
@图片1 低声说道："签了它，以后就跟这家人没关系了。"情绪压抑克制，语调平缓下沉，语速缓慢，声音低沉沙哑，标准普通话。
@图片2 停顿一秒后回应："你以为一张纸就能了事？"情绪冷静带讽意，语调平直微扬，语速平稳偏慢，声音清亮偏冷，标准普通话。
环境音为挂钟秒针声与窗外极轻车流底噪，无背景音乐。
两人五官与身形比例全程稳定，朝向与相对位置保持不变，画面干净无字幕叠加，机位与焦距全程不变。生成单镜头。
```

**注意**：
- 正反打天然是两个镜头，若要真正正反打请走 §8 多镜头模板；本模板是"同框双人"的单镜头写法
- 动作句里**重复 @** 一次（推荐手法），比写"男人""女人"更能防止指代漂移
- 想再稳一层音色：参数挂 `reference_voice`，提示词里在台词句后紧跟一句「音色参考 @音频1」（必须与说话动作同句，独立成句的"提取音色特征"前置式不生效），两者可叠加

**采访感消除**（对话场景必查）：
- **严禁直视镜头**——角色面部不得正面朝向镜头方向（约0度），对话场景一律用**过肩镜头 / 侧拍 / 旁观者视角**，角色面部与镜头呈约45度或约90度侧脸
- **严禁面部特写锁定**——不写「镜头焦点锁定面部特写」「面部特写」等直视镜头指令，这些会让角色像在念采访稿
- **倾听人几何化处理**——不写「听着对方说话」，写为几何状态：「背部朝向镜头（约180度），仅露出右耳轮廓，处于自然虚化状态」
- **台词与朝向绑定**——说话人面部约45度朝向画面右侧（严禁正面朝向镜头），视线水平投向画面右侧，嘴唇动作严格匹配台词

## 2. 情绪特写（无台词）

**形态**：`first_frame`（有剧照）或全能参考
**参数**：duration 5–8 / 720P 或 1080P / audio=true 但显式无人声

骨架：
```
[边缘光/侧逆光] + 近景特写 + 中心构图 + 浅景深 + 长焦 + [色调] + [极缓慢推进/固定镜头]。
人物先[起始微表情]，随后[过渡动作]，[情绪终点的生理表现]。
全片无台词，仅保留[环境音]，无背景音乐。
面部轮廓与五官比例保持稳定自然，画面干净无叠加图形，机位与焦距全程不变。生成单镜头。
```

示例：
```
边缘光，近景特写，中心构图，浅景深，长焦，低饱和度，镜头极缓慢推进。
人物先垂眼看向手中的照片，睫毛微颤，嘴角轻微下压；随后缓缓抬头望向窗外，
眼中逐渐泛起水光但未落泪，喉结上下滚动一次，呼吸变得深长。
全片无台词，仅保留纸张轻微摩擦声与窗外风声，无背景音乐。
面部轮廓与五官比例保持稳定自然，画面干净无叠加图形，机位与焦距全程不变。生成单镜头。
```

**注意**：
- 情绪必须写**变化过程**（从 A 到 B），不要只写"她很悲伤"。静态形容词模型无从表演，会变成呆脸或表情乱跳
- 首帧形态走图生公式「运动 + 运镜」（§3），图里已有的长相、服装、场景**一个字都不要复述**
- 「全片无台词」是标准控制词，比"无台词"更硬；`audio` 默认开着，不写就会被配旁白

## 3. 独白 / 长口播

**形态**：全能参考 + `reference_voice`
**参数**：duration 按字数反推（字数 ÷ 3–5，安全线 4 字/秒）/ 720P / audio=true

骨架：
```
[光线] + [中近景/近景] + 中心构图 + 平拍 + 干净的单人镜头 + [色调] + [固定镜头/极缓慢推进]。
@图片1 的[角色]在画面中央，[姿态与手部动作]，视线[朝向]。
@图片1 说："[台词，字数 ≤ duration×（3–5），安全线 4 字/秒]"，[情绪]，[语调]，[语速]，[音色]，[口音]。
[环境音]，无背景音乐。
面部与身形比例全程稳定，口型与台词同步，画面干净无字幕叠加，机位与焦距全程不变。生成单镜头。
```

**字数卡尺**：

| duration | 安全字数（4 字/秒） | 上限（5 字/秒） |
|---|---|---|
| 5s | ≤ 20 字 | 25 字 |
| 8s | ≤ 32 字 | 40 字 |
| 10s | ≤ 40 字 | 50 字 |
| 15s | ≤ 60 字 | 75 字 |

超上限 → 拆段。拆段做法：
1. 按语义断句切成 N 段，每段独立跑
2. 下一段台词首句加**衔接锚点**（例：上段结尾"…我不会再让步"，下段开头"不会再让步的意思是——"）
3. 取上一段**末帧**作为下一段 `first_frame`；或整段走**视频编辑·视频延长**（见 §10），把上一段成片当输入直接续
4. 每段独立 `task_id`，`seed` 分段固定

**注意**：六要素缺哪一项，模型就在哪一项上自由发挥 —— 独白最常见的翻车是只写了情绪没写语速，念成播音腔。

## 4. 走位与进出画面

**形态**：全能参考
**参数**：duration 6–10 / 720P / audio=true

骨架：
```
[光线] + [中景/全景] + [构图] + [机位] + [色调] + [固定镜头 或 镜头跟随]。
@图片1 的[角色]从画面[入画方向]入画，以[步速]走向画面[目标位置]，
在[停留点]停下并[动作]，随后 @图片1 向画面[出画方向]走出画面。
[环境音]，[BGM 或"无背景音乐"]。
人物身形比例与服装保持稳定，行走速率均匀真实，脚步与地面接触自然，机位与焦距全程不变。生成单镜头。
```

**注意**：入画方向、出画方向、步速三者缺一模型就自由发挥。跨镜头连戏时，"上镜从右出画 → 下镜必须从左入画"，方向反了观众立刻看出跳轴。

## 5. 多角色群戏（≥3 人）

**形态**：全能参考（`reference_image` 多张，≤10）
**参数**：duration 8–12 / 720P / audio=true

骨架（**先分区，再给动作**）：
```
[光线] + [群像镜头] + [景别] + [构图] + [色调] + [运镜]。
画面[左侧]是 @图片1 的[角色A]与 @图片2 的[角色B] 并肩[姿态]，[中间]是 @图片3 的[角色C] 独立[姿态]，[右侧]是 @图片4 的[角色D] 半侧身[朝向]。
@图片3 [主动作]；@图片1、@图片2、@图片4 [各自的反应动作，一句带过]。
@图片3 说："[台词]"，[情绪]，[语调]，[语速]，[音色]，[口音]。
[环境音]，[BGM 或"无背景音乐"]。
四人五官与服装各自保持稳定不互相混淆，站位与朝向全程不变，人物身高比例协调，画面干净无字幕叠加。生成单镜头。
```

**注意**：
- 群戏必须**先分区**（左/中/右）再给动作，否则站位全乱
- 只让**一个人**有主动作 + 台词，其余给一句反应；多人同时主动作 = 必崩
- 交付前**逐一核对 @图片N 序号与角色的映射**，序号错位是最高频事故；图片与视频**分开计数**（第一张图是 @图片1，第一个视频是 @视频1）

## 6. 打戏 / 剧烈动作

**形态**：全能参考，**建议拆段**
**参数**：duration 5–8（别贪长）/ 720P / audio=true

先走 SKILL.md 的"检测→提醒→方案→用户决定"，用户选完再写。

**方案①拆两段** —— A 段（对峙起势）：
```
硬光，侧逆光，中景，双人镜头，低角度拍摄，高对比度，冷色调，镜头缓缓推进。
@图片1 的男人在画面左侧半侧身面向右方，重心下沉右脚后撤半步，右手握拳抬至腰侧；
@图片2 的男人在画面右侧正面朝左，肩膀微沉，目光锁定对方，两人相距约两米。
双方均未出手，仅呼吸起伏与肌肉紧绷，衣料因动作产生轻微褶皱变化。
环境音为风声与远处金属撞击回声，全片无台词，无背景音乐。
两人四肢数量清晰可数、肢体轮廓完整，站位与朝向全程不变，机位与焦距全程不变。生成单镜头。
```

B 段（结果与余波），取 A 段末帧作 `first_frame`：
```
硬光，中近景，手持轻微晃动，冷色调。
左侧男人单膝跪地、上半身前倾撑住地面，右侧男人站立于其右后方、右臂自然垂下，
两人衣料凌乱，尘土在光束中缓慢飘落。
环境音为粗重呼吸与尘土落地的细碎声，全片无台词，无背景音乐。
两人肢体轮廓完整不穿透，比例协调，画面干净无叠加图形。生成单镜头。
```

**方案②换视角** —— 局部特写规避穿帮：
```
硬光，极近景特写，浅景深，长焦，冷色调，固定镜头。
一只拳头从画面右侧极速掠过画面前方，带起的气流吹动左侧人物额前碎发，
该人物瞳孔收缩，头部随冲击方向轻微后偏。
环境音为破空声与衣料摩擦声，全片无台词，无背景音乐。
面部五官比例保持稳定，手部形态完整可辨，画面干净无叠加图形。生成单镜头。
```

**方案③硬跑约束句**（追加到排除层）：
```
双臂与双腿数量清晰可数、肢体轮廓完整不互相穿透，接触后物体保持连续形态不消失，
人物身高比例与场景尺度协调，动作以真实速率进行，节奏连贯。
```

**动作句按五要素写**：打戏最容易写成一串动词，模型只能瞎猜轨迹。每个关键动作补齐 **谁发起 + 从哪出发 + 沿什么路径 + 作用于谁 + 落在哪**，例如「@图片1 的男人从画面左侧起身，右拳沿水平弧线由外向内挥向 @图片2 的男人左肩，@图片2 侧身避开后重心落在右脚」。细则见 [`prompt-craft-discipline.md`](prompt-craft-discipline.md) §4。

## 7. 转场（时间 / 空间跳跃）—— 首尾帧专属

**形态**：`first_frame` + `last_frame`（**与全能参考互斥**，此模板不能用 @图片N 指代）
**参数**：duration 5–8 / 720P / audio=true

骨架（走图生公式「运动 + 运镜」（§3），**只写中间过渡过程**，两端画面已由首尾帧承载）：
```
[运镜]，[色调过渡描述]。
画面从[首帧状态]逐渐过渡到[尾帧状态]，过渡方式为[具体手段：光线渐变/人物走位/景物推移/焦点转移]，
过程连续平滑无跳变，中途[中间态描述]。
[环境音的渐变]，[BGM 或"无背景音乐"]。
过渡过程中画面结构保持连续，无突变闪烁，机位运动匀速。生成单镜头。
```

示例（黄昏→夜晚同场景）：
```
镜头固定，色调由暖橙缓慢过渡到冷蓝。
画面从窗边洒满夕照的客厅逐渐过渡到仅有台灯照明的夜间客厅，
过渡方式为窗外天光均匀衰减、室内台灯亮度同步渐强，
过程连续平滑无跳变，中途出现天光与灯光强度相当的短暂平衡状态，家具位置全程不动。
环境音由傍晚鸟鸣渐弱过渡到夜间虫鸣渐强，全片无台词，无背景音乐。
过渡过程中画面结构保持连续，无突变闪烁，机位与焦距全程不变。生成单镜头。
```

**注意**：首尾帧模式下**不能**再传 `reference_image`，报 `media type conflict`。需要角色一致性又要转场 → 改成两段全能参考任务后期剪接。

## 8. 多镜头叙事段落

**形态**：T2V 或全能参考
**参数**：duration = 各镜头之和 / 720P / audio=true / 镜头数 ≤4

骨架（多镜头公式 §6：总体描述 + 镜头序号 + 时间戳 + 分镜内容，**用「第N个镜头[a-b秒]」标准写法**）：

```
[总体描述：故事主题、叙述风格、主要情感或核心事件，一句话概括全局]。
第1个镜头[0-[t1]秒][景别]，[机位]，[运镜]。[分镜内容：动作、语言、表情、姿态]。
第2个镜头[[t1]-[t2]秒][景别]，[机位]，[运镜]。[分镜内容]。（同场景连续动作用运镜衔接/顺切，可不写转场词）
第3个镜头[[t2]-[t3]秒][景别]，[机位]，[运镜]。[分镜内容]。（若这里发生跨场景/跨时空/情绪跳转，按性质选叠化/淡入淡出/闪白闪黑/遮挡Wipe/光效过渡/硬切之一，并把转场逻辑写进本镜分镜内容）
[音效]，[台词或"全片无台词"]，[BGM 或"无背景音乐"]。
各镜头中人物的服装与面部特征保持一致，场景空间朝向前后统一，画面干净无字幕叠加。
```

> **🚨 核心口径：按场景选多样转场，忌一律硬切。** 每到切点先判断「人物/场景/时间是否跳变」：都没变就用**运镜衔接（不切）或顺切**（可不写词），靠空间锚点承接；有跳变就按性质挑一个合适的手法——**硬切只是其中一种**（叙事反转/爆点用），此外还有叠化（回忆/情绪）、淡入淡出（段落/大时间跨度）、闪白闪黑（惊吓/闪回）、遮挡 Wipe（同空间位移）、光效过渡（进入内景/情绪推进）、匹配剪辑（形状衔接）。**每镜开头都写"硬切转场" = 严重错误。** 完整选择表见 `prompt-craft-discipline.md` §10。

示例 A（全程同场景连续动作 —— 用运镜/顺切承接，无需转场词）：

```
这个故事以第三人称视角，讲述一个男人在深夜楼道里读到一封改变处境的信，整体冷色调，纪实手持质感。
第1个镜头[0-3秒]中景，仰拍，固定镜头。@图片1 的男人从画面右下方走进老式居民楼楼道，脚步声触发声控灯亮起，他停在信箱前抬手。
第2个镜头[3-6秒]镜头由中景连续推进至近景特写。@图片1 的手指撕开一封信的封口，纸张边缘毛糙，指节因用力而发白。
第3个镜头[6-10秒]中近景，平拍。@图片1 低头读信，眼神从平静转为震惊，嘴唇微张但未出声。
音效为声控灯电流嗡鸣、纸张撕裂声与楼道回声，室内安静环境；全片无台词，无背景音乐。
三个镜头中人物的服装与面部特征保持一致，楼道空间朝向前后统一，画面干净无字幕叠加。
```

> 上例三镜同在一个楼道、同一段时间、没有跳变，所以靠时间戳分界 + "楼道空间朝向前后统一"这句空间锚点承接：1→2 用"连续推进至近景特写"运镜衔接（不切），2→3 是同场景机位切换直接顺切——这类**同场景连续动作**本就无需写转场词。**注意这只是"没跳变"这一种情况的写法，不代表所有镜头都不写转场**；一旦发生跨场景/跨时空/情绪跳转，就要按性质挑一个合适的转场手法（见下方示例 B）。

**注意**：
- 标准格式是「**第N个镜头[a-b秒]**」，景别 / 机位 / 运镜写在分镜内容**开头**
- **每到切点先判断「人物/场景/时间是否跳变」**：没跳变（同场景连续动作/换机位）用**运镜衔接或顺切**，可不写转场词；有跳变就**按性质选一个合适的转场**——叠化（回忆/情绪）、淡入淡出（段落/大时间跨度）、闪白闪黑（惊吓/闪回）、遮挡 Wipe（同空间位移）、光效过渡（进入内景）、匹配剪辑（形状衔接）、硬切（叙事反转/爆点）。**忌一律硬切、更忌每镜无脑复制"硬切转场"。** 完整切点性质表 + 转场词库见 `prompt-craft-discipline.md` §10
- 单镜 ≥2s；时间戳之和 = `duration`，对不上就报错或被裁
- 每段都要落一句**结束状态**，且**上段结束 = 下段起始**，否则两镜之间必跳戏
- 段数按卡尺控制（5s→1 镜 / 8–10s→2–3 / 15s→3–4 / 20–30s→4 封顶），**一段只留一个运镜动作**
- 跨镜一致性声明**只在结尾写一次**，不要每镜重复
- 多镜头 + 长台词 = 高风险组合，优先拆成多次任务
- 只想要一镜到底就**别写镜头序号**，改写「生成单镜头」「一镜到底」

示例 B（有跨场景 / 情绪跳变 —— 按性质选多样转场，不是一律硬切）：

```
这个故事以第三人称视角，讲述女人收到旧照片后陷入回忆又被现实惊醒，暖旧调与冷现实交替，电影质感。
第1个镜头[0-4秒]近景，平拍，缓慢推近。@图片1 的女人坐在窗边书桌前，指尖翻开一张泛黄的旧照片，眼神逐渐柔和，嘴角微动。
第2个镜头[4-9秒]中景，暖金色调，画面叠化溶入回忆。少年时的两人在夏日操场并肩奔跑，阳光斑驳，笑声清亮（此处用叠化 Dissolve 进入回忆，暖光与颗粒感区分时空）。
第3个镜头[9-12秒]特写，冷蓝调。一声关门巨响，画面闪白后切回现实——@图片1 的女人猛地抬头，瞳孔收缩，照片从指间滑落（此处用闪白衔接回忆到现实的惊醒跳转）。
音效为翻纸声、夏日蝉鸣与操场喧闹（回忆段）、关门巨响与心跳声（现实段）；全片无台词，回忆段配轻柔钢琴、现实段戛然而止。
三个镜头中女人的五官与服装保持一致，书桌空间朝向前后统一，画面干净无字幕叠加。
```

> 上例三镜发生了两次真实跳变，所以各挑了不同手法：1→2 是**同人跨时空进回忆**，用**叠化 Dissolve**＋暖光颗粒区分；2→3 是**回忆被现实惊醒**，用**闪白**做惊醒跳转。**没有一处硬切，也没有机械复制同一个转场词**——这就是"按场景选多样转场"的正确示范。


> 时间线连续四要素与段数卡尺细则见 [`prompt-craft-discipline.md`](prompt-craft-discipline.md) §1；照参考片反推分镜见 §5（按真实剪辑切点还原，不做创意外推）。

## 9. 剧本文件直出

**形态**：`file` ×1（**必须 `enable_thinking=true`**）
**参数**：duration 15–30 或 -1 / 720P / audio=true

```
根据这份剧本第[X]场，生成一段[风格]质感的短剧片段，
[景别偏好]，[色调]，[运镜倾向]，保留剧本中的关键台词与情绪转折，
[BGM 或"无背景音乐"]，画面干净无字幕叠加。
```

**注意**：
- `file` 与 `link` 互斥，各最多 1 个；≤100MB、≤50 页
- 忘开 `enable_thinking` 会直接报错，提交前检查参数
- 文件直出的可控性远低于手写分镜，**只推荐做初稿探索**，正式出片仍建议拆镜手写

## 10. 老素材改造 / 续拍（视频编辑 V2V）

**形态**：`reference_video` ×1（要改的成片）+ 可选 `reference_image`（新角色/新服装）
**参数**：duration 5–10 / 720P / audio=true；**输入视频总时长 + 输出 duration ≤ 30s**

公式 §7：**编辑对象 + 编辑行为**。核心纪律是**只写要改的地方，绝不把原视频重新描述一遍**；想保住其余部分就补一句「其他保持不变」。

| 剧集诉求 | 玩法 | 指令写法 |
|---|---|---|
| 改台词但保音色 | 时序编辑 | 「保持人物音色和语气，将男人的说话内容改为：'这件事到此为止。'」 |
| 补一个动作 | 时序编辑 | 「让视频里的女人放下杯子，转身走向门口」 |
| 换角色 | 元素编辑 | 「把视频中的男人换成 @图片1 中的男人，其他保持不变」 |
| 换服装 | 元素编辑（多图编号） | 「让视频中的男人穿上 @图片1 中的外套和 @图片2 中的裤子」 |
| 换季节 / 改天气 | 全局编辑 | 「视频修改为阴天，窗外飘落细雨，其他保持不变」 |
| 改整体氛围色调 | 全局编辑 | 「修改为冷蓝色调，压低整体亮度，其他保持不变」 |
| 去穿帮物 | 元素编辑（删除） | 「去除画面右下角的矿泉水瓶」 |
| 加道具 | 元素编辑（添加） | 「桌面左侧添加一台老式座机电话，其他保持不变」 |
| 续拍下一拍 | 视频延长 | 「男人继续往前走，在门口停下回头看了一眼」 |
| 风格化改造 | 全局编辑 | 「把视频改为 2D 卡通风格」/「把视频改为 @图片1 中的插画风格」 |
| 白膜转正式成片 | 参考生视频 | 「将 3D 预览视频转化为正式成片，把预览视频中的白模角色换成 @图片1 的男人和 @图片2 的女人，保持原有运镜与走位」 |

**剧集专属翻车点**：
- **换角色/换装的参考图必须同角度同光位**，正脸图套侧身镜头会有明显接缝
- **改台词一定要写「保持人物音色和语气」**，漏了音色必漂，多角色片尤其明显
- **视频延长只写"后续发生什么"**，把已有画面又描述一遍会导致模型重演旧动作
- **全局调色会连带改角色肤色与服装本色**，对色彩有连戏要求的剧集慎用，改走元素编辑
- **白膜转成片属于参考生视频形态**（走 `reference_video` + `reference_image`），提示词里要明确"保持原有运镜与走位"，否则模型会重新设计机位
- 输入视频计入时长上限，一段 12s 的原片最多再要 18s 输出

> **白膜与延长的细则**：白膜先分粗细——粗白膜（只有几何体与走位）要在提示词里补齐材质、光线、服装；细白膜（已有面部与道具轮廓）只补材质与光线，别再描述结构，否则会跟原片打架。延长与编辑的要素补全见 [`prompt-craft-discipline.md`](prompt-craft-discipline.md) §7，白膜粗细分类见 §8。

## 低风险反转五类型

写叙事短片时，反转是一把双刃剑：好的反转重新解释前面信息，坏的反转靠突然出现的新元素解决。优先选以下五种**低风险反转**：

| 类型 | 核心手法 | 前面须埋的线索 |
|---|---|---|
| **空间揭示** | 拉远/开门/移焦改变观察角度，揭示观众误解了场所或尺度 | 该空间在前面的镜头中已出现，只是未被注意 |
| **意图反转** | 看似逃跑/破坏/攻击，实际在保护/归还/释放/修复 | 角色动作存在歧义，回头看是合理的 |
| **物件功能反转** | 同一物件的真实用途在结尾被看见 | 物件在前面的镜头中已出现 |
| **关系反转** | 画面内的配角并非威胁，而是帮助者/见证者/被保护者 | 配角在前面的镜头中已出现 |
| **规律反转** | 异常不是故障，而是在执行另一套可验证规则 | 异常规律在前面的镜头中已建立 |

> 反转必须回看可成立：前面至少埋一个可见线索。结尾不得依赖突然出现的新角色、新地点、新设定或新产品。避免把"巨大爆炸、变成怪兽、醒来是梦、又一次反转"当作默认惊喜。

## 五段叙事节拍（30s 叙事骨架）

| 时间段 | 节拍 | 要写什么 |
|---|---|---|
| **0—7s** | 钩子与状态 | 第一秒就让异常物件/动作/视觉规律出现，同时建立主角、空间和任务 |
| **7—14s** | 验证与升级 | 主角做一个简单测试或继续任务，异常以同一规律升级 |
| **14—22s** | 阈值与选择 | 异常逼迫主角作出一个动作；接触、重心、物件位置和因果必须连续 |
| **22—27s** | 反转与重释 | 通过空间揭示、意图反转、物件功能或尺度关系重释前 22 秒 |
| **27—30s** | 余韵与落点 | 摄影机停稳，给一个呼吸、眼神、动作回声或小笑点，不再开启第二个故事 |

> 运动或需要更清楚动作链的任务可细分为六段，但总因果只能有一条。每个时间段必须描述可见动作，不写抽象情绪或纯风格口号。
> 本节拍与 [`prompt-craft-discipline.md`](prompt-craft-discipline.md) §1 的 30s 节奏骨架互补——后者偏时间分配，本节拍偏叙事节拍。
