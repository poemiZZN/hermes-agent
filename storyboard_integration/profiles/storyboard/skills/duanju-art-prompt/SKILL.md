# 短剧美术生图提示词生成 (Art Prompt Generator)

## Overview

内置三套固定提示词模板，用于短剧美术资产 AI 生图。用户只需提供「具体主体描述」，
本技能自动套用对应模板，拼出风格统一、参数齐全的完整生图提示词。

模板原文见 `references/templates.md`（**固定修饰词必须逐字保留，不得增删改写**）。

## 工作流

### Step 1: 判断资产类型

根据用户意图判定为三类之一：
- **人设**：描述的是人物 / 角色 / 演员 / 服装造型 → 套人设模板
- **场景**：描述的是空间 / 环境 / 建筑 / 地点（无人物）→ 套场景模板
- **道具**：描述的是物品 / 物件 / 陈设 → 套道具模板

用户未明确类型但可判断时直接套用；无法判断时简要询问。

### Step 2: 提炼主体描述

将用户提供的具体信息浓缩为一段通顺的「主体描述」，填入对应槽位：
- 人设：年龄、性别、外貌特征、发型、服装、气质等
- 场景：空间类型、建筑材质、光线、氛围、陈设等（**严禁出现人物**）
- 道具：物品名称、材质、造型、用途等

### Step 3: 拼装完整提示词

把主体描述写入对应模板的 `[...]` 槽位，固定修饰词逐字保留，输出一段完整、可直接复制的提示词。

### Step 4: 输出

- 以代码块形式输出完整提示词，方便一键复制。
- 多主体时按主体分别输出多条，每条前标注类型与编号（如「人设-01」）。
- 场景类再次确认描述中无人物；道具类保持白底、三视图要求。

## 质量自检清单

输出前确认：
- [ ] 类型判定正确（人设 / 场景 / 道具）？
- [ ] 固定修饰词是否**逐字保留**、无增删改写？
- [ ] 主体描述是否通顺、无歧义、无重复累赘？
- [ ] 场景描述是否**无人物**？道具是否保留白底 + 三视图 + 16:9？
- [ ] 人设左区是否保留「面部不对称/眉毛高低/胎毛碎发/头部不可缺少头顶/证件照拍照姿势/证件照全光源」？
- [ ] 比例参数是否与模板一致（三视图与场景/道具均为 16:9）？
