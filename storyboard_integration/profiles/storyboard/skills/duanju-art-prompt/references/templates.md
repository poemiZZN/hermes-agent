## 1. 人设提示词固定（角色）

原文：

> 人设提示词固定：西方现代风格，外国白人，真人，真实感皮肤质感，去3d感，正面，手自然放下，衣服设计有疏有密，白色背景。身高比例185，腿长，超写实人像摄影，8K超清。一位9头身比例的超模身材，头部精致小巧。眉毛高低略有不同，左右眼神存在微妙差异，面部轻微不对称，几缕凌乱的胎毛和碎发左边是脸部特写，脸部真实皮肤质感，自然肤色不均，毛孔克制可见但不堆砌，无美颜磨皮，无塑料感，皮肤上有环境痕迹，皮肤通透感。头发有真实重量感和分股，自然油光，没有 CG 完美感。眼睛有湿润的真实反光，瞳孔清晰但不锐利，眼白有自然血丝（不夸张），睫毛根部细节自然皮肤质感，左边特写图的头部不可缺少头顶，证件照拍照姿势，证件照全光源，右边是三视图，不改变人物身材比例，侧面头部不要往前倾，正常身材比例侧面，图片规格16：9 ，不改变人物身材比例，侧面头部不要往前倾，正常身材比例。

### 字段拆解

| 字段 | 内容 |
|---|---|
| 画风基调 | 西方现代风格、外国白人、真人、真实感皮肤质感、去 3D 感 |
| 姿态 | 正面、手自然放下、衣服有疏有密 |
| 背景 | 白色背景 |
| 身材 | 身高比例 185、腿长、9 头身超模身材、头部精致小巧 |
| 面部不完美 | 眉毛高低略有不同、左右眼神存在微妙差异、面部轻微不对称、几缕凌乱的胎毛和碎发 |
| 左区 | 脸部特写（真实皮肤质感、自然肤色不均、毛孔克制、无美颜磨皮、无塑料感、皮肤环境痕迹、皮肤通透感；头发重量感与分股；眼睛湿润反光、瞳孔清晰不锐利、眼白自然血丝、睫毛根部自然；头部不可缺少头顶、证件照拍照姿势、证件照全光源） |
| 右区 | 三视图（不改变身材比例、侧面头部不前倾、正常比例侧面） |
| 右区比例 | 16：9 |

## 2. 场景固定提示词

原文：

> 场景固定提示词：生成下面以下场景，比例16：9，西方风格，真实感，带有宏伟震撼感觉，场景有疏密感，场景设计有疏有密，大场景，场景留白，结构清晰，结构符合逻辑，比例协调，不要假细节，都非常震撼 ，无人物 克制的细节，大色块优先，留白，统一的材质表现，平滑表面，真实皮肤纹理，自然肤色不均

### 字段拆解

| 字段 | 内容 |
|---|---|
| 比例 | 16：9 |
| 风格 | 西方风格、真实感、宏伟震撼 |
| 构图 | 大场景、场景留白、结构清晰、结构符合逻辑、比例协调 |
| 密度 | 场景有疏密感、设计有疏有密、大色块优先、留白 |
| 细节 | 不要假细节、克制的细节 |
| 人物 | 无人物（严禁出现人物） |
| 材质 | 统一的材质表现、平滑表面、真实皮肤纹理、自然肤色不均 |

### 槽位

- 唯一可变槽位：`生成下面以下场景，` 之后插入 `[场景主体描述]`（空间类型 / 建筑材质 / 光线 / 氛围 / 陈设等，**不得出现人物**）。
