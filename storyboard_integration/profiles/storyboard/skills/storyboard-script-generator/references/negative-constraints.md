# 负面约束清单（Negative Constraints Checklist）

> 供 `storyboard-director` 技能在每段分镜末尾的"负面约束"处调用。AI 视频有固定的已知弱点，必须用显式禁止句堵住。
> 每个镜头至少选 2–3 条相关项写进提示词；不相关的写"负面约束：无"也不要空着。

## 一、按失败模式归类的负面约束

### A. 比例 / 解剖崩坏
- 禁止人物肢体比例错误（手过大/过长、颈部过长、手指数量异常）
- 禁止出现多余或缺失的肢体（六指、三只手、无手）
- 禁止角色突然变性/换脸/换发型
- 禁止道具尺寸忽大忽小

### B. 角色行为失控
- 禁止角色无理由乱转头 / 突然看镜头（除非 POV 设计）
- 禁止人物突然消失或出现 / 穿模
- 禁止非人类角色做出拟人化表情（如机械体害怕）
- 禁止违背设定动作（如设定背对则禁止回头）

### C. 光影 / 画面
- 禁止均匀照明（必须半明半暗，有主光与阴影）
- 禁止画面过曝 / 死黑无细节
- 禁止无理由的物体漂浮 / 重力失效
- 禁止镜头毫无理由地自转或翻转

### D. 音频（红线）
- **严禁生成背景音乐（BGM）**——任何情况下都不写"配乐/歌曲/抒情乐"
- 禁止突然的静音断层（环境底噪应延续）
- 禁止音画严重错位（对白与口型偏差过大）

### E. 动作 / 节奏
- 禁止动作瞬移 / 跳变（应拆微节拍 + 标时间）
- 禁止上一镜与下一镜姿态/视线/声音不衔接
- 禁止无过渡的硬情绪跳变（需按情绪曲线递进）

### F. 字幕 / 文字
- 全片不显示任何字幕（除非用户要求）——固定内容见 SKILL.md 固定结尾
- 禁止画面中凭空出现可读文字/LOGO（除非产品广告需求）

## 二、合规红线（强烈负面情绪类必看）

写涉及崩溃、失控、冲突等强情绪的分镜时，规避极端词：
- 用"情绪失控 / 内心崩溃 / 肢体紧绷 / 颤抖"替代自伤、暴力、伤害类具体动词
- 不描写明确的自残、自杀、血腥伤害动作
- 冲突戏用"推搡/对峙/僵持"等可拍中性词，避免渲染伤害细节

## 三、快速自检（生成后逐镜过一遍）

- [ ] 每个镜头都有量化参数（速度/角度/色温/声学至少一项）
- [ ] 每个镜头都有"负面约束"句（至少 2 条相关）
- [ ] 有"首尾帧 / 衔接注记"对齐上下镜
- [ ] 结尾两块固定内容（字幕处理 + 音频配置）齐全
- [ ] 无 BGM、无字幕（除非用户特别要求）
- [ ] 强情绪场景遵守合规红线
