> 供 `Basics-pro` 技能在生成打斗戏份时调用。
> v5.5 新增：基于袁和平 50+ 年动作设计实践，提炼可跨类型复用的核心设计原则。

## 总纲——"看得懂，看得爽"

袁和平的动作美学浓缩为六个字：**「看得懂，看得爽」**。所有设计原则都服务于这个总纲。

> 「一个人就两只手两只脚，还能怎么打。」——袁和平

---

## 六维设计体系

### 一、动作流——因果链设计

袁和平的动作最核心的机制是**因果链**——每个动作都是前一个动作的结果，每个动作又引发下一个动作。不是"你打我一轮，我打你一轮"，而是**在一次连续动作流中完成攻防互转**。

**攻防转换五法：**

| 手法 | 说明 | 示例 |
|------|------|------|
| 化解 | 格挡对方攻击，同时创造反击角度 | A格挡B刺拳→顺势将B手臂压下→暴露B面部 |
| 补击 | 对方攻击落空后，趁其收招时反击 | B拳锋刺空→A趁B收拳的 0.3s 窗口刺出反击 |
| 借力 | 利用对方攻击的力量，改变自身位置或角度 | B膝盖顶来→A借这股力往后仰→双腿蹬地扑向B |
| 躲击 | 闪避的同时攻击 | A侧闪B刺拳→同时右拳从腰间弹射→B下颌 |
| 截击 | 在对方攻击途中打断 | B拳锋刺出中途→A更快一步命中B面部 |

**因果链示例：**
```
❌ 站桩式：B出拳 → A格挡 → B再出拳 → A再格挡（无限循环）
✅ 因果链：B拳锋刺空 → A趁收拳反击 → B被迫格挡 → A不收拳转肘击 →
          B本能抬臂 → A不收肘转膝撞 → B侧身卸力 → A重心失衡 → B趁机扣颈
```

### 二、镜头流——单机位 + 最佳角度

> 「我永远只用一台摄影机。因为任何一个瞬间，只有一个最好的角度。你永远不可能同时拥有两个最好的角度。」——袁和平

| 原则 | 说明 |
|------|------|
| **单机位** | 每镜只用一个最佳角度，不切多机位 |
| **变焦替代剪辑** | 快速推拉变焦完成景别转换，而非快切 |
| **长镜头力量** | 长镜头不可造假——完整展示动作链，观众能看到每个动作都不是假的 |

**最佳角度选择：**
- 出拳：侧面 45°——同时看到拳锋轨迹和命中点
- 踢腿：正面或侧面 30°——展示腿部弧线和脚背
- 摔技：侧面——展示身体旋转轨迹
- 地面缠斗：俯拍 45°——展示位置关系

### 三、空间呈现——相机作为参与者

袁和平的镜头不是旁观者，而是**动态跟随战斗节奏的参与者**。镜头运动与角色运动同步。

| 原则 | 说明 |
|------|------|
| **首镜锚定空间** | 每场打斗第一镜必须全景——建立空间关系 |
| **每 3-4 镜重建空间** | 特写连击后必须回到中景/全景——重建空间关系 |
| **空间一致性** | 同一场景中，角色位置关系跨镜不变 |

### 四、剪辑节奏——停顿/爆发/停顿

袁和平的节奏根植于京剧训练——舞台上的亮相、起势、收势，被转化为电影语言。

```
节奏模式：停顿（对峙/走位）→ 爆发（交手）→ 停顿（喘息/重新评估）→ 爆发 → 停顿
```

| 阶段 | 镜头时长 | 景别 |
|------|:---:|------|
| 停顿 | 3-5s | 中景/全景 |
| 爆发 | 1-2s | 中景/大特写 |
| 停顿 | 2-4s | 大特写面部 |

**断点剪辑**：一个镜头用完，第二个镜头快速从另一个角度接入——不是固定机位一镜到底（那是成龙风格）。

### 五、力度表达——破坏效果倒推力度

袁和平不依赖特效展示打击力度，而是通过**物理后果**让观众"计算"出力度。

| 力度层级 | 命中证据 | 环境破坏 |
|---------|---------|---------|
| 轻击 | 皮肤泛红 | 无 |
| 中击 | 衣料凹陷 + 身体后仰 | 身体撞上物体 |
| 重击 | 唾液甩出 + 身体踉跄 | 物体凹陷/倒塌 |
| 致命击 | 血珠渗出 + 倒地 | 大面积破坏 |

### 六、视听统一——画面服务动作

袁和平的视听语言中，**画面、声音、剪辑全部服务于同一个目标：让观众理解动作**。

- 音效同步：命中瞬间音效 0 延迟
- 画面服务动作：构图、运镜、景别全部为展示动作服务
- 无冗余元素：背景简洁，不分散注意力

---

## 设计前必问三问

1. 观众能看懂这个动作吗？（因果链是否清晰？）
2. 这个角度是最好的角度吗？（单机位原则）
3. 力度是否通过物理后果表达清楚了？（破坏效果倒推）

## 与其他动作导演的对比

| 维度 | 袁和平 | 程小东 | 成龙/洪金宝 |
|------|--------|--------|-----------|
| 镜头 | 单机位+最佳角度 | 多机位+慢动作 | 固定机位+长镜头 |
| 动作 | 攻防一体因果链 | 招式美感优先 | 环境交互+喜剧 |
| 钢丝 | 增强（借力点） | 飞行（无借力点） | 几乎不用 |
| 节奏 | 停顿/爆发/停顿 | 全程快节奏 | 渐强式 |
| 剪辑 | 断点剪辑 | 快切 | 长镜头不切 |
