# 情绪表演词库（Emotion Library）

> 供 `storyboard-director` 技能在填写"动作表演 / 画面描述"栏时调用。核心主张：**情绪 = 面部细节 → 肢体动作 → 时间词节奏** 三维度，缺一不真实。

## 一、三维拆解法（每条情绪必按此三栏写）

- **面部细节**：眼神（明亮/黯淡/涣散）、嘴角（上扬/下垂/微颤）、眉头（紧锁/舒展）、鼻翼（微张）、泪（蓄泪/滑落）、肤色（泛红/苍白）。
- **肢体动作**：手（攥衣角/捂脸/握拳/微微张开）、肩（放松/紧绷/耸动）、身体（前倾/蜷缩/后仰）、头（低垂/晃动/猛抬）。
- **时间词节奏**：用副词控制"演得多快"，直接映射运镜快慢（见第四节）。

## 二、基础情绪库（12 + 4，简单场景直接复制）

| 情绪 | 面部 | 肢体 | 节奏词 |
|---|---|---|---|
| 喜悦 | 眼角弯、齿露、眼下细纹 | 肩松、手自然张开 | 缓缓舒展开 |

| 爱慕 | 瞳孔微放、唇半张 | 不自觉靠近、指尖微动 | 缓缓、欲近又止 |
| 安心 | 眉舒、呼吸平 | 肩落、身体后靠 | 渐渐放松 |
| 期待 | 眉挑、目光亮 | 身体前倾、手指轻敲 | 微微、渐渐 |
| 释然 | 长叹、眉展 | 肩塌一下、手松开 | 缓缓泄气 |

## 三、递进式情绪曲线（电影感内心戏）

任何情绪套入同一条曲线，按阶段写、对齐运镜快慢：
```
酝酿期（微表情+轻微肢体，节奏舒缓 → 慢镜头）
   ↓
爆发期（明显表情+大幅肢体，节奏急促 → 正常速度/快切）
   ↓
收尾期（缓和表情+舒缓肢体，节奏回落 → 慢镜头）
```
**递进路线（可直接取用）：**
- 悲伤：难过 → 悲伤 → 崩溃大哭 / 绝望告别
- 愤怒：生气 → 愤怒 → 暴怒 / 克制愤怒
- 心动：初遇心动 → 暧昧拉扯 → 确认爱意
- 恐惧：预警恐惧 → 爆发恐惧 → 失控恐惧
- 紧张 → 焦虑 → 恐慌
- 平静 → 疑惑 → 震惊
- 满足 → 得意 → 傲慢
- 愧疚 → 自责 → 崩溃

> 禁止跳过酝酿期直接爆发（情绪断层、AI 易出怪表情）。职场/日常场景要收着写，别无脑上暴怒、大幅肢体。

## 四、时间词节奏副词表（节奏旋钮 ↔ 运镜快慢）

| 节奏类型 | 用词 | 对应镜头速度 |
|---|---|---|
| 舒缓/轻 | 缓缓、慢慢、轻轻、微微、逐渐、渐渐 | 慢镜头 |
| 爆发/急 | 猛地、瞬间、突然、剧烈、迅速、骤然、急促 | 正常速度 / 快切 |
| 过渡/克制 | 缓缓…又…、停顿 1 秒、欲擒故纵、压住、克制地 | 慢放 + 停顿 |

**用法**：把"时间词副词"直接对齐到运镜速度——酝酿期慢镜头、爆发期正常速度、收尾期慢镜头。这是把"情绪"和"镜头"打通的旋钮。

## 五、可直接套用的完整范例（风格样板）

1. **王家卫风（暧昧拉扯）**：一镜到底 + 百叶窗光影切割面部 + 暖橙台灯 + 时间词"缓缓抬眼→睫毛轻颤→视线缓慢聚焦"。
2. **日常写实风（崩溃大哭）**：特写 + 昏暗卧室 + 呜咽声（带混响）+ 泪水滑落轨迹量化。
3. **职场风（克制愤怒）**：特写 + 整洁办公室 + 办公环境底噪 + "指节发白→缓缓松手→面无表情"。

## 六、合规红线（务必遵守）

涉及强烈负面情绪时，**规避**"自杀/自残/暴力"等极端词，改用中性表达：
- "情绪失控" 替代 极端行为描述
- "内心崩溃" 替代 自伤类词
- "肢体紧绷/颤抖" 替代 暴力动作词
