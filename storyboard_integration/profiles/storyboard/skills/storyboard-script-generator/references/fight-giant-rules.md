# 巨物场景规则（Giant & Monster Rules）

> 供 `Basics-pro` 技能在生成**任何出现巨物/怪兽/机甲/Kaiju 的场景**时调用。
> v5.1 新增 → v5.9 大升级：高度分级体系 + 压迫感/笨重感双公式 + 混合比例场景规则。
> **参考资料**：电影级分析——哥斯拉2014（压迫感体系）+ 环太平洋2013（笨重感+打斗感体系）。

---

## 零、触发条件与高度分级（v5.9 核心升级）

### 0.1 触发条件

剧本中出现**高度 ≥3m 的非人类或机甲角色**时，加载本模块。不仅限于打斗——登场、行走、与人类同框、环境交互均适用。

**本模块是独立规则体系，不套用写实格斗规则（action-scene-rules.md）。**

### 0.2 高度分级——不同尺度的巨物，完全不同的设计逻辑

**这是巨物场景设计的第一性原理。** 10m 以下机甲的速度感、50m 怪兽的笨重感、100m 哥斯拉的压迫感——三者是完全不同的视觉语言，不可互相套用。

| 高度分级 | 典型角色 | 运动速度 | 登场感觉 | 打斗风格 | 参照物 |
|:---:|------|------|------|------|------|
| **3-10m 轻战型** | 《汉江怪物》水怪、轻型机甲、异形 | 较快——可奔跑/跳跃/滑铲/S形闪躲 | 敏捷威胁感——"追得上你" | 快速机动、蓄力爆发、光刃枪炮、浓烟 | 人类/车辆/房间 |
| **10-50m 中型** | 中型机甲、中小型怪兽、金刚 | 中等——每步 1-2s，可蓄力加速 | 混合感——"能躲但躲不远" | 笨重感+速度感混合，环境破坏显著 | 建筑/街道/桥梁 |
| **50m+ 巨型** | 哥斯拉、环太平洋 Jaeger、巨蛛 | 极慢——每步 2-5s，平方-立方定律 | 压迫感——"跑不掉" | 纯粹笨重感，每次命中=灾难级环境破坏 | 建筑群/城市/山脉 |

**10m 以下不叫"巨物"**——它们的打斗逻辑更接近写实格斗但放大 5 倍，可以快切、可以蓄力爆发、可以用 ACT 命中推拉。**50m 以上才是真正的"巨物"**——必须遵循本节的全部压迫感+笨重感规则。

## 一、核心原则——镜头永远在人类视角

**摄影机高度 = 人类眼睛高度（140-160cm）。** 这是哥斯拉和环太平洋的第一铁律：相机离开地面 = 巨物变玩具。

| 原则 | 说明 | 来源 |
|------|------|------|
| **人类视角** | 镜头永远在地面高度——贴地仰拍、雪坑仰拍、透过窗户拍摄 | Godzilla 2014 |
| **负空间构图** | 巨物被烟雾/夜雨/建筑/雪雾持续遮挡——"看不清全貌"制造恐惧 | Godzilla 2014 |
| **碎片揭示** | 一次只给一个身体部位——尾巴→腿→背鳍→最后才露头 | Godzilla 2014 |
| **比例尺锚点** | 每镜必含观众认识真实尺寸的物体——人类/校车/建筑/树木 | 两部通用 |
| **阴影覆盖** | 巨物未出现，阴影先到——悬念 > 直接展示 | Godzilla 2014 |
| **灾难化氛围** | 灰暗调色、碎屑悬浮、平民逃亡非战斗——"这不是战斗，是自然灾害" | Godzilla 2014 |

## 二、两张公式卡——压迫感 + 笨重感

### 2.1 压迫感公式（Godzilla 2014 体系）

适用于**登场/行走/与人类同框/碾压**场景，无需打斗。

```
负空间遮挡 + 地面仰视 + 碎片揭示 + 可识别比例锚 + 阴暗调色 + 人类无力
= 观众感到自己渺小到可以被踩死
```

**镜头技法（压迫感专用）**：

| 技法 | 说明 | 参数 |
|------|------|------|
| 超广角压迫 | 等效 16-20mm，巨物局部占满画面——强调被压在脚下的纯粹压迫感 | 仰角 70-85° |
| 极近贴地 | 镜头距离人类脚后跟 30cm 或埋在雪/地面中——观众被"塞进"现场 | 距离 30-100cm |
| 极端仰拍 | 仰角 70-90°，巨物从画面上方覆盖——天空被吞噬 | 仰角 70-90° |
| 局部占满画面 | 一只眼睛占画面 85%，复眼网格/鳞片纹理清晰可见 | 大特写 |
| 光眼/光斑作为唯一光源 | 巨物自发光（幽蓝光眼/背鳍蓝光）成为画面的唯一光源——底光扭曲人类面部 | 底光 |
| 被动位移 | 人类不是主动跑，是被气流推、被冲击波推、被雪浪推——"被推着走"才有重量感 | 环太平洋原则 |

### 2.2 笨重感公式（Pacific Rim 2013 体系）

适用于**巨物之间打斗/巨物攻击环境/巨物被攻击**场景。

```
机械延迟蓄力 + 环境大面积破坏反馈 + 伤损累进可见 + 被动位移为主 +
命中瞬间慢放 + 粒子密度爆炸 + 人类受力锚点
= 观众相信银幕上的东西真的有几万吨
```

**镜头技法（笨重感专用）**：

| 技法 | 说明 | 参数 |
|------|------|------|
| 拳峰相机 | 虚拟摄影机绑在 Jaeger/巨物拳头上——以 150mph 传达命中速度 | 环太平洋独有 |
| 打击冻结 | 命中瞬间画面微冻结 0.3-0.5s + 升格——"钉住"打击 | 命中瞬间 |
| 环境破坏作为命中证据 | 不是皮肤凹陷——是建筑倒塌/地面炸裂/雪崩/海啸/裂纹放射扩散 | 每一步/每拳 |
| 粒子密度 | 每帧都有雨水/火花/碎片/灰尘/雪粒同时悬浮——粒子的物理轨迹独立计算 | 慢放中更突出 |
| 人类受力锚点 | 切镜到舱内/地面上人类被甩飞/鼻子流血/面部被风压变形——把抽象重量转化为具身体验 | 环太平洋独有 |
| 被推着走 | 巨物/机甲不主动移动，被怪兽拖行/摔/砸进建筑——主动=轻，被动=重 | 环太平洋独有 |
| 伤损可见 | 机甲每次挨打都掉零件——液压油喷射/装甲崩裂/火花飞溅/电路暴露。伤损跨镜累积 | 环太平洋独有 |

## 三、高度分级打斗规则

### 3.1 10m 以下轻战型机甲/怪物打斗

**不适用笨重感和压迫感规则。** 用写实格斗的因果链+速度感，但加入机甲/怪物的特色。

| 规则 | 说明 |
|------|------|
| 速度 | 可奔跑/跳跃/滑铲/S 形闪躲——因果链拳拳无间隔 |
| 蓄力 | 光刃/能量炮蓄力 0.5-1s 后爆发——蓄力瞬间用升格强调 |
| 特效 | 光刃轨迹、能量弹幕、推进器火焰、浓烟烟尘 |
| 运镜 | 可使用 ACT 命中推拉+QTE 切入——快节奏 |
| 环境反馈 | 浓烟扬起、地面龟裂、车辆被踢飞、建筑玻璃震碎 |
| 节奏 | 快切可用（0.3-0.5s/镜），长镜头仍是主力 |
| 比例参照 | 人类/车辆/房间——机甲站在街道上，脚边是正常尺寸的汽车 |

### 3.2 10-50m 中型打斗

**笨重感和速度感混合。** 全景时笨重，近景特写时可适当加速。

| 规则 | 说明 |
|------|------|
| 远景速度 | 每步 1-2s，出拳有蓄力和回弹 |
| 近景速度 | 切入跟随镜头/拳峰相机时速度感提升——但仍有明显惯性 |
| 蓄力 | 每次出拳/踢腿有 0.5s 蓄力——机械关节/肌肉蓄力清晰可见 |
| 环境反馈 | 建筑倒塌、地面凹陷、桥梁断裂——每次命中 = 至少一栋建筑受损 |
| 伤损 | 装甲崩裂、怪兽皮肤裂口渗出蓝血/绿血——跨镜累积 |
| 粒子密度 | 浓烟、碎石、火花、血雾——每帧都有悬浮粒子 |
| 比例参照 | 建筑/街道/桥梁——巨物手掌按在建筑上 = 手掌 = 3 层楼 |

### 3.3 50m+ 巨型打斗

**纯粹笨重感+压迫感。** 平方-立方定律强制执行。不可使用快切、不可使用 ACT 命中推拉。

| 规则 | 说明 |
|------|------|
| 速度 | 每步 2-5s，每个出拳包含完整蓄力→加速→命中→回弹循环（共 3-5s） |
| 蓄力 | 蓄力阶段占出拳总时长的 40%——甲壳/机械关节缓慢蓄力、冰壳碎裂、液压嘶鸣 |
| 命中 | 命中瞬间微冻结 0.3-0.5s + 升格——粒子密度达到峰值 |
| 环境反馈 | 每次命中 = 灾难级环境破坏：建筑群倒塌、地面炸裂数十米、海啸/雪崩/地震 |
| 伤损 | 巨物伤口以米计——裂口如地质裂缝，蓝血/岩浆喷涌 |
| 被动位移 | 巨物之间互相推、摔、拖行——"被推着走"才是重量感来源 |
| 粒子密度 | 每帧都有无数碎片、烟尘、水雾、火花悬浮——慢放时如银河 |
| 运镜 | 禁用快切、禁用 ACT 推拉——镜头只在拳峰相机/地面仰拍/人类 POV 之间切换 |
| 比例参照 | 建筑群/城市街区/山脉——巨物踩过 = 一条街消失 |

## 四、混合比例场景规则（v5.9 新增）

当一个 **50m+ 巨物** 与一个 **10m 以下轻战型机甲** 同时入镜时，必须同时凸显两种尺度感。

### 4.1 全景/远景——景别压缩法则

```
远景/全景时，两者的运动速度都被"拉远"的景别压缩——
巨物看起来极慢（每步 3-5s），机甲看起来也比近景时慢（每步 1-2s）。
比例参照必须同时存在——巨物脚下踩碎一排建筑，机甲在巨物脚边如昆虫。
```

### 4.2 近景跟随——机甲速度感释放

```
当镜头切入机甲的跟随镜头（贴脸过肩/第一人称 POV）时：
- 机甲恢复近景速度感——S 形闪躲巨物脚掌、滑铲穿过巨物腿间、蓄力爆发跳跃
- 巨物局部大特写同时入镜——巨腿/脚掌从画面外缓慢压入如黑色铁壁，
  速度极慢但力量感极强——每移动 1m 需 1s，但所过之处建筑粉碎
- 机甲近景的快 vs 巨物局部的慢——在同一画面中形成速度对比
```

### 4.3 混合场景运镜规则

| 景别 | 巨物呈现 | 机甲呈现 | 运镜 |
|------|---------|---------|------|
| 全景 | 全身慢速移动——如移动的山脉 | 在巨物脚边如昆虫——远景中速度也被压缩 | 地面仰拍+超广角 |
| 中景 | 局部缓慢压入——腿/脚掌/尾部遮天蔽日 | 机甲在巨物局部前闪躲/滑铲——近景速度感释放 | 机甲跟随镜头+巨物局部入镜 |
| 大特写 | 一只眼睛/脚掌占画面 85% | 机甲的渺小剪影投射在巨物表面 | 机甲 POV 仰拍 |
| 拳峰相机 | 巨物出拳——拳锋以 100mph 命中 | 机甲在拳锋前方极限闪避 | 拳峰相机 |

## 五、尺度参照物体系

| 巨物高度 | 参照物类型 | 在画面中的角色 |
|:---:|------|------|
| 3-10m | 人类、车辆、房间内部 | 人类与机甲面对面——机甲是人类的 5 倍 |
| 10-50m | 建筑、街道、桥梁 | 机甲手掌按在建筑上——手掌 = 3 层楼 |
| 50m+ | 建筑群、城市街区、山脉 | 巨物踩过——一条街消失 |

**每镜必含参照物**——缺参照物 = 巨物被生成为普通大小。

## 六、镜头与运镜

### 6.1 景别与运镜（焦段搭配表）

**核心原则：镜头焦段必须根据场景需求搭配使用，不是所有压迫感镜头都是超广角。**

**焦段选用决策流程（每镜必执行）**：

```
这镜的叙事目的？
├─ 建立空间关系 / 展示双兽位置 / 首次登场全身 ──→ 广角 24-28mm
├─ 展示巨物体型 / 正面 / 转身 / 中景（比例真实）──→ 标准 35-50mm
├─ 展示巨物局部细节 / 眼睛 / 鳞片 / 纹理 / 伤口 ──→ 长焦微距 85-135mm
├─ 展示人类面部 / 反应 / 瞳孔倒映（面部比例正常）──→ 中焦 85mm
├─ 极端压迫 / 头顶极近掠过 / 腿即将踩下 / 贴脸 ──→ 超广角 16-20mm
└─ 巨物出拳命中 / 拳锋视角（仅打斗）──────────→ 拳峰相机 14-20mm
```

**「贴地仰拍」不等于「超广角」**：贴地仰拍描述的是**相机高度**（放在地面/雪坑/脚后跟），焦段描述的是**镜头视野**。两者独立选择——可以是「贴地仰拍 + 长焦微距」来拍巨物眼睛，也可以是「贴地仰拍 + 广角」来展示全景空间。

| 焦段 | 等效焦距 | 适用场景 | 效果 | 使用频率 |
|------|:---:|------|------|:---:|
| 长焦微距 | 85-135mm | 巨物眼睛/鳞片/纹理大特写 | 压缩空间，突出细节——竖瞳占画面 85% | 每登场 2-3 镜 |
| 中焦 | 85mm | 人类面部/反应/瞳孔倒映 | 面部比例真实，不畸变——突出表情 | 每登场 1-2 镜 |
| 标准 | 35-50mm | 巨物正面/轉身/中景 | 比例真实，接近人眼所见——不扭曲不压缩 | 每登场 2-3 镜 |
| 广角 | 24-28mm | 登场全景/双兽对峙/远景建立 | 展示空间关系——翼展/全身/环境，不扭曲 | 每登场 1-2 镜 |
| 超广角 | 16-20mm | **仅**头顶极近掠过/腿即将踩下/贴脸压迫 | 极近距离压迫——巨物局部占画面 75-85%——**全场最多 2 镜** | 每登场 ≤2 镜 |
| 拳峰相机 | 14-20mm | 巨物出拳命中（环太平洋式） | 150mph 速度感 | 仅打斗 |

### 6.2 禁用规则

- **禁用漂浮镜头**：禁止无来源的空中全景（除非明确标注航拍/直升机视角）
- **50m+ 禁用快切**：快切在巨物战中不可用——巨物动作太慢，切快了观众看不懂
- **50m+ 禁用 ACT 命中推拉**：巨物不适合 4-8px 级快速推拉
- **禁用巨物全身照作为默认**：全身照仅在远景建立空间时使用 1 次

## 七、登场结构——五种模式 + 通用逻辑（v5.9 新增）

### 7.1 五种登场模式

**① 视引导式（Eye-line Guided）**
镜头从人类中景开始 → 人类视线被某物吸引抬头/转头 → 镜头顺视野方向摇移 → 先切入巨物局部（足部/尾部/腿部）→ 再缓缓向上揭示全身。悬念最足，最常见的哥斯拉式。

```
人类中景（2s）→ 人类转头/抬头（1s）→ 镜头顺视线摇至巨物足部/尾部（2s）→ 缓慢向上摇至全身（3s）
```

**② 表面扫描式（Surface Scan）**
镜头沿巨物表面（背部/腿部/头部）快速平移或横摇 → 持续扫描 2-3s 展示覆盖范围 → 镜头后拉露出整个头部/上身。突出"这东西大到一眼望不到边"。

```
镜头沿巨物腿部快速横摇（2s）→ 沿背部脊刺平移（2s）→ 镜头后拉——整个头部缓缓显露（2s）
```

**③ 过肩俯拍式（Over-the-Shoulder Aerial）**
从巨物肩部后方接近垂直的角度 — 俯拍下方 — 人类/车辆/建筑如蚂蚁。突出高度差和"你在他脚下"的渺小感。

```
巨物肩膀前景虚化→垂直俯拍→地面——建筑群如棋盘、人类如黑点（3s）
```

**④ 贴地仰拍式（Ground-Level Low Angle）**
从人类视角贴地仰拍——巨物局部（腿/脚掌/胸腹）占满整个画面。巨物不必完整入画——占满就够了。

```
贴地仰拍（1.5s）→巨物腿部占据画面 80%，天空被遮挡→阴影覆盖画面（1.5s）
```

**⑤ 混乱追逃式（Chaos Pursuit）**
参照物→巨物→反应→混乱四步完整链条。先通过参照物建立比例，再给巨物全身/上半身，切回人类反应（俯拍+阴影覆盖），然后跟随某人逃跑——身后巨物追赶、巨石/建筑碎片砸落。

```
参照物建立（2s）→ 巨物全身/上半身出现（3s）→ 俯拍人类反应+阴影覆盖（2s）→ 跟随逃跑者快速移动+背后巨物追赶+巨石砸落（4s）
```

### 7.2 通用逻辑——四条铁律

**逻辑 1：先参照物，再巨物**
永远不先给巨物。先给观众认识的东西（人/车/建筑/树木）→ 再通过对比引出巨物。

**逻辑 2：先局部，再整体**
先给足部→再腿部→再身体→最后头部。巨物从不"一步到位"出现在画面中。

**逻辑 3：巨物出现后必须切回人类反应**
不能一直看巨物。给完巨物后必须切回人类——从巨物的角度俯拍，人类渺小如蚁，或被阴影覆盖。这是压迫感的来源。

**逻辑 4：必须有环境破坏/碎片作为"力量证据"**
巨物走过的地方——建筑倒塌、地面炸裂、巨石砸落、雪崩/海啸。不是"它在走"，是"它走过的路都毁了"。

### 7.3 模式选用指南

| 场景 | 推荐模式 | 焦段 | 关键镜头 |
|------|---------|:---:|------|
| 首次登场+建立压迫感 | ④贴地仰拍 → ①视线引导 | 广角 24→标准 35 | 足部局部→缓缓上摇全身 |
| 展示巨物覆盖范围 | ②表面扫描 | 广角 24mm | 快速横摇 2-3s 展示表面 |
| 展示高度差+渺小感 | ③过肩俯拍 | 广角 24→长焦 135 | 肩部前景虚化+垂直俯拍 |
| 紧张追逃 | ⑤混乱追逃 | 广角 24+超广角 10 | 逃跑 POV+巨石砸落 |
| 双兽对峙 | ④贴地+①视线 | 广角 24→长焦 135 | 人类夹中间→双兽对视
