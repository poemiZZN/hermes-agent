# 运动/速度戏规则（Sports & Speed Action Rules）

> 供 `Basics-pro` 技能在生成运动/速度类戏份时调用。
> v5.1 新增：非战斗高速运动类型——滑板、跑酷、车追逐、冲浪、攀爬。

---

## 一、核心原则——对手是重力、速度、地形

运动戏和打斗的本质区别：**没有对手，只有障碍**。紧张感来自"会不会摔/撞/失控"，不是"会不会被打中"。

| 原则 | 说明 |
|------|------|
| **Trick 展示** | 核心不是"命中"，是"空中动作的完整展示"——起跳→空中旋转→落地 |
| **落地 = 命中** | 运动戏的"命中瞬间"是落地——脚踩滑板落地、车轮着地、手掌抓住岩壁 |
| **差点失败** | 制造"差点摔但稳住了"的瞬间——比完美落地更有紧张感 |
| **速度参照物** | 比打斗更需要环境参照物——护栏后退、地面纹理模糊、头发被风吹起 |
| **POV 镜头** | 运动戏的 POV 比打斗更重要——观众需要"体验"速度 |

## 二、子类型及镜头设计

### 2.1 滑板/BMX

**代表作品**：Lords of Dogtown、Tony Hawk 视频

**镜头设计**：
- GoPro 超广角贴地——轮子/板底特写，地面纹理在镜头下高速后退
- 无人机跟拍——从高空跟随滑板轨迹，展示地形全貌
- 慢动作 Trick——空中 ollie/kickflip 的 360° 多角度回放
- 落地特写——脚踩滑板落地的瞬间，板面震动，轮子着地

**动作设计**：起跳→空中旋转/翻转→落地→滑行，四阶段完整展示

**节奏**：滑行（中速）→ 起跳（慢动作）→ 空中（极慢）→ 落地（实时）→ 滑行（中速）

### 2.2 跑酷/楼顶跳跃

**代表作品**：District 13、Casino Royale 开场

**镜头设计**：
- 手持跟拍——镜头跟在跑者身后，模拟追逐感
- 广角夸张距离——楼顶之间的间隙在广角下看起来更宽更危险
- 落地缓冲特写——脚掌着地、膝盖弯曲缓冲、手掌撑地
- 俯瞰深渊——从跳跃者视角向下看，地面在远处

**动作设计**：助跑→起跳→空中→落地缓冲→继续跑，五阶段完整展示

**关键瞬间**：落地时脚滑了一下、手掌擦过墙壁边缘、碎石从楼顶边缘坠落

### 2.3 车/摩托追逐

**代表作品**：Baby Driver、Mission: Impossible - Fallout

**镜头设计**：
- 车内 POV——方向盘、仪表盘、前方道路
- 低角度贴地——车轮高速旋转、地面纹理模糊后退
- 后视镜特写——追击者出现在后视镜中
- 无人机俯拍——展示追逐路线和两车距离

**动作设计**：加速→过弯漂移→躲避障碍→再加速→近距逃脱

**速度参照物**：护栏快速后退、路灯被甩在身后、路面标线模糊

### 2.4 冲浪/滑雪

**代表作品**：Point Break、Free Solo

**镜头设计**：
- 无人机俯瞰——冲浪者在浪管中穿行
- 水下 POV——从浪底向上看，冲浪者在浪尖
- 慢动作浪花/雪雾——浪花破碎的瞬间、雪雾在阳光下闪烁
- 板底特写——冲浪板/滑雪板与水面/雪面的接触

**动作设计**：等待浪/雪→加速→切入→空中动作→落地→继续滑行

### 2.5 极限攀爬

**代表作品**：Free Solo、Mission: Impossible 2

**镜头设计**：
- 手指特写——指尖扣住岩壁裂缝，指关节泛白
- 俯瞰深渊——从攀爬者视角向下看，地面在数百米下方
- 碎石坠落——攀爬时踩落的碎石从岩壁坠落，消失在深渊中
- 全身远景——攀爬者在巨大岩壁上如蚂蚁

**动作设计**：寻找支点→发力→抓握→脚踩稳→向上移动，五阶段完整展示

**关键瞬间**：手指打滑、脚踩空、碎石坠落——制造"差点摔"的紧张

## 三、节奏弧线——滑行→Trick→落地→滑行

运动戏的节奏弧线是**循环式的**，不是打斗的线性推进：

```
① 滑行/助跑（2-3s，1镜）：建立速度——背景高速后退
② Trick/动作（2-4s，1-2镜）：空中动作——慢动作展示
③ 落地/收尾（1-2s，1镜）：落地缓冲——实时速度
④ 滑行/继续（2-3s，1镜）：回到滑行——准备下一个 Trick
```

**镜头时长基准**：

| 运动动作 | 单镜时长 | 原因 |
|---------|:---:|------|
| 滑行/助跑 | 2-3s | 建立速度感 |
| 空中 Trick | 2-4s | 慢动作展示——需要看清动作细节 |
| 落地缓冲 | 1-2s | 实时速度——落地瞬间的冲击力 |
| 差点失败 | 1-2s | 紧张的瞬间——不需要长 |
| 环境展示 | 2-3s | 建立空间——路线/地形/障碍 |

## 四、镜头与运镜

### 4.1 景别比例

| 景别 | 占比 | 用途 |
|------|:---:|------|
| 全景 | 20% | 地形展示 + 全身动作 |
| 中景 | 30% | 运动主体——滑板/跑酷/驾驶 |
| 大特写 | 30% | Trick 细节——脚/手/板/轮子 + 落地瞬间 |
| POV | 20% | 第一人称体验——滑板 POV、驾驶 POV、攀爬 POV |

### 4.2 运镜配对

| 运动动作 | 推荐运镜 | 原因 |
|---------|---------|------|
| 滑行/助跑 | 跟镜/无人机跟拍 | 与运动者同步，背景高速后退 |
| 空中 Trick | 子弹时间/多角度环绕 | 慢动作展示空中动作的每个角度 |
| 落地 | 贴地掠行/大特写 | 聚焦落地瞬间——脚踩板/轮子着地 |
| 差点失败 | 推近压迫 | 极速推进至打滑的手指/脚 |
| 环境展示 | 航拍/无人机俯瞰 | 展示路线和地形 |

## 五、自检

生成运动戏镜后检查：
- [ ] 每个 Trick 是否展示了完整的起跳→空中→落地三阶段？
- [ ] 是否至少制造了 1 次"差点失败"的瞬间？
- [ ] 每镜是否有至少 1 个速度参照物在高速后退？
- [ ] 是否穿插了 POV 镜头？（运动戏 POV 比打斗更重要）
- [ ] 落地瞬间是否有特写？（脚踩板/轮子着地/手掌抓握）
- [ ] 是否使用了慢动作展示关键 Trick？（不是全程慢动作，仅 Trick 部分）
