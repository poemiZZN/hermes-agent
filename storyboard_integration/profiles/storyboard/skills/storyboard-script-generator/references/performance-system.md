# 通用表演系统（Performance System）v5.6

> 供 `Basics-pro` 所有戏份类型模块调用。
> 本文件提供与戏份类型无关的通用表演核心能力——适用于对白戏、无声情绪戏、打斗戏、悬疑氛围戏等所有场景。

## 一、说话者表演七层分层

对白戏中，演员在说话时的表演不只是嘴在动。以下是七层递进式表演拆解，用于填写「动作表演」字段。

### 1.1 七层框架

```
说话者表演模板（每镜「动作表演」字段中使用）：
层级 1 — 眼睛：视线方向/焦点/瞳孔变化/眨眼频率/微跳动/眼神接触/视线游移路径（详见 §1.2.6）
层级 2 — 眉毛：眉形变化/眉间状态
层级 3 — 嘴巴：唇部动作/嘴角/牙关（说话时嘴在动，但唇形和嘴角独立于台词）
层级 4 — 呼吸：说话间隙的呼吸节奏/换气点/叹息
层级 5 — 头颈：头部倾斜/点头/摇头/下巴抬起或压低
层级 6 — 躯干：身体前倾/后仰/侧转/肩部松紧
层级 7 — 手势：手部动作/手指状态/是否接触物体或自身
```

### 1.2.5 情绪身体语言词汇库（v5.8 新增）

**核心原则**：真实人类在感受情绪时，身体会不由自主地产生反应——这些反应先于意识控制，是情绪最诚实的生理信号。面部可以伪装，但肩部的僵硬、手指的颤抖、身体的微缩——这些无法完全抑制。

以下按情绪类型分类的身体反应词汇，用于充实「动作表演」字段中层级 6（躯干）和层级 7（手势）的描述。

#### 愤怒

| 身体部位 | 下意识反应 | 描述词汇 |
|---------|----------|---------|
| 肩部 | 耸起→收紧→微颤 | 双肩上提至耳侧→肩胛骨收紧→三角肌紧绷→肩部微微发抖 |
| 手臂 | 绷紧→叉腰→交叉胸前 | 肱二头肌紧绷→双手叉腰（扩张领地）→双臂交叉抱胸（压抑愤怒） |
| 手部 | 握拳→松开→再握拳→指关节泛白→微颤 | 五指收紧成拳→指关节皮肤泛白→手腕微颤→突然松开再握紧 |
| 胸腔 | 扩张→起伏加剧 | 吸气时胸腔明显扩展→呼气急促→肋骨外翻→胸肌紧绷 |
| 颈部 | 颈肌凸显→青筋 | 胸锁乳突肌拉紧→颈侧血管可见→下巴前伸→头部微前倾 |
| 脊柱 | 挺直→前倾 | 脊柱从自然弯曲变为僵直→上半身前倾逼近对方 |
| 腿部 | 膝微屈→重心前移 | 双腿微分开与肩同宽→膝盖微屈→重心移至前脚掌→准备行动 |
| 脚部 | 跺脚→脚趾抓紧地面 | 脚跟抬起→前脚掌压地→脚趾弯曲抓地 |
| 全身 | 身体微微发抖 | 从手臂→肩膀→躯干，可见的细微高频震颤（肾上腺素释放的生理结果） |

#### 悲伤

| 身体部位 | 下意识反应 | 描述词汇 |
|---------|----------|---------|
| 肩部 | 下垂→内收→完全松弛 | 肩膀从自然位置下沉 2-3cm→肩胛骨外展→锁骨下沉→"被抽空了力气" |
| 手臂 | 下垂如死重→环抱自己 | 双臂从身体两侧自然下垂→像没有骨头的重量→或环抱自己腹部/胸口（自我安慰） |
| 手部 | 松开→无力→手指微蜷 | 手掌自然张开→手指无力微蜷→放在膝盖上不动→或抓起衣物一角揉搓 |
| 胸腔 | 内收→塌陷 | 胸骨下沉→肋骨内收→呼吸时胸腔起伏幅度减小→像被压了一块石头 |
| 颈部 | 低头→下巴贴胸 | 颈部前屈→下巴向胸口靠近→后颈暴露→头部沉重 |
| 脊柱 | 弯曲→蜷缩 | 脊柱从直立变为 C 形弯曲→上半身前倾→整个人向内收缩 |
| 腿部 | 膝弯曲→坐下/蹲下 | 膝盖微屈→身体重心下沉→靠墙滑坐→或直接蹲下抱住膝盖 |
| 脚部 | 脚趾微蜷→不动 | 脚趾向内蜷缩→双脚并拢→静止不动 |
| 全身 | 动作变慢→沉重 | 所有动作都比平时慢半拍到一拍→像在水中移动→起身困难 |

|---------|----------|---------|
| 肩部 | 耸起→乌龟反射→收紧 | 双肩向上向前耸起→像乌龟缩壳→肩部肌肉僵硬→三角肌紧绷 |
| 手臂 | 夹紧→抬起防御→抱胸 | 上臂紧贴身体两侧→前臂抬起护胸→或双臂交叉抱紧自己 |
| 手部 | 抓紧→指尖发白→颤抖 | 手指死死抓住最近固定物（桌/椅/扶手/自己衣襟）→指尖因缺血发白→手指微颤 |
| 胸腔 | 屏息→急促 | 吸气后胸腔膨胀→屏住呼吸→然后转为浅快呼吸→胸腔起伏频率↑深度↓ |
| 颈部 | 后缩→僵硬 | 头向后缩→下巴内收→颈部肌肉僵硬→颈动脉可见搏动 |
| 脊柱 | 后仰→僵直 | 上半身向后倾斜→脊柱僵直不弯→整个人像被钉在墙上 |
| 腿部 | 膝微屈→准备逃跑→或僵住 | 膝盖微屈→重心后移→准备后退→或完全僵住不能动 |
| 脚部 | 脚趾抓地→脚跟离地 | 脚趾弯曲抓紧地面→脚跟微抬→随时准备转身逃跑 |

#### 喜悦

|---------|----------|---------|
| 肩部 | 下沉→舒展→放松 | 肩膀从日常紧张位置自然下沉→肩胛骨后展→整个人"松一口气" |
| 手臂 | 张开→上举→挥舞 | 双臂从身体两侧自然展开→手掌向外→或上举过头顶→或轻微挥动 |
| 手部 | 展开→轻拍→捂嘴笑 | 手掌自然张开→手指分开→轻拍胸口/桌面/大腿→或捂嘴（因喜悦而害羞） |
| 胸腔 | 扩张→起伏加深 | 深吸气时胸腔充分扩展→呼气时胸腔缓慢回落→呼吸深而慢 |

#### 焦虑/紧张

| 身体部位 | 下意识反应 | 描述词汇 |
|---------|----------|---------|
| 肩部 | 耸起→反复耸肩 | 双肩不自觉地上提至耳侧→放下→再上提——循环动作，本人往往不自知 |
| 手臂 | 交叉→松开→再交叉 | 双臂反复交叉抱胸→放下→再交叉——寻求安全感的重复仪式 |

| 脚部 | 脚掌拍地→脚趾抓地松地交替 | 脚前掌反复轻拍地面→或脚趾在鞋内蜷缩→伸展→蜷缩 |
| 全身 | 坐立不安→反复调整姿势 | 在椅子上变换坐姿→前倾→后靠→侧坐→站起来→又坐下 |

### 1.2.6 眼睛的动态行为规则——让眼睛活起来（v5.8 新增）

**核心原则**：真人的眼睛永远不会完全静止。AI 生成的"完美凝视"之所以看起来假，正是因为眼睛太安静了——没有微跳动、没有自然的眨眼节奏、没有视线的细微游移。让眼睛活起来，就是在表演描述中加入这些"不完美"的生理真实。

#### 微跳动的视线（Microsaccades）

即使在凝视一个固定点时，人眼每秒也会有 2-3 次肉眼不可见的微跳动（microsaccades），以及持续极短的视线漂移。在表演描述中，不需要逐帧标注 microsaccade，但必须用以下方式传达"眼睛在活"：

| 凝视状态 | 描述方式 | 示例 |
|---------|---------|------|
| 专注凝视 | 视线锁定但眼内仍有微弱的动态——瞳孔以不可见的频率微调焦点 | "视线锁定对方左眼——瞳孔在锁定中仍有微弱的焦点跳动" |
| 放空凝视 | 视线方向固定但焦点在远处/近处之间漂移 | "视线朝向窗外——但焦点在窗玻璃上的雨滴和远处的街灯之间游移" |
| 思考中的凝视 | 视线看似固定但每隔 1-2s 有一次极微小的方向偏移 | "视线固定在桌面——焦点在笔尖和 3cm 外的水渍之间微移" |

#### 自然的眨眼节奏

| 状态 | 眨眼频率 | 描述 |
|------|:---:|------|
| 正常中性 | 每 3-4s 一次 | 眨眼流畅自然——上眼睑闭合 0.1-0.15s，不作停留 |
| 高度专注/凝视 | 每 5-8s 一次或更低 | 眨眼被有意识地抑制——眼睛干涩感逐渐积累 |
| 紧张/焦虑 | 每 1-2s 一次 | 眨眼频率明显升高——快速眨眼像是要"清除视野" |
| 情绪高潮 | 不眨眼 4-8s | 眼睛睁大→泪膜开始破裂→眼睑微颤——对抗不眨眼的意志力 |
| 说谎/隐瞒 | 眨眼频率突然升高后降低 | 说话前眨眼加快→说话时强行压制→说完后补偿性快速眨眼 |
| 思考/回忆 | 闭眼 0.3-0.8s | 不是眨眼——是主动闭眼阻断视觉输入以集中思考 |
| 释然/接受 | 一次极慢眨眼 0.5-1.0s | 像在内心说"算了"——闭眼时间远超正常眨眼 |
| 刚哭完/泪眼 | 眨眼频率升高至每 1.5s | 泪膜不稳定→需要频繁眨眼来重新铺平泪液 |

**书写规范**：每段「动作表演」中至少标注一次眨眼状态——不是每镜都要写，但如果连续 3 镜未提及眨眼/闭眼/眼动，必须检查是否有遗漏。

#### 视线的转动与游移——情绪驱动的眼球运动

人眼在不同情绪和认知状态下会有特定的眼球运动模式，这些是下意识且真实的：

| 状态 | 眼球运动模式 | AU 编码 | 典型场景 |
|------|------------|--------|---------|
| **回忆视觉信息** | 视线向上——左或右上 | AU63（眼球上转） | "那天你穿了什么颜色？"——回忆画面 |
| **回忆听觉信息** | 视线水平——左或右 | AU61/62（眼球左/右转） | "他说了什么？"——回忆声音 |
| **内部对话/自我交谈** | 视线向下——左下 | AU64（眼球下转） | 内心在跟自己辩论——"该不该说？" |
| **心算/逻辑思考** | 视线水平微移——通常向右 | AU62（眼球右转）+微移 | "如果我表白，有三种可能的结果…" |
| **情绪闪避** | 视线从对方眼睛快速移开→回到眼睛→再移开 | AU61↔AU62 交替 | 说谎者、害羞者、被质问者 |
| **威胁评估** | 视线在对方双眼和双手之间快速扫视 | AU61/62/63/64 交替 | 面对潜在攻击者——"他的手动了没有？" |
| **渴望/向往** | 视线锁定目标→缓慢从上到下扫视→回到眼睛 | AU64 缓慢下移→AU63 缓慢上移 | 暗恋者看着喜欢的人——从头看到脚再回到眼睛 |
| **迷茫/困惑** | 视线在空间中无目标游移——不聚焦任何东西 | AU61/62 慢速交替 | "我完全不知道该怎么办" |
| **突然警觉** | 视线猛然转向声源/运动方向 | AU61 或 AU62 快速跳转 | 听到身后有声音 |
| **厌倦/不耐烦** | 视线反复扫向出口/窗户/时钟 | AU61↔AU62 周期性转向一侧→回到当前→再转 | 开会时每分钟看一次门 |

#### 瞳孔的无声语言

瞳孔大小不受意识控制，是情绪最诚实的泄漏源：

| 状态 | 瞳孔变化 | 生理原因 | 表演描述 |
|------|---------|---------|---------|
| 兴趣/吸引 | 放大 10-30% | 交感神经激活——"想看清楚" | "瞳孔缓缓扩大——视线锁定对方，眼里像有光在扩散" |
| 恐惧/警觉 | 放大 20-50% | 肾上腺素释放——最大化光线进入 | "瞳孔猛然放大——眼睛在 0.2s 内从正常扩大到最大" |
| 愤怒/敌意 | 缩小 10-20% | 交感神经另一种反应——"聚焦目标" | "瞳孔微缩——眼神从柔和变为针尖般锐利" |
| 认知负荷 | 放大——与任务难度成正比 | 大脑需要更多信息 | "瞳孔随问题难度逐渐扩大——他在认真思考" |
| 说谎 | 瞳孔可能放大——取决于谎言的认知难度 | 编造谎言比说真话需要更多脑力 | "瞳孔在回答前 0.3s 短暂放大——认知负荷的泄漏" |
| 药物/酒精 | 放大或缩小 | 药理作用 | — |
| 光线变化 | 强光缩小，暗光放大 | 正常瞳孔光反射 | — |

**书写规范**：瞳孔变化与 AU5（上睑提升）配合使用——AU5 控制眼睑开合，瞳孔变化控制进入光线量。两者组合产生丰富的眼部表情：恐惧 = AU5(C) + 瞳孔放大，愤怒 = AU5(B) + 瞳孔缩小，爱慕 = AU5(A) + 瞳孔放大 + AU6(B)。

#### 眼睛动态书写格式

在「动作表演」字段中，眼睛的描写必须包含三层：

```
时间范围 眼睛：{视线方向/焦点}——{瞳孔变化}——{眨眼状态}
      【AU 校准：AU61-64（眼球方向）强度，AU5（上睑提升）强度，AU45（眨眼）频率】
```

**完整示例——暗恋者的凝视**：

```
动作表演（无声情绪——暗恋凝视，眼睛动态三层描写）：

0-2s [凝视建立] 眼睛：视线锁定画面左前方——他的侧脸——焦点在他右眼和嘴角之间以 2Hz 微移——瞳孔缓缓放大 15%——眨眼频率降至每 5s 一次——眼内泪膜开始不稳定但未到流泪程度
      【AU 校准：AU62（眼球右转）C 维持，AU5（上睑提升）A→B，AU45（眨眼）频率↓至 0.2Hz——专注凝视模式，瞳孔放大 = 兴趣/吸引】
      眼动细节：凝视中有不可见微跳动（2-3Hz）——视觉焦点在他眼部和唇部之间以 0.5Hz 低频切换

2-4s [念头闪过] 眼睛：视线从他侧脸移向画面外下方——焦点在虚空——瞳孔微微缩小——一次正常眨眼 0.15s——睁开后视线回到他侧脸但焦点比之前更柔和
      【AU 校准：AU64（眼球下转）B——视线下移想后果，AU5（上睑提升）B→A，AU45（眨眼）一次 0.15s——恢复正常，AU62（眼球右转）A→B——重新看向他但眼神已不同】
      眼动细节：下移→回到他身上的过程中，视线在他肩膀处短暂停留 0.3s——她在犹豫

4-6s [决定不说] 眼睛：视线从他侧脸缓慢收回——先移向他肩膀→再移向自己放在栏杆上的手——瞳孔恢复到正常大小——一次极慢眨眼 0.8s——像在内心说"算了"——睁开后视线停留在自己手上
      【AU 校准：AU62（眼球右转）B→0——离开他，AU64（眼球下转）B——看向自己手上，AU43（闭眼）一次 0.8s——决定点，AU5（上睑提升）A——正常状态，AU45（眨眼）恢复至 0.3Hz】
      眼动细节：从他→肩膀→栏杆→自己的手——视线在 1.5s 内的四步旅程，每一步都是一次犹豫
```

### 1.2.7 皮肤颜色变化描写——脸红的正确写法（v5.9.1 新增）

**核心原则**：Seedance 对颜色词的字面映射会导致「脸红=脸颊被涂成 Photoshop 色块」。真实的脸红是毛细血管扩张、血液从皮下透出的斑驳淡粉——不是均匀覆盖的颜料。

**四原则**：

1. **过程优先**：写「血色从皮下透出」「像被热气蒸过」而非「脸色变红」「渐变至深红」
2. **空间不均**：脸红不是整张脸同色——苹果肌最深、耳根渐淡、额头和下巴保持原色
3. **类比锁定**：用视觉类比（「像喝完半杯白酒」「被冬日冷风刮过后的淡粉」）替代颜色绝对值
4. **排他指令**：末尾附加否定锚定——「不是覆盖色块」「不是磨皮后的」「不是颜料涂上去的」

**词汇替换表**：

| 避免 | 推荐 |
|------|------|
| 深红、通红、涨红 | 温热淡粉、醉酒般的血色、半透明珊瑚色 |
| 渐变至X色 | 从皮下透出、不均匀散开、中心向外渐淡 |
| 满脸变红 | 颧骨、耳根、苹果肌——逐区扩散，额头下巴原色 |

**脸红模板**：

```
{角色名}面部血色变化（{持续时长}s）：
- 从{颧骨/耳根/鼻翼}开始——毛细血管扩张，血色从皮下透出
- 斑驳不均匀地扩散至{范围}——中心最深，边缘不规则渐淡
- {额头/下巴/太阳穴/人中}保持原肤色或仅微微泛粉
- 整体呈现被{热气/酒精/情绪}蒸过的温热淡粉，而非颜料覆盖
- 皮肤纹理和毛孔在红晕区域清晰可见——不是磨皮后的色块
```

**与光影联动**：脸红在不同色温下呈现不同质感——暖光（2800-3200K）下呈半透明琥珀色，被暖光融合；冷光（5600K+）下呈珊瑚色，与冷白皮肤对比；暗面中呈柔和玫红暗调。每镜「动作表演」和「画面描述」中描写脸红时，优先写「光线穿透扩张毛细血管后在皮肤表面的呈现」而非孤立颜色。

### 1.3 表演书写示例（双轨格式：自然语言 + AU 编码校准）

**书写规则**：每个时间段的表演描述先写自然语言（看得见的动作），再以 `【AU 校准】` 标注对应的 AU 编码和强度等级，用于精确校准和跨镜一致性验证。

```

0-2s 眼睛直视对方——瞳孔微缩，眼神锐利，不眨眼
      【AU 校准：AU5（上睑提升）B→C，AU7（眼睑收紧）B】

2-4s 眉间紧锁——眉心形成竖纹，眉尾下压，牙关逐渐咬紧——说话时嘴角下拉
      【AU 校准：AU4（降眉）C→D，AU23（唇收紧）C，AU15（嘴角下拉）B】

4-6s 身体前倾——重心从座椅后移向前，肩部上提，右手握拳——指关节泛白
      【AU 校准：AU57（头前移）C，躯干前倾——非面部 AU，以自然语言为主】

6-8s 鼻翼翕动——呼吸急促，胸腔起伏明显，说话间隙换气声加重
      【AU 校准：AU38（鼻孔扩张）C→D】
```

### 1.4 FACS AU 编码校准

FACS（Facial Action Coding System，面部动作编码系统）将面部所有可见肌肉运动拆解为 **Action Unit（AU）**。本章提供面向 storyboard 分镜的 AU 快速参考，用于在「动作表演」字段中为自然语言描述附加编码级精度校准。

**用途**：
- **精确度**：自然语言"眉间紧锁"→ AU4 强度 C，可量化可验证
- **Subtext 检测**：真笑 = AU6+AU12，假笑 = AU12 无 AU6——AU 编码是客观的"表演裂缝"指标
- **跨镜一致性**：S-01 AU4 强度 C，S-05 不能突然变成 AU4 强度 A——AU 编码可追踪
- **对接动画管线**：Blender/Maya 面部 rig、Metahuman ARKit blendshape 均可直接映射 AU

#### 1.4.1 强度等级

| 等级 | 标识 | 说明 | 可见度 |
|:---:|------|------|--------|
| A | Trace | 微弱——仅慢放或逐帧可见 | 几乎不可见 |
| B | Slight | 轻微——可察觉但不会引起注意 | 可察觉 |
| C | Marked | 明显——清晰可辨 | 清晰可见 |
| D | Severe | 强烈——面部显著变形 | 非常明显 |
| E | Maximum | 最大——肌肉收缩极限 | 极端 |

#### 1.4.4 双轨书写格式规范

**规则**：每段表演描述分为两行——
1. **自然语言行**：描述看得见的动作、变化和时序
2. **【AU 校准】行**：以 `【AU 校准：AU编码（中文名）强度等级】` 格式标注，多个 AU 用逗号分隔

```

      【AU 校准：AU编号（中文名）强度，AU编号（中文名）强度，...】
```

**完整示例——冲突对话中的情绪递进（面部 + 身体语言双轨）**：

```

```

### 1.5 情绪表情生命周期（起势→峰值→消退→衔接）

情绪表情**不是瞬间切换的**——每个表情都有完整的生命周期，正常表演中表情必须经历 onset→peak→offset 三个阶段，然后衔接到下一个表情的 onset。跳过任一阶段会产生机械感或"面瘫"感。

#### 1.5.1 四阶段模型

```
onset（起势）→ peak（峰值）→ offset（消退）→ transition（衔接到下一个表情的 onset）
```

| 阶段 | 说明 | AU 强度变化 | 可见特征 |
|------|------|-----------|---------|
| **onset（起势）** | 表情从无到有，肌肉开始收缩 | A→B→目标强度 | 表情浮现——从不可见到可察觉 |
| **peak（峰值）** | 表情达到最大强度并维持 | 目标强度 维持 | 表情最清晰——情绪最外显 |
| **offset（消退）** | 表情从峰值逐渐减弱 | 目标强度→B→A→0 | 表情退去——肌肉放松，面部恢复中立 |
| **transition（衔接）** | 前一个表情的 offset 与后一个表情的 onset 重叠 | 前 AU 消退 + 后 AU 起势 | 0.2-0.5s 的交叠窗口——表情切换的"呼吸间隙" |

**关键约束**：
- 任何表情都要经历完整的 onset→peak→offset 三阶段，**禁止 A→D 瞬间跳变**
- 前一个表情的 offset 必须与后一个表情的 onset 有时间上的交叠（transition 窗口），**禁止硬切**
- 同一时间面部可以同时存在两个表情的痕迹（前一个在消退，后一个在起势）——这正是"微表情"的自然来源

#### 1.5.2 各情绪类型典型阶段时长

| 情绪 | onset 时长 | peak 维持 | offset 时长 | 完整周期 | 说明 |
|------|:--------:|:--------:|:--------:|:--------:|------|
| 平静→微怒 | 0.5-1.0s | 1.0-3.0s | 0.5-1.5s | 2.0-5.5s | 愤怒渐进——需要时间让观众感受到情绪升级 |
| 微怒→暴怒 | 0.3-0.5s | 0.5-1.5s | 0.5-1.0s | 1.3-3.0s | 愤怒加速——已在情绪中，升级更快 |
| 平静→悲伤 | 1.0-2.0s | 2.0-5.0s | 1.0-2.0s | 4.0-9.0s | 悲伤慢起慢落——眼泪从酝酿到滑落需要物理时间 |
| 平静→恐惧 | 0.3-0.5s | 0.5-2.0s | 0.5-1.5s | 1.3-4.0s | 恐惧 onset 快但 offset 慢——肾上腺素消退需要时间 |
| 平静→喜悦 | 0.3-0.8s | 1.0-3.0s | 0.5-1.0s | 1.8-4.8s | 真笑 onset 快——但 offset 有残留（笑意余韵） |
| 愤怒→悲伤 | 0.5-1.0s | — | — | 0.5-1.0s transition | 情绪切换——愤怒的 offset 与悲伤的 onset 交叠 |
| 喜悦→困惑 | 0.3-0.5s | — | — | 0.3-0.5s transition | 快速切换——但仍有 transition 窗口 |

#### 1.5.3 特殊情况：允许加速 onset

以下情况可以缩短 onset 时长（但不跳过），因为生理上真实反应确实更快：

| 情况 | 加速 onset | 理由 |
|------|:--------:|------|
| **惊吓/震惊** | 0.1-0.2s | 生理惊恐反射——onset 极快，但 offset 仍慢（至少 0.5s） |
| **突然的物理疼痛** | 0.1-0.2s | 疼痛反射——onset 快，但 offset 随疼痛消退而缓慢 |
| **极度恐惧（生命威胁）** | 0.2-0.3s | 战斗/逃跑反应——onset 加速，但仍有起势 |
| **惊喜（正面）** | 0.2-0.3s | 正面惊喜——onset 快但较惊吓慢 |
| **被精准戳中痛处** | 0.2-0.3s | 心理冲击——onset 比一般愤怒快，但 peak 更短 |

**即使加速，也必须经历 onset→peak→offset 三个阶段**——只是 onset 从 0.5s 缩短到 0.1s，不是跳过。

### 1.6 表达规则——内心强度 ≠ 外显强度

**核心原则**：人感受到的情绪强度 ≠ 人表现出来的情绪强度。社会场景、权力关系、角色性格会让人对情绪表达进行四种调控。当前 skill 默认"内心强度 = 外显强度"，但真实表演中几乎从不如此。

#### 1.6.1 四种调控方式

| 调控方式 | 定义 | 内心强度 | 外显强度 | 典型场景 |
|---------|------|:---:|:---:|---------|
| **减弱 (de-amplify)** | 感受强烈但表现轻微 | D-E | B-C | 老板被下属顶撞、暗恋者不敢表现 |
| **放大 (amplify)** | 感受轻微但表现夸张 | A-B | C-D | 收到不喜欢的礼物还要笑、小孩摔倒求关注 |
| **中和 (neutralize)** | 感受强烈但面无表情 | C-E | A | 扑克脸、谈判、审讯、被公开羞辱时强装镇定 |
| **伪装 (mask)** | 用另一种情绪覆盖真实情绪 | 真实情绪 C-E | 伪装情绪 C-D | 输了比赛却笑、讨厌一个人却表现热情 |

#### 1.6.2 内心-外显强度映射表

| 场景 | 真实情绪 | 内心强度 | 调控方式 | 外显情绪 | 外显强度 | AU 差异 |
|------|---------|:---:|------|---------|:---:|------|
| 暗恋中想表白 | 渴望/紧张 | C | 减弱 | 嘴唇微启 | A | 内心 AU25(B)→外显 AU25(A) |
| 会议上被怼 | 愤怒 | D | 减弱 | 眉间微蹙 | B | 内心 AU4(D)→外显 AU4(B) |
| 收到烂礼物 | 失望 | B | 放大+伪装 | 夸张笑容 | C | 内心 AU15(B)→外显 AU12+6(C) |
| 被公开羞辱 | 羞耻/愤怒 | E | 中和 | 面无表情 | A | 内心 AU4+15(E)→外显 所有 AU≤A |
| 输了比赛面对镜头 | 崩溃 | D | 伪装 | 微笑 | C | 内心 AU1+15(D)→外显 AU12(C) |
| 看暗恋的人跟别人在一起 | 嫉妒 | D | 减弱 | 眼神变冷 | B | 内心 AU4+5(D)→外显 AU7(B) |

#### 1.6.3 表达规则书写格式

在「动作表演」字段中，当存在表达规则调控时，必须标注内心强度和外显强度的差异：

```
动作表演（表达规则：减弱——内心 C 级愤怒，外显 B 级）：
0-1.5s [内心] 愤怒在胸腔积聚——牙关咬紧至 C 级，指关节泛白，呼吸急促
      【AU 校准：内心 AU4(C) + AU23(C) + AU38(B)】
1.5-3s [外显] 但面部只释放了 B 级——眉间微蹙，嘴唇抿成一线，眼神变冷
      【AU 校准：外显 AU4(B) + AU23(B) + AU7(B)】
      【表达规则：减弱——内心 C 级 → 外显 B 级，差值 1 级，泄漏窗口：AU38 鼻翼微翕无法完全抑制】
```

#### 1.6.4 表达规则与 Subtext 泄漏

表达规则调控越强，Subtext 泄漏越有价值。以下泄漏窗口是表演的黄金时刻：

| 调控方式 | 泄漏窗口 | 表演特征 |
|---------|---------|---------|
| 减弱 | 0.3-0.5s 的 onset 瞬间——表情在达到外显 B 级之前，短暂闪过内心 C 级 | 眉间瞬间紧锁→立即舒展 |
| 中和 | 呼吸和手部无法完全抑制——面部 AU 全 A，但 AU38 鼻翼翕动、手指收紧 | 脸不动但手在抖 |
| 伪装 | 上半脸不容易伪装——嘴在笑但眼没笑（AU6 缺失），或眉间微蹙干扰微笑 | 最经典的 Subtext 泄漏 |

### 1.7 复合情绪——真实情绪不是单一标签

**核心原则**：真实场景中，人物很少只体验一种纯情绪。背叛感 = 悲伤 + 愤怒，嫉妒 = 愤怒 + 悲伤 + 恐惧，释然 = 悲伤 + 喜悦。当前词汇库和 AU 组合表都是单情绪模型，需要补充复合情绪的 AU 组合和表演规则。

#### 1.7.1 常见复合情绪 AU 组合

| 复合情绪 | 成分 | 上半脸 AU | 下半脸 AU | 典型场景 |
|---------|------|---------|---------|---------|
| **背叛感** | 悲伤 + 愤怒 | AU1(A) 眉头微扬 + AU4(B) 眉间紧锁 | AU15(B) 嘴角下拉 + AU23(B) 唇收紧 | "我以为你是我的朋友" |
| **劫后余生** | 恐惧 + 喜悦 | AU1+2(A) 残留眉扬 + AU6(B) 眼角微弯 | AU5(B) 瞳孔仍放大 + AU12(B) 嘴角上扬 | 差点被车撞→没事了 |
| **嫉妒** | 愤怒 + 悲伤 + 恐惧 | AU4(C) 眉间深锁 + AU5(B) 瞳孔放大 | AU15(B) 嘴角下拉 + AU7(B) 眼睑收紧 | 看到暗恋的人跟别人在一起 |
| **愧疚** | 悲伤 + 恐惧 | AU1(B) 眉头上扬 + AU5(B) 瞳孔放大 | AU64(B) 视线下垂 + AU15(A) 嘴角微垂 | "是我搞砸的" |
| **释然** | 悲伤 + 喜悦 | AU1(A) 眉头微扬→消退 + AU6(B) 笑意浮现 | AU15(B→A) 嘴角从下垂回升 + AU12(A→B) 微笑 onset | 告别——难过但知道这是对的 |
| **不甘** | 愤怒 + 悲伤 | AU4(C) 眉间紧锁 + AU1(A) 眉头微扬 | AU23(C) 唇收紧 + AU15(B) 嘴角下拉 | 努力了但还是输了 |
| **羞耻** | 恐惧 + 悲伤 | AU5(B) 瞳孔放大 + AU1(A) 眉头微扬 | AU64(C) 视线完全下垂 + AU54(B) 低头 | 在众人面前出丑 |
| **渴望** | 喜悦 + 恐惧 | AU6(B) 眼中有光 + AU5(B) 瞳孔放大 | AU12(B) 嘴角上扬 + AU25(A) 唇微启 | 暗恋者看着对方——想靠近又怕 |

#### 1.7.2 复合情绪的时间分布

复合情绪中不同成分不一定是同时 peak 的——它们可以在时间上错开：

| 复合情绪 | 时间分布 | 表演轨迹 |
|---------|---------|---------|
| 劫后余生 | 恐惧先 peak → 恐惧 offset → 喜悦 onset → 喜悦 peak | 瞳孔放大→身体僵住→呼吸恢复→笑出来 |
| 背叛感 | 悲伤先 peak → 悲伤 offset 中愤怒 onset → 愤怒 peak | 眼眶泛红→"为什么…"→眼神变冷→牙关咬紧 |
| 释然 | 悲伤 peak → 悲伤 offset 与喜悦 onset 交叠 → 喜悦 peak | 眼泪滑落→嘴角开始上扬→泪中带笑 |
| 嫉妒 | 恐惧+悲伤同时 peak → 愤怒 onset → 愤怒 peak | 瞳孔放大+嘴角下拉→眉间紧锁→眼神变冷 |

#### 1.7.3 复合情绪书写格式

```
动作表演（复合情绪：嫉妒——恐惧 + 悲伤 + 愤怒，时间错开）：
0-1.5s [恐惧+悲伤 同时 peak] 瞳孔放大——视线锁定画面左侧（他和她），嘴角下拉，嘴唇微启
      【AU 校准：AU5(B) + AU1(A) + AU15(B) + AU25(A)——恐惧+悲伤复合】

1.5-2.5s [悲伤 offset + 愤怒 onset 交叠] 嘴角从下拉转为抿紧，眉间开始紧锁，瞳孔从放大转为微缩
      【AU 校准：AU15(B→A) + AU4(A→B→C) + AU5(B→A)——transition：悲伤消退+愤怒起势】

2.5-4s [愤怒 peak] 眉间深锁，牙关咬紧，眼神锐利，嘴唇抿成一线
      【AU 校准：AU4(C) + AU23(C) + AU7(B)——愤怒主导，恐惧和悲伤已消退】
```

### 1.8 角色情绪基线——每个角色都有"中性状态"

**核心原则**：没有一个角色在中性状态下是所有 AU 为 0 的。每个角色都有一个"默认表情"——它反映了角色的性格底色、生活经历和当前状态。这个基线决定了所有情绪从什么起点开始、需要多大力度的 AU 变化才能"看出来"。

#### 1.8.1 四种基线类型

| 基线类型 | 中性面部 AU | 视觉特征 | 角色类型 | 情绪倾向 |
|---------|-----------|---------|---------|---------|
| **上扬型** | AU6(A) + AU12(A) | 眼角微弯、嘴角微扬——天生微笑脸 | 乐观/开朗/天真 | 喜悦 onset 只需 0.3s（从 A→B）; 悲伤需要 AU15 从 A→C 才能"看出来" |
| **下沉型** | AU15(A) + AU4(A) | 嘴角微垂、眉间微蹙——天生严肃脸 | 忧郁/深沉/经历过创伤 | 悲伤 onset 只需 0.3s（从 A→B）; 喜悦需要 AU12 从 A→C 才能"看出来" |
| **紧张型** | AU7(A) + AU23(A) | 眼睑微收、嘴唇微抿——天生紧绷脸 | 焦虑/谨慎/防御型 | 恐惧 onset 只需 0.3s; 放松需要 AU7+AU23 → 0 |
| **开放型** | AU5(A) + AU25(A) | 眼睛微睁、嘴唇微启——天生好奇脸 | 天真/外向/不设防 | 任何情绪 onset 都快（0.3-0.5s），但 offset 也快 |

#### 1.8.2 基线如何影响表演

同一个情绪（如"喜悦"），在不同基线的角色上需要不同的 AU 变化幅度：

| 情绪 | 上扬型基线 | 下沉型基线 | 差异 |
|------|----------|----------|------|
| 微笑 | AU12 从 A→B（+1 级）——几乎看不出来 | AU12 从 0→C（+3 级）——变化巨大，非常明显 | 下沉型角色笑一次，比上扬型角色笑十次更有冲击力 |
| 悲伤 | AU15 从 A→C（+2 级）——需要更大力度 | AU15 从 A→C（+2 级）——但基线已有 A，所以"看起来更悲伤" | 上扬型角色哭一次更有冲击力 |
| 愤怒 | AU4 从 0→C（+3 级）——正常 | AU4 从 A→C（+2 级）——更快到达 | 下沉型角色更容易"看起来在生气" |

#### 1.8.3 基线在书写中的使用

在「动作表演」字段中，当角色的基线影响情绪表达时，首镜必须标注基线类型：

```
动作表演（角色基线：下沉型——AU15(A) 嘴角微垂 + AU4(A) 眉间微蹙）：
0-1.5s [onset·喜悦——从下沉基线出发] 嘴角从 A 级微垂上扬至 B 级——对下沉基线的她来说，这已经是"很大的笑容"
      【AU 校准：AU15(A→0) + AU12(0→B)——从下沉基线到微笑，变化幅度 +3 级】
```

### 1.9 呼吸系统——情绪与表演的生理桥梁

**核心原则**：呼吸是唯一一个既受自主神经控制、又能被意识调节的生理系统。它是情绪和表演之间的桥梁——情绪通过呼吸外化为可见的身体变化，演员通过呼吸控制来塑造表演。

#### 1.9.1 六大呼吸模式

| 呼吸模式 | 情绪对应 | 生理特征 | 可见变化 | AU 关联 |
|---------|---------|---------|---------|---------|
| **叹息式** | 释然/放弃/悲伤回落 | 深吸→屏息 0.5s→长呼 1.5s | 胸腔起伏一次→肩膀下沉 | AU25(A) 呼出时唇微启，AU38(B→A) 鼻孔扩张后收缩 |
| **屏息式** | 恐惧/紧张/集中注意力 | 吸气后停滞 1-3s | 胸腔膨胀→静止→身体不动 | AU5(C) 上睑提升，AU26(A) 下巴微坠——嘴微张但屏息 |
| **浅快式** | 焦虑/愤怒酝酿 | 频率↑至 0.3s/次，深度↓ | 胸腔起伏快但幅度小 | AU38(B→C) 鼻翼翕动，AU23(B) 唇收紧 |
| **颤抖式** | 悲伤/恐惧高潮 | 呼气不平稳——频率和深度波动 | 呼气时胸腔抖动 | AU25(A) 唇微启，呼出时嘴唇微颤 |
| **吞咽式** | 克制/咽回去 | 喉结滚动→屏息→恢复 | 颈部可见吞咽动作 | AU26(A) 下巴微坠→AU23(A) 唇微抿 |
| **深慢式** | 平静/冥想/极度放松 | 频率↓至 0.2Hz，深度↑ | 胸腔缓慢大幅起伏 | 所有 AU 趋近基线——面部最放松 |

#### 1.9.2 呼吸在情绪生命周期中的位置

呼吸不是独立于表情的——它在生命周期的每个阶段有不同表现：

| 生命周期阶段 | 呼吸特征 | 与 AU 的关系 |
|------------|---------|------------|
| onset | 呼吸频率变化先于表情变化——表情还没出来，呼吸已经变了 | 呼吸是情绪的"前奏"——AU38 鼻翼变化先于 AU4 眉间变化 |
| peak | 呼吸模式与 AU 强度同步 peak | AU38 鼻翼翕动与 AU4 眉间紧锁同时达到最大 |
| offset | 呼吸恢复比 AU 恢复慢——表情已经没了，呼吸还在喘 | AU 已消退但 AU38 仍在 B 级——这是情绪残留的生理证据 |
| transition | 前一个情绪的呼吸模式尚未完全恢复，后一个情绪的呼吸模式已经开始 | 两种呼吸模式在 0.5-1s 内交叠——与 AU transition 同步 |

#### 1.9.3 呼吸可被意识控制——表演视角

演员可以通过呼吸控制来"表演"情绪，即使内心没有这个情绪：

| 表演目标 | 呼吸控制 | 效果 |
|---------|---------|------|
| 表演"紧张" | 自主加快呼吸频率→浅快式 | 身体会真的产生紧张感——生理反馈 |
| 表演"平静" | 自主做一次深慢呼吸→深慢式 | 从浅快式中恢复——观众看到角色"冷静下来了" |
| 表演"咽回去" | 自主做吞咽+屏息 | 话到嘴边咽回去了——这是可主动执行的表演动作 |
| 表演"释然" | 自主做一次叹息式呼吸 | 肩膀下沉+长呼=观众收到"放下了"的信号 |

### 1.10 触发源类型对表情 onset 的影响

**核心原则**：表情的 onset 速度不仅取决于情绪类型，还取决于**触发源的性质**。外部突发、内部认知、他人影响——不同触发源产生不同的表情 onset 轨迹。

#### 1.10.1 五种触发源

| 触发源 | onset 特征 | 全身反应 | 例子 | 表演规则 |
|--------|-----------|---------|------|---------|
| **外部突发** | 极快 onset 0.05-0.2s + 全身同步反应 | 面部+身体同时僵住/后仰 | 爆炸声、突然的巨响、被人从背后拍肩 | 惊吓反射——onset 极快，面部和身体不可分割 |
| **外部渐进** | 慢 onset 0.5-2s + 逐步加强 | 身体先警觉，面部后变化 | 慢慢走近的脚步声、逐渐变暗的光线 | 听觉/视觉线索先触发身体反应，面部滞后 0.3-0.5s |
| **内部认知** | 中速 onset 0.3-0.8s + 眼睛先有反应 | 瞳孔先变化，然后嘴角，最后身体 | 突然想通一件事、意识到被骗了 | 瞳孔先放大/缩小→嘴角再变化→身体再反应 |
| **内部回忆** | 慢 onset 0.5-1.5s + 视线先放空 | 视线先放空→表情渐变→身体静止 | 想起往事、回忆涌上心头 | 视线放空是 onset 的第一个信号——AU64 或 AU61/62 先动 |
| **他人影响** | 中速 onset 0.3-0.5s + 视线驱动 | 先看到对方→视线反应→面部反应 | 看到对方表情变化、对方说了某句话 | 视线和瞳孔先反应（AU61/62 + AU5），然后才是自己的表情 |

#### 1.10.2 触发源与 1.5.3 加速 onset 的关系

触发源类型决定了 onset 的基线速度，1.5.3 的"加速 onset"是在触发源基线之上的进一步加速：

| 触发源 | 基线 onset | 叠加惊吓 | 叠加疼痛 | 叠加生命威胁 |
|--------|:---:|:---:|:---:|:---:|
| 外部突发 | 0.05-0.2s | 0.05s | 0.05s | 0.05s |
| 外部渐进 | 0.5-2s | 0.3-0.5s | 0.2-0.3s | 0.2-0.3s |
| 内部认知 | 0.3-0.8s | — | — | — |
| 内部回忆 | 0.5-1.5s | — | — | — |
| 他人影响 | 0.3-0.5s | 0.2-0.3s | 0.2-0.3s | 0.2-0.3s |

### 1.11 不对称性规则——真实情绪的签名

**核心原则**：FACS 的核心发现之一——真实情绪往往左右不对称，刻意表演的表情往往左右对称。这是因为大脑两半球对情绪的控制不对称，而意识控制的表情倾向于对称。

#### 1.11.1 不对称性 AU 表

| 情绪 | 真实表达（不对称） | 刻意表演（对称） | 不对称特征 |
|------|----------------|---------------|-----------|
| 微笑 | AU12 左 B / 右 A——左侧嘴角上扬更多 | AU12 左 B / 右 B——完全对称 | 真实微笑左侧更强（右脑控制） |
| 愤怒 | AU4 左 C / 右 B——左侧眉间更紧 | AU4 左 C / 右 C——完全对称 | 真实愤怒左侧更强 |
| 轻蔑 | AU12 仅右侧 A——单侧嘴角上扬 | AU12 双侧 A——对称 | 轻蔑天然不对称——单侧是核心 |
| 悲伤 | AU1 左 B / 右 A——左侧眉头更上扬 | AU1 左 B / 右 B——对称 | 真实悲伤左侧更强 |
| 恐惧 | AU5 左 C / 右 B——左眼比右眼睁得更大 | AU5 左 C / 右 C——对称 | 真实恐惧不对称，但差异较小 |
| 假笑 | AU12 左 B / 右 B——完全对称 + AU6 缺失 | AU12 左 B / 右 B——完全对称 | 假笑对称 + 无眼笑——双重证据 |

#### 1.11.2 不对称性规则

| 规则 | 说明 |
|------|------|
| **真实情绪默认不对称** | 除非有特殊理由，真实情绪表达中 AU 左右强度差 1 级（如左 B / 右 A） |
| **刻意表演默认对称** | 角色在"表演"一个情绪时（如假装开心），AU 左右对称 |
| **轻蔑天然不对称** | 轻蔑（AU12 或 AU10 单侧）本身定义就是不对称的——双侧就不是轻蔑了 |
| **Subtext 黄金规则** | 当角色试图伪装情绪时，对称的表情 + 但某个 AU 出现不对称泄漏 = 伪装被识破 |
| **强度越高越不对称** | 情绪强度越高，左右不对称越明显——A 级几乎对称，E 级明显不对称 |

#### 1.11.3 不对称性书写格式

在 AU 校准中，用 L/R 标注左右差异：

```
【AU 校准：AU12 L(B)/R(A)——左侧嘴角上扬更多，真实微笑的不对称签名】
【AU 校准：AU4 L(C)/R(B)——左侧眉间更紧，真实愤怒的不对称签名】
【AU 校准：AU12 L(B)/R(B)——完全对称 + AU6 缺失 = 假笑】
```
