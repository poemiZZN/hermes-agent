## 一、动作节拍计时模型（Action Beat Timing）

当镜头不含对白、以打斗/动作为主时，**不再使用第 3 步的对话驱动计时公式**，改用以下节拍计时模型：

### 1.1 核心公式

```
动作镜头时长 = 动作播报时长 + 缓冲时长

动作播报时长 = Σ（每个微节拍的标准时长）
缓冲时长 = 0.3 ~ 0.8s（动作起势/收势/呼吸）
```

### 1.2 动作微节拍标准时长基准

| 动作类型 | 标准时长 | 细分 | 说明 |
|---------|---------|------|------|
| **拳击/掌击** | 0.3 ~ 0.5s | 出拳 0.2s + 命中 0.1s + 收拳 0.2s | 直拳快于摆拳，近身快于远距 |
| **踢击** | 0.5 ~ 0.8s | 起腿 0.2s + 命中 0.1s + 落地 0.3s | 高踢慢于低扫，回旋踢取上限 |
| **武器挥砍** | 0.4 ~ 0.6s | 起势 0.15s + 轨迹 0.2s + 命中 0.1s + 收势 0.15s | 轻重武器差异：匕首 0.3s，双手剑 0.7s |
| **武器刺击** | 0.2 ~ 0.4s | 蓄力 0.1s + 刺出 0.1s + 命中 0.05s + 抽回 0.15s | 短兵器最快，长枪/矛偏慢 |
| **格挡/招架** | 0.3 ~ 0.4s | 架招 0.15s + 碰撞 0.1s + 卸力 0.15s | 武器碰撞可延长至 0.5s |
| **闪避/翻滚** | 0.5 ~ 0.8s | 预判 0.15s + 位移 0.35s + 复位 0.3s | 侧闪快于翻滚，翻滚取上限 |
| **受击反应** | 0.4 ~ 0.7s | 冲击 0.1s + 身体后仰 0.3s + 落地/撞墙 0.3s | 轻击取 0.4s，重击/抛飞取 0.7s |
| **倒地/起身** | 0.8 ~ 1.2s | 倒地 0.4s + 停顿 0.2s + 起身 0.6s | 受伤起身取上限 |
| **投掷/摔技** | 0.8 ~ 1.2s | 抓取 0.3s + 发力 0.3s + 落地 0.6s | 过肩摔/抱摔 |

### 1.3 连击间隔与节奏

| 连击类型 | 间隔 | 镜头策略 |
|---------|------|---------|
| **快速连击（2-3 击）** | 0.15 ~ 0.25s | 单镜头内完成，手持微抖运镜 |
| **中速连击（3-4 击）** | 0.2 ~ 0.3s | 可单镜，或用快切拆分为 2 镜 |
| **长连击（5+ 击）** | 0.2 ~ 0.3s | 必须用快切拆分，每 2-3 击 = 1 镜 |
| **招式间喘息** | 0.5 ~ 1.0s | 独立镜头，中近景/特写，人物呼吸/眼神 |
| **重击后的停顿** | 0.3 ~ 0.5s | 冻结帧或慢动作，打击感最强时刻 |

### 1.4 计算示例

**示例 1：三连击快切**
```
动作：直拳 → 上勾拳 → 回旋踢
微节拍：0.4s（拳1）+ 0.15s（间隔）+ 0.4s（拳2）+ 0.2s（间隔）+ 0.7s（踢）
动作播报时长：1.85s
拆分为 3 个快切镜头：
  S-X.1-01 直拳特写：0.4 + 0.3 = 0.7s → 取 1.0s
  S-X.1-02 上勾拳仰拍：0.4 + 0.3 = 0.7s → 取 1.0s
  S-X.1-03 回旋踢全景：0.7 + 0.3 = 1.0s → 取 1.5s
```

**示例 2：武器交锋**
```
动作：A 挥砍 → B 格挡 → A 变招刺击 → B 闪避 → 双方对峙喘息
微节拍：0.5s（砍）+ 0.4s（挡）+ 0.3s（刺）+ 0.6s（闪）+ 0.8s（喘息）
动作播报时长：2.6s
镜头规划：
  S-X.1-01 交锋碰撞特写（砍+挡）：0.5 + 0.4 + 0.3 = 1.2s → 取 1.5s
  S-X.1-02 刺击+闪避全景：0.3 + 0.6 + 0.3 = 1.2s → 取 1.5s
  S-X.1-03 对峙中近景（喘息）：0.8 + 0.5 = 1.3s → 取 2.0s
```

## 二、打斗节奏弧线（Fight Rhythm Arc）

每一场打斗戏必须遵循 5 段式节奏弧线，确保打斗不是"一堆动作镜头的随机排列"：

### 2.1 五段式结构

```
┌─────────────────────────────────────────────────────┐
│ ① 起势 Beat        │ 对峙/蓄力/空间建立              │
│    1-2 镜，3-6s    │ 中景+全景，低机位仰拍，环境音    │
├─────────────────────────────────────────────────────┤
│ ② 交锋 Beat        │ 首次攻击/试探/先手               │
│    2-3 镜，4-8s    │ 快切为主，动作镜头 §5 交锋类      │
├─────────────────────────────────────────────────────┤
│ ③ 升级 Beat        │ 加速/连击/武器切换/局势变化       │
│    3-5 镜，6-12s   │ 快切+特写，连击追踪，节奏加速     │
├─────────────────────────────────────────────────────┤
│ ④ 高潮 Beat        │ 致命一击/绝招/逆转               │
│    2-3 镜，3-8s    │ 慢动作/冻结帧/打击感镜头          │
├─────────────────────────────────────────────────────┤
│ ⑤ 收尾 Beat        │ 胜负落定/喘息/情绪回落           │
│    1-2 镜，3-6s    │ 中近景/特写，手持/空镜余韵        │
└─────────────────────────────────────────────────────┘
```

### 2.2 各 Beat 的镜头设计要点

**① 起势 Beat（对峙/蓄力）**
- 景别：中景→全景，建立空间关系与人物位置
- 运镜：低机位仰拍（压迫感）+ 环绕镜头（空间建立）
- 时长：2-3 镜，单镜 2-3s，总计 3-6s
- 音效：环境底噪（风声、水滴、心跳），低频渐强
- **必须标明**：人物站位、朝向、距离，确保后续镜头空间一致

**② 交锋 Beat（首次攻击/试探）**
- 景别：中近景→特写，聚焦攻击者
- 运镜：侧向切入 + 贴地掠行 + 斜向俯冲
- 时长：2-3 镜，单镜 1.5-2.5s，总计 4-8s
- 转场：切（硬切），首尾帧对齐攻击方向

## 三、动作编辑节奏（Action Editing Rhythm）

### 3.1 快切（Rapid Cut）在打斗中的使用

快切是打斗戏的核心剪辑手法，但必须遵循以下规则：

| 规则 | 说明 |
|------|------|
| **每镜 1 个动作** | 每镜只展示 1 个打击/受击/闪避动作，不堆叠 |
| **时长递减** | 升级 Beat 中每镜时长递减：2.0 → 1.5 → 1.2 → 1.0s |
| **方向一致性** | 连续快切中，攻击方向必须一致（左→右 或 右→左），不可跳轴 |
| **冲击停顿** | 每 3-4 个快切后插入 1 个 0.5-1.0s 的短停顿（反应镜/道具近景） |
| **禁止切碎** | 单个动作（如一次挥拳）不能被切碎成多镜——一次完整的起→落 = 1 镜 |

### 3.2 动-静-动节奏（打斗版）

```
连续 3-4 个动作镜 → 1 个静态反应镜 → 连续 3-4 个动作镜 → 1 个静态反应镜 → ...
                       ↑                                    ↑
              呼吸窗口/喘息镜                        呼吸窗口/喘息镜
```

**静态反应镜类型**：
- 攻击者面部特写（眼神/咬牙/汗水）
- 受击者反应特写（痛苦/惊恐/血液）
- 关键道具近景（武器震颤/地面裂纹/飞溅碎片）
- 环境空镜（尘埃/血滴/光影）

### 3.3 速度变化（Speed Ramp）

仅在 ④ 高潮 Beat 中使用，不用于常规打斗：

| 速度变化类型 | 用法 | 效果 |
|------------|------|------|
| **慢动作（0.3-0.5×）** | 高潮 Beat 的致命一击瞬间 | 强调打击感，放大冲击力 |
| **冻结帧（静止 0.3-0.5s）** | 命中最强瞬间 | 最强打击感，类似漫画定格 |
| **加速（1.5-2.0×）** | 起势→交锋过渡 | 仅在过渡镜使用，不用于主体动作 |

## 四、动作音效词汇库（Action Sound Design）

### 4.1 四类动作音效

| 类别 | 典型音效 | 频率范围 | 声压级 | 说明 |
|------|---------|---------|--------|------|
| **打击音效** | 拳肉碰撞 | 60-200Hz | 85-95dB | 低频闷响，拳击袋质感 |
| | 骨裂声 | 100-400Hz | 90-100dB | 脆裂感，短促 |
| | 金属撞击 | 2-8kHz | 90-105dB | 高频尖锐，余音 0.3-0.5s |
| | 身体砸地 | 40-150Hz | 88-95dB | 重物落地，低频为主 |
| **空间音效** | 拳风掠过 | 200-800Hz | 70-80dB | whoosh，0.2-0.3s |
| | 武器破空 | 500-2kHz | 75-85dB | 金属质感嗖声 |
| | 脚步擦地 | 100-500Hz | 60-70dB | 沙沙声，急促 |
| | 衣物摩擦 | 200-1kHz | 55-65dB | 近身缠斗 |
| **生理音效** | 心跳加速 | 40-80Hz | 后台混入 | 低频脉冲，BPM 递增 |
| | 呼吸急促 | 200-600Hz | 60-70dB | 喘息声，频率递增 |
| | 耳鸣高频 | 4-8kHz | 65-75dB | 受重击后，持续 0.5-1.0s |
| | 血液滴落 | — | 55-65dB | 环境音，间歇性 |
| **冲击音效** | 墙壁开裂 | 50-300Hz | 85-95dB | 低频轰鸣 + 高频碎裂 |
| | 玻璃碎裂 | 2-6kHz | 85-95dB | 高频清脆碎裂 |
| | 地面震动 | 20-80Hz | 80-90dB | 次低频，全身震动感 |

### 4.2 音效字段填写格式（打斗版）

```
音效：{节拍段} {动作音效}（{频率}Hz·{持续时长}s·{声压}dB）+ {环境/生理音效}（{频率}Hz·{混响特征}）；严禁BGM
```

**示例**：
```
音效：0-0.5s 拳风掠过（350Hz·0.3s·75dB），0.5-0.7s 拳肉碰撞（120Hz·0.2s·90dB）+ 心跳加速（60Hz·后台脉冲·BPM 90→120）；严禁 BGM
```

## 五、多人物打斗空间规则（Multi-Fighter Spatial Rules）

### 5.1 180° 轴线（打斗版）

在打斗场景中，180° 轴线的定义与文戏不同：
- **攻击轴线**：攻击者 → 受击者 连线即为 180° 轴线
- **同一轮交锋**：所有镜头必须在轴线同一侧
- **换轴条件**：仅当一轮交锋结束（喘息/对峙）、角色位置发生明确变化后，才可重新建立轴线
- **换轴时必须用中性镜头过渡**：正面全景/俯拍/环境空镜，不可直接跳轴

### 5.2 混战位置锚定

当 3 人以上混战时：
- **首镜建立空间地图**：全景/鸟瞰，标注所有人物位置（A 左前、B 右前、C 后中）
- **每镜标注人物朝向**：所有出场人物必须用「人物站位」字段标注朝向目标
- **武器/飞行道具轨迹**：连续镜头中，武器/飞行道具的飞行方向必须一致，不可突然反向
- **位置微调规则**：同一镜头内，人物位置可因打斗发生赛璐珞级位移（2-3 步），但不可跨越大半个场景

### 5.3 双人打斗的镜头切换节奏

```
A 攻击（特写）→ B 受击（特写）→ A 追击（中近景）→ B 格挡（特写）
→ 武器碰撞（大特写）→ A 被反制（全景）→ 双方对峙（中景）
```

**规则**：
- 攻击者和受击者特写交替出现，节奏均匀
- 每 3-4 个特写/大特写后插入 1 个中景/全景建立空间关系
- 武器碰撞等关键瞬间必须用大特写

## 六、竖屏 9:16 动作场景专属指南

### 6.1 竖屏运镜放宽

v3.6 中"竖屏 9:16 运镜幅度小"的规则**不适用于动作打斗场景**。竖屏动作内容可使用的运镜：

| 竖屏动作运镜 | 用法 | 示例 |
|------------|------|------|
| **纵向跟拍** | 人物向镜头方向冲刺/跳跃 | 从全景急速推至特写，配合纵向空间压缩 |
| **90° 翻转** | 角色倒地/翻滚时画面旋转 | 人物倒地瞬间画面横转 90°，增强失重感 |
| **贴地仰拍** | 低机位仰拍人物腾空/跳跃 | 镜头贴地，人物从画面底部跃出顶部 |
| **垂直甩镜** | 攻击自上方/下方袭来 | 镜头快速上甩或下甩，方向与攻击一致 |
| **手持剧烈晃动** | 近身缠斗/地面格斗 | 手持晃动幅度 2-3× 文戏标准，频率 1-2Hz |

### 6.2 竖屏打斗构图

| 构图方式 | 适用场景 | 说明 |
|---------|---------|------|
| **纵向纵深** | 追击/冲刺 | 人物从画面底部冲入，向顶部纵深推进 |
| **上下对峙** | 高低位战斗 | 攻击者在上 1/3、受击者在下 2/3（或反向） |
| **对角线** | 武器交锋 | 两把武器沿左上→右下 或 右上→左下 斜线碰撞 |
| **中心冲击** | 命中瞬间 | 碰撞点置于画面正中，四周留出血/碎片飞溅空间 |

## 七、动作场景自检清单

生成打斗镜头后，追加以下 10 项检查（在原有 12 项自检之后）：

1. [ ] 每镜时长是否按动作节拍计时模型计算（而非对话公式）？
2. [ ] 是否存在完整的 5 段式打斗节奏弧线（起势→交锋→升级→高潮→收尾）？
3. [ ] ③ 升级 Beat 的镜头时长是否呈递减趋势（加速感）？
4. [ ] ④ 高潮 Beat 是否至少包含 1 镜慢动作或冻结帧？
5. [ ] 快切镜头中，每镜是否只包含 1 个完整动作（不切碎单动作）？
6. [ ] 每 3-4 个动作镜后是否有 1 个静态反应镜（喘息窗口）？
7. [ ] 多人物打斗中，180° 轴线是否在每轮交锋内保持一致？
8. [ ] 混战首镜是否建立了空间地图（全景/鸟瞰）？
9. [ ] 音效字段是否按动作音效四类（打击/空间/生理/冲击）精确填写？
10. [ ] 竖屏场景是否使用了放宽后的动作运镜（纵向跟拍/90°翻转/贴地仰拍等）？
11. [ ] **写实打斗自检（v3.9 新增）**：剧本是否包含超自然元素？如否，所有镜头中是否存在冲击波/能量环/光效等超现实视觉描述？必须全部清除，替换为拳拳到肉的写实表达（肌肉凹陷/汗珠飞溅/画面微震/皮肤泛红）

## 八、写实打斗 vs 特效打斗（v3.9 新增）

**默认原则：除非剧本明确描述超自然/魔法/异能元素，否则所有动作打斗场景一律按写实风格生成。禁止在普通武术/格斗戏中添加冲击波、能量环、光效等超现实视觉元素。**

### 8.1 写实打斗的视觉语言

写实打斗的冲击力通过以下**可拍物理量**传达，而非视觉特效：

| 视觉元素 | 写实表达 | 禁止 |
|---------|---------|------|
| **命中瞬间** | 拳面/脚面陷入肌肉——皮肤凹陷+衣料褶皱；画面微震（镜头抖动 2-6px） | ❌ 冲击波环形扩散 |
| | 汗珠/唾液从受击者面部甩出——逆光中呈金色光点 | ❌ 能量光效 |
| | 受击者身体局部变形——脸颊肌肉被拳锋挤压变形 | ❌ 光晕/辉光冲击 |
| **碰撞点** | 皮肤泛红/淤青即时出现（皮下毛细血管破裂） | ❌ 发光碰撞点 |
| | 衣料在命中点向内凹陷——纤维纹理被压缩 | ❌ 魔法纹路 |
| **飞溅物** | 汗珠、沙土、尘土——真实物理粒子 | ❌ 能量粒子/光点 |
| | 唾液/血沫（仅重伤时） | ❌ 彩色光尘 |
| **音效** | 拳肉碰撞——低频闷响（60-120Hz），短促（0.1-0.2s） | ❌ 科幻/魔法音效 |
| | 骨骼/关节响声——中频（200-500Hz）脆响 | ❌ 能量嗡鸣 |
| **画面震动** | 命中时镜头微震（2-6px抖动），命中后立即恢复 | ❌ 持续震动/余震波纹 |
| **身体反应** | 肌肉震颤、皮肤泛红、呼吸急促、汗珠滑落 | ❌ 身体发光/能量外溢 |

### 8.2 写实打斗的命中描述模板

```
动作表演（写实版）：
0-0.2s 拳锋破空——拳面皮肤绷紧
0.2-0.4s 拳锋命中——受击者脸颊肌肉被拳锋挤压变形（向内凹陷约2cm），
        汗珠从受击者额头甩出
0.4-0.6s 画面微震 4px——命中冲击力传递
0.6-1.0s 拳锋从命中点弹回——受击者脸颊皮肤泛红，肌肉回弹震颤
```

**对比（特效版，非写实场景禁用）：**
```
❌ 0.2-0.4s 拳锋命中——冲击波从命中点环形扩散，能量光晕照亮受击者面部
```

### 8.3 特效打斗的触发条件

仅当剧本明确包含以下元素时，才启用特效打斗的视觉语言：
- 魔法/魔力/暗影/元素（如《莉维娅的挑战》暗影触须）
- 超能力/异能/气功/内功外放
- 科幻武器/能量武器
- 变身/爆气/领域展开
- 剧本明确标注"特效"或"超自然"

### 8.4 动作音效（写实版）

写实打斗不使用 v3.7 动作音效词汇库中的"冲击音效"类别（墙壁开裂、玻璃碎裂、地面震动等），仅使用：

| 类别 | 写实音效 | 频率 | 声压 | 时长 |
|------|---------|------|------|------|
| 拳肉碰撞 | 低频闷响 | 60-120Hz | 85-92dB | 0.1-0.2s |
| 脚踢命中 | 中低频闷响 | 80-150Hz | 88-95dB | 0.15-0.25s |
| 骨骼脆响 | 中频 | 200-500Hz | 65-75dB | 0.05-0.1s |
| 衣料摩擦 | 中高频 | 300-800Hz | 55-65dB | 持续 |
| 脚步/沙土 | 中频 | 400-600Hz | 55-65dB | 0.2-0.3s |
| 汗珠甩出 | 高频 | 1-2kHz | 45-55dB | 0.05s |
| 呼吸急促 | 中频 | 200-400Hz | 55-65dB | 持续 |
| 地面摩擦 | 低频 | 80-150Hz | 60-70dB | 0.3-0.5s |

> 写实打斗场景中，音效字段仍按原格式填写，但仅保留打击/空间/生理三类，删除"冲击"类别。

## 九、受击命中镜取景规则（v3.10 新增）

**致命缺陷修复**：v3.7-v3.9 的快切连击镜头只展示攻击方拳/脚，命中点标注为"画面外"，导致 AI 生成时攻击方对着空气出拳——无受击方入镜，打击感完全丧失。

### 9.1 核心约束

```
攻击命中镜头 = 攻击方身体部位 + 受击方被命中部位 → 必须在同一画面内
```

**严禁**：命中点完全在画面外。任何标注"命中（画面外X侧）"的攻击镜均为违规。

### 9.2 合法例外

| 例外场景 | 条件 | 示例 |
|---------|------|------|
| **POV 受击镜** | 镜头即为受击者第一人称视角，攻击物从画面外逼近 | 第一人称受击镜头（§5 #21） |
| **画面外命中 + 独立反应镜** | 攻击镜不展示命中，但紧接着下一镜为受击者反应特写（命中声画重叠） | 攻击镜→切→受击者面部被击中变形 |
| **音效暗示命中** | 攻击镜以命中音效暗示命中，但画面不展示命中点 | 仅限风格化处理，不用于常规打斗 |

### 9.3 快切连击的取景修正

**v3.9 错误示例（命中点画面外）：**
```
❌ S-1.1-06 | 大特写 武者A左拳 | 拳锋命中（画面外右侧）
   画面中只有一只拳头从左侧刺入 → AI 生成：拳头在空气中挥过
```

**v3.10 修正（受击方入镜）：**
```
✅ S-1.1-06 | 大特写 命中点（武者A左拳 + 武者B肋部）
   画面中包含：拳锋（左侧）→ 命中点衣料凹陷（中央）→ 武者B身体（右侧）
```

### 9.4 取景构图模板（v3.10.1 修正）

**v3.10 原版错误**：将"受击方必须入镜"曲解为"每镜必须大特写命中点"，导致交锋+升级 Beat 全部变成同一景别，丧失运动感和空间层次。

**修正原则**：受击方入镜是底线，但景别应按剧情需要灵活选择——大特写命中点仅在需要强调打击感的节点使用，其余攻击镜可用中景/中近景展示全身动作和空间关系。

| 攻击类型 | 可选景别 | 画面必须包含 | 使用场景 |
|---------|---------|------------|---------|
| **中景全身攻击** | 中景 | 攻击方全身动作 + 受击方全身 + 命中点 + 空间关系 | 交锋 Beat 首击——展示攻击起势和运动轨迹 |
| **中近景半身攻击** | 中近景 | 攻击方半身动作 + 受击方半身 + 命中点 | 交锋 Beat 反击——展示身体扭转和力量传递 |
| **大特写命中点** | 大特写 | 攻击方拳/脚 + 受击方被命中部位 + 命中点凹陷 | 升级 Beat 快切连击——强调打击感 |
| **全景动作** | 全景 | 攻击方全身 + 受击方全身 + 空间关系 | 高潮 Beat 摔技/投技——展示身体轨迹 |

**景别搭配比例（推荐）：**

| 打斗 Beat | 全景 | 中景 | 中近景 | 大特写 |
|-----------|------|------|--------|--------|
| ① 起势 | 1 镜 | — | — | 1 镜（眼神） |
| ② 交锋 | — | 1 镜 | 1 镜 | — |
| ③ 升级 | — | — | 1 镜（喘息） | 2-3 镜（快切连击） |
| ④ 高潮 | 1 镜 | 1 镜 | — | 1 镜（冻结帧） |
| ⑤ 收尾 | — | 1 镜 | 1 镜 | — |

### 9.5 自检

生成每镜后检查：
- [ ] 本镜是否展示攻击命中？如是，命中点是否在画面内？
- [ ] 画面中是否同时包含攻击方身体部位和受击方被命中部位？
- [ ] 如果命中点在画面外，是否属于 9.2 的合法例外？是否紧接反应镜？

## 十、近战动作指导与运镜设计（v3.11 新增）

**背景**：v3.7-v3.10 的打斗分镜存在"站桩式输出"问题——两人站在原地不动，轮流出拳，缺乏运动感和空间动态。天台战术对决通过持续走位、距离变化、近在咫尺的 miss 解决了这个问题。本章提炼可复用的设计原则。

### 10.1 去站桩三原则

| 原则 | 说明 | 禁止 |
|------|------|------|
| **每镜必有位移** | 每镜至少有一个角色发生身体位移（前冲/后跳/侧移/旋转），禁止两人站在原位只动手臂 | ❌ 两人原地站桩出拳 |
| **距离必有变化** | 两人之间的距离在每镜中必须有变化（逼近/拉开/交错），通过距离变化制造张力 | ❌ 整场打斗距离固定不变 |
| **环境必有交互** | 身体必须与环境元素发生物理接触（背靠立柱/脚踩积水/衣袂被风吹动/手扶栏杆），让空间参与叙事 | ❌ 环境只是背景板 |

### 10.2 身体力学描述词汇库

AI 生图/生视频模型对"打斗"的理解常停留在表面，需要用精确的身体力学词汇来引导。以下词汇库用于「动作表演」字段：

#### 重心与发力

| 术语 | 描述 | 使用场景 |
|------|------|---------|
| 重心下沉 | 膝盖微弯，身体重心降低 5-10cm，核心收紧 | 防御预备、攻击蓄力 |
| 重心前压 | 身体前倾，重心从后脚转移到前脚 | 出拳发力、追击 |
| 重心后移 | 身体后仰，重心从前脚拉回后脚 | 闪避、后跳 |
| 重心旋转 | 以脊柱为轴，上半身旋转 | 摆拳、回旋踢、肘击 |
| 蹬地发力 | 后脚前掌碾地→力量从脚底→腿→腰→肩→拳锋传递 | 任何攻击的起势 |

#### 关节与肢体

| 术语 | 描述 |
|------|------|
| 拳锋 | 拳面四指指关节突出部位，命中时最先接触目标 |
| 前脚掌碾地 | 脚掌前部与地面摩擦旋转，用于调整站位方向 |
| 膝盖微弯 | 缓冲落地冲击，保持重心稳定 |
| 核心收紧 | 腹肌+背肌同时收缩，稳定躯干——所有攻击和防御的基础 |
| 肩部旋转 | 出拳时肩部向前旋转，增加拳锋延伸距离 5-8cm |
| 胯部扭转 | 踢击时胯部旋转，将腿部力量最大化 |

#### 受击反应

| 术语 | 描述 |
|------|------|
| 头部偏转 | 被拳锋命中面部后，头部向反方向偏转——幅度与冲击力成正比 |
| 身体后仰 | 躯干被冲击力推动向后倾斜 |
| 肌肉回弹 | 命中点肌肉在拳锋离开后恢复原状——产生震颤 |
| 皮肤泛红 | 命中后 0.5s 内命中点皮肤因毛细血管破裂泛红 |
| 淤青扩散 | 重击后 2-5s 内淤青从命中点向外扩散 |

### 10.3 距离层次设计

两人之间的距离是打斗戏最有力的叙事工具。推荐设计完整的距离变化弧线：

```
起势：8m（最大安全距离）——评估、走位
  ↓
交锋：5m → 2m（逼近试探）——刺拳、低扫
  ↓
升级：2m → 1m（贴身交换）——组合拳、肘击
  ↓
高潮：1m → 0cm（交错/面贴面）——同时出拳miss、冻结帧
  ↓
收尾：0cm → 8m（同时后跳拉开）——对峙、平局
```

**距离与景别的对应关系：**

| 两人距离 | 推荐景别 | 画面效果 |
|---------|---------|---------|
| 8m | 全景 | 两人在画面中如剪影，空间感宏大 |
| 5m | 中景 | 两人全身同框，脚下步伐可见 |
| 2m | 中近景 | 两人半身同框，拳锋与面部同时可见 |
| 1m | 大特写 | 拳锋与面部/身体的极近细节 |
| 0cm | 大特写 | 交错瞬间——以毫米计的距离 |

### 10.4 运镜-动作配对表

不同打斗动作应匹配不同的运镜方式，而非随机选用：

| 动作类型 | 推荐运镜 | 原因 |
|---------|---------|------|
| 走位/绕圈 | 移镜（横向移动） | 镜头与脚步同步，保持流动感 |
| 前冲出拳 | 推近压迫镜头 | 镜头随身体前冲推进，增强压迫感 |
| 闪避/后仰 | 后撤疏离镜头 | 镜头随身体后撤，放大空间 |
| 低扫腿 | 贴地掠行镜头 | 超低机位捕捉腿部弧线 |
| 组合连击 | 连击追踪镜头 | 焦点在拳/肘/膝间跳跃 |
| 摔技/投技 | 子弹时间 + 环绕 | 慢动作展示身体轨迹，环绕展示空间 |
| 命中瞬间 | 打击冻结镜头 | 冻结帧强调冲击力 |
| 近在咫尺的 miss | 微距失控镜头 | 极近景深突出毫米级距离 |
| 对峙/喘息 | 空镜余韵镜头 | 静态或微推，让呼吸成为主角 |
| 后跳拉开 | 抽离镜头 | 镜头上升远离，放大空间感 |

### 10.5 未命中的美学（v3.11 新增）

战术走位型对决的核心张力来自"几乎命中但未命中"。以下为未命中镜头的设计模板：

| 未命中类型 | 距离 | 视觉锚点 | 示例 |
|-----------|------|---------|------|
| 拳锋擦过面部 | 2cm | 拳锋与鼻尖之间的光隙 + 发丝被拳风拂动 | S-1.1-03 |
| 拳锋擦过发丝 | 1cm | 发丝被拳锋气流吹散——在逆光中呈半透明金色 | S-1.1-07 |
| 肘尖擦过胸膛 | 3cm | 肘尖与胸膛之间的光隙 + 衬衣被气流拂动产生波纹 | S-1.1-08 |
| 两拳锋交错 | 1cm | 从相反方向穿过——前后景纵深间隙 + 极细金色光隙 | S-1.1-09/10 |
| 扫腿被提膝格挡 | 0cm | 小腿迎面骨与脚背碰撞——皮肤泛红但无伤害 | S-1.1-04 |

**未命中镜头的三个必备元素：**
1. **距离标注**：精确到 cm 的距离（如"鼻尖前 2cm"）
2. **气流证据**：拳锋/脚背产生的气流对周边物体的影响（发丝飘动、衣料波纹、汗珠震落）
3. **逆光光隙**：夕阳/灯光穿过拳锋与目标之间的缝隙，形成极细光线——视觉化"距离"

### 10.6 环境交互设计

让空间参与打斗叙事，而非只是背景板：

| 环境元素 | 交互方式 | 叙事效果 |
|---------|---------|---------|
| 混凝土立柱 | 被击退后背部撞上立柱——立柱表面粗糙纹理在背后 | 空间限制——无处可退 |
| 地面水渍 | 脚步踩过水渍产生涟漪、倒地时水渍被震起 | 物理真实感 |
| 铁栏杆 | 手扶栏杆借力、身体反弹 | 空间道具 |
| 通风管道 | 背靠管道喘息 | 空间地标 |
| 日光灯闪烁 | 闪烁频率与打斗节奏呼应——命中瞬间灯光熄灭 | 情绪放大器 |

### 10.6.5 写实格斗光影（v5.6.2 新增）

写实格斗的光影应**服务于动作可读性**——光影不能遮挡动作，而应强化力度和空间关系。按 6 维参数配置：

| 打斗场景 | 光线描述 | 色温 | 光源动机 | 氛围 |
|---------|---------|------|---------|------|
| 室内/仓库 | 顶光 + 硬光 + 对比度 8:1 | 冷 5000K（日光灯） | 画面内日光灯管 | 日光灯闪烁与打斗节奏呼应，命中瞬间熄灭 |
| 黄昏街头 | 逆光 + 硬光 + 对比度 8:1 + 剪影光 | 暖 2800K（夕阳） | 画面外夕阳逆光 | 拳锋与目标间的逆光光隙——金色极细光线可视化距离 |
| 雨夜巷道 | 单侧光 + 硬光 + 对比度 16:1+ | 冷 5600K（街灯） | 画面内单盏街灯 | 水花逆光呈白色光点，汗珠/唾液在逆光中呈金色 |
| 天台/屋顶 | 顶光 + 硬光 + 对比度 16:1+ | 中性 5000K（正午） | 画面外烈日 | 衣袂与头发被风 + 光共同作用——剪影中细节清晰 |
| 地下/暗室 | 单光源 + 硬光 + 对比度 16:1+ | 暖 2800K（单灯泡） | 画面内单盏裸灯泡 | 仅一束光——角色在光亮与黑暗间移动，黑暗中的攻击仅凭声音判断 |

> **写实格斗光影核心原则**：① 逆光光隙是"未命中距离"的视觉化工具——夕阳/灯光穿过拳锋与目标之间的缝隙形成极细光线；② 光源必须参与叙事——日光灯闪烁/熄灭、街灯被撞歪、灯泡被击碎；③ 光影服务于动作可读性——如果光线让动作看不清，就是错误设计。详见 `references/lighting-taxonomy.md`。
| 天台风 | 衣袂与头发被风吹动——静止对峙时风成为唯一运动 | 紧张感 |

### 10.7 自检（v3.11 新增）

生成每镜后追加检查：
- [ ] 本镜是否有角色发生身体位移？（前冲/后跳/侧移/旋转）如无，是否属于合法静止镜（喘息窗口/对峙定格）？
- [ ] 两人之间的距离在本镜是否有变化？与上一镜相比距离是逼近还是拉开？
- [ ] 环境元素是否在本镜中参与了动作？（身体接触/物理交互）如无，是否至少通过光影/声音参与了叙事？
- [ ] 运镜方式是否与动作类型匹配？（参考 10.4 配对表）
- [ ] 「动作表演」字段是否使用了身体力学词汇？（重心/关节/发力链）还是模糊描述如"出拳"？

## 十一、特效打斗规则（v4.2 新增）

**背景**：v3.9 第八章仅划定了"写实 vs 特效"的边界（什么情况下可以用特效），但没有告诉 agent 特效打斗**怎么拍**。本章提供特效打斗的独立视觉语言和节奏体系。

### 11.1 特效打斗 vs 写实打斗的本质区别

| 维度 | 写实打斗 | 特效打斗 |
|------|---------|---------|
| 攻击距离 | 近身（0-2m） | 近身→远程（0-50m）——魔法/能量可远程 |
| 命中证据 | 皮肤凹陷/泛红/淤青 | 能量光效/粒子/冲击波/元素残留 |
| 移动方式 | 步行/跑动/跳跃 | 瞬移/飞行/闪现/残影 |
| 防御方式 | 格挡/闪避/硬扛 | 能量护盾/魔法屏障/元素抵消 |
| 环境破坏 | 地面裂纹/水渍涟漪 | 地面炸裂/建筑倒塌/元素侵蚀 |
| 节奏 | 快切连击 | 蓄力→释放→爆发——节奏更极端 |

### 11.2 特效打斗的视觉词汇库

**能量/魔法攻击的视觉描述模板：**

| 攻击类型 | 视觉描述模板 | 色温/光效 |
|---------|------------|---------|
| 能量弹/光球 | {颜色}光球在{角色}掌心{凝聚/旋转}，表面{粒子/符文/电弧}流转，{大小}约{直径}cm，脱离掌心后以{速度}轨迹射向{目标} | 单色高亮 + 同色系粒子拖尾 |
| 光束/射线 | {颜色}光束从{角色}{身体部位/武器}射出，光束直径{约Xcm}，边缘{锐利/模糊/跳动}，射程内空气{电离/扭曲/冻结} | 核心白→边缘渐变至{颜色} |
| 范围冲击波 | 以{角色}为中心，{颜色}冲击波呈{环形/球形}向外扩散，扩散速度{快/慢}，所过之处{地面龟裂/物体掀飞/空气扭曲} | 冲击波前缘高亮，尾部渐暗 |
| 元素召唤 | {火焰/冰霜/雷电/暗影}从{角色}身周{涌出/凝聚/降临}，形态呈{龙卷/巨兽/触须/风暴}，{数量}条/道，{颜色}为主色调 | 元素本色 + 场景环境光被元素色覆盖 |
| 瞬移/闪现 | {角色}身形{模糊/化作粒子/被暗影吞没}，{0.Xs}后在{目标位置}{重新凝聚/从粒子中显形/从暗影中踏出}，原位置残留{残影/光尘/暗影余烬} | 过渡色——原位置渐暗，目标位置渐亮 |

**防御/护盾的视觉描述模板：**

| 防御类型 | 视觉描述 | 受击反应 |
|---------|---------|---------|
| 能量护盾 | {颜色}半透明{球形/六边形蜂巢/符文阵列}包裹{角色}，表面{数据流/符文/能量纹路}流转 | 被命中时护盾{闪烁/凹陷/产生涟漪}，命中点颜色{变亮/变暗} |
| 魔法屏障 | {颜色}光墙在{角色}前方{展开/升起}，{半透明/完全不透明}，表面{符文/魔法阵}旋转 | 被命中时屏障{震颤/裂纹扩散/符文加速旋转} |
| 元素抵消 | {角色}以{对立元素}迎击——火焰被冰霜熄灭、暗影被光柱驱散 | 两股元素在碰撞点{互相侵蚀/同时湮灭/产生爆炸} |

### 11.3 特效打斗的节奏弧线

特效打斗的节奏与写实打斗不同——**魔法需要蓄力，不是即时的**：

```
① 蓄力 Beat（3-5s，1-2镜）：角色凝聚能量——能量在掌心/身周积聚
② 释放 Beat（2-4s，1-2镜）：能量释放——光束/弹幕/冲击波射出
③ 碰撞 Beat（2-3s，1-2镜）：能量命中——护盾/屏障/元素碰撞
④ 反制 Beat（3-5s，1-2镜）：对方反击——另一种能量/魔法回击
⑤ 余波 Beat（3-5s，1-2镜）：能量消散——环境残留、角色喘息
```

**与写实打斗的节奏对比：**
```
写实：起势(对峙) → 交锋(试探) → 升级(连击) → 高潮(致命一击) → 收尾
特效：蓄力(凝聚) → 释放(射出) → 碰撞(命中) → 反制(回击) → 余波(消散)
       慢          极快         爆          慢→极快       慢
```

### 11.4 特效打斗的运镜

| 特效动作 | 推荐运镜 | 原因 |
|---------|---------|------|
| 能量凝聚/蓄力 | 推近压迫镜头（极慢） | 聚焦掌心/身周——能量从小到大 |
| 能量释放/射出 | 贴地掠行/斜向俯冲 | 跟随能量弹/光束的飞行轨迹 |
| 范围冲击波 | 抽离镜头（快速后撤） | 展示冲击波扩散范围 |
| 元素碰撞 | 打击冻结 + 子弹时间 | 两股能量碰撞瞬间冻结，展示视觉效果 |
| 瞬移/闪现 | 快速推进变焦 | 从原位置急速推至目标位置 |
| 护盾展开 | 升降镜头 | 跟随护盾从脚底向头顶展开 |

### 11.5 特效打斗的音效

| 特效元素 | 音效设计 | 频率/特征 |
|---------|---------|---------|
| 能量凝聚 | 低频嗡鸣——渐强 | 40-80Hz·渐强·60→80dB |
| 能量释放 | 高频撕裂——瞬间爆发 | 2-4kHz·0.3s·85-95dB |
| 光束/射线 | 持续高频——如电流 | 3-6kHz·持续·70-80dB |
| 冲击波扩散 | 超低频——从中心向外 | 20-40Hz·0.5s·90-100dB |
| 护盾受击 | 金属共鸣——如钟鸣 | 1-2kHz·0.3s·80dB |
| 元素碰撞 | 两种音色叠加——互相侵蚀 | 低频+高频同时·0.5s |
| 瞬移 | 短促高频——如空气被撕裂 | 4kHz·0.1s·70dB |
| 能量消散 | 嗡鸣渐弱——如退潮 | 60Hz·渐弱·80→40dB |

## 十二、巨物打斗规则（v4.2 新增）

**背景**：v3.x 所有规则默认"两个人类等比例战斗"。当一方是巨物（怪兽/机甲/巨人/巨龙）时，景别、运镜、节奏、命中证据全部需要重新定义。

### 12.1 巨物打斗的核心挑战

AI 生图/生视频模型对"比例"的理解薄弱。如果不刻意建立尺度参照，巨物会被生成为普通大小。**每一镜都必须包含尺度参照物**。

### 12.2 尺度建立——每镜必备参照物

| 参照物类型 | 在画面中的角色 | 示例 |
|-----------|-------------|------|
| 人类对比 | 画面中必须出现正常尺寸的人类 | 人类站在巨物脚边——仅到脚踝高度 |
| 建筑对比 | 画面中必须出现建筑 | 巨物手掌按在建筑上——手掌 = 3 层楼 |
| 车辆对比 | 画面中必须出现车辆 | 巨物脚掌踩过——汽车如玩具 |
| 树木对比 | 画面中必须出现树木 | 巨物穿过森林——树冠仅到膝盖 |
| 门窗对比 | 画面中必须出现门窗 | 巨物眼睛从窗外窥视——眼球 = 窗户大小 |

**尺度参照物规则**：巨物打斗的每镜必须至少包含 1 个尺度参照物。如果镜头中没有参照物，AI 会默认生成等比例大小。

### 12.3 巨物打斗的景别与运镜

| 景别 | 用途 | 运镜 |
|------|------|------|
| 超远景/航拍 | 展示巨物全身 + 城市/环境全貌 | 航拍镜头——缓慢下降 |
| 全景（人类视角） | 人类仰望巨物——巨物占据画面 80% | 低角度仰拍——极端仰角 60-80° |
| 中景（巨物局部） | 巨物手掌/脚掌/头部——与人类/建筑对比 | 移镜——沿巨物身体横向移动 |
| 大特写（巨物细节） | 巨物眼睛/皮肤纹理/鳞片——画面中如地形 | 微距失控镜头——极慢推进 |
| 第一人称（人类 POV） | 巨物脚掌从头顶踩下——阴影逐渐覆盖 | 主观镜头——向上仰视 |

**"阴影覆盖"镜头模板**——巨物打斗最具辨识度的镜头：
```
镜 1（全景）：人类站在街道上，突然地面被巨大阴影覆盖
镜 2（仰拍）：人类抬头——巨物脚掌从上方踩下，遮天蔽日
镜 3（大特写）：人类面部——瞳孔中倒映出越来越大的脚掌
镜 4（全景）：脚掌踩下——地面炸裂，冲击波扩散
```

### 12.4 巨物打斗的节奏弧线

巨物打斗的节奏比人类打斗**慢得多**——巨物的每个动作以秒计而非以帧计：

```
① 降临 Beat（5-8s，2-3镜）：巨物出现——阴影覆盖/地面震动/建筑摇晃
② 威胁 Beat（4-6s，1-2镜）：巨物攻击——脚掌踩下/手掌横扫/尾部甩击
③ 躲避 Beat（3-5s，2-3镜）：人类闪避/逃跑/寻找掩护——建筑倒塌为背景
④ 反击 Beat（5-8s，2-3镜）：人类利用环境/武器反击——攀爬巨物身体/攻击弱点
⑤ 撤退 Beat（5-8s，1-2镜）：巨物受伤/被驱逐——人类幸存/环境废墟
```

**节奏特点**：巨物 Beat 之间的镜头切换比人类打斗慢 2-3 倍。快切（1-1.5s/镜）在巨物打斗中几乎不用——因为巨物的动作本身就需要 2-3s 才能完成。

### 12.5 巨物打斗的命中证据

巨物打斗中，人类攻击巨物不可能造成"皮肤凹陷"——命中证据必须通过**环境破坏**来体现：

| 人类攻击巨物 | 命中证据 |
|------------|---------|
| 武器攻击巨物腿部 | 巨物皮肤上出现划痕——如地质裂缝，深度以米计 |
| 爆炸物命中巨物 | 巨物身体局部被炸出缺口——碎片如建筑大小坠落 |
| 攻击巨物眼睛 | 巨物闭眼——眼睑如巨型闸门合拢，产生气浪 |
| 攀爬巨物身体 | 人类在巨物皮肤上攀爬——皮肤纹理如岩石地形 |

| 巨物攻击人类/环境 | 命中证据 |
|-----------------|---------|
| 脚掌踩下 | 地面炸裂——裂纹延伸数十米，建筑倒塌 |
| 手掌横扫 | 建筑被拦腰扫断——上半截滑落，玻璃幕墙如瀑布碎裂 |
| 尾部甩击 | 地面被抽出沟壑——深度数米，长度数十米 |
| 咆哮 | 声波可见——空气扭曲，玻璃震碎，人类捂住耳朵 |

### 12.6 巨物打斗的音效

巨物打斗的音效核心是**次低频**——观众用身体感受而非耳朵听到：

| 音效 | 频率 | 声压 | 特征 |
|------|------|------|------|
| 巨物脚步声 | 10-30Hz | 100-110dB | 每步间隔 2-3s，地面震动同步 |
| 建筑倒塌 | 20-80Hz | 95-105dB | 低频轰鸣 + 高频碎裂 |
| 巨物咆哮 | 15-50Hz | 100-115dB | 超低频持续 2-4s，空气可见扭曲 |
| 地面炸裂 | 30-60Hz | 90-100dB | 从撞击点向外扩散 |
| 金属扭曲（机甲） | 50-200Hz | 85-95dB | 持续——金属疲劳声 |
| 玻璃碎裂 | 2-6kHz | 80-90dB | 高频——与低频形成对比 |

生成特效/巨物打斗镜后检查：
- [ ] 特效打斗：魔法/能量的视觉描述是否使用了视觉词汇库中的模板？
- [ ] 特效打斗：是否遵循了"蓄力→释放→碰撞→反制→余波"的节奏弧线？
- [ ] 巨物打斗：每镜是否至少包含 1 个尺度参照物（人类/建筑/车辆/树木）？
- [ ] 巨物打斗：命中证据是否通过环境破坏（而非皮肤凹陷）来体现？
- [ ] 巨物打斗：镜头时长是否比人类打斗长 2-3 倍？是否避免了快切？

## 十三、袁和平核心原则（v5.5 合并）

> 本章提炼袁和平 50+ 年动作设计实践的核心原则，可跨打斗类型复用。
> 完整哲学体系见 `references/yuen-woo-ping-philosophy.md`。
> v5.5 合并：集成因果链描述规范、镜头不稳定性、贴脸镜头、紧张感设计、打击感体系、穿模防护。

### 13.1 动作流——因果链 + 攻防转换

**13.1.1 零断点因果链**

核心信条：**每一个动作都必须有原因、有目的、有结果。** 动作不是"好看才做的"，是"非做不可"的。

分镜规则：
- 每个攻击镜的「动作表演」字段必须标注：**触发条件** → **动作本身** → **产生的结果**
- 严禁出现"没有原因的动作"——旋子转体是因为有人攻击下盘被迫跃起，不是因为"好看"
- 每个动作的结果必须在下一镜被承接——A 击中 B → 下一镜必须展示 B 的身体反应

**因果链描述规范（v5.5 合并）**：动作表演必须用"同时"、"顺势"、"不收"、"借力"、"趁"等连接词串联，而非"先…然后…接着…"的回合制分句。

```
❌ 回合制：B拳锋刺来 → A格挡 → B再出拳 → A侧闪 → A反击
✅ 因果链：B拳锋刺来，A格挡的同时右肘顺势横摆，B抬臂格挡——骨头撞骨头，
          A不收肘，右膝借力顶上去，B侧身卸了力，A重心失衡，B趁机扣住A后颈往下压
```

关键连接词：顺势（不收招直接转下一个动作）、不收（命中后继续攻击）、借力（利用对方力量改变位置）、同时（防御和反击在同一时刻）、趁机（利用对方收招/失衡/落地的间隙）

**13.1.2 攻防转换五类型**

袁和平的攻防转换不是"你一轮我一轮"，而是**在同一个连续动作流中完成攻防互转**。

| 类型 | 分镜描述模板 | 使用 Beat |
|------|------------|:---:|
| **化解** | 顺来力方向旋转/后撤/侧移，将力道卸掉 | 起势→交锋 |
| **补击** | 被击中{部位}，身体后仰的同时，{另一部位}顺势踢出 | 升级 |
| **借力** | 被摔出，顺飞出方向扒住{环境物}，借旋转力踢回 | 高潮 |
| **躲击** | 后仰躲避横扫的同时，脚从下方踢出，命中支撑腿 | 升级 |
| **截击** | 判明来拳方向，以更快的速度出拳，先命中对方 | 高潮 |

分镜规则：
- 每个交手回合必须在「动作表演」字段中标注攻防转换类型
- 一场打斗至少包含 3 种不同类型的攻防转换
- 严禁"元奎式连攻连守"——A 打一轮 B 不还手，然后 B 打一轮 A 不还手

**13.1.3 动作简练——一举多得**

一个动作同时完成多个目标——手脚同时击中多人、躲避的同时完成攻击蓄力。

分镜规则：在「动作表演」字段中，如果角色身体的一个部位在防御，检查另一个部位是否在同时攻击。

### 13.2 镜头流——单机位 + 变焦 + 长镜头

**13.2.1 单机位最佳角度**

> 「任何瞬间只有一个最好的角度。」——袁和平

分镜规则：
- 生成每镜后自问：这个角度展示了动作的最关键信息吗（力度/轨迹/空间关系）？
- 如果两个角度拍到的东西差不多，选更简洁的那个
- 景别选择必须服务于"让观众看清动作"
- 出拳用侧面 45°，踢腿用正面 30°，摔技用侧面，地面缠斗用俯拍 45°

**13.2.2 变焦/推拉替代硬切**

在起势 Beat 和交锋 Beat 的过渡中，至少 1 镜使用推近或后撤运镜来完成景别转换，而非硬切。

**13.2.3 长镜头原则**

分镜规则：
- 出拳阶段（四阶段模型的第②阶段）必须使用长镜头——完整展示招式链，≥2s
- 攻防转换的关键回合必须使用长镜头——展示攻防互转的完整过程
- 一场打斗中 ≥30% 的交手镜头使用长镜头（≥2s）；实战风格参照猎犬2：长镜头（≥4s）时长 ≥60%
- 严禁在出拳阶段使用快切——快切打断招式连续性，观众看不到完整动作

**为什么**：长镜头让观众"跟着动作走"，看到完整轨迹，理解空间关系。快切只能看到剪辑技巧，看不到真正的武术。

**13.2.4 镜头不稳定性原则（v5.5 合并）——打击感与临场感**

打斗镜头不是客观记录者，而是身临其境的参与者。**稳定镜头 = 丧失打击感**。

| 手法 | 阶段 | 参数 | 效果 |
|------|------|------|------|
| **画面微震** | 每个命中瞬间 | 轻击 4-6px，中击 6-8px，重击 10-12px，KO一击 15px | 观众"感受"到冲击力 |
| **荷兰角（倾斜镜头）** | 出拳/爆发阶段 | 3-8°，倾斜方向与攻击方向一致 | 失衡感=临场感 |
| **手持微晃** | 观察/对峙阶段 | 2-4px，0.5-1Hz，如呼吸般轻微晃动 | 模拟目击者的不稳定视角 |
| **运动模糊** | 拳锋/脚背/膝盖等高速运动部位 | 3-5px 方向性模糊拖影 | 速度感 |
| **闪避模糊** | 角色急速侧闪/后仰/低头 | 3-4px 面部/头部边缘模糊 | 闪避的瞬间速度感 |

使用规则：每个命中瞬间必须有画面微震，力度与微震幅度成正比；每场打斗至少 2 镜使用荷兰角；出拳/踢腿/膝撞必须包含至少 1 条运动模糊描述；模糊方向必须与运动方向一致。

### 13.3 空间呈现——相机作为参与者

分镜规则：
- 首镜必须建立空间关系——谁在左、谁在右、谁在前、谁在后
- 每 3-4 个特写后插入 1 个中景/全景建立空间
- 同一轮交锋内所有镜头必须在轴线同一侧

**多人物打斗**：
- 主角有明确的推进路线（从左到右/从下到上）
- 敌人分层出现——前排→中排→后排
- 主角始终在画面中央或移动轨迹清晰

**贴脸镜头与前景遮挡（v5.5 合并）**：镜头不是旁观者，是被卷入战斗的参与者。

| 手法 | 说明 | 距离/参数 |
|------|------|------|
| **贴脸过肩** | 镜头紧贴角色肩膀后方 30cm，肩膀和后背在画面前景放大虚化占据画面 40% | 30cm |
| **贴地仰拍** | 镜头放置在地面高度，脚底从镜头正上方 5cm 踩过，鞋底纹理清晰可见 | 5cm |
| **前景遮挡** | 手臂、肩膀、衣袂在画面边缘快速掠过——形成模糊残影 | 覆盖画面边缘 20-30% |
| **镜头被迫运动** | 出拳时镜头被拳锋气流推向后方 2-3px，膝撞时镜头被冲击力推动后仰 3px | 2-3px |
| **灰尘/碎片遮挡** | 地面灰尘和碎石在镜头前飞溅——覆盖镜头边缘形成模糊遮挡 | 覆盖画面边缘 10-20% |
| **贴脸特写** | 推近至距离面部 15cm——连睫毛的颤动都清晰可见 | 15cm |

过肩镜头交替规则：攻击方用攻击方视角，防御方反击时切到防御方视角。

### 13.4 剪辑节奏——一张一弛

**13.4.1 核心公式**

```
简单交手（刀刀相撞、攻防未转换）→ 大景别、双人镜头、正常速度、镜头少 → 快速带过
复杂过招（攻防转换频繁）→ 小景别、局部特写、升格、镜头多 → 仔细交代
```

**13.4.2 停顿/爆发/停顿**

每个 Beat 内部也遵循"停顿→爆发→停顿"的微节奏：
- 对峙镜头（停顿）的时长应 ≥ 交手镜头（爆发）的时长
- 爆发后的停顿必须给反应镜头——胜者的喘息、败者的痛苦、环境的余震

**13.4.3 断点剪辑 vs 快切**

- 断点剪辑：每个镜头 1.5-3s，展示完整动作，角度快速切换——保证迅猛凌厉
- 快切：每个镜头 0.5-1s，碎片化——仅限升级 Beat 的连击使用
- 断点剪辑的切换点必须在动作"收势"和下一动作"起势"之间

**13.4.4 运动节奏——加速→爆发→减速→再加速（v5.5 合并）**

打斗节奏不是匀速，是速度变化的曲线：

```
正常节奏（刺拳试探）→ 加速（连续攻击）→ 爆发（抓住时机，3-5拳连击无间隔）→
减速（被格挡/闪避，重新评估）→ 再加速（换角度攻击）
```

节奏变化规则：试探阶段 1-2拳后停顿；连续攻击 3-5拳无间隔（≤0.3s）；爆发点 5-8拳连续轰击（≤0.15s）；减速点停顿 0.5-1s；全程至少 3-4 次加速→减速波动。

**13.4.5 喘息设计（v5.5 合并）**

喘息不是随机插入的"休息时间"，而是**剧情转折点**。每个喘息必须服务于叙事。

| 总时长 | 喘息频率 | 喘息时长 | 动作占比 |
|:---:|---|:---:|:---:|
| ≤30s | 0-1 次 | 1-2s | 90%+ |
| 30-60s | 1-2 次 | 2-3s | 80-85% |
| 60-120s | 2-4 次 | 2-4s | 70-80% |

喘息必须服务于以下叙事节点之一（禁止无理由喘息）：近距逃脱后、重击命中后、位置变化后、局势逆转前、环境破坏后。禁止两人站着对视喘气、喘息中插入无关环境描写、喘息时间超过动作时间的 1/3。

### 13.5 力度表达——破坏效果倒推力度

| 力度层级 | 命中证据 | 使用 Beat |
|---------|---------|:---:|
| 轻击 | 皮肤泛红、衣料微皱、头部偏转 ≤15° | 交锋 |
| 中击 | 身体后仰、汗珠甩出、踉跄后退 2-3 步 | 升级 |
| 重击 | 身体抛飞、撞墙/撞物、地面滑行 | 升级→高潮 |
| 致命一击 | 慢动作、冻结帧、身体变形、环境大面积破坏 | 高潮 |

分镜规则：
- 力的传递链条必须完整展示：命中 → 变形 → 位移 → 环境破坏
- 环境是最好的力度标尺——人撞墙（墙裂）> 特效光效

**穿模防护（v5.5 合并）**：命中衣物覆盖部位时，只描述衣物变化（衣料凹陷），不描述皮肤变化（泛红）。只有裸露皮肤（面部、前臂、颈部）被命中时才描述皮肤泛红。禁止"衣料凹陷+皮肤泛红"同时出现于同一命中点。

**伤害相互**：双方都在受伤——攻击者也会被反作用力伤害。拳锋砸在水泥地上，指节皮破血渗。

### 13.6 视听统一

- 音效跟随动作节奏——打击音频率/声压与力度层级匹配
- 画面描述必须服务于动作理解——如果光线/色彩让动作看不清，就是错误设计
- 每个镜头只做一件事——出拳镜展示轨迹，击中镜展示碰撞，效果镜展示后果

### 13.7 紧张感设计（v5.5 合并）

因果链保证动作流畅，但**紧张感来自"差点被打中"和"环境在伤害你"**。

| 手法 | 说明 | 示例 |
|------|------|------|
| **近距逃脱** | 每场打斗至少 2-3 次"差点命中"，距离标注 2-5cm | 拳锋从太阳穴前 2cm 擦过，风压压出皮肤凹痕 |
| **环境冲击** | 每次重击后角色必须撞上环境物体 | 后背撞上锈蚀铁板，铁板凹陷，铁锈震落 |
| **加速度描写** | 动作描述中加入"突然"、"猛力"、"瞬间"、"如剃刀般" | 脚背贴地，如剃刀般扫向小腿 |
| **声音爆发** | 重击声用"轰响"、"尖锐"、"回荡" | 倒地声在工厂中回荡 |
| **伤害相互** | 攻击者也会被反作用力伤害 | 拳锋砸在水泥地上，指节皮破血渗 |

### 13.8 打击感体系（v5.5 合并）

**真实打击感——不是"看起来疼"，是"感觉疼"**

| 要素 | 说明 |
|------|------|
| 真实技术 | 使用真实拳击/格斗技术（刺拳、勾拳、肘击、膝撞），每个动作有明确的力学逻辑 |
**重量感——命中证据细节库（v5.5.3 新增，v5.7 扩展）**

力量感不是靠"震了 8px"，而是靠**命中后角色的身体和随身物品发生了什么**。

**身体非自主反应**（最具真实感的证据——角色无法控制这些反应）：

| 命中部位 | 非自主反应 | 力度层级 |
|---------|---------|:---:|
| 腹部/肋部 | 口水从嘴角甩出——不是"流出来"，是被冲击力"震出来" | 中击 |
| 腹部 | 胃部痉挛——身体瞬间弯曲，干呕的动作，喉结上下滚动 | 重击 |
| 头部 | 眼睛瞬间闭合——冲击力强制眼睑闭合，不受意识控制 | 中击 |
| 头部 | 眼泪被震出——非哭泣，是物理冲击导致泪腺被挤压 | 重击 |
| 头部 | 耳鸣——角色表情出现短暂空白，听不见声音的生理反应 | 重击 |
| 躯干 | 呼吸被打断——命中瞬间呼吸停滞，胸口剧烈起伏才能恢复 | 中击 |
| 腿部 | 膝盖本能弯曲——被命中后腿不受控制地下沉 | 中击 |
| 全身 | 肌肉痉挛——被命中部位肌肉不由自主地抽动 | 重击 |

**随身物品互动**（增强真实感——观众看到熟悉的日常物品在暴力中失控）：

| 物品 | 互动 | 力度层级 |
|------|------|:---:|
| 眼镜 | 被震飞——镜腿从耳后脱落，在空中翻转，落地碎裂 | 中击 |
| 眼镜 | 镜片碎裂——命中后镜片出现放射状裂纹，但镜框仍挂在脸上 | 中击 |
| 手机 | 从口袋滑出——身体被撞时手机从口袋飞出，屏幕朝下摔在水泥地上 | 中击 |
| 手表/手链 | 表带断裂——命中手臂时手表带被冲击力崩开 | 重击 |
| 项链/耳环 | 被扯断——项链在空中断裂，珠子散落滚满地 | 中击 |
| 帽子 | 被击飞——帽子从头上弹起，在空中旋转飘落 | 中击 |
| 发圈/发夹 | 头发散开——发圈/发夹被震飞，头发瞬间散开覆盖面部 | 中击 |
| 鞋子 | 鞋底离地——身体被击退时鞋底与地面摩擦，一只鞋脱落 | 重击 |

**衣物渐进破坏**（不是一次性扯烂，是逐级升级）：

| 层级 | 衣料状态 | 触发条件 |
|:---:|------|------|
| 1级 | 衣料褶皱——命中点衣料出现放射状褶皱 | 任何命中 |
| 2级 | 衣料拉伸——被抓住拉扯时衣领/袖口变形，松手后不回弹 | 被抓住/拉扯 |
| 3级 | 衣料破裂——拳锋/刀锋命中处纤维绽开，线头露出 | 中击以上 |
| 4级 | 纽扣弹飞——纽扣被震飞，衣襟敞开 | 重击命中躯干 |
| 5级 | 大面积撕裂——衣料从破裂处沿纹理撕裂，露出内层皮肤 | 重击+拉扯 |

**命中证据应用规则**：
- 每个命中镜头必须包含至少 1 项细节证据，非自主反应优先于物品互动
- 同一部位连续命中，证据逐次升级——第一拳皮肤泛红，第二拳红肿隆起，第三拳裂口血珠
- 衣物破坏必须逐级升级，不能第一拳就写"衣服大面积撕裂"
- 细节证据写入「画面描述」字段，作为视觉质感的描述
| 体力消耗 | 打斗后半段动作变慢、呼吸加重、汗水甩出、格挡变多攻击变少 |
| 风格差异 | 每个角色有独特的打斗风格，不能两人都用同样的招式 |

**拳腿组合库（v5.5.3 新增）**：打斗不能只有拳法，必须混合拳、腿、膝、肘形成立体攻击。

| 技术 | 动作 | 使用时机 | 运镜 |
|------|------|---------|------|
| 低扫腿 | 脚背贴地横扫小腿 | 破站姿，对手重心在前脚 | 贴地掠行仰拍 |
| 高扫腿 | 脚背横扫头部 | 对手格挡上身后打上方 | 侧面 30° |
| 正蹬 | 脚掌直推胸口 | 控制距离，推开对手 | 正面命中点 |
| 侧踹 | 侧身蹬出，脚掌外侧命中 | 对手侧身时打腰/肋部 | 侧面展示旋转 |
| 膝撞 | 膝盖顶向腹部/面部 | 近距离，对手身体弯曲 | 低角度仰拍 |
| 回旋踢 | 转身 360°，脚背扫向头部 | 对手追击时突然转身反击 | 环绕镜头 |
| 斧踢 | 脚后跟从上往下砸 | 对手低头/前倾时 | 侧面展示下砸 |
| 飞膝 | 跃起膝盖顶向面部 | KO 或重创 | 正面展示腾空 |

**拳腿组合链**：

| 组合 | 序列 | 节奏 |
|------|------|------|
| 拳→腿 | 2拳面部→对手格挡→低扫破站姿 | 快→快→快 |
| 腿→拳 | 低扫破站姿→对手踉跄→2拳面部 | 快→快→快 |
| 拳→膝 | 2拳面部→对手格挡→膝撞顶腹 | 快→快→爆发 |
| 拳→腿→回旋 | 2拳→后仰闪避→低扫→回旋踢 | 快→快→快→爆发 |
| 腿→腿→拳 | 低扫→高扫→对手跳跃→2拳追击 | 快→快→快→快 |

**每场打斗拳腿比例**：拳法 40-50%，腿法 30-40%，膝肘 10-20%。禁止纯拳法打斗。

**长镜头——镜头不切，让观众看到完整动作**：一个完整的攻防回合（3-5个动作）必须在同一个镜头中完成。出拳/攻击用长镜头（≥4s），命中/特写用短镜头（1-2s），但长镜头才是主力。整场打斗中，长镜头（≥4s）时长应占总时长的 ≥60%。

### 13.8.1 升格与快切（v5.5.3 新增）——速度变化制造节奏起伏

因果链保证连续性，但**节奏起伏靠速度变化**——升格拉长决定性瞬间，快切压缩命中密度。

**升格镜头（慢动作）——命中瞬间的子弹时间（v5.7 修正）**

升格应放在**命中瞬间或未命中的闪避瞬间**——就像子弹时间，时间在拳锋触碰到皮肤的 0.1s 突然减速，观众能看到皮肤凹陷的每一帧、口水飞出的每一滴、发丝被风压推开的每一根。

| 使用场景 | 升格幅度 | 放在哪个阶段 | 效果 |
|---------|:---:|------|------|
| **重击命中**（KO一击/终结技） | 120-240fps | 命中瞬间 0.3-0.8s | 拳锋接触皮肤的瞬间→皮肤凹陷→冲击波扩散→然后口水飞出——全在慢动作中 |
| **重击命中**（非终结级） | 60-120fps | 命中瞬间 0.2-0.5s | 肘尖/膝盖接触的瞬间→衣料/皮肤凹陷→身体下沉——慢放力量传递 |
| **近距闪避**（≤3cm逃脱） | 120-240fps | 闪避瞬间 0.3-0.5s | 拳锋从面部 3cm 擦过→风压推开皮肤→发丝被气流拨开——如子弹时间 |
| **近距闪避**（≤10cm逃脱） | 60-120fps | 闪避瞬间 0.2-0.3s | 刀锋/铁管从身前擦过→衣料被风压吹动→身体后仰轨迹 |

**升格规则**：
- 重击/终结技必须使用升格——每场打斗至少 1 次重击升格，KO 或决胜一击必须升格
- 近距闪避建议使用升格——每场打斗至少 1 次闪避升格
- 升格镜头用「升格（120fps）」标注在运镜字段中（子弹时间格式）
- 每 30s 打斗升格不超过 3 次
- 升格期间，画面微震幅度额外 +6px——慢动作让震动更明显
- 升格前后各保留 0.5s 正常速度——让观众感受到"突然减速"的冲击

**快切——爆发点的加速引擎**

快切不是随机切镜头，而是在**同一个因果链内部，用快速切换增加命中密度**。

| 使用场景 | 切速 | 镜头数 | 标注方式 |
|---------|:---:|:---:|------|
| 连续命中（3-5拳） | 0.3-0.5s/镜 | 3-5镜 | 运镜字段标注「快切（0.3s/镜）」 |
| 攻防转换加速点 | 0.5s/镜 | 2-3镜 | 运镜字段标注「快切（0.5s/镜）」 |
| 爆发点 | 0.2-0.4s/镜 | 3-4镜 | 运镜字段标注「快切（0.2s/镜）」 |

**快切规则**：快切前必须有 1 个长镜头（≥3s）建立因果链，快切后回到长镜头。快切期间保持空间一致性——每个快切镜头必须看到上一个镜头的空间参照物。快切镜头之间用声画重叠衔接。

**快切+升格组合（好莱坞式 KO 节奏）**：
```
长镜头（蓄力，2s）→ 快切（每拳4镜×0.3s，多角度同一拳，正常速度）→ 升格（命中瞬间，120fps，0.5s）→ 正常速度（倒地+效果，2s）
```
节奏曲线：正常蓄力→加速快切→子弹时间减速→正常倒地。**升格在命中的那一帧触发，不是倒地之后。**

### 13.8.2 ACT镜头三法（v5.7 新增）——游戏化运镜增强打击感与节奏

借鉴动作游戏（ACT = Action Game，《鬼泣》《战神》《猎天使魔女》）的专属镜头逻辑，让打斗分镜拥有"玩家视角"的临场感。

**⚠️ 使用原则：按需选用，禁止全盘套用。** ACT三法是运镜工具箱的扩展——根据打斗类型、叙事目的和情绪节奏**按需搭配**，不是每场打斗的固定模板。一场写实巷战可能只用命中推拉而不用QTE切入；一场巨物对决可能三项都不用；一场BOSS终结战可能三项全用。

**① 命中推拉——镜头也有"蓄力-释放"节奏**

不是匀速跟拍，而是每次命中时镜头猛推至大特写命中点（+4-8px），收拳后弹回越肩位置（-4-8px）。镜头如呼吸——攻击吸入（推近），收招呼出（弹回）。

| 动作阶段 | 镜头行为 | 幅度 | 效果 |
|---------|---------|:---:|------|
| 出拳/攻击 | 镜头跟随锁定攻击部位 | 同步移动 | 观众被"拉入"攻击 |
| 命中瞬间 | **猛推至大特写命中点** | +4-8px | 衣料凹陷/皮肤红肿清晰可见 |
| 收拳/收招 | **弹回越肩位置** | -4-8px | 观众被"弹回"安全距离 |
| 连击 | **每拳一次推拉** | 左推右拉交替 | 节奏如鼓点，拳拳到肉 |
| 膝撞/踢腿 | **低角度仰拍猛推** | +6-10px | 仰拍放大腿部力量和轨迹 |

**标注方式**：运镜字段写「ACT命中推拉」，并在动作表演中标注每次【猛推至大特写】和【弹回越肩】。

**② 终结技环绕——KO 时升格 + 镜头绕角色 180°**

KO 或决胜一击后立即触发升格 + 镜头环绕，结合子弹时间和空间审视——像《战神》QTE 处决镜头。

| 阶段 | 内容 | 升格幅度 | 镜头运动 |
|------|------|:---:|------|
| 触发 | KO 一击命中后立即触发 | — | 镜头从侧面锁定角色 |
| 升格 | 慢动作展开命中效果 | 120fps | 镜头环绕角色 180°（左→右）|
| 内容 | 身体瘫软倒地、灰尘扬起、电火花凝固 | — | 攻击方收招站起，露出全身 |
| 结束 | 升格解除→正常速度回弹 | — | 角色倒地不动，尘土落地 |

**标注方式**：运镜字段写「升格（120fps）+ 镜头环绕 180°」，动作表演标注【升格 120fps·子弹时间】。

**③ QTE式切入——爆发瞬间切角度打破稳定感**

爆发瞬间（致命一击/终结技）从越肩视角**突然切到低角度仰拍大特写命中点**，命中后再切回越肩。打破长镜头的"稳定感"——像按了处决键。

| 阶段 | 视角 | 内容 |
|------|------|------|
| 切换前 | 越肩跟拍 | 长镜头中的连续攻击 |
| 切换瞬间 | 突然切到低角度仰拍 | 命中点大特写——拳锋/肘尖/膝盖从画面外砸入 |
| 命中 | 仰拍大特写 | 皮肤凹陷/胸甲贯穿/电火花炸开——画面微震 14-18px |
| 回切 | 切回越肩视角 | 攻击方收招→被攻击方倒地 |

**标注方式**：运镜字段写「QTE切入 + 低角度仰拍」，机位字段写「QTE式切入——镜头从越肩突然切到{低角度仰拍大特写}」。

**ACT三项组合节奏（KO 标准弧线）**：
```
ACT越肩跟拍 + 命中推拉（长镜头，连续攻击，N秒）
→ QTE切入（低角度仰拍，KO一击，1.5s）
→ 升格 + 终结技环绕（子弹时间，120fps，镜头绕 180°，1.5-3s）
→ 正常速度结束（硬切黑屏或收尾镜）
```

**按场景选用指南**：

| 打斗类型 | 命中推拉 | QTE切入 | 终结技环绕 |
|---------|:---:|:---:|:---:|
| 写实巷战/近身格斗 | ✅ 推荐，增加打击密度 | ⚠️ 慎用，仅在KO一击时 | ⚠️ 慎用，仅在KO一击时 |
| BOSS终结战（机甲/巨物） | ❌ 巨物不适合快速推拉 | ✅ QTE处决感强烈 | ✅ 环绕展示空间+破坏 |
| 群战/混战 | ❌ 多目标无法锁定单一命中点 | ❌ 视角混乱 | ❌ 会被多个目标遮挡 |
| 武侠/功夫 | ✅ 适合特写招式细节 | ⚠️ 仅在致命一击时 | ⚠️ 仅在致命一击时 |
| 特效/魔法对决 | ❌ 命中推拉不适用能量碰撞 | ❌ 魔法视觉不适合仰拍 | ✅ 环绕展示元素碰撞全景 |
| 快速试探/闪避为主 | ❌ 命中太少无法形成推拉节奏 | ❌ 无KO无需QTE | ❌ 无KO无需终结技

### 13.9 袁和平六维自检

**动作流**：
- [ ] 每个动作都有原因和结果？触发条件是否标注？
- [ ] 攻防转换是否双向拉锯？是否包含 ≥3 种转换类型？
- [ ] 是否避免了"你一轮我一轮"的连攻连守模式？
- [ ] 动作表演是否用因果链连接词（顺势/不收/借力/同时/趁）串联？

**镜头流**：
- [ ] 每个镜头的角度选择有原因吗？
- [ ] 出拳阶段是否使用长镜头（≥2s）？
- [ ] 长镜头比率是否 ≥30%（写实打斗）/ ≥60%（实战风格）？
- [ ] 每个命中瞬间是否有画面微震？
- [ ] 是否使用了 ≥2 镜荷兰角？倾斜方向是否与攻击方向一致？

**空间呈现**：
- [ ] 首镜是否建立了空间关系？
- [ ] 每 3-4 个特写后是否有中景/全景重建空间？
- [ ] 攻击方向是否在每轮交锋内保持一致？
- [ ] 是否使用了贴脸镜头/前景遮挡增强临场感？

**剪辑节奏**：
- [ ] 景别是否形成"大→小→大→小"的交替？
- [ ] 是否遵循"停顿→爆发→停顿"的微节奏？
- [ ] 每个动作是否完整（不可切碎单动作）？
- [ ] 速度变化是否有至少 3-4 次加速→减速波动？
- [ ] 喘息是否只出现在叙事节点上？

**力度表达**：
- [ ] 命中证据是否与力度层级匹配？
- [ ] 是否有环境破坏作为力度标尺？
- [ ] 力的传递链条是否完整展示？
- [ ] 是否避免了穿模问题（衣料覆盖部位不描述皮肤泛红）？

**视听统一**：
- [ ] 音效是否与动作节奏同步？
- [ ] 画面是否服务于动作理解（而非反过来）？
- [ ] 每个镜头是否只做一件事？
