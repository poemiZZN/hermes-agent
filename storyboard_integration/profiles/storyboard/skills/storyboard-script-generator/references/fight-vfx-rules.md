# 特效/魔法对轰规则（VFX & Magic Combat Rules）

> 供 `Basics-pro` 技能在生成特效/魔法/异能打斗戏份时调用。
> v5.0 新增：从 action-scene-rules.md 第十一章拆出独立模块，基于电影级分析扩充。

---

## 一、核心原则——魔法是主角，角色是载体

特效打斗的视觉核心不是"谁在打"，而是"魔法长什么样"。观众记住的是传送门的金色火花圆圈、暗影触须的紫色纹路、符文护盾的六边形蜂巢——不是角色的脸。

| 原则 | 说明 |
|------|------|
| **魔法视觉规则一致性** | 每种魔法有固定的颜色、形态、粒子行为——跨镜不变 |
| **反制 > 对轰** | 最好的魔法战不是"你放波我放波"，而是"你用魔法A，我用魔法B破解A" |
| **环境破坏 = 威力标尺** | 魔法有多强不靠台词，靠环境破坏——地面龟裂范围、建筑倒塌规模 |
| **魔法有代价** | 使用魔法后角色有消耗——喘息、魔力消退、身体虚弱 |

## 二、魔法视觉规则——跨镜一致性硬约束

**致命缺陷**：AI 生成的特效打斗中，同一魔法在不同镜头中颜色/形态/粒子行为不一致——上一镜暗影触须是深紫色，下一镜变成亮蓝色。这是特效打斗最常见的穿帮。

### 2.1 魔法视觉档案

每场特效打斗开始前，必须为每种魔法建立视觉档案：

```markdown
## 魔法：{魔法名称}
颜色：{核心色} → {边缘色}（如：深紫 #3D0060 → 亮紫 #8B00FF）
形态：{球体/光束/触须/冲击波/护盾/粒子}
粒子行为：{旋转/脉动/扩散/流动/悬浮}
大小：{直径/长度/覆盖范围}
速度：{移动速度/旋转速度/脉动频率}
残留：{命中后是否留下痕迹？什么痕迹？}
```

**生成后自检**：每镜中同一魔法的颜色/形态/粒子行为是否与档案一致？

### 2.2 能量/魔法攻击的视觉描述模板

| 攻击类型 | 视觉描述模板 | 色温/光效 |
|---------|------------|---------|
| 能量弹/光球 | {颜色}光球在掌心{凝聚/旋转}，表面{粒子/符文/电弧}流转，直径约{X}cm，脱离掌心后以{速度}轨迹射向{目标} | 单色高亮 + 同色系粒子拖尾 |
| 光束/射线 | {颜色}光束从{身体部位/武器}射出，直径{X}cm，边缘{锐利/模糊/跳动}，射程内空气{电离/扭曲/冻结} | 核心白→边缘渐变至{颜色} |
| 范围冲击波 | 以{角色}为中心，{颜色}冲击波呈{环形/球形}向外扩散，所过之处{地面龟裂/物体掀飞/空气扭曲} | 冲击波前缘高亮，尾部渐暗 |
| 元素召唤 | {火焰/冰霜/雷电/暗影}从{角色}身周{涌出/凝聚/降临}，形态呈{龙卷/巨兽/触须/风暴}，{数量}条/道 | 元素本色 + 环境光被元素色覆盖 |
| 瞬移/闪现 | 身形{模糊/化作粒子/被暗影吞没}，{0.Xs}后在目标位置{重新凝聚/从粒子中显形/从暗影中踏出}，原位置残留{残影/光尘/暗影余烬} | 过渡色——原位置渐暗，目标位置渐亮 |

### 2.3 防御/护盾的视觉描述模板

| 防御类型 | 视觉描述 | 受击反应 |
|---------|---------|---------|
| 能量护盾 | {颜色}半透明{球形/六边形蜂巢/符文阵列}包裹角色，表面{数据流/符文/能量纹路}流转 | 被命中时护盾{闪烁/凹陷/产生涟漪}，命中点颜色{变亮/变暗} |
| 魔法屏障 | {颜色}光墙在角色前方{展开/升起}，{半透明/完全不透明}，表面{符文/魔法阵}旋转 | 被命中时屏障{震颤/裂纹扩散/符文加速旋转} |
| 元素抵消 | 以{对立元素}迎击——火焰被冰霜熄灭、暗影被光柱驱散 | 两股元素在碰撞点{互相侵蚀/同时湮灭/产生爆炸} |

## 三、节奏弧线——蓄力→释放→碰撞→反制→余波

特效打斗的节奏与写实打斗完全不同——**魔法需要蓄力，不是即时的**。

```
① 蓄力 Beat（3-5s，1-2镜）：能量凝聚——能量在掌心/身周积聚
② 释放 Beat（2-4s，1-2镜）：能量释放——光束/弹幕/冲击波射出
③ 碰撞 Beat（2-3s，1-2镜）：能量命中——护盾/屏障/元素碰撞
④ 反制 Beat（3-5s，1-2镜）：对方反击——另一种能量/魔法回击
⑤ 余波 Beat（3-5s，1-2镜）：能量消散——环境残留、角色喘息
```

**与写实打斗的节奏对比：**
```
写实：起势(对峙) → 交锋(试探) → 升级(连击) → 高潮(致命一击) → 收尾
特效：蓄力(凝聚) → 释放(射出) → 碰撞(命中) → 反制(回击) → 余波(消散)
       慢          极快         爆          慢→极快       慢
```

### 3.1 反制 > 对轰——魔法战的精髓

**错误做法**：你放一个波，我放一个波，两个波在空中碰撞 → 无限循环。这就是"站桩式魔法对轰"，和站桩打斗一样无聊。

**正确做法**：每一轮攻击-反制必须形成**逻辑链条**：
```
A 释放暗影触须 → B 展开符文护盾格挡 → A 瞬移至 B 身后绕过护盾 → B 预判，护盾自动扩展至后背 → A 被弹飞
```

每轮反制不是"换一种颜色再放一次"，而是"用新的魔法破解上一轮魔法的弱点"。

**反制设计模板：**
| 上一轮攻击 | 弱点 | 反制方式 |
|-----------|------|---------|
| 能量弹幕 | 扇形扩散，中间有缝隙 | 从缝隙中穿过，近身攻击 |
| 护盾格挡 | 护盾有方向性，后方无防护 | 瞬移至身后攻击 |
| 光束直射 | 直线轨迹，可预判 | 侧闪 + 同时反击 |
| 范围冲击波 | 扩散需要时间 | 在扩散前近身打断蓄力 |

## 四、镜头与运镜

### 4.1 景别比例

| 景别 | 占比 | 用途 |
|------|:---:|------|
| 全景 | 15% | 展示魔法规模——能量覆盖范围、环境破坏 |
| 中景 | 25% | 角色与魔法的关系——谁在释放、谁在格挡 |
| 大特写 | 60% | 魔法细节——能量凝聚、符文流转、碰撞侵蚀边界 |

### 4.2 运镜配对

| 特效动作 | 推荐运镜 | 原因 |
|---------|---------|------|
| 能量凝聚/蓄力 | 推近压迫镜头（极慢） | 聚焦掌心/身周——能量从小到大 |
| 能量释放/射出 | 贴地掠行/斜向俯冲 | 跟随能量弹/光束的飞行轨迹 |
| 范围冲击波 | 抽离镜头（快速后撤） | 展示冲击波扩散范围 |
| 元素碰撞 | 打击冻结 + 子弹时间 | 两股能量碰撞瞬间冻结，展示侵蚀边界 |
| 瞬移/闪现 | 快速推进变焦 | 从原位置急速推至目标位置 |
| 护盾展开 | 升降镜头 | 跟随护盾从脚底向头顶展开 |
| 魔法余波 | 空镜余韵镜头 | 能量粒子飘落、环境破坏残留 |

### 4.3 关键镜头——魔法碰撞冻结帧

特效打斗最具辨识度的镜头：两股能量碰撞的瞬间，画面冻结 0.5s，展示侵蚀边界——银蓝色光如火焰般侵蚀暗影，暗影如触须般缠绕光束。冻结帧中能量粒子悬浮如星空。

## 五、魔法代价——角色不是永动机

**每个魔法释放后，角色必须有消耗反应**：喘息、魔力消退、身体虚弱、汗珠滑落。禁止"连续释放 5 个魔法脸不红气不喘"。

| 魔法强度 | 消耗反应 | 恢复时间 |
|---------|---------|---------|
| 小魔法（弹幕/光束） | 轻微喘息，魔力微暗 | 1-2s |
| 中魔法（冲击波/护盾） | 明显喘息，魔力大幅消退 | 3-5s，需穿插喘息镜 |
| 大魔法（终极一击） | 剧烈喘息，魔力几乎耗尽，汗珠滑落 | 5-8s，必须穿插 1-2 个喘息镜 |

## 六、音效设计

| 特效元素 | 音效设计 | 频率/特征 |
|---------|---------|---------|
| 能量凝聚 | 低频嗡鸣——渐强 | 40-80Hz·渐强·60→80dB |
| 能量释放 | 高频撕裂——瞬间爆发 | 2-4kHz·0.3s·85-95dB |
| 光束/射线 | 持续高频——如电流 | 3-6kHz·持续·70-80dB |
| 冲击波扩散 | 超低频——从中心向外 | 20-40Hz·0.5s·90-100dB |
| 护盾受击 | 金属共鸣——如钟鸣 | 1-2kHz·0.3s·80dB |
| 元素碰撞 | 两种音色叠加——互相侵蚀 | 低频+高频同时·0.5s |
| 瞬移 | 短促高频——如空气被撕裂 | 4kHz·0.1s·70dB |
| 能量消散 | 嗡鸣渐弱——如退潮 | 60Hz·渐弱·80→40dB |

## 七、自检

生成特效打斗镜后检查：
- [ ] 每种魔法是否建立了视觉档案？同一魔法在跨镜中颜色/形态/粒子行为是否一致？
- [ ] 是否遵循了"蓄力→释放→碰撞→反制→余波"的节奏弧线？
- [ ] 每轮反制是否形成了逻辑链条（破解上一轮弱点），而非简单对轰？
- [ ] 魔法释放后角色是否有消耗反应？高强度魔法后是否穿插了喘息镜？
- [ ] 魔法威力是否通过环境破坏展示？（地面龟裂/建筑倒塌/元素侵蚀）
- [ ] 碰撞冻结帧是否展示了侵蚀边界的细节？

## 八、特效融入感——灯光交互与环境互动（v5.1 新增）

> **6 维光影基础**：特效融入感建立在通用光影系统之上。特效场景的「画面描述」字段应同时覆盖：① 基础 6 维光影参数（光源方向/质量/色温/对比度/光型/光源动机，详见 SKILL.md 字段规范中的光影速查表）+ ② 以下 5 维特效交互。

**致命缺陷**：AI 生成的特效常常"浮"在画面之上——特效看起来很假，和场景/人物风格不统一，像贴上去的贴纸。根因是 prompt 只描述了特效本身，没有描述特效如何与场景互动。

### 8.1 五条融入原则

| 原则 | 说明 | 必须写在「画面描述」中 |
|------|------|----------------------|
| **灯光投射** | 特效光源必须照亮附近物体 | "暗影光球从下方照亮莉维娅面部，冷紫色光在面部形成上暗下明的 split lighting" |
| **环境反射** | 特效必须在反光表面产生倒影 | "金色光束在竞技场地面水渍中投下移动的金色倒影" |
| **颜色溢出** | 特效颜色必须"染"到周围环境 | "暗影触须所过之处，石砖表面被暗紫色光晕染——如墨水扩散" |
| **大气散射** | 空气中尘埃/雾气被特效光照亮 | "符文光束穿过空中悬浮的尘埃——尘埃被照亮呈金色光柱" |
| **遮挡关系** | 特效必须被前景物体部分遮挡 | "暗影光球被莉维娅右手掌遮挡——手掌边缘被暗紫色逆光勾勒" |

### 8.2 融入感描述模板

每镜的「画面描述」字段必须包含至少 2 条融入感描述：

```
画面描述：
{灯光投射}——{特效}从{方向}照亮{被照亮的物体}，{色温}光在{被照面}形成{明暗效果}
{颜色溢出}——{特效}的{颜色}光晕{染/扩散}到{周围环境}，{环境表面}被{颜色}光染色
{环境反射}——{特效}在{反光表面}中投下{颜色}倒影/反射
{大气散射}——{特效}穿过空气中{尘埃/雾气/水汽}，{尘埃}被照亮呈{颜色}光柱
{遮挡关系}——{前景物体}遮挡{特效}的{部分}，{前景物体}边缘被{颜色}逆光勾勒
```

### 8.3 融入感对比示例

**融入前（特效如贴纸，不融入场景）：**
```
❌ 画面描述：暗影光球在掌心旋转，表面暗紫色符文流转。景深 f/1.8。
```

**融入后（特效融入场景，五条原则全覆盖）：**
```
✅ 画面描述：暗影光球在掌心旋转——核心深黑（#0A0015），表面暗紫色符文（#3D0060）流转。
   【灯光投射】光球从下方照亮莉维娅面部——冷紫色光在面部形成上暗下明的 split lighting，
   瞳孔中倒映暗影光球如针尖大小紫色光点。
   【颜色溢出】光球周围的月光被暗影吞噬——光球边缘形成一个移动的暗区，
   暗区内的石砖地面被暗紫色光晕染如墨水扩散。
   【大气散射】空气中悬浮的尘埃在光球周围被暗紫色光照亮——形成微型暗紫色光晕。
   【遮挡关系】光球被莉维娅右手掌部分遮挡——手掌边缘被暗紫色逆光勾勒。
   景深 f/1.8。
```

### 8.4 融入感自检

每镜生成后检查：
- [ ] 「画面描述」是否同时覆盖了 6 维基础光影（方向/质量/色温/对比度/光型/光源动机）和 5 维特效交互？
- [ ] 「画面描述」是否包含至少 1 条灯光投射？（特效照亮了什么？）
- [ ] 「画面描述」是否包含至少 1 条颜色溢出？（特效颜色染到了什么？）
- [ ] 场景中是否有反光表面？（如有，是否写了特效在其中的倒影？）
- [ ] 空气中是否有尘埃/雾气？（如有，是否写了特效光穿过大气的散射效果？）
- [ ] 特效是否被前景物体遮挡？（如有，是否写了遮挡关系和逆光效果？）
