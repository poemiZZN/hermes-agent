# 无声情绪戏规则（Emotional Scene Rules）

> 供 `Basics-pro` 技能在生成无声情绪戏份时调用。
> v4.0 新增，v5.6 升级：演员表演部分升级为引用通用表演系统 `performance-system.md`。
>
> **表演系统引用**：无声情绪戏的演员表演（微表情/身体语言/呼吸）统一使用 `references/performance-system.md` 的通用规则。本文件保留无声情绪戏专属的段落结构、景别、运镜、光线、声音设计规则。

---

## 一、核心原则——少即是多

无声情绪戏与对白戏/打斗戏有本质区别：**信息密度越低，情感密度越高**。不要用镜头数量填充时间，用留白和微表情填充。

| 维度 | 对白戏/打斗戏 | 无声情绪戏 |
|------|-------------|----------|
| 镜头时长 | 1.5-5.5s | **3-10s**（单镜可长达 10s） |
| 镜头数量 | 密集（每段 4-8 镜） | 稀疏（每段 2-4 镜） |
| 剪辑节奏 | 快切/对切 | 长镜头/慢推/定格 |
| 景别 | 多样化 | **大特写 80%+** |
| 运镜 | 主动（跟/推/环绕） | 被动（微推/定格/手持微晃） |
| 信息传达 | 对白/动作 | 微表情/呼吸/环境 |

---

## 二、时长基准

无声情绪镜头不含对白也不含动作，不使用第 3 步或第 3.A 步的计时公式。使用以下基准：

| 情绪类型 | 单镜时长 | 原因 |
|---------|---------|------|
| 凝视/思考 | 4-8s | 需要时间让观众进入角色的内心世界 |
| 悲伤/哭泣 | 5-10s | 眼泪从酝酿到滑落需要物理时间 |
| 愤怒/压抑 | 3-6s | 微表情变化节奏较快 |
| 孤独/空虚 | 6-10s | 留白本身就是情绪——环境音为主角 |
| 回忆/闪回 | 3-5s/镜 | 片段式、碎片化——但单镜仍比打斗镜长 |
| 释然/微笑 | 4-7s | 情感从酝酿到释放的完整弧线 |

**一镜到底原则**：如果一个情绪弧线（如从平静到流泪）可以在单镜内完成，就不要切。单镜 8-10s 的无声情绪镜比 4 个 2s 的快切更有力量。

## 三、微表情拆解模板

无声情绪戏的"动作表演"字段不写肢体动作，写微表情的五层递进：

```
动作表演（情绪镜模板）：
0-Xs  眼睛——{瞳孔变化/视线方向/眨眼频率}
X-Ys  眉毛——{眉间变化/眉形}
Y-Zs  嘴巴——{唇部变化/嘴角}
Z-Ws  呼吸——{频率/深度/胸腔起伏}
W-结束 手部——{手指/手掌的细微动作}（仅当手在取景范围内）
```

**微表情词汇库：**

| 层级 | 悲伤 | 愤怒 | 恐惧 | 喜悦 | 思考 |
|------|------|------|------|------|------|
| 眼睛 | 眼眶泛红→泪光积聚→泪水滑落 | 瞳孔缩小→眼神锐利→眼白增多 | 瞳孔放大→眼神游移→眼睑颤抖 | 眼角微弯→眼中有光→笑意蔓延至眼周 | 视线固定→瞳孔微扩→眼神放空 |
| 眉毛 | 眉头上扬→眉间微蹙→眉尾下垂 | 眉间紧锁→眉尾下压→眉心形成竖纹 | 眉头上扬→眉尾上挑→眉心舒展 | 眉间舒展→眉尾微扬→眉毛自然 | 眉间微蹙→眉头微抬→眉尾不动 |
| 嘴巴 | 嘴角下垂→嘴唇微颤→下唇咬住 | 牙关紧咬→嘴唇抿成一线→嘴角下拉 | 嘴唇微张→嘴角颤抖→嘴唇发白 | 嘴角上扬→嘴唇微启→笑意漾开 | 嘴唇微抿→嘴角不动→舌尖轻舔嘴唇 |
| 呼吸 | 呼吸变浅→间或深吸气→叹息式呼出 | 呼吸急促→鼻翼翕动→胸腔起伏 | 呼吸停滞→急促短吸→开始过度换气 | 呼吸平稳→轻叹一声→呼吸更深 | 呼吸变缓→屏息 2-3s→恢复呼吸 |
| 手部 | 手指蜷缩→抓紧衣角→松开 | 握拳→指关节泛白→微微颤抖 | 手指冰凉→指尖微颤→抓住物体 | 手掌轻抚胸口→手指自然放松 | 手指轻敲→托腮→指尖摩挲物体 |

**示例：**
```
动作表演：
0-2s 眼眶泛红——泪光在眼眶中积聚，视线模糊但仍锁定画面外某物
2-4s 眉头上扬——眉间微蹙，眉心形成浅纹
4-6s 下唇咬住——嘴唇微颤，嘴角下垂
6-8s 第一滴泪从左眼滑落——沿脸颊滑至下颌，呼吸变浅，胸腔起伏减弱
8-10s 泪水连续滑落——呼吸转为间或深吸气，右手手指缓缓蜷缩抓紧衣角
```

## 四、景别与运镜

### 景别比例

| 景别 | 占比 | 用途 |
|------|:---:|------|
| 大特写（眼部/嘴部/手部） | ≥60% | 微表情——情绪戏的核心 |
| 特写（面部） | 20% | 面部整体情绪 |
| 中近景 | 15% | 人物与环境的关系（孤独感） |
| 中景/全景 | ≤5% | 仅环境建立——人物在环境中显得渺小 |

### 运镜原则

无声情绪戏的运镜应该**被动、缓慢、克制**——镜头是观察者，不是参与者。

| 运镜 | 速度 | 情绪效果 |
|------|------|---------|
| 微推（极慢） | 0.5-1mm/s | 逐渐靠近角色的内心世界 |
| 定格 | 静止 | 让观众有足够时间感受情绪 |
| 手持微晃 | 0.3Hz | 如呼吸般的轻微晃动——代入感 |
| 后撤疏离 | 极慢 | 角色被环境吞没——孤独感 |
| 空镜余韵 | 静止 | 角色离开后情绪仍留在空间中 |

**禁止的运镜**：快速推拉、环绕、快切、甩镜——任何主动的运镜都会打断情绪沉浸。

## 五、光线与声音设计

### 光线

无声情绪戏的光线应该**参与叙事**——用光影变化映射角色的内心状态。按 6 维参数配置：

| 情绪 | 光线描述 | 色温 | 光源动机 | 氛围 |
|------|---------|------|---------|------|
| 悲伤 | 单侧柔光 + 对比度 4:1 + 半面光 | 冷色 5600K | 画面外单侧窗光 | 半张脸隐入阴影，泪光在亮侧可见——孤独感 |
| 孤独 | 顶光 + 漫射光 + 对比度 8:1 + 无特定 | 冷色 6000K+ | 画面外单一顶灯 | 人物在画面中占比 <30%，大面积阴影吞噬——环境光为主 |
| 愤怒 | 侧光 + 硬光 + 对比度 8:1 + 分割光 | 中性 4000K | 画面外单侧光源 | 面部半明半暗，阴影锐利——内心冲突外化 |
| 释然 | 正面光 + 柔光 + 对比度 2:1 + 无特定 | 暖色 3200K | 画面外窗光（晨光） | 均匀照亮面部，暖色调——释然如日出 |
| 回忆 | 逆光 + 柔光 + 对比度 2:1 + 无特定 | 暖色 2800K | 画面外逆光（夕阳/窗光） | 柔焦——画面边缘柔化，高光溢出，梦幻感 |

> **光源动机强制规则**：每镜必须写明光的来源。无声情绪戏中光源动机尤为关键——孤独的"单一顶灯"、回忆的"夕阳逆光"、释然的"晨光窗光"——光源本身就是情绪隐喻。

### 声音

无声情绪戏的声音设计原则：**去掉所有非必要声音，让环境音和生理音成为主角**。

| 声音元素 | 用法 |
|---------|------|
| 呼吸声 | 主角——频率和深度随情绪变化 |
| 心跳声 | 后台脉冲——仅在情绪高潮时混入 |
| 环境底噪 | 雨声/风声/钟表滴答——作为情绪放大器 |
| 衣物摩擦 | 极轻微——角色微动时触发 |
| 泪滴声 | 仅在高潮瞬间——泪滴落在地面/衣物上的极轻微声音 |

**严禁**：BGM、任何旋律性声音、环境音以外的任何主动音效。

## 六、段落结构

无声情绪戏的段落结构不遵循打斗的五段式弧线，而遵循**情绪弧线**：

```
① 建立（1 镜，4-6s）：环境或面部——建立情绪基调
② 酝酿（1-2 镜，6-12s）：微表情渐进——情绪从平静向高潮推进
③ 高潮（1 镜，5-8s）：情绪爆发点——泪落/微笑/释然/崩溃
④ 回落（1 镜，4-6s）：情绪从高潮回落——呼吸平稳，残留
```

## 七、自检

生成无声情绪镜后检查：
- [ ] 单镜时长是否在 3-10s 范围内？是否存在 <2s 的碎片镜？
- [ ] 动作表演是否使用了微表情五层递进（眼→眉→嘴→呼吸→手）？
- [ ] 运镜是否被动/缓慢/克制？是否存在快速/主动的运镜？
- [ ] 景别是否以大特写为主（≥60%）？
- [ ] 声音设计是否以呼吸/心跳/环境音为主？是否禁止了 BGM？
- [ ] 光线是否服务于情绪？6 维参数是否完整（方向/质量/色温/对比度/光型/光源动机）？光源动机是否已写明？
- [ ] 是否存在一整段情绪弧线（建立→酝酿→高潮→回落）？
