# 电影打斗风格参考库（Fight Style Reference Library）

> 供 `Basics-pro` 技能在生成打斗戏份时参考。
> v5.1 新增：提供多样化的打斗风格参考，避免陷入单一模板。

---

## 使用原则

**模板是起点，不是终点。** 每场打斗的设计应回答三个问题：
1. **这场打斗的叙事目的是什么？**（展示实力差距？制造紧张？释放情绪？角色成长？）
2. **角色的性格如何影响打斗风格？**（冷静型用精准高效的动作，暴躁型用狂野混乱的动作）
3. **这场打斗在整部剧的情感弧线中处于什么位置？**（开场炫技？中点转折？结局决战？）

---

## 一、按叙事目的分类

### 1.1 实力展示型——"碾压"

**目的**：展示一个角色压倒性的实力，让观众敬畏。

**代表作品**：John Wick 俱乐部场景、Ip Man "我要打十个"、Darth Vader 走廊屠杀

**设计要素**：
- 主角动作简洁高效——一拳一个，不恋战
- 镜头以中景跟随主角——不切碎，展示流畅的杀敌路线
- 敌人不断涌来但如纸片般倒下——数量不是威胁
- 主角表情平静甚至无聊——杀戮对他来说是日常
- 节奏：主角匀速推进，敌人加速倒下

**镜头设计**：长镜头跟拍主角穿越战场，主角在画面中央稳定，敌人从画面边缘进入→被击倒→退出

### 1.2 势均力敌型——"苦战"

**目的**：双方实力相当，观众无法预测谁会赢。

**代表作品**：The Raid 2 厨房决战、Rocky 拳击赛、Hero 李连杰 vs 甄子丹

**设计要素**：
- 双方轮流占上风——A 压制 B → B 反击压制 A → 循环
- 伤害双向累积——两人都在变慢、变弱
- 环境被逐渐破坏——打斗的激烈程度通过环境破坏升级
- 中间穿插对峙喘息——不是一直打，有重新评估对方的时间
- 节奏：爆发→对峙→更激烈的爆发→更长的对峙

**镜头设计**：中景对称构图——两人各占画面一半，攻击-反击-攻击-反击的循环在同一个镜头中完成

### 1.3 以弱胜强型——"逆转"

**目的**：弱势方利用智慧/环境/意志力战胜强大对手。

**代表作品**：Die Hard 麦克莱恩、Home Alone、The Matrix Neo 觉醒

**设计要素**：
- 弱势方不断躲避——不是正面对抗，而是利用环境周旋
- 环境即武器——弱势方用周围一切可以拿到的东西反击
- 弱势方每次反击都付出代价——受伤更重，但意志更坚定
- 关键转折点——弱势方发现对手的弱点，局势逆转
- 节奏：躲避→躲避→微小反击→再次躲避→发现弱点→逆转

**镜头设计**：POV 穿插——弱势方视角看到对手的巨大和压迫感，观众代入弱势方

### 1.4 情绪宣泄型——"爆发"

**目的**：角色压抑已久的情绪在打斗中爆发，打斗是情感的出口。

**代表作品**：Oldboy 走廊锤子战、The Raid、Kill Bill 新娘复仇

**设计要素**：
- 打斗不是"技术性的"，是"情绪性的"——动作粗糙但有力量
- 角色在打斗中会吼叫、哭喊、笑——情感外露
- 伤害不是阻碍——角色即使受伤也继续前进，愤怒驱动
- 打斗结束后角色崩溃——情绪释放后的空虚/疲惫
- 节奏：渐进式疯狂——开始有章法，越来越狂野，最后完全失控

**镜头设计**：手持晃动——镜头像情绪一样不稳定，从客观记录者变为情绪参与者

### 1.5 初次交锋型——"试探"

**目的**：两个角色第一次交手，互相试探实力，为后续决战铺垫。

**代表作品**：The Matrix Neo vs Morpheus 训练场、Batman Begins 忍者训练

**设计要素**：
- 攻击不致命——试探性的刺拳、低扫，不是全力攻击
- 大量走位和观察——角色在交手后拉开距离，重新评估
- 每个角色展示 1-2 个标志性招式——为后续决战埋下伏笔
- 打斗以"平局"或"中断"结束——不是决战，不需要分出胜负
- 节奏：试探→评估→试探→评估→中断

**镜头设计**：中景+全景为主——展示空间关系和走位，不需要大特写命中点

## 二、按角色性格分类

### 2.1 冷静精准型

**代表角色**：John Wick、Jason Bourne、Agent 47

**动作特征**：每个动作有明确目的，无多余动作，枪枪爆头、拳拳要害
**镜头特征**：稳定、中景为主、长镜头展示流畅的杀敌序列
**节奏**：匀速——如机器运转，不快不慢，稳定输出

### 2.2 狂野混乱型

**代表角色**：The Joker、Trevor (GTA V)、Tyler Durden

**动作特征**：动作不规则、不可预测，利用身边一切物品，不在乎自己受伤
**镜头特征**：手持晃动、快切、倾斜构图——镜头和角色一样混乱
**节奏**：忽快忽慢——一会儿疯狂输出，一会儿停下来喘气大笑

### 2.3 优雅技巧型

**代表角色**：James Bond、Sherlock Holmes (RDJ)、黑寡妇

**动作特征**：动作如舞蹈——流畅、精准、有美感，利用西装/道具
**镜头特征**：慢动作关键帧、稳定器平滑跟拍、对称构图——镜头和动作一样优雅
**节奏**：慢→快→慢——慢动作起势，极快出手，慢动作收势

### 2.4 暴力碾压型

**代表角色**：Hulk、Bane、The Mountain

**动作特征**：不防守，不闪避，硬扛攻击然后一拳打飞对手
**镜头特征**：低角度仰拍——巨物感，画面微震——每次命中镜头都在颤抖
**节奏**：慢→爆→慢——缓慢逼近，一拳爆炸性输出，缓慢走向下一个目标

## 三、按环境分类

### 3.1 狭窄空间

**代表作品**：Oldboy 走廊、The Raid 楼道、Daredevil 走廊

**环境特征**：宽度限制人数优势，长度提供推进路线
**动作设计**：主角沿走廊推进，敌人从两侧房间涌出，利用墙壁作为武器
**镜头设计**：侧面长镜头跟拍走廊推进，背景是不断涌来的敌人

### 3.2 开阔空间

**代表作品**：Hero 沙漠、Mad Max 沙漠、Gladiator 竞技场

**环境特征**：无遮挡，视线开阔，适合大规模战斗
**动作设计**：需要建立空间坐标——观众需要知道每个人/每辆车的位置
**镜头设计**：航拍建立空间→中景展示战斗→特写展示关键瞬间

### 3.3 多层空间

**代表作品**：The Raid 楼层战、John Wick 3 玻璃屋、Inception 旋转走廊

**环境特征**：上下多层，垂直移动，每层有不同的威胁
**动作设计**：角色在不同层之间移动——坠落、攀爬、跳跃
**镜头设计**：纵向运镜——镜头跟随角色上下移动，展示空间层次

### 3.4 环境交互型

**代表作品**：Jackie Chan 任何电影、The Raid 2 厨房

**环境特征**：环境中每件物品都是潜在武器
**动作设计**：角色不只用拳头，用椅子、锅、玻璃、门框——环境即武器
**镜头设计**：中景——需要展示角色和环境物品的空间关系

## 四、经典打斗场景拆解

### 4.1 John Wick 俱乐部（写实枪战+格斗，1vN）

**叙事目的**：展示 John Wick 压倒性的实力 + 复仇情绪的宣泄
**结构**：入场→第一波敌人（快速解决）→第二波敌人（开始吃力）→BOSS（苦战）
**镜头**：长镜头跟拍 + 中景为主 + 环境交互
**节奏**：匀速推进——John 的节奏不变，敌人的数量在变
**可借鉴点**：长镜头不切碎动作链条、环境交互让打斗不单调

### 4.2 Hero 棋馆（武侠，1v1）

**叙事目的**：首次交锋试探 + 展示武侠的美学
**结构**：对峙→琴声起→招式交锋→琴声停→对峙结束，全程无对白
**镜头**：对称构图 + 慢动作关键帧 + 全景展示招式
**节奏**：慢→快→慢→快→极慢——节奏如音乐
**可借鉴点**：打斗的节奏和背景音乐同步、用颜色区分角色

### 4.3 Oldboy 走廊（群战，1vN）

**叙事目的**：情绪宣泄——主角被囚禁 15 年后的愤怒释放
**结构**：主角从走廊左侧推进到右侧，敌人不断涌来
**镜头**：侧面长镜头从左到右跟拍，全程不切
**节奏**：主角越打越累，但敌人不断涌来——疲劳感递增
**可借鉴点**：长镜头+侧面视角、主角从轻松到吃力的过渡

### 4.4 The Raid 2 厨房（写实格斗，1v1）

**叙事目的**：苦战——双方势均力敌，环境逐渐被破坏
**结构**：试探→交锋→环境破坏升级→双方受伤→致命一击
**镜头**：中景为主，稳定器跟拍，环境破坏在同一个镜头中展示
**节奏**：爆发→对峙→更激烈的爆发→更长的对峙
**可借鉴点**：环境破坏作为打斗激烈程度的标尺、伤害双向累积

### 4.5 Doctor Strange 镜像维度（特效/魔法，1v1）

**叙事目的**：展示魔法的视觉奇观 + 师徒对决
**结构**：魔法展示→环境折叠→追逐→陷阱→反制→逃脱
**镜头**：全景展示魔法规模 + 大特写魔法细节 + 环境折叠的长镜头
**节奏**：魔法展示（慢）→环境变化（快）→追逐（极快）→对峙（慢）
**可借鉴点**：魔法改变环境——不是简单的能量对轰，环境本身参与战斗

### 4.6 袁和平《太极张三丰》刀战（武侠，1v1）——v5.5 新增

**叙事目的**：展示武侠的因果链——每个动作引发下一个动作
**结构**：对峙→钱小豪砍向李连杰腿部→李连杰被迫跃起→跃起后顺势旋子转体→转身从最佳角度劈下
**镜头**：单机位侧面 45°——同时看到刀锋轨迹和命中点
**可借鉴点**：因果链设计——不是"你砍一刀我砍一刀"，而是每个动作都是被迫产生的

### 4.7 袁和平《精武英雄》道场（写实格斗，1vN）——v5.5 新增

**叙事目的**：展示袁和平式群战——空间锚定+每 3-4 镜重建
**结构**：首镜全景建立道场→中景跟拍主角推进→每 3 个特写后回到中景重建空间
**可借鉴点**：群战空间管理——主角路线清晰，敌人分层涌来，每 3-4 镜重建空间

### 4.8 袁和平《卧虎藏龙》竹林（武侠，1v1）——v5.5 新增

**叙事目的**：展示钢丝的物理可信度——增强，不是飞行
**结构**：对峙→竹梢借力跃起→空中交手→竹梢借力落下→再对峙
**镜头**：单机位全景——展示竹梢上的两人和竹身的弯曲弧度
**可借鉴点**：钢丝必须有借力点，滞空不超过 1.5s，落地有缓冲
