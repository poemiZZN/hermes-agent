# 枪战规则（Gunfight Rules）

> 供 `Basics-pro` 技能在生成枪战/射击战斗戏份时调用。
> v5.1 新增：基于电影级分析，建立枪战的空间逻辑和战术体系。

---

## 一、核心原则——空间清晰度 > 一切

枪战最容易犯的错误：全程快切枪口火焰+中弹反应，观众不知道谁在哪里、子弹从哪来。**枪战的第一要务是让观众理解空间关系。**

| 原则 | 说明 |
|------|------|
| **先建立空间** | 枪战开始前用 1 镜展示空间布局——谁在哪里、掩体在哪 |
| **掩体逻辑** | 每个角色始终有掩体——没有掩体 = 死亡 |
| **弹药管理** | 弹夹有限，需要换弹——换弹是最脆弱的时刻 |
| **声音设计** | 不同枪械不同声音——手枪、步枪、霰弹枪各自不同 |
| **射击反应** | 中弹后身体反应——手臂中弹无法持枪、腿部中弹跛行 |

---

## 二、空间建立——枪战前必须的 1 镜

**枪战开始前，必须用 1 个全景/中景镜头建立空间：**

```
镜 0（全景）：展示空间布局——角色A在掩体后（左侧），角色B在掩体后（右侧），
     掩体是什么（车/墙/柱子），空间有多大，有无其他出口
```

**没有这个镜头的枪战 = 空间混乱的枪战。**

---

## 三、掩体逻辑——枪战的空间规则

| 规则 | 说明 |
|------|------|
| 掩体覆盖方向 | 掩体只能防护一个方向——角色必须时刻注意暴露的侧面 |
| 掩体切换 | 角色从掩体A移动到掩体B时最脆弱——需要掩护射击 |
| 掩体破坏 | 掩体可以被子弹/爆炸破坏——不是永久安全 |
| 无掩体 = 死亡 | 暴露在开阔地的角色必须在 1-2 镜内中弹或找到掩体 |

---

## 四、弹药管理——紧张感的来源

| 弹药状态 | 视觉表现 | 镜头 |
|---------|---------|------|
| 射击中 | 枪口火焰 + 弹壳弹出 | 中景全身 |
| 弹夹将尽 | 滑套锁定/弹仓空转声 | 大特写枪械 |
| 换弹 | 手部动作——拔出空弹夹→插入新弹夹→拉滑套 | 大特写手部 |
| 弹药耗尽 | 扔枪/拔备用枪/肉搏 | 中景全身 |

**节奏设计**：每次换弹都是节奏的"呼吸点"——射击（快）→ 换弹（慢）→ 射击（快）。

---

## 五、声音设计——枪战的第一主角

枪战的声音设计比画面更重要。不同枪械有不同的声音特征：

| 枪械类型 | 声音特征 | 频率 |
|---------|---------|------|
| 手枪 | 清脆、短促 | 1-3kHz，0.1s |
| 步枪 | 响亮、有回音 | 500Hz-2kHz，0.2s |
| 霰弹枪 | 沉重、有机械声 | 200-800Hz，0.3s |
| 消音器 | 闷响 + 机械声 | 500Hz，0.1s |
| 弹壳落地 | 清脆金属声 | 2-4kHz，0.05s |

**环境回响**：室内枪战必须有回响——枪声在墙壁之间反弹。室外枪战枪声更干净。

---

## 六、中弹反应——不同部位不同反应

| 中弹部位 | 反应 |
|---------|------|
| 手臂 | 手臂被弹开——无法持枪，换手射击 |
| 腿部 | 单膝跪地——跛行，无法快速移动 |
| 躯干（有防弹衣） | 身体被冲击力推动后仰——钝痛，但继续战斗 |
| 躯干（无防弹衣） | 立即倒地——无法继续战斗 |
| 头部 | 瞬间倒地——死亡 |

**禁止**：中弹后若无其事继续射击——除非角色穿了防弹衣。

## 七、镜头与运镜

### 7.1 景别比例

| 景别 | 占比 | 用途 |
|------|:---:|------|
| 全景 | 15% | 建立空间——展示所有角色和掩体位置 |
| 中景 | 40% | 射击姿态——角色在掩体后的全身动作 |
| 大特写 | 30% | 枪口火焰、弹壳弹出、换弹手部、中弹反应 |
| POV | 15% | 瞄准视角——准星对准目标 |

### 7.2 运镜配对

| 枪战动作 | 推荐运镜 | 原因 |
|---------|---------|------|
| 空间建立 | 航拍/全景固定 | 让观众看清空间布局 |
| 射击 | 中景稳定——手持微晃 | 模拟战场的不稳定 |
| 换弹 | 大特写手部 | 紧张感在手指上 |
| 掩体切换 | 跟镜——跟随角色移动 | 观众体验移动的脆弱感 |
| 中弹 | 画面微震 + 身体被推开 | 冲击力通过镜头和身体反应传达 |

## 八、节奏弧线——交火→换弹→压制→推进→决战

```
① 交火 Beat（3-5s，2-3镜）：双方射击——子弹命中掩体，碎片飞溅
② 换弹/喘息 Beat（2-3s，1-2镜）：换弹夹——角色呼吸急促，评估局势
③ 压制 Beat（3-5s，1-2镜）：一方火力压制——另一方被压在掩体后无法抬头
④ 推进 Beat（3-5s，2-3镜）：掩护射击下推进——从掩体A移动到掩体B
⑤ 决战 Beat（3-5s，1-2镜）：近距离交火——弹药将尽，可能转为肉搏
```

## 九、自检

生成枪战镜后检查：
- [ ] 枪战开始前是否有 1 镜建立空间？（展示所有角色和掩体位置）
- [ ] 每个角色是否始终有掩体？暴露在开阔地的角色是否在 1-2 镜内中弹或找到掩体？
- [ ] 是否至少有一次换弹？换弹时是否有大特写手部？
- [ ] 中弹后是否有身体反应？（手臂中弹换手、腿部中弹跛行）
- [ ] 声音设计是否区分了不同枪械？（手枪、步枪、霰弹枪各自不同）
- [ ] 室内枪战是否有环境回响？
