# 变奏机制规则（Variation Rules）

> 供 `Basics-pro` 技能在跨集生成时调用。
> v4.1 新增：解决 60 集模板疲劳——教 agent 如何在弧线框架内做变奏，防止每集都"起势→交锋→升级→高潮→收尾"。

---

## 一、核心原则——模板是起点，不是终点

v4.0 的戏份类型弧线提供了**默认结构**，但 60 集每集都套用相同结构 = 观众在第 3 集就审美疲劳。变奏机制教 agent **如何打破模板而不破坏节奏**。

**黄金法则**：任何模板的变奏必须保留至少 2 个核心 Beat，删除/合并/重排不超过 2 个 Beat。完全打乱所有 Beat = 丧失节奏感。

---

## 二、五大变奏手法

### 2.1 Beat 重排

保留所有 Beat，但改变顺序。适用于"观众知道接下来会发生什么，但不知道以什么顺序发生"的场景。

**示例——打斗戏变奏：**
```
默认：起势 → 交锋 → 升级 → 高潮 → 收尾
变奏：交锋 → 起势 → 升级 → 高潮 → 收尾
      （先打，再揭示为什么打——倒叙开场）
```

**示例——悬疑戏变奏：**
```
默认：建立 → 酝酿 → 假安全 → 揭示 → 余震
变奏：揭示 → 建立 → 酝酿 → 假安全 → 余震
      （先揭示结果，再倒叙过程——如先拍尸体，再拍凶案前）
```

### 2.2 Beat 省略

当剧情需要加速或上一集已建立部分信息时，省略某些 Beat。

**适用场景：**
| 省略 Beat | 适用条件 | 效果 |
|-----------|---------|------|
| 省略起势 | 上一集结尾已建立对峙/环境 | 开场即打——节奏加速 |
| 省略收尾 | 下一集紧接本集结尾 | 悬念延续——不给人喘息 |
| 省略假安全 | 紧张感已持续多集 | 直接揭示——不给假希望 |
| 省略酝酿 | 情绪已积累多集 | 直接爆发——情绪释放 |

**约束**：单集最多省略 2 个 Beat。连续 3 集不能省略同一个 Beat。

### 2.3 Beat 融合

将两个相邻 Beat 合并为一个——在同一个镜头或同一组镜头中完成两个 Beat 的功能。

**示例——打斗戏融合：**
```
默认：交锋（2镜，4s）→ 升级（3镜，6s）
融合：交锋+升级（3镜，8s）——试探性攻击直接升级为连击，中间没有喘息
      镜头 1：刺拳试探（交锋）→ 立即接组合拳（升级）
      镜头 2：对方格挡→反击（交锋+升级同镜）
      镜头 3：两人同时被击退喘息（升级收尾）
```

**示例——情绪戏融合：**
```
默认：建立（1镜，5s）→ 酝酿（2镜，10s）
融合：建立+酝酿（1镜，12s）——一镜到底，角色从平静到眼眶泛红在同一个长镜头中完成
```

### 2.4 节奏反转

不改变 Beat 顺序，但改变每个 Beat 的节奏——让"应该快的地方慢，应该慢的地方快"。

**示例——打斗戏节奏反转：**
```
默认节奏：慢(起势3s)→快(交锋2s)→更快(升级1.5s)→爆(高潮2s)→慢(收尾3s)
反转节奏：快(起势1.5s)→慢(交锋4s)→更快(升级1.2s)→慢(高潮5s 慢动作)→极快(收尾1s)
           ↑ 开场即冲刺    ↑ 交锋放慢看细节                 ↑ 收尾不给喘息
```

**适用场景**：
- 反转节奏用于"意料之外"的戏——角色以为要打，结果对方只是走过
- 第 30 集（中点转折）和第 60 集（大结局）至少各用 1 次节奏反转

### 2.5 类型融合

将两种戏份类型的元素混合在同一段落中。最常用的融合方式：

| 融合类型 | 做法 | 示例 |
|---------|------|------|
| **情绪化打斗** | 打斗的 Beat 中穿插情绪 Beat | 起势→交锋→{情绪高潮：角色A回忆起某事，动作停顿1s}→升级→高潮→收尾 |
| **悬疑化对白** | 对白中插入悬疑的延迟揭示 | 角色A说话→角色B反应→{延迟揭示：B看到了什么}→继续对话 |
| **动作化情绪** | 情绪戏用打斗的运镜 | 用推近压迫镜头拍角色独自哭泣——增强压迫感 |

**约束**：类型融合仅用于关键剧情节点（每 10 集不超过 2 次），避免滥用。

## 三、变奏调度表

为防止 agent 在 60 集中随机变奏导致混乱，推荐以下调度策略：

| 集数范围 | 变奏频率 | 推荐手法 |
|---------|:---:|---------|
| 1-5 | 0 次 | 严格使用默认模板——建立观众对节奏的预期 |
| 6-10 | 1 次 | Beat 重排——观众开始感到"不太一样" |
| 11-20 | 2-3 次 | Beat 省略 + 节奏反转——叙事节奏开始丰富 |
| 21-40 | 3-4 次 | 全部五种手法交替使用——叙事进入多变期 |
| 41-55 | 2-3 次 | 逐步回归默认模板——为结局建立稳定节奏 |
| 56-60 | 1-2 次 | 类型融合 + 节奏反转——大结局需要最强冲击 |

**调度原则**：变奏频率呈"中间高、两头低"的驼峰曲线——开头建立预期，中间丰富多变，结尾回归稳定。

---

## 四、变奏自检

每集生成后检查：
- [ ] 本集是否使用了变奏？使用了哪种手法？
- [ ] 变奏后的 Beat 是否保留了至少 2 个核心 Beat？
- [ ] 删除/合并/重排的 Beat 是否不超过 2 个？
- [ ] 本集变奏频率是否在调度表的推荐范围内？
- [ ] 如果使用了类型融合，是否用于关键剧情节点？

---

## 五、快速参考

```
Beat 重排  → 保留所有 Beat，改顺序（倒叙、插叙、预叙）
Beat 省略  → 最多删 2 个，连续 3 集不能删同一个
Beat 融合  → 两个 Beat 合并为一个镜头/一组镜头
节奏反转  → 快慢互换——该快的地方慢，该慢的地方快
类型融合  → 两种戏份类型混合，每 10 集最多 2 次
```
