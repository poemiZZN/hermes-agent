# 语种语速基准表与对白时长计算公式（Speech Rate Table）

> 供 `Basics-pro` 技能在"第 3 步：对白驱动镜头时长计算"时调用。

## 一、核心公式

```
镜头时长 = 对白播报时长 + 缓冲时长

对白播报时长 = 对白总音节数 ÷ 实际语速（音节/秒）
实际语速   = 中性语速（音节/秒） × 情绪调整系数
```

**缓冲时长规则：**
- 最短缓冲：0.5s（台词极短 + 无动作，如"不！"）
- 标准缓冲：0.8 ~ 1.0s（正常对白，含呼吸/微表情起落）
- 长缓冲：1.0 ~ 1.5s（对白前后有明确动作/情绪转换，如推门后说话、说完后转身）

## 二、各语种音节计数指南

### 西班牙语
```
规则：每个元音（a/e/i/o/u/á/é/í/ó/ú）为一个音节。双元音（ia/ie/io/ua/ue/uo/ai/ei/oi/au/eu/ou）算一个音节。
示例：
  "No me toques" = No(1) + me(1) + to(1) + ques(1) = 4 音节
  "Serafina, ¿qué te pasa?" = Se(1)+ra(1)+fi(1)+na(1) + qué(1) + te(1) + pa(1)+sa(1) = 8 音节
  "Tengo que encontrar la respuesta" = Ten(1)+go(1) + que(1) + en(1)+con(1)+trar(1) + la(1) + res(1)+pues(1)+ta(1) = 10 音节
```

### 英语
```
规则：每个元音音素为一个音节。词尾不发音的 -e 不计数。双元音（diphthong）算一个音节。
示例：
  "You lied to me" = You(1) + lied(1) + to(1) + me(1) = 4 音节
  "I can never go back" = I(1) + can(1) + ne(1)+ver(1) + go(1) + back(1) = 6 音节
  "You have no idea what you're talking about" = You(1)+have(1)+no(1)+i(1)+dea(1)+what(1)+you're(1)+tal(1)+king(1)+a(1)+bout(1) = 11 音节
```

### 日语
```
规则：每个假名（かな）为一个音节（音拍）。促音「っ」、长音「ー」各算一拍。
示例：
  "百年か…すべてが変わった" = ひゃく(2)+ねん(2)+か(1)+す(1)+べ(1)+て(1)+が(1)+か(1)+わ(1)+っ(1)+た(1) = 13 音拍
  "これは何？" = こ(1)+れ(1)+は(1)+な(1)+に(1) = 5 音拍
  "もう誰も覚えていない" = も(1)+う(1)+だ(1)+れ(1)+も(1)+お(1)+ぼ(1)+え(1)+て(1)+い(1)+な(1)+い(1) = 12 音拍
```

### 泰语
```
规则：每个辅音+元音组合为一个音节。声调标记不改变音节数。
示例：
  "ไม่ต้องกลัว" = ไม่(1)+ต้อง(1)+กลัว(1) = 3 音节
  "แกจะต้องเสียใจ" = แก(1)+จะ(1)+ต้อง(1)+เสีย(1)+ใจ(1) = 5 音节
```

### 印尼语
```
规则：每个元音为一个音节。双元音 ai/au/oi 算一个音节。
示例：
  "Semua akan baik-baik saja" = Se(1)+mu(1)+a(1) + a(1)+kan(1) + ba(1)+ik(1)+ba(1)+ik(1) + sa(1)+ja(1) = 11 音节
  "Jangan bergerak" = Ja(1)+ngan(1) + ber(1)+ge(1)+rak(1) = 5 音节
```

### 阿拉伯语
```
规则：每个短元音+辅音组合为一个音节。长元音（ā/ī/ū）算一个音节。
示例：
  "هذه مسؤوليتك" = hā(1)+dhi(1)+hi(1) + mas(1)+'ū(1)+liy(1)+ya(1)+tu(1)+ka(1) = 9 音节
  "لا أريد الرحيل" = lā(1) + 'u(1)+rī(1)+du(1) + ar(1)+ra(1)+ḥī(1)+la(1) = 8 音节
```

## 三、中性语速基准（音节/秒）

| 语种 | 中性语速范围 | 推荐默认值 | 说明 |
|------|-------------|-----------|------|
| 西班牙语 | 6.5 ~ 7.5 | 7.0 | 音节密集，日常口语语速较快 |
| 英语 | 5.0 ~ 6.0 | 5.5 | 中等密度，美式英语略快于英式 |
| 日语 | 5.5 ~ 6.5 | 6.0 | 音拍均匀，节奏稳定 |
| 泰语 | 5.0 ~ 6.0 | 5.5 | 中等密度，声调不改变节奏 |
| 印尼语 | 5.5 ~ 6.5 | 6.0 | 节奏适中，元音清晰 |
| 阿拉伯语 | 5.0 ~ 6.0 | 5.5 | 辅音丰富，语速适中 |
| 中文（普通话） | 4.0 ~ 5.0 | 4.5 | 信息密度高，单字信息量大 |

> **为什么中文语速最低？** 中文是单音节语言，每个字就是一个音节，但每个字承载的信息量远超拼音文字。中文正常语速约 4-5 字/秒，而西班牙语约 7 音节/秒——但两者在单位时间内传递的信息量相当。

## 四、情绪调整系数速查表

| 情绪状态 | 系数 | 等效语速变化 | 典型场景 |
|----------|------|-------------|---------|
| 平静 / 中性 | 1.00 | 正常 | 日常对话、陈述、旁白 |
| 温柔 / 安抚 | 0.80 | 明显放缓 | 安慰、告白、哄睡、对小孩说话 |
| 悲伤 / 低落 | 0.75 | 明显放缓 | 哭泣、告别、抑郁独白 |
| 困惑 / 犹豫 | 0.85 | 略放缓 | 思考、迟疑、反问、不确定 |
| 坚定 / 严肃 | 0.95 | 接近正常 | 命令、宣告、承诺、下决心 |
| 紧张 / 焦虑 | 1.15 | 略加快 | 争吵前奏、催促、不安 |
| 愤怒 / 激动 | 1.30 | 明显加快 | 争吵、爆发、指责、咆哮 |
| 恐惧 / 惊慌 | 1.40 | 急促 | 尖叫、求救、逃命、极度恐慌 |
| 兴奋 / 喜悦 | 1.20 | 加快 | 惊喜、欢呼、分享好消息 |
| 讽刺 / 轻蔑 | 0.90 | 略放缓 | 话中有话、拖长音、冷嘲热讽 |
| 疲惫 / 虚弱 | 0.70 | 严重放缓 | 受伤、病重、临终、极度疲惫 |

## 六、对白镜头时长自检清单

生成每个含对白的镜头后，逐镜检查：

- [ ] 是否统计了目标语言对白的音节数？
- [ ] 是否根据语种选择了正确的中性语速？
- [ ] 是否根据说话人情绪状态应用了调整系数？
- [ ] 对白播报时长 = 音节数 ÷（中性语速 × 情绪系数），结果是否正确？
- [ ] 镜头时长 = 对白播报时长 + 缓冲时长，是否 ≥ 对白播报时长 + 0.5s？
- [ ] 对白播报时长超过 8s 的镜头是否已拆分为对切？
- [ ] 多人对白镜头是否累加了所有说话人的对白时长？
- [ ] 对白与动作重叠时，是否取 max（对白时长，动作时长）+ 缓冲？
