# 对白翻译指南（Dialogue Translation Guide）

> 供 `Basics-pro` 技能在"第 2 步：对白翻译"时调用。

## 一、翻译原则

### 1.1 准确性优先
- 翻译必须忠实于中文原文的含义和情绪
- 不能遗漏、添加或改变原文的意思
- 专有名词（人名、地名）保持原文或用意译

### 1.2 口语化
- 使用目标语言的自然口语表达，而非书面语
- 符合角色身份和社会地位的语言风格
- 贵族说贵族的话，平民说平民的话，小孩说小孩的话

### 1.3 情绪一致
- 保持原文的情绪强度（愤怒就是愤怒，不是"有点不高兴"）
- 保持原文的语气（讽刺、温柔、命令、恳求等）
- 保持原文的节奏（短句急促、长句舒缓）

### 1.4 在地化
- 使用目标语言的自然口语表达，而非书面语
- 符合目标语言文化的表达习惯
- 避免直译导致的文化隔阂

### 1.5 俚语强化规则（v5.7 升级）

**原则**：非中文对白拒绝字面直译。对白中应充分使用当地俚语、口语化缩略形式、文化符号。目标语言对白中至少 20% 的句子包含当地俚语/口语表达。

**英语俚语词汇库**：

| 类别 | 俚语示例 | 替代书面表达 | 使用场景 |
|------|---------|-------------|---------|
| 缩略式 | gonna, wanna, gotta, ain't, kinda, sorta, lemme, gimme | going to, want to, got to, am not, kind of, sort of, let me, give me | 所有日常对话默认使用 |
| 口语词 | dude, man, bro, pal, buddy | — | 男性角色间称呼 |
| 口语词 | babe, hon, sweetie | — | 亲密关系间称呼 |
| 强化词 | hell no, damn right, freaking, friggin' | no, yes, very | 情绪激动时 |
| 动作俚语 | back off, buzz off, get lost, screw this | leave me alone, go away, forget this | 愤怒/拒绝 |
| 文化符号 | make my day, bring it on, you wish | try me, I dare you, in your dreams | 对峙/挑衅 |
| 脏话 | damn, hell, crap, screw you, what the hell | — | 愤怒/挫败（视角色设定使用） |

**英语翻译对比示例**：

```
中文：Elena（愤怒）："你没资格碰它。"
  ❌ 书面直译："You don't get to touch that."
  ✅ 俚语强化："Back off. That's mine."

中文：Marcus（挑衅）："你觉得你能阻止我吗？"
  ❌ 书面直译："Do you think you can stop me?"
  ✅ 俚语强化："You gonna stop me?"

中文：Elena（冷笑）："试试看。"
  ❌ 书面直译："Try it."
  ✅ 俚语强化："Go ahead. Make my day."

中文：Marcus（挫败）："算了，我不干了。"
  ❌ 书面直译："Forget it. I quit."
  ✅ 俚语强化："Screw this. I'm out."
```

**西班牙语俚语词汇库**：

| 类别 | 俚语示例 | 替代书面表达 |
|------|---------|-------------|
| 口语词 | vale, guay, molar, tío/tía, hostia | de acuerdo, bien, gustar, hombre/mujer, ¡Dios mío! |
| 缩略式 | pa' (para), 'ta (está), 'toy (estoy) | para, está, estoy |
| 动作俚语 | ¡Ni se te ocurra!, ¡Lárgate!, ¡Déjame en paz! | No lo hagas, Vete, No me molestes |

**西班牙语翻译对比示例**：

```
中文：Elena："好吧，听你的。"
  ❌ 书面直译："De acuerdo, como tú digas."
  ✅ 俚语强化："Vale, como tú digas."

中文：Marcus："我觉得这主意不错。"
  ❌ 书面直译："Creo que es una buena idea."
  ✅ 俚语强化："Tío, eso mola."
```

## 二、输出格式

每句对白按以下格式输出：

```
角色名（情绪·音高·音量·重音·停顿·气息·约X音节/秒）："目标语言原文" （中："中文原文"）
```

**字段说明：**
- **角色名**：说话的角色
- **情绪**：当前情绪状态（如：愤怒、温柔、困惑、恐惧、讽刺）
- **音高**：升高 / 降低 / 平稳
- **音量**：增大 / 减小 / 不变
- **重音**：关键词加重（如 "You **LIED** to me"）
- **停顿**：句中停顿位置和时长（如 逗号处0.3s / 句末0.5s）
- **气息**：呼吸控制（气声 / 屏息 / 叹气 / 哽咽 / 正常）
- **约X音节/秒**：估算的音节速率，用于 AI 模型对口型
- **目标语言原文**：翻译后的对白
- **中文原文**：编剧提供的原始中文对白，仅供人类审阅

## 三、多语种对照示例

### 西班牙语
```
中文：塞拉菲娜（愤怒）："别碰我！"
→ 西班牙语：塞拉菲娜（惊怒·音高升高·音量增大·重音"碰"·停顿0.1s·气息急促·7.5音节/秒）：¡No me toques! （中："别碰我！"）

中文：陌生男伴（困惑）："塞拉菲娜，你怎么了？"
→ 西班牙语：陌生男伴（困惑·音高平稳·音量不变·无重音·句末停顿0.3s·气息正常·7.0音节/秒）：Serafina, ¿qué te pasa? （中："塞拉菲娜，你怎么了？"）

中文：塞拉菲娜（坚定）："我一定要找到答案。"
→ 西班牙语：塞拉菲娜（坚定·音高降低·音量增大·重音"一定"·句末停顿0.5s·气息正常·6.5音节/秒）：Tengo que encontrar la respuesta. （中："我一定要找到答案。"）
```


## 四、翻译质量自检清单

生成对白翻译后，逐条检查：

- [ ] 翻译是否准确传达了中文原文的意思？
- [ ] 目标语言表达是否自然、口语化？
- [ ] 情绪和语气是否与原文一致？
- [ ] 是否符合角色的身份和说话风格？
- [ ] **俚语覆盖率（v5.7 新增）**：≥20% 的句子是否包含当地俚语/口语表达？是否存在可替换的书面直译？缩略式（gonna/wanna/gotta 等）是否已默认使用？
- [ ] 输出格式是否正确（角色名 + 情绪 + 节奏 + 原文 + 中文）？
- [ ] 是否在音频配置中声明了对白语言？

## 五、音频配置声明

在所有镜头的"音频配置（固定内容）"中，必须包含对白语言声明：

```
对话均为{目标语言}，适当使用{目标语言}俚语。
对白均为外语原声，中文翻译仅供人类审阅。
```

示例（西班牙语）：
```
对话均为西班牙语，适当使用西班牙俚语。
对白均为外语原声，中文翻译仅供人类审阅。
```

示例（英语）：
```
对话均为英语，适当使用英语俚语。
对白均为外语原声，中文翻译仅供人类审阅。
```
