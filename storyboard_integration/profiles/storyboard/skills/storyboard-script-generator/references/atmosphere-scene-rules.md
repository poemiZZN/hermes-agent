# 悬疑/氛围戏规则（Atmosphere Scene Rules）

> 供 `Basics-pro` 技能在生成悬疑/恐怖/紧张氛围戏份时调用。
> v4.0 新增，v5.6 升级：面部表演部分升级为引用通用表演系统 `references/performance-system.md`。
>
> **表演系统引用**：悬疑/氛围戏中的角色面部表演（恐惧表情/紧张表情/克制表情等）统一使用 `references/performance-system.md` 的通用规则。本文件保留悬疑戏专属的段落结构、延迟揭示、负空间构图、光线设计、声音设计等规则。

---

## 一、核心原则——信息控制

悬疑的本质是**信息的不对称分配**——观众知道的比角色多（或比角色少），或两者都不知道但感到不安。镜头就是信息阀门——什么时候给、给多少、怎么给。

| 原则 | 说明 |
|------|------|
| **延迟揭示** | 先拍反应，再拍原因——先拍角色惊恐的脸，再拍他看到了什么 |
| **负空间** | 画面中大量留白——人物被压缩到边缘，未知占据画面主体 |
| **声音先行** | 声音比画面早 0.5-1s 进入——观众先听到，再看到 |
| **假安全** | 先建立平静，再打破——一个日常场景中的异常细节 |

---

## 二、逆向节奏——慢→极慢→突然爆发

悬疑戏的节奏弧线与打斗戏完全相反：

```
打斗：慢（起势）→ 快（交锋）→ 更快（升级）→ 爆（高潮）→ 慢（收尾）
悬疑：慢（建立）→ 极慢（酝酿）→ 静止（假安全）→ 爆（揭示）→ 余震（回落）
```

| Beat | 时长 | 镜头数 | 节奏 |
|------|------|--------|------|
| ① 建立 | 5-8s | 2-3 镜 | 缓慢——环境展示，角色进入空间 |
| ② 酝酿 | 10-15s | 2-3 镜 | 极慢——不对劲的细节逐渐浮现，每个镜头 4-6s |
| ③ 假安全 | 3-5s | 1-2 镜 | 静止——似乎一切正常，但…… |
| ④ 揭示 | 2-4s | 2-3 镜 | 极快——信息突然释放，镜头时长 1-2s |
| ⑤ 余震 | 5-8s | 1-2 镜 | 慢——角色反应，观众消化 |

## 三、负空间构图

悬疑戏的构图核心是**让未知占据画面**——角色在画面中越小，未知越大。

| 构图方式 | 画面占比 | 情绪效果 |
|---------|---------|---------|
| 人物在画面边缘 | 人物 <20% | 被环境压迫——无处可逃 |
| 门缝/钥匙孔视角 | 人物被遮挡 >50% | 偷窥感——观众是不该在场的人 |
| 前景遮挡 | 前景物体占 40-60% | 隐藏的威胁——画面中有什么观众看不到 |
| 镜面反射 | 人物在镜中 | 真实与虚幻的边界模糊 |
| 极深景深 | 前景虚化+后景清晰 | 注意力被引导到远处——那里有什么？ |
| 浅景深反向 | 前景清晰+后景虚化 | 威胁在前景——角色没注意到 |

**景别比例：**

| 景别 | 占比 | 用途 |
|------|:---:|------|
| 全景/远景 | 30% | 环境建立——人物在空间中显得渺小 |
| 中景 | 30% | 角色与环境的关系——空间中的异常 |
| 特写/大特写 | 30% | 角色反应——恐惧/困惑/警觉 |
| 空镜 | 10% | 环境本身作为叙事者——门缓缓打开、灯闪烁、水滴 |

## 四、延迟揭示模板

**标准延迟揭示序列（3 镜）：**

```
镜 1（大特写）：角色面部——瞳孔放大，表情从困惑转为恐惧
镜 2（中景）：角色缓慢转头——朝向威胁方向
镜 3（全景/中景）：揭示威胁——角色看到了什么
```

**变体：**

| 变体 | 序列 | 效果 |
|------|------|------|
| 声音先行 | 声音→镜 1（反应）→镜 2（转头）→镜 3（揭示） | 声音比画面早 0.5s |
| 假揭示 | 镜 1（反应）→镜 2（转头）→镜 3（空无一物）→镜 4（威胁在身后） | 双重反转 |
| 不揭示 | 镜 1（反应）→镜 2（转头）→镜 3（黑场/切走） | 观众永远不知道——最恐怖 |

## 五、光线与运镜

### 光线

悬疑戏的光线应该**制造不确定性**——不要让观众看清楚一切。按 6 维参数配置：

| 光线技巧 | 光线描述 | 色温 | 对比度 | 光源动机 | 氛围效果 |
|---------|---------|------|--------|---------|---------|
| 单光源 | 单侧硬光 + 分割光，其余区域完全黑暗 | 冷 5600K | 16:1+ | 画面外单一点光源 | 威胁在黑暗中——观众不知道暗处有什么 |
| 闪烁光源 | 顶光 + 硬光，明暗交替（频率 0.5-2Hz） | 冷 5000K | 16:1+ | 画面内日光灯/蜡烛 | 威胁在暗处时出现——每次熄灭都可能是"那次" |
| 逆光剪影 | 逆光 + 硬光，面部全黑仅有轮廓 | 冷 5600K | 16:1+ | 画面外逆光（门缝/窗光） | 身份不明——轮廓是唯一定义 |
| 底光 | 底光 + 硬光，面部阴影倒置 | 冷 5000K | 8:1 | 画面外下方光源 | 不自然的恐怖感——面部阴影反向 |
| 长阴影 | 低位侧光 + 硬光，影子被拉长 3-5 倍 | 暖 2800K | 8:1 | 画面外低位光源 | 影子的动作比人物更恐怖——影子是独立角色 |
| 色温对比 | 暖色安全区（2800K）+ 冷色危险区（5600K） | 双色温 | 4:1 | 画面内暖光源 + 画面外冷光源 | 空间被光线冷暖分割——角色在安全与危险之间移动 |

> **光源动机强制规则**：悬疑戏中光源动机就是悬念本身——"画面外单一点光源"意味着"有人在暗处"、"画面内闪烁日光灯"意味着"系统失控"。每镜必须写明光源位置和状态。

### 运镜

悬疑戏的运镜应该**制造不安**——镜头不是稳定客观的观察者，而是有主观意图的。

| 运镜 | 速度 | 情绪效果 |
|------|------|---------|
| 慢摇预兆镜头 | 极慢平移 | 逐步揭示空间信息——每移动 1cm 都可能发现什么 |
| 侧移窥视镜头 | 慢速 | 前景遮挡物横向移动——偷窥感 |
| 手持微晃 | 0.5-1Hz 不规则 | 如呼吸般的不稳定——代入角色的不安 |
| 倾斜镜头 | 3-5° 倾斜 | 画面失衡——世界不对劲 |
| 推近压迫镜头 | 极慢推进 | 逐渐靠近——但不知道靠近的是什么 |
| 定格凝视 | 完全静止 | 观众被迫长时间注视——等待 |
| 穿越障碍镜头 | 穿过门框/窗户 | 进入未知空间 |

**禁止的运镜**：快速环绕、快切、甩镜——除非在揭示 Beat 中使用。

## 六、声音设计

悬疑戏的声音是**第一主角**——比画面更早传递信息。

| 声音元素 | 用法 | 频率/声压 |
|---------|------|---------|
| 环境底噪 | 持续但逐渐增强——如空调嗡鸣、风声 | 40-60Hz·渐强·50→65dB |
| 低频嗡鸣 | 后台持续——观众感知到但不确定来源 | 30-50Hz·持续·50dB |
| 心跳声 | 随紧张度递增——BPM 从 70 渐增至 120 | 50Hz·脉冲·渐强 |
| 呼吸声 | 角色呼吸——频率从平稳到急促 | 300Hz·渐快·55→65dB |
| 脚步声 | 每步清晰——但来源不明 | 500Hz·每步·60dB |
| 水滴/钟表 | 规律性声音——作为时间标记，打破规律时制造紧张 | 1kHz·规律→突然变奏 |
| 静默 | 绝对静默 1-2s——在揭示前的最强武器 | — |

## 七、自检

生成悬疑/氛围镜后检查：
- [ ] 镜头序列是否遵循延迟揭示原则？信息是否逐步释放？
- [ ] 画面构图是否使用了负空间？人物占比是否 <50%？
- [ ] 节奏是否遵循"慢→极慢→静止→爆发"的逆向弧线？
- [ ] 光线是否制造了不确定性？观众是否无法看清一切？6 维参数是否完整（方向/质量/色温/对比度/光型/光源动机）？
- [ ] 声音是否比画面更早传递信息？是否使用了静默？
- [ ] 是否存在假安全 Beat？揭示 Beat 是否在假安全之后？
