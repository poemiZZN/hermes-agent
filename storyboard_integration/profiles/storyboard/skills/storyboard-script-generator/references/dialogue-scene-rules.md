# 对白文戏规则（Dialogue Scene Rules）

> 供 `Basics-pro` 技能在生成对白戏份时调用。
> v5.6 新增：弥补 v5.5.2 对文戏表演的系统性覆盖空白——演员在说话/听话时的微表情、身体语言、语气、反应镜头、Subtext 处理。

---

## 一、核心原则——对白是表演，不是信息传递

对白戏与打斗戏/无声情绪戏有本质区别：**对白戏的核心张力在于"说"和"听"之间——说话者用台词传递信息，但真正打动观众的是听者的反应和说话者的潜台词。**

| 维度 | 打斗戏 | 无声情绪戏 | 对白文戏 |
|------|--------|----------|---------|
| 信息载体 | 动作 | 微表情/环境 | **台词 + 微表情 + 潜台词** |
| 镜头焦点 | 攻击方→受击方 | 单一角色 | **说话者 ↔ 听者（双向）** |
| 剪辑驱动 | 动作节拍 | 情绪弧线 | **对白节奏 + 反应时机** |
| 表演重点 | 身体力学 | 五层微表情 | **七层表演（眼→眉→嘴→呼吸→头颈→躯干→手势）+ 语气参数** |
| 核心张力 | 看得懂看得爽 | 内心世界外化 | **台词与真实意图的落差（Subtext）** |

---

## 二、对白戏类型识别

### 2.1 类型速查

| 类型 | 识别特征 | 情感基调 | 典型场景 |
|------|---------|---------|---------|
| **冲突对话** | 角色立场对立、情绪升级、打断/抢话 | 紧张→爆发→沉默 | 争吵、对峙、审讯、分手 |
| **亲密对话** | 角色情感连接、距离拉近、自我暴露 | 试探→温暖→释放 | 告白、安慰、谈心、和解 |
| **信息对话** | 角色传递关键信息、一方知一方不知 | 悬念→揭示→反应 | 交代背景、密谋、汇报、发现真相 |
| **权力对话** | 角色地位不平等、一方施压一方承受 | 压迫→服从→或反抗 | 命令、谈判、威胁、审问 |
| **独白/内心OS** | 单一角色自言自语或内心声音 | 内省→释放→转变 | 反思、下决心、回忆、崩溃 |

### 2.2 混合类型

一集对白戏可能包含多种类型。以段落为单位切换类型标记，一个段落内类型保持一致。

## 三、对白节奏弧线（按类型）

### 3.1 冲突对话弧线

```
试探 → 升温 → 爆发 → 沉默 → 余震
（1-2镜）→（2-3镜）→（2-3镜）→（1镜）→（1镜）
```

| Beat | 时长 | 镜头数 | 特征 |
|------|------|--------|------|
| 试探 | 3-5s | 1-2 镜 | 双人中景——角色在克制，但眼神/手势已泄露情绪 |
| 升温 | 5-8s | 2-3 镜 | 对切加速——每 1-2 句切一次，听者反应镜头穿插 |
| 爆发 | 3-5s | 2-3 镜 | 大特写——面部/手部/嘴部，台词最激烈处 |
| 沉默 | 2-3s | 1 镜 | 定格——不说话比说话更有力量，呼吸声/环境音主导 |
| 余震 | 3-5s | 1 镜 | 中景/全景——角色各自的空间关系，沉默中的距离 |

### 3.2 亲密对话弧线

```
试探 → 破冰 → 坦诚 → 情绪释放 → 温柔收束
（1-2镜）→（1-2镜）→（2-3镜）→（1-2镜）→（1镜）
```

| Beat | 时长 | 镜头数 | 特征 |
|------|------|--------|------|
| 试探 | 3-5s | 1-2 镜 | 双人中景——角色保持安全距离，视线回避或偶尔接触 |
| 破冰 | 4-6s | 1-2 镜 | 过肩镜头——一方先跨出一步，语气变软/眼神变暖 |
| 坦诚 | 6-10s | 2-3 镜 | 特写——眼神接触增多，面部柔和，嘴角微扬 |
| 情绪释放 | 4-6s | 1-2 镜 | 大特写——泪光/微笑/释然，身体的物理靠近（牵手/拥抱） |
| 温柔收束 | 3-4s | 1 镜 | 双人中景——角色距离变近，安静但充实 |

### 3.3 信息对话弧线

```
建立 → 铺设 → 关键信息 → 反应 → 确认
（1镜）→（1-2镜）→（1-2镜）→（1-2镜）→（1镜）
```

| Beat | 时长 | 镜头数 | 特征 |
|------|------|--------|------|
| 建立 | 2-3s | 1 镜 | 双人中景——角色空间关系，场景氛围 |
| 铺设 | 4-6s | 1-2 镜 | 过肩/中近景——信息逐步释放，听者镜头穿插 |
| 关键信息 | 3-5s | 1-2 镜 | 大特写——信息释放瞬间，优先切听者反应而非说话者 |
| 反应 | 3-5s | 1-2 镜 | 听者特写——瞳孔变化/呼吸停滞/嘴唇微启 |
| 确认 | 2-3s | 1 镜 | 中景/双人——信息确认后的状态，可能是沉默或追问 |

### 3.4 权力对话弧线

```
施压 → 承受 → 拉锯 → 突破 → 结果
（1-2镜）→（1-2镜）→（2-3镜）→（1-2镜）→（1镜）
```

| Beat | 时长 | 镜头数 | 特征 |
|------|------|--------|------|
| 施压 | 3-5s | 1-2 镜 | 低机位仰拍强势方——镜头服务于权力关系 |
| 承受 | 4-6s | 1-2 镜 | 高机位俯拍弱势方——角色被压缩在画面中 |
| 拉锯 | 5-8s | 2-3 镜 | 对切——权力关系在动摇，弱势方开始反击或屈服 |
| 突破 | 3-5s | 1-2 镜 | 大特写——权力关系转变的瞬间，优先切弱势方表情 |
| 结果 | 3-4s | 1 镜 | 中景/全景——新的权力关系建立，空间位置反映关系 |

### 3.5 独白/内心 OS 弧线

独白不遵循对切规则，全程固定在一个角色上。节奏弧线等同于无声情绪戏的四段式：

```
建立 → 酝酿 → 高潮 → 回落
（1镜）→（1-2镜）→（1镜）→（1镜）
```

详见 `emotional-scene-rules.md` 第六章。

## 五、听者反应系统

听者的反应往往比说者的台词更有戏。每一段对白必须同时规划"说者表演"和"听者反应"。

### 5.1 反应镜头插入时机

| 对白类型 | 反应镜头频率 | 触发条件 |
|---------|:----------:|---------|
| 冲突对话 | 每 1-2 句 | 情绪升温时加速、关键攻击性台词后立即切 |
| 亲密对话 | 每 2-3 句 | 关键告白/安慰句后、对方情绪释放时 |
| 信息对话 | 每 1-2 句 | 关键信息释放后、信息量大的句子后 |
| 权力对话 | 每 1-2 句 | 施压句后切弱势方、反击句后切强势方 |
| 独白/OS | 无 | 不需要切——全程固定镜 |

### 5.2 听者反应分类

| 反应类型 | 微表情特征 | AU 编码（典型强度） | 典型场景 |
|---------|----------|-------------------|---------|
| **认同** | 微点头、眼神柔和、嘴角微扬、呼吸平稳 | AU53+54 交替(A) + AU12(B) + AU6(B) | 对方说出自己认同的观点 |
| **震惊** | 瞳孔放大、嘴唇微张、呼吸停滞 0.5-1s、身体微微后仰 | AU5(C) + AU26(B) + AU1+2(B) + AU58(A) | 听到意外消息 |
| **愤怒（被激怒）** | 牙关咬紧、眼神变冷、手部握紧、呼吸变急促 | AU4(C) + AU7(B) + AU23(C) + AU38(B) | 被指责/被侮辱 |
| **受伤** | 眼神闪躲→下垂、嘴唇微颤、呼吸变浅、身体微缩 | AU64(C) + AU15(B) + AU1(A) + AU54(B) | 被在乎的人伤害 |
| **思考/消化** | 视线偏移至画面外、眉间微蹙、手指轻敲或托腮、呼吸变缓 | AU61/62(C) + AU4(A) + AU28(A) | 接收复杂信息 |
| **怀疑** | 眉间微蹙、嘴角微撇、头部微侧、眼神在对方脸上扫视 | AU4(B) + AU12 单侧(A) + AU55/56(B) + AU61/62 交替 | 对方说的话不可信 |
| **释然** | 眉间舒展、肩膀下沉、嘴角微扬、轻叹一口气 | AU4→0 + AU12(B) + AU6(B) + AU25(A) 叹息呼出 | 确认担心的事没有发生 |
| **恐惧** | 瞳孔放大、嘴唇微张、呼吸停滞转急促、喉结滚动 | AU5(C) + AU26(B) + AU1+2(B) + AU20(A) + AU38(B) | 听到威胁性信息 |
| **冷漠** | 面无表情、眼神放空、呼吸平稳、身体不动 | 所有 AU 强度 ≤A——面部无显著肌肉运动 | 不关心/麻木 |

### 5.3 听者反应书写模板（双轨格式）

```
动作表演（听者反应——震惊→恐惧）：
0-1s 瞳孔放大——嘴唇微张，呼吸停滞，身体微微后仰
      【AU 校准：AU5（上睑提升）B→C，AU26（下巴下坠）A，AU58（头后缩）A】

1-2s 眉头上扬——眉尾上挑，眼睑颤抖，视线锁定说话者
      【AU 校准：AU1+2（眉头+眉尾上扬）B→C，AU5（上睑提升）C 维持 + 眼睑微颤】

2-3s 嘴唇开始颤抖——嘴角下拉，手指收紧抓住座椅扶手，呼吸转为急促短吸
      【AU 校准：AU15（嘴角下拉）B，AU20（唇横向拉伸）A→B，AU38（鼻孔扩张）B→C】
```

### 5.4 视线匹配规则

| 对白类型 | 视线规则 |
|---------|---------|
| 冲突对话 | 说话者直视对方（压迫），听者可能回避（承受）或回瞪（反击） |
| 亲密对话 | 说话者视线在对方眼睛和下方之间徘徊，听者温柔注视 |
| 信息对话 | 关键信息释放时，听者视线锁定说话者——不能游移 |
| 权力对话 | 强势方俯视（或平视但下巴抬起），弱势方仰视（或平视但下巴内收） |
| 说谎 | 说话者视线飘忽→短暂回避→强行对视——中间有 0.3-0.5s 的断裂 |

## 六、Subtext（潜台词）处理

Subtext 是对白文戏的灵魂——角色说的和想的不一样，表情和身体语言会泄露真相。

### 6.1 Subtext 三要素

```
1. 台词（表面意思）——角色说出口的话，用于应付场面
2. 真实意图（潜台词）——角色真正想表达的，可能自己都没意识到
3. 表演裂缝（Leakage）——微表情/身体语言/语气暴露的真实情绪，往往只有 0.5-1s
```

### 6.2 典型 Subtext 场景

| 场景 | 台词 | 潜台词 | 表演裂缝 |
|------|------|--------|---------|
| "我没事" | 否认情绪 | 需要被关心 | 嘴角微颤→强行微笑→手指掐进掌心 |
| "恭喜你" | 表面祝福 | 嫉妒/受伤 | 眼神避开对方→嘴角上扬但眼周无笑意→声音发紧 |
| "我不在乎" | 否认在乎 | 非常在乎 | 声音颤抖→说话后立即低头→手指无意识摩挲物体 |
| "随便你" | 表面让步 | 放弃/失望 | 肩膀下沉→转身动作比平时慢→不说话后呼吸变深 |
| "我相信你" | 表面信任 | 怀疑/不确定 | 眉间微蹙→视线在对方脸上扫视→说话前 0.3s 停顿 |
| "你走吧" | 表面放手 | 希望你留下 | 说"走"时声音变轻→眼眶泛红→说完后视线仍锁定对方 |

### 6.3 Subtext 书写规则

**在「动作表演」字段中，Subtext 场景必须额外标注台词-表情矛盾**：

```
动作表演（Subtext——台词与表情矛盾）：
台词："我没事"（0-1.5s）
  眼睛：眼眶泛红——泪光在积聚，但强行睁大
      【AU 校准：AU5（上睑提升）C——强行睁大以对抗泪光，AU7（眼睑收紧）B——克制】

  嘴巴：嘴角上扬形成微笑——但嘴唇微颤，微笑维持 0.5s 后开始松动
      【AU 校准：AU12（嘴角上扬）B，AU6（脸颊提升）缺失——假笑标志，AU15（嘴角下拉）A 微颤泄漏】

  手势：右手手指掐进左手掌心——指关节泛白

  呼吸：说话前深吸一口气——台词在颤抖的呼气中说出
      【AU 校准：AU38（鼻孔扩张）B→AU25（唇分开）A 颤抖呼出】

  表演裂缝：AU12(B) + AU6 缺失 = 假笑，同时 AU5(C) 强行睁大 + 眼眶泛红——微笑与眼部痛苦的矛盾
      【AU 校准关键：AU6 缺失是此镜 Subtext 最可靠的编码级证据】
```

### 6.4 面部上下半区矛盾——Subtext 的核心视觉机制

**核心原则**：下半脸（嘴部）比上半脸（眼+眉）更容易被意识控制。当角色试图隐藏情绪时，往往能控制嘴部做出"正确"的表情，但眼部会泄漏真实情绪。这就是 Subtext 最核心的视觉机制——**上半脸和下半脸讲不同的故事**。

#### 6.4.1 矛盾类型速查表

| 矛盾类型 | 上半脸（眼+眉） | 下半脸（嘴） | Subtext 解读 | 典型场景 |
|---------|--------------|-----------|------------|---------|
| **礼貌性冷静** | AU5(B) 瞳孔放大——恐惧 | AU12(B) 微笑——"我很好" | 内心在害怕但不让你看出来 | 面试中、见重要人物 |
| **压抑愤怒** | AU4(C) 眉间紧锁——愤怒 | AU12(B) 微笑——"没关系" | 我在忍你，而且快忍不住了 | 被公开指责但必须保持风度 |
| **强装镇定** | AU5+7(B) 眼睑绷紧——紧张 | AU23(B) 唇抿紧——克制 | 我快撑不住了 | 等待重要结果、被审讯 |
| **假意关心** | AU1(A) 眉头微扬——假装关心 | AU12 单侧(A) 轻蔑 | 我其实看不起你 | 社交场合的虚伪问候 |
| **幸灾乐祸** | AU6(B) 眼角微弯——真开心 | AU23(B) 唇抿紧——克制 | 我很高兴你倒霉了但不能表现出来 | 讨厌的人出丑 |
| **被迫接受** | AU1(A) 眉头微扬——悲伤 | AU12(B) 微笑——"我接受" | 我其实不想接受但必须笑 | 输了比赛说"恭喜你" |
| **暗恋者的注视** | AU6(B) 眼角微弯——真温柔 | AU25(A) 唇微启想说→AU23(A) 抿住咽回去 | 我想告诉你但不敢 | 看着暗恋对象 |

#### 6.4.2 上半脸 vs 下半脸的可控性差异

| 面部区域 | 意识控制难度 | 泄漏概率 | 原因 |
|---------|:---:|:---:|------|
| 下半脸（嘴 AU9-28） | 容易 | 低 | 嘴部肌肉受意识直接控制——微笑、抿嘴可以主动执行 |
| 上半脸（眉 AU1-2-4） | 中等 | 中 | 眉间微蹙可以主动做，但 onset 0.3s 内往往是无意识的 |
| 上半脸（眼 AU5-6-7） | 困难 | 高 | 眼轮匝肌（AU6）很难主动收缩——假笑时 AU6 缺失是最可靠的泄漏 |
| 瞳孔（非 AU） | 不可能 | 极高 | 瞳孔放大/缩小完全不受意识控制——恐惧和兴奋无法伪装 |

#### 6.4.3 上下半区矛盾书写格式

在「动作表演」字段中，当存在上下半区矛盾时，必须分别标注上半脸和下半脸的 AU：

```
动作表演（Subtext——上半脸愤怒 + 下半脸微笑，压抑愤怒）：
上半脸：
  0-2s 眉间紧锁——眉心形成深竖纹，眉尾下压，瞳孔缩小，眼神锐利
      【AU 校准：AU4(C) + AU5(B) + AU7(B)——上半脸：愤怒】

下半脸：
  0-2s 嘴角上扬——形成微笑，但嘴唇绷紧，牙关轻咬
      【AU 校准：AU12(B) + AU23(B)——下半脸：微笑 + 克制】

矛盾：
  上半脸愤怒 + 下半脸微笑 = 压抑愤怒——他在笑，但眼睛在说"我快忍不住了"
  泄漏证据：AU4(C) 眉间无法被完全控制，AU6 缺失——微笑不真实
```

### 6.5 语气 Subtext

语气本身也可以是 Subtext 的载体——同样的台词，不同语气传达完全不同的潜台词：

| 台词 | 语气 | 潜台词 |
|------|------|--------|
| "你真的很厉害" | 真诚（音高平稳·音量正常·语速正常） | 真心佩服 |
| "你真的很厉害" | 讽刺（音高拖长·音量降低·语速 0.6x） | 你在炫耀 |
| "你真的很厉害" | 冷漠（音高压低·音量极小·语速正常） | 我懒得跟你争 |

## 七、对白戏景别与角度系统

对白戏的景别与角度服务于"谁在说话、谁在听、观众应该看谁"。

### 7.1 景别比例

| 景别 | 占比 | 用途 |
|------|:---:|------|
| 中景（双人/多人） | 15-20% | 场景建立、角色空间关系、弧线收尾 |
| 中近景/过肩 | 30-35% | 对白主体——说话者占画面 60%，听者肩部或后脑入镜。角度统一为「侧面过肩」或「侧面双人」 |
| 特写（面部） | 25-30% | 情绪升温时——关键台词或关键反应。角度用「侧面平视」，避免正面平视的证件照感 |
| 大特写（眼部/嘴部/手部） | 15-20% | 高潮瞬间——情绪爆发/Subtext 泄漏/信息揭示 |
| 空镜/对白空镜 | 5-10% | 对话中的呼吸间隙——环境或道具作为情绪延伸 |

> **角度硬约束**：所有对白镜的「景别」字段角度部分**禁止出现「正面平视」组合**——即角色正对镜头且视线与镜头等高。此组合产生证件照/面试感，在 9:16 竖屏中被进一步放大。
>
> 「正面」配合仰拍/俯拍（如 `正面仰拍`/`正面俯拍`）不受此限；「平视」配合侧面方向（如 `侧面平视`/`侧面过肩`）不受此限。禁止的仅是该特定组合 `正面平视`。

### 7.2 特写切入时机

| 时机 | 景别 | 切入对象 | 角度 |
|------|------|---------|------|
| 关键台词前 0.5s | 特写→大特写 | 说话者——观众看到台词从形成到说出 | 侧面平视 |
| 关键台词后 0.3s | 特写→大特写 | 听者——看到台词落地后的冲击 | 侧面平视 |
| 情绪峰值 | 大特写（眼部） | 说话者或听者——泪光/瞳孔变化/眼神 | 侧面平视或微斜 |
| Subtext 泄漏 | 大特写（嘴部/手部） | 说话者——嘴角微颤/手指掐进掌心 | 侧面平视 |
| 沉默 Beat | 近景（单人侧面）→定格 | 任一角色——不说话时的犹豫/消化/克制 | 侧面平视 |
| 听者消化 | 近景（单人侧面） | 听者——台词落地后不切过肩反应，切干净的单人侧脸让观众"观察 ta 一个人" | 侧面平视 |
| 转折前停顿 | 近景（单人侧面）+微推 | 说话者——嘴唇分开又抿紧的"决定前一刻" | 侧面平视 |

> **单人侧面近景**（solo side-angle）是对话的呼吸标点——它不等同于过肩（有过肩=观众仍是"旁听者"），也不等同于大特写（大特写=被拉进内心）。单人侧面是干净的侧脸单人镜，让观众在连续对白中有片刻喘息。默认节奏：每 2-3 句对白之间插入一镜，连续 4 句以上纯过肩对切 = 节奏灾难。

### 7.3 双人/单人镜头切换节奏

| 对白类型 | 切换节奏 | 双人镜占比 | 规则 |
|---------|---------|:---:|------|
| 冲突对话 | 快切——每 1-2 句 | 10-15% | 双人镜仅用于建立和收尾，中间用「过肩→单人侧面→过肩」三拍交替 |
| 亲密对话 | 慢切——每 2-3 句 | 25-30% | 双人镜用于建立+破冰+收尾，坦诚段穿插单人侧面近景作为沉默 Beat |
| 信息对话 | 中速——每 1-2 句 | 15-20% | 关键信息释放时切听者单人侧面（干净侧脸，非过肩），信息量大时插说话者单人侧面停顿 |
| 权力对话 | 中速——每 1-2 句 | 15-20% | 双人镜用于建立，全程对切服务于权力关系。强势方可用「低机位正面仰拍」，弱势方可用「高机位正面俯拍」 |
| 独白/OS | 不切 | 不适用 | 全程固定镜，运镜用微推/定格，角度用侧面平视 |

### 7.4 对白空镜与过渡特写

对白中的空镜和过渡特写是对话的呼吸间隙。**空镜（纯环境/道具无人物）严格 ≤2s**——超过 2s 时 AI 视频模型可能"脑补"额外内容。如需更长的情绪延续，拆分为「空镜 + 道具近景/反应特写」延续。

| 插入时机 | 内容 | 时长 | 超时处理 | 情绪效果 |
|---------|------|------|---------|---------|
| 关键台词后 | 环境空镜（窗外/雨滴/钟表） | 1.5-2s | 不适用 | 给观众消化台词的时间 |
| 沉默 Beat | 角色手部/道具特写 | 1.5-2s | 不超时 | 用手指/物体的状态延续情绪 |
| 转折前 | 环境空镜（门/走廊/空椅） | 1.5-2s | 不适用 | 预示即将发生的事 |
| 弧线收尾 | 环境空镜 | 1.5-2s | 若需 >2s→空镜1.5s + 道具/反应特写1-1.5s 延续 | 情绪回落后留在空间中的余味 |

> **过渡特写（无表演/极简表演）**：指仅展示道具或角色局部（手指、后颈、衣物纹理）而无表情变化的镜头——它们不是空镜但也非表演镜。时长范围 1.5-2.5s，与空镜交替使用构成对话呼吸节奏。超过 2.5s 的无表演特写同样有 AI 脑补风险，应通过轻微动作（手指微曲、衣角飘动）赋予其明确视觉约束。

## 八、对白戏光线与空间

### 8.1 光线情绪映射（6 维参数配置）

对白戏光线按 6 维参数配置。每镜「画面描述」字段从以下预设中取值，按 `{光源方向} + {光源质量} + {色温}K + 对比度{比率} + {光型}；动机：{光源来源}；{氛围效果}` 格式填入。

| 对白类型 | 光线描述 | 色温 | 光源动机 | 氛围 |
|---------|---------|------|---------|------|
| 冲突对话 | 侧光 + 硬光 + 对比度 8:1 + 分割光 | 中性 4000-4500K | 画面外单侧窗光或顶灯 | 阴影锐利，面部半明半暗——角色的立场对立用光线可视化 |
| 亲密对话 | 正面偏侧 + 柔光 + 对比度 2:1 + 无特定 | 暖色 2800-3200K | 画面内台灯/烛光/落地灯 | 高光柔和，暗部有细节——温暖感，角色距离在拉近 |
| 信息对话 | 正面光 + 漫射光 + 对比度 2:1 + 无特定 | 中性 4500-5000K | 画面外顶灯或窗光 | 平淡均匀，无强烈明暗对比——客观，信息本身比情绪更重要 |
| 权力对话 | 底光或顶光 + 硬光 + 对比度 8:1 | 冷色 5000-5600K | 画面外单光源（上方或下方） | 强势方在亮处面部轮廓锐利，弱势方在暗处——权力关系用光线分配可视化 |
| 独白/OS | 单侧柔光 + 对比度 4:1 + 半面光 | 冷色 5600K | 画面外单侧窗光 | 半张脸隐入阴影，仅眼睛在亮处——内省，角色面对自己 |

> **光源动机强制规则**：每镜必须写明光的来源——画面内（如"右侧台灯"）或画面外（如"画面外左侧窗光"）。禁止出现无来源的"凭空柔光"。这是 Seedance 生成真实感光影的关键。详见 `references/lighting-taxonomy.md`。

### 8.2 空间关系

对白场景中角色之间的物理距离反映情感距离：

| 关系状态 | 物理距离 | 景别选择 | 构图 |
|---------|---------|---------|------|
| 敌对/疏远 | >2m | 双人中景→对切 | 角色在画面两端，中间留空 |
| 中立/工作 | 1-1.5m | 过肩/中近景 | 听者肩部入镜，保持距离感 |
| 亲密/信任 | <0.5m | 双人特写/过肩近景 | 画面紧凑，角色物理靠近 |
| 权力关系 | 不固定 | 低机位仰拍强势方 + 高机位俯拍弱势方 | 镜头角度服务于权力 |

## 九、对白戏运镜规则

### 9.1 运镜选用原则

对白戏的运镜应该**服务于对话节奏和权力关系**——镜头是隐形的第三方参与者。

| 原则 | 运镜 | 速度 | 用途 |
|------|------|------|------|
| **观察者** | 固定机位/微推 | 静止/极慢 | 客观对话——让观众自己判断 |
| **共情者** | 微推（极慢） | 0.5-1mm/s | 逐渐靠近角色内心——情绪升温时 |
| **压迫者** | 推近压迫 | 慢速 | 逼问/施压——镜头代表强势方的意志 |
| **退让者** | 后撤疏离 | 极慢 | 角色被对话压垮——无力感 |
| **不安者** | 手持微晃 | 0.3-0.5Hz | 对话中的紧张——谎言/对峙 |
| **凝视者** | 定格 | 静止 | 关键台词后的沉默——强迫观众注视 |

### 9.2 禁止的运镜

- 快速环绕——分散注意力，打断对白节奏
- 甩镜——除非在冲突对话的爆发 Beat 用作转场
- 快速推拉——除非角色情绪突然剧烈变化
- 倾斜镜头——除非对话内容本身是扭曲/不真实的（如被操控/被欺骗）

## 十、自检清单

生成对白戏份后逐镜检查：

### 10.1 结构完整性
- [ ] 对白戏的类型是否已识别？（冲突/亲密/信息/权力/独白）
- [ ] 段落结构是否遵循了对应类型的节奏弧线？
- [ ] 每个 Beat 的镜头数和时长是否在合理范围内？

### 10.2 表演完整性
- [ ] 每镜「动作表演」是否至少覆盖了七层中的 3-4 层？
- [ ] 关键台词镜是否同时写了说话者表演和听者反应？
- [ ] 听者反应镜头是否按类型设置了合理的插入频率？
- [ ] Subtext 场景是否标注了台词-表情矛盾？

### 10.3 语气完整性
- [ ] 每句对白是否标注了情绪、音高、音量、重音、停顿？
- [ ] 语气是否与角色语料库的情绪表达模式一致？
- [ ] 是否存在 Subtext 语气？（台词与语气不一致）

### 10.4 景别完整性
- [ ] 对白景别比例是否合理？（中景 15-20% / 中近景+过肩 30-35% / 特写 25-30% / 大特写 15-20%）
- [ ] 特写切入时机是否在关键台词前后 0.3-0.5s？
- [ ] 双人/单人镜头切换节奏是否与对白类型匹配？
- [ ] 是否需要空镜插入？（沉默 Beat / 关键台词后 / 弧线收尾）

### 10.5 连续性
- [ ] 同一场景中角色的空间位置（左右/前后）是否跨镜一致？
- [ ] 视线方向是否跨镜匹配？（A 看向右→B 在右侧，B 看向左→A 在左侧）
- [ ] 角色情绪状态是否随弧线渐进变化，而非跳跃？

### 10.6 光线与空间
- [ ] 光线设计是否服务于对白类型？（对照 §8.1 预设表）
- [ ] 6 维参数是否完整？（光源方向/质量/色温/对比度/光型/光源动机）
- [ ] 光源动机是否已写明？（画面内或画面外，禁止"凭空柔光"）
- [ ] 角色物理距离是否反映了情感距离？
- [ ] 权力关系是否通过镜头角度（仰/俯/平）体现？
