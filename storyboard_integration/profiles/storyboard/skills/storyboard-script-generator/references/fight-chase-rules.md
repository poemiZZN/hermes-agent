# 追逐战斗规则（Chase Combat Rules）

> 供 `Basics-pro` 技能在生成追逐/追击/高速移动战斗戏份时调用。
> v5.0 新增：基于电影级分析，建立追逐战的独立空间逻辑和节奏体系。

---

## 一、核心原则——速度感来自参照物，不是镜头晃动

追逐战最容易犯的错误：镜头疯狂晃动但角色原地不动，背景静止。速度感的唯一来源是**背景物体的高速后退**——岩壁、树木、建筑、路标。

| 原则 | 说明 |
|------|------|
| **追逐线硬约束** | 追击者始终在被追击者后方——攻击方向不能反 |
| **速度感 = 参照物后退** | 每镜必须有至少 1 个背景参照物在高速后退 |
| **障碍物节奏** | 追逐不是直线——躲避障碍物制造变奏 |
| **近距逃脱** | 最紧张的不是"追上了"，而是"差点追上但逃脱了" |

---

## 二、追逐线——空间一致性硬约束

**致命缺陷**：空中追逐测试中，光之战士在暗影法师后方追击，但攻击从暗影法师前方射来——空间逻辑断裂。

### 2.1 追逐线标注

每镜的「人物站位」必须标注追逐方向：
```
追逐线：{追击者}在{被追击者}{后方/左后方/右后方}，追击方向{从左向右/从右向左/从下向上}
```

### 2.2 攻击方向规则

| 角色 | 攻击方向 | 示例 |
|------|---------|------|
| 追击者 | 向**前**方发射攻击（朝向被追击者） | 光之战士在左后方，向右发射光弹 |
| 被追击者 | 向**后**方反击（朝向追击者） | 暗影法师在右前方，转身向左发射弹幕 |

**禁止**：追击者的攻击从被追击者前方射来；被追击者反击时攻击方向与追击者位置不一致。

### 2.3 追逐线变更

追逐线可以在以下节点变更，但**必须用 1 个镜头明确展示变更动作**：
- **急转弯**：被追击者转弯，镜头展示转弯动作 + 背景旋转
- **两人交错**：空中交错飞过，追逐方向反转，镜头展示交错瞬间
- **场景切换**：进入新场景重新建立追逐线，镜头展示新场景全貌

## 三、节奏——"快切+爆炸+喘息"三拍循环

追逐战的节奏比站桩打斗快 1.5-2 倍。

```
快切（攻击/闪避，1.0-1.5s/镜，2-3镜）→ 爆炸（命中，1.5-2.0s，1镜）→ 喘息（停顿，1.5-2.0s，1镜）
```

### 3.1 镜头时长基准

| 追逐动作 | 单镜时长 | 原因 |
|---------|:---:|------|
| 高速飞行/追击 | 1.0-1.5s | 速度感——背景高速流动，不需要长镜头 |
| 攻击发射/闪避 | 1.0-1.5s | 攻击的瞬间性——弹幕/光束发射即切 |
| 爆炸/命中 | 1.5-2.0s | 爆炸需要展示但不要拖 |
| 喘息停顿 | 1.5-2.0s | 比站桩喘息（2-3s）更短——保持紧张感 |
| 高潮碰撞 | 2.5-3.0s | 最后一击可以稍长——但仍是快节奏 |

### 3.2 速度分级——不是匀速运动

追逐不能全程匀速——必须有加速和减速的变奏：

```
加速追击（背景后退加速）→ 急转弯减速（背景后退减速）→ 再加速 → 近距逃脱（对方突然加速拉开距离）→ 再加速追击
```

**每轮速度变化在「动作表演」中体现**：标注"飞行加速，背景后退速度加快"或"急转弯减速，背景后退速度放缓"。

---

## 四、近距逃脱——追逐战的紧张核心

追逐战最紧张的瞬间不是"追上了"，而是"差点追上但逃脱了"。**每场追逐必须制造 2-3 次近距逃脱**。

### 4.1 近距逃脱模板

```
攻击逼近至 2m → 被追击者极限闪避（攻击擦过）→ 爆炸/命中环境 → 浓烟 → 被追击者从浓烟中穿出 → 距离重新拉开
```

### 4.2 近距逃脱的视觉锚点

| 逃脱方式 | 视觉锚点 | 距离标注 |
|---------|---------|---------|
| 急转弯闪避 | 攻击擦过身边——命中后方岩壁/建筑 | 攻击从身侧 1m 擦过 |
| 俯冲/爬升闪避 | 攻击从头顶/脚下擦过 | 攻击从头顶 2m 擦过 |
| 障碍物遮挡 | 被追击者躲入障碍物后方——攻击击中障碍物 | 攻击命中障碍物，被追击者从另一侧穿出 |
| 瞬移逃脱 | 被追击者身形化作粒子——攻击穿过原位置 | 攻击命中原位置后方环境 |

## 五、每镜 1 动作——追逐镜头最小化原则

追逐战的每个镜头只做一件事。禁止在一个镜头里塞"飞行+转身+攻击+爆炸"。

| 每镜 1 动作 | 禁止 |
|------------|------|
| ① 飞行回头 | ❌ 飞行+回头+蓄力+攻击 四合一 |
| ② 发射攻击 | ❌ 发射+命中+爆炸 三合一 |
| ③ 爆炸/命中 | ❌ 爆炸+闪避+反击 三合一 |
| ④ 喘息停顿 | ❌ 喘息+发现+蓄力 三合一 |
| ⑤ 急转弯/俯冲 | ❌ 转弯+闪避+反击 三合一 |

## 六、镜头与运镜

### 6.1 景别比例

| 景别 | 占比 | 用途 |
|------|:---:|------|
| 全景 | 15% | 建立追逐空间——峡谷/城市/森林全貌 + 两人位置 |
| 中景 | 40% | 追逐主体——展示飞行姿态、攻击轨迹、闪避动作 |
| 大特写 | 45% | 关键细节——爆炸、近距逃脱、喘息、攻击擦过 |

### 6.2 运镜配对

| 追逐动作 | 推荐运镜 | 原因 |
|---------|---------|------|
| 高速飞行/追击 | 跟镜（与角色同步移动） | 背景高速后退建立速度感 |
| 攻击发射 | 斜向俯冲（跟随攻击轨迹） | 观众跟着攻击飞行 |
| 急转弯/闪避 | 移镜（跟随角色横向移动） | 展示转弯幅度和环境变化 |
| 爆炸/命中 | 贴地掠行（从爆炸点掠过） | 展示爆炸规模和碎片飞溅 |
| 近距逃脱 | 推近压迫（极速推进至擦过点） | 强调毫厘之间的差距 |
| 喘息停顿 | 空镜余韵（镜头缓慢后撤） | 给观众呼吸空间 |

### 6.3 关键镜头——POV 穿插

追逐战中穿插 1-2 个 POV 镜头可以大幅增强代入感：
- **追击者 POV**：前方被追击者忽远忽近，背景高速后退
- **被追击者 POV**：回头看到追击者越来越近，转身加速

---

## 七、开场原则——无对峙，直接追

追逐战不需要"起势对峙"——开场镜头就是追逐进行中。用 1 个镜头快速建立空间关系后，立即进入攻击-闪避循环。

---

## 八、自检

生成追逐镜后检查：
- [ ] 每镜「人物站位」是否标注了追逐线？追击者是否始终在被追击者后方？
- [ ] 攻击方向是否与追逐线一致？
- [ ] 追逐线变更时是否有 1 镜展示转弯/交错/场景切换？
- [ ] 镜头时长是否在 1.0-2.0s 范围内？是否存在 >3s 的慢镜？
- [ ] 是否遵循"每镜 1 动作"原则？
- [ ] 是否穿插了 2-3 次近距逃脱？
- [ ] 是否至少有 1-2 个喘息停顿镜？
- [ ] 每镜是否有至少 1 个背景参照物在高速后退？
