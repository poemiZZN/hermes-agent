# 表演连续反应链（Performance Chain）v1.2

## 性质

**Agent 内部推理框架。** 生成每镜「动作表演」时按此六步因果链在内部推导角色的表演逻辑。**输出到分镜脚本时**：
- **禁止标注六步标题**（「原状态：」「触发点：」等）
- **禁止输出 AU 编码**（AU4、AU5 等——内部推导使用，输出翻译为自然语言）
- **禁止输出精度数字**（mm/°/Hz/dB/%——仅保留 Seedance 可解读的时间、大致距离）
- **输出为流畅的自然语言**——导演对演员说话的口吻

## 为什么需要反应链

AU 编码告诉你"皱眉肌收紧 30%"，但不告诉你为什么在这一帧收紧——是上一镜的残留，还是这一镜看见了什么，还是为下一镜的选择做准备。

Seedance 等 AI 视频模型逐帧生成。如果缺少因果链，模型会在帧与帧之间"脑补"过渡——结果可能是表情在不该变的时候变了，或者该变的时候延迟了 3 帧。

表演连续反应链为每镜的「动作表演」提供六步因果框架。每一步都可以映射为可拍摄的物理行为。

---

## 六步反应链

```
原状态 → 触发点 → 短暂处理 → 可见反应 → 人物选择 → 结束残留
  ↑                                                          ↓
  └—————————— 接下一镜原状态 ————————————————————————————————┘
```

### 第 1 步：原状态（Origin State）——"带着什么进来"

角色在当前镜头开始时的表情、姿势、呼吸、情绪的残留状态。**直接从上一镜的「结束残留」继承**——如果上一镜的结束残留是"AU4 皱眉肌收紧 20%+双手交叉抱胸"，本镜原状态必须相同。

**可拍描述**：面部 AU 编码组合 + 身体姿势 + 呼吸模式。禁止抽象情绪标签（"愤怒""悲伤"）。

```
✅ 原状态：AU4 皱眉肌收紧 20%+AU23 口轮匝肌收紧 15%（嘴唇紧抿），双臂交叉抱于胸前——肘关节弯曲约 120°，呼吸为浅快的 0.3s 吸·0.4s 呼
❌ 原状态：他很生气
```

**首镜特殊处理**：如果本镜是该集/该场景第一镜，原状态从剧本上下文推导——角色在上一个剧情节点结束时是什么状态？

### 第 2 步：触发点（Trigger）——"看见/听见/想到了什么"

角色在本镜中接收到的刺激——视觉（看到某人/某物）、听觉（听到声音/对话）、触觉（被触碰/温度变化）、内感受（突然的疼痛/心跳加速/记忆闪回）。

**可拍描述**：触发源的方向+距离+时间点+刺激的物理属性。

```
✅ 触发点：T+0.0s——画面外右侧约 3m 处传来敲门声（1kHz·50dB）——角色右耳朝向声源——头部未转动
❌ 触发点：他意识到仇人来了
```

**触发类型**：
| 类型 | 可拍描述格式 | 示例 |
|------|------------|------|
| 视觉触发 | 视线方向+目标距离+出现时间 | "T+0.3s——视线左方约 5m 处门被推开——门缝中出现人脸" |
| 听觉触发 | 声源方向+频率/音量+到达时间 | "T+0.0s——画面外后方传来脚步声（1.5kHz·35dB·渐近）" |
| 触觉触发 | 接触部位+力道+时间 | "T+0.5s——左手背被另一只手触碰——接触压强约 50g/cm²——持续约 1s" |
| 内感受触发 | 身体部位+感觉类型+出现时间 | "T+1.0s——胃部肌肉突然收缩——伴随心率从 70bpm→90bpm 的加速" |

### 第 3 步：短暂处理（Brief Processing）——"这意味着什么"

角色的大脑在极短时间内（0.2-1.5s）处理触发信息的含义。**这一步的可见物理信号极少**——主要是微小的延迟/停顿/呼吸变化——因为大脑在认知处理期间会暂时抑制外显运动。

**可拍描述**：处理时长 + 在此期间身体/面部的抑制信号。

```
✅ 短暂处理：触发后 0.3s-0.8s——身体冻结——呼吸暂停——AU 编码维持原状态不变——眼球固定不动——视线锁定触发源方向——眨眼完全停止——瞳孔在 0.4s 内从 3mm 扩至 4.5mm（认知负荷导致瞳孔扩张）
❌ 短暂处理：他在想这意味着什么
```

**处理时长基准**：
| 触发复杂度 | 处理时长 | 示例 |
|-----------|---------|------|
| 简单刺激（巨响/突然触碰） | 0.1-0.3s | 枪响→身体冻结 |
| 中等刺激（辨认某人/理解一句话） | 0.3-0.8s | 听到仇人的声音→确认是谁 |
| 复杂刺激（理解局势/道德困境） | 0.8-1.5s | 看到全村被包围→理解逃跑路线只有一条 |

### 第 4 步：可见反应（Visible Reaction）——"身体说了什么"

经过处理后，身体产生的**少量的、可拍摄的**外部信号。这不是情绪，是情绪的物理外化——AU 编码变化、呼吸模式切换、身体姿态微调。

**关键约束**：可见反应 ≠ 情绪表演的"高潮"。它是信号，不是宣泄。AU 强度在此步骤通常不超过 40%。

```
✅ 可见反应：T+0.8s-1.5s——AU4 皱眉肌收紧从 20%→35%——AU7 下眼睑收紧从 5%→20%——嘴角左侧 AU12 颧大肌收缩 10%（极浅的不对称收紧——未形成笑容）——呼吸从暂停→0.5s 吸·0.3s 呼（加速）——右手五指从自然半张→缓慢收拢为拳——收拢角速度约 15°/s
❌ 可见反应：他的脸因愤怒而扭曲
```

**可见反应的五类信号**（每镜至少覆盖 2 类）：
| 信号类别 | AU/物理描述 | 时间精度 |
|---------|-----------|---------|
| 眼部 | AU4/AU5/AU6/AU7+瞳孔直径+视线方向 | 0.1s 精度 |
| 嘴部 | AU23/AU25/AU12/AU15+嘴唇厚度变化 | 0.1s 精度 |
| 呼吸 | 吸气时长/呼气时长/屏息/幅度 | 0.1s 精度 |
| 手部 | 手指位置/握力/移动方向+速度 | 0.2s 精度 |
| 姿态 | 脊柱角度/重心转移/头颈角度 | 0.3s 精度 |

### 第 5 步：人物选择（Character Choice）——"接下来做什么"

角色基于处理结果做出的行动决策。这是反应链的"输出端"——决定角色在本镜剩余时间内的行为方向。

**不是内心独白，是可见的行为转向。**

```
✅ 人物选择：T+1.5s-2.0s——右手从身侧抬起——五指张开——抓住莉娜左上臂（握力使衣物凹陷约 2cm）——向上提拉——身体重心从右脚转移至左脚——头转向后门方向——转向角速度约 60°/s
❌ 人物选择：他决定带她逃跑
```

**选择类型的可拍信号**：
| 选择方向 | 身体信号 |
|---------|---------|
| 靠近/保护 | 身体前倾+手臂伸向目标+步幅增大 |
| 远离/回避 | 身体后仰+视线移开+步幅减小或后退 |
| 对抗/攻击 | 重心下沉+握拳+下颌收紧+身体转向威胁源 |
| 隐藏/压抑 | AU 编码全面收紧+呼吸频率降低+身体缩小（蜷缩/贴墙） |
| 等待/观察 | 身体冻结+视线锁定+呼吸极缓+肌肉维持等长收缩 |

### 第 6 步：结束残留（Residual State）——"带到下一镜去"

本镜结束时角色的表情、姿势、呼吸状态。**必须与下一镜的「原状态」完全一致**。

```
✅ 结束残留：AU4 皱眉肌收紧 35%+AU7 下眼睑收紧 20%+AU23 口轮匝肌收紧 30%——右手握拳（四指收拢——握力约 5kg）——呼吸为 0.3s 吸·0.4s 呼——身体重心前倾约 10°——面朝后门方向——步幅准备约 80cm（右腿微屈——重心在左脚）——瞳孔维持在直径约 3mm（警觉聚焦）
```

**结束残留的三项必须标注**：
1. 面部 AU 编码 + 强度（≥3 个 AU）
2. 呼吸模式（吸/呼时长+幅度）
3. 身体姿态（脊柱角度+重心位置+面向方向）

## 完整示例

以下是一个完整六步链的「动作表演」字段：

```
【镜头 S-21-04】

原状态（接 S-21-03 结束残留）：
AU4 皱眉肌收紧 15%+AU23 口轮匝肌收紧 15%（嘴唇紧抿），右手握莉娜左手——身体重心前倾约 10°——面朝门口方向——呼吸 0.4s 吸·0.5s 呼。

触发点：
T+0.0s——老头从门外伸出手——右手抓住纳撒尼尔左手腕——接触面积约 15cm²——握力使腕部皮肤下陷约 3mm——老头面部进入视线——距离约 40cm——AU2 眉尾上提 40%+AU5 上睑提肌收缩 60%。

短暂处理：
T+0.0s-0.5s——身体冻结——呼吸暂停——AU 编码维持原状态（AU4 15%+AU23 15%）——眼球固定锁定老头左眼——瞳孔维持在直径约 3mm——无眨眼——大脑处理老头阻挡行为的含义（他不同意北上的路线）。

可见反应：
T+0.5s-1.0s——AU4 皱眉肌收紧从 15%→30%——AU7 下眼睑收紧从 5%→15%——嘴唇厚度减少约 1mm（AU23 收紧至 25%）——呼吸从暂停→0.3s 吸（短促吸入约正常量的 60%）——颈部向左微转约 5°（倾听姿态）。

人物选择：
T+1.0s-1.5s——右手松开莉娜左手——从腰间抽出银币袋——将银币袋塞进老头右手掌心——手掌接触后立即抽回——身体重心后移约 5cm（接受老头的路线修正）。

结束残留（接 S-21-05 原状态）：
AU4 皱眉肌收紧 30%+AU7 下眼睑收紧 15%+AU23 口轮匝肌收紧 25%——右手已收回身侧——身体重心前倾约 10%——面朝门外——呼吸 0.3s 吸·0.4s 呼——瞳孔维持在直径约 3mm——准备冲出后门。
```

## 与现有系统的关系

| 系统 | 作用 | 与本链的关系 |
|------|------|------------|
| FACS AU 编码 | 描述肌肉运动（什么动了） | AU 编码嵌入链的每一步——原状态/可见反应/选择/残留都含 AU |
| 情绪上下文分析（Step 1.6） | 推导情绪本质（为什么有这个情绪） | 上下文分析的结果驱动"触发点→短暂处理"的识别 |
| 身体力学词汇 | 描述动作技术（怎么动的） | 嵌入"人物选择"步——写实打斗使用身体力学描述 |

本链不替代以上系统——它在它们之上加一层时间因果结构。

---

## 约束

1. **每镜「动作表演」必须包含六步链**——缺失任一步视为不合格
2. **链的每一步必须可拍摄**——禁止"他意识到""他觉得""他决定"等内心描述，仅保留该步对应的物理信号
3. **原状态 = 上一镜结束残留**——如果两镜的链衔接不上，回修上一镜的结束残留或本镜的原状态
4. **可见反应的 AU 强度 ≤ 40%**——超过 40% 是"宣泄"而非"信号"，属于情绪高潮镜，使用不同的 AU 强度区间（可放宽至 80%）
5. **短暂处理的时长与触发复杂度匹配**——简单刺激 ≤ 0.3s，复杂刺激 ≤ 1.5s
6. **结束残留至少包含 3 个 AU 编码 + 呼吸模式 + 身体姿态**
