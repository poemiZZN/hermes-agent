# 武侠/功夫规则（Wuxia & Kung Fu Rules）

> 供 `Basics-pro` 技能在生成武侠/功夫戏份时调用。
> v5.2 新增：基于电影级分析，建立武侠的独立视觉语言和节奏体系。
> v5.4 深化：集成袁和平武侠动作设计哲学（因材施打、攻防一体、钢丝物理可信度、单机位最佳角度）。

---

## 一、核心原则——镜头是观众，在最佳位置欣赏武艺

武侠和写实格斗的本质区别：**武侠不是"打架"，是"演武"**。动作不是为击倒对手，是为展示武艺的美感。镜头不是目击者，是欣赏者。

| 原则 | 说明 |
|------|------|
| **招式完整** | 每招每式有起承转合——起手→出招→收招，节奏如书法 |
| **以静制动** | 对峙时间长于交手时间——对峙是武侠的精髓（袁和平：对峙占 30-40%） |
| **轻功/失重** | 重力不是限制——飞檐走壁、水面行走、竹梢对决。**但必须有借力点**（袁和平：钢丝增强，不是飞行） |
| **武器即人** | 剑有性格、刀有脾气——武器不是工具，是角色的延伸（袁和平：因材施打，武器选择反映角色性格） |
| **韵律感** | 打斗有节奏——如音乐，有快板、慢板、休止符（袁和平：停顿/爆发/停顿的戏曲节奏） |
| **攻防一体** | 袁和平核心：化解、补击、借力、躲击、截击——在同一个动作流中完成攻防互转，不是"你打一轮我打一轮" |

---

## 二、招式设计——起承转合

武侠的每一招都是完整的，不是"打一拳"那么简单：

```
起手（0.5-1s）：蓄势——剑缓缓出鞘，衣袂飘起，眼神锁定
出招（0.3-0.5s）：极快——剑锋划过，招式释放
收招（0.5-1s）：回势——剑归鞘，衣袂落下，呼吸平稳
```

**招式不可切碎**——一个完整招式必须在同一个镜头中完成。如果招式被切到两个镜头中，就丧失了武侠的韵律感。

---

## 三、对峙——武侠的精髓

武侠的紧张感不在交手中，在交手前的对峙中。**对峙时长应占整场打斗的 30-40%。**

**对峙设计要素：**
- 眼神——瞳孔微缩、眉间微蹙、眼神锁定
- 呼吸——呼吸变缓、胸腔起伏可见
- 微动作——手指微动、脚底碾地、衣袂被风吹动
- 环境——风吹树叶、水面涟漪、烛火摇曳

**对峙节奏：** 极慢→缓慢逼近→眼神交锋→突然出手（极快）

---

## 四、轻功/失重——武侠的标志性视觉

| 轻功动作 | 视觉描述 | 镜头 |
|---------|---------|------|
| 飞檐走壁 | 角色在墙壁上横向奔跑——衣袂飘起，身体与墙面呈 45° | 侧面跟拍 |
| 水面行走 | 脚掌轻点水面——涟漪从脚下扩散，角色借力飞起 | 低角度仰拍水面 |
| 竹梢对决 | 两人站在竹梢上——竹身弯曲但不折断，风吹竹叶飘落 | 全景+逆光 |
| 空中旋转 | 角色在空中旋转——衣袂如花瓣展开，慢动作 | 子弹时间环绕 |

**轻功的关键**：不是"飞"，是"借力"——每次轻功展示必须有借力点（墙壁/水面/竹梢/树冠），角色从借力点弹起。

---

## 五、武器即人——武器有性格

| 武器 | 性格 | 动作特征 | 镜头 |
|------|------|---------|------|
| 剑 | 君子、优雅、精准 | 刺、挑、削——动作如书法 | 中景展示剑锋轨迹 |
| 刀 | 豪迈、霸气、力量 | 劈、砍、扫——动作大开大合 | 中景+画面微震 |
| 暗器 | 阴险、精准、致命 | 飞镖、针——出手瞬间 | 大特写手指+慢动作 |
| 长枪/棍 | 稳重、范围、守势 | 横扫、戳刺——范围攻击 | 全景展示范围 |
| 软剑/鞭 | 灵动、诡异、不可预测 | 缠绕、抽击——轨迹如蛇 | 中景+跟拍轨迹 |

## 六、镜头与运镜

### 6.1 景别比例

| 景别 | 占比 | 用途 |
|------|:---:|------|
| 全景 | 30% | 展示招式全貌、轻功、对称构图 |
| 中景 | 30% | 对峙、过招、武器交锋 |
| 大特写 | 30% | 眼神、手指、剑锋、武器出鞘 |
| 慢动作 | 10% | 关键招式的高潮瞬间 |

### 6.2 运镜配对

| 武侠动作 | 推荐运镜 | 原因 |
|---------|---------|------|
| 对峙 | 定格凝视/极慢推近 | 让观众感受紧张 |
| 出招 | 实时速度/中景稳定 | 展示招式速度 |
| 招式高潮 | 子弹时间/慢动作 | 展示招式美感 |
| 轻功 | 航拍/跟拍 | 展示飞行轨迹 |
| 武器交锋 | 中景+画面微震 | 展示武器碰撞 |
| 收招 | 空镜余韵 | 衣袂落下、风吹叶落 |

### 6.3 关键镜头——对称构图

武侠的对称构图是标志性视觉语言——两人各占画面一半，衣袂飘起，武器对峙。这种构图需要全景来展示。

---

## 七、节奏弧线——对峙→交锋→对峙→交手→收招

武侠的节奏和写实格斗完全不同——**对峙 > 交手**：

```
① 对峙 Beat（5-8s，1-2镜）：眼神交锋、环境渲染、微动作
② 交锋 Beat（2-3s，1-2镜）：第一招——试探性交手
③ 对峙 Beat（3-5s，1镜）：重新评估——衣袂飘落、呼吸可见
④ 交手 Beat（4-6s，2-3镜）：多招连续交手——节奏加快
⑤ 收招 Beat（3-5s，1-2镜）：最后一招定胜负——武器归鞘、衣袂落下
```

**镜头时长基准**：对峙镜 4-8s，交手镜 1-3s，收招镜 3-5s。

---

## 八、颜色与光线——武侠的视觉美学

武侠的视觉风格与写实格斗完全不同——**颜色是情绪，光线是氛围**。按 6 维参数配置：

| 元素 | 光线描述 | 色温 | 光源动机 | 氛围 |
|------|---------|------|---------|------|
| 竹梢对决 | 逆光 + 硬光 + 对比度 8:1 + 剪影光 | 暖 2800K（夕阳） | 画面外逆光落日 | 角色在逆光中如剪影，衣袂飘起——竹叶逆光呈半透明金色 |
| 夜战/月下 | 顶光 + 漫射光 + 对比度 4:1 + 无特定 | 冷 6500K（月光） | 画面外月光 | 冷蓝月光统一色调，水面反光——角色如画中游走 |
| 室内对决 | 侧光 + 柔光 + 对比度 4:1 + 伦勃朗光 | 暖 2800K（烛光/灯笼） | 画面内烛光/灯笼 | 暖色烛光在面部形成三角光斑——光影在招式间摇曳 |
| 沙漠/雪地 | 顶光 + 硬光 + 对比度 16:1+ + 无特定 | 中性 5000K | 画面外烈日 | 极简环境——空旷沙漠/雪地，高对比度，留白构图 |
| 雨中决斗 | 顶光 + 漫射光 + 对比度 2:1 + 无特定 | 冷 6000K（阴天） | 画面外阴天漫射光 | 雨丝在光中呈银色线条——水花四溅时逆光呈白色光点 |

> **光源动机强制规则**：武侠光源必须来自画面内或画面外的自然/人造元素——夕阳、月光、烛光、灯笼。禁止出现无来源的"氛围光"。光线在招式起落间应有变化——烛火在剑气中摇曳、月光被衣袂遮挡形成动态阴影。

## 十、袁和平式武侠动作设计（v5.4 新增）

### 10.1 因材施打——为每个角色量身定制动作

袁和平武侠动作设计的核心哲学：**不为"好看"设计动作，为"角色"设计动作。** 每个角色的打斗风格是其性格的外化。

| 角色类型 | 袁和平式动作特征 | 案例 |
|---------|---------------|------|
| 少年英雄（成长型） | 招式从生涩到熟练，身体语言从僵硬到舒展 | 《太极张三丰》君宝从疯癫到太极宗师 |
| 宗师/大师 | 动作极简，一招制敌，不浪费一个动作 | 《一代宗师》梁朝伟——少即是多 |
| 狂傲/反派 | 动作大开大合，力度夸张，但破绽逐渐暴露 | 《太极张三丰》天宝——越华丽越接近败亡 |
| 女性武者 | 以柔克刚，借力打力，动作如舞蹈但每招致命 | 《卧虎藏龙》玉娇龙——狂野不羁 vs 俞秀莲——沉稳内敛 |
| 喜剧角色 | 动作中融入"失误"和"巧合"——歪打正着 | 《醉拳》成龙——看似乱打实则章法 |

**分镜规则**：
- 为每个角色定义 1-2 个标志性招式（signature move），在首次出场时展示，后续战斗中重复出现但每次有变奏
- 角色的打斗风格必须与其性格描述一致——冷静型用精准高效的动作，暴躁型用狂野但消耗大的动作
- 同一角色在不同集数中的打斗风格应有成长弧线

### 10.2 攻防一体——武侠的动作逻辑

袁和平式武侠的核心不是"谁先打到谁"，而是**"谁在攻防转换中更快一步"**。

**攻防转换五类型在武侠中的应用**：

| 类型 | 武侠场景 | 分镜描述 |
|------|---------|---------|
| **化解** | 对方剑锋刺来，侧身让过，剑锋从衣袂旁 2cm 擦过 | "剑锋刺来——侧身 15°，剑锋从胸前衣袂旁 2cm 擦过，衣料被剑气吹起波纹" |
| **补击** | 被一掌击中肩膀，身体后仰的同时脚踢出，命中对方膝盖 | "左肩中掌——身体后仰 30°，同时右脚踢出，命中对方前腿膝盖，对方重心失衡" |
| **借力** | 被摔出，空中翻身，脚尖点墙借力，反弹飞踢 | "被摔出——空中翻转一周，脚尖轻点立柱侧面，借反弹力飞踢回" |
| **躲击** | 后仰躲过横扫的同时，从下方出掌击中对方肋部 | "后仰——上半身与地面平行，对方剑锋从面部上方 3cm 扫过，同时左掌从下方击出" |
| **截击** | 判明对方剑路，在剑招完成前以更快速度封住剑锋 | "对方剑锋刚起——以更快速度出剑，剑尖点中对方剑格，剑招被封在半途" |

**分镜规则**：
- 武侠打斗中，每场至少包含 3 种攻防转换类型
- 化解和借力是展示"以柔克刚"的关键——优先使用
- 攻防转换回合必须用长镜头展示——不可切碎

### 10.3 钢丝的物理可信度——袁和平 vs 程小东

袁和平的钢丝哲学：**钢丝是增强，不是飞行。**

| 维度 | 袁和平式钢丝 | 程小东式钢丝（避免） |
|------|------------|-------------------|
| 借力点 | 必须有——墙壁/水面/竹梢/树冠 | 不需要——凭空起飞 |
| 力学逻辑 | 起跳→空中弧线→落地，动量守恒 | 失重——悬浮、飘浮 |
| 重量感 | 落地有重量——衣袂落下、尘土扬起 | 轻如鸿毛——无重量感 |
| 情感功能 | 钢丝是角色内心状态的视觉化 | 钢丝是视觉奇观 |

**分镜规则**：
- 每次轻功/腾空必须标注借力点和落地方式
- 空中动作的起势和落地必须完整展示——不可只拍空中
- 禁止"凭空悬浮"——除非角色是神仙/鬼魂（剧本明确标注）

### 10.4 武侠的力度表达——不同于写实格斗

武侠的力度表达不是"皮肤凹陷"，而是**环境反馈**和**身体轨迹**：

| 力度层级 | 武侠命中证据 | 分镜描述 |
|---------|------------|---------|
| 轻击 | 衣袂飘动、发丝被气流吹起 | "掌风掠过——对方鬓角发丝被气流吹起，衣领微颤" |
| 中击 | 身体后退滑行、脚底在地面擦出痕迹 | "中掌——身体后退滑行 3m，脚底在石板上擦出两道白痕" |
| 重击 | 撞断木栏/撞裂墙壁/水面炸开 | "被击飞——背部撞断木栏杆，木屑飞溅，身体继续飞出" |
| 致命一击 | 慢动作、冻结帧、衣袂如花瓣展开、环境大面积破坏 | "致命一剑——冻结帧，剑锋刺入心口 2cm，衣袂在剑气中如花瓣展开" |

### 10.5 袁和平式武侠镜头设计原则

**单机位最佳角度——武侠版**：
- 对峙：侧面全景——两人各占画面一半，衣袂飘起，对称构图
- 出招：中景正面——展示招式从起手到收招的完整轨迹
- 关键命中：大特写——剑锋与目标之间的 1cm 间隙
- 轻功：低角度仰拍——展示腾空高度和借力点
- 收招：空镜余韵——风吹叶落、衣袂缓缓落下

**长镜头原则——武侠版**：
- 每一招的起承转合必须在同一个镜头中完成——不可切碎招式
- 攻防转换回合（化解→反制→再化解→再反制）用长镜头展示
- 对峙到首击的过渡在同一个镜头中——从极静到极动的爆发

**景别比例——武侠版（袁和平式）**：

| 景别 | 占比 | 用途 |
|------|:---:|------|
| 全景 | 25% | 展示招式全貌、轻功、对称构图、空间关系 |
| 中景 | 35% | 对峙、过招、武器交锋、攻防转换 |
| 大特写 | 30% | 眼神、手指、剑锋、武器出鞘、命中瞬间 |
| 慢动作 | 10% | 关键招式的高潮瞬间——致命一击 |

### 10.6 袁和平式武侠自检

在原第九章自检基础上追加：
- [ ] 每个角色的打斗风格是否与其性格匹配？
- [ ] 是否包含 ≥3 种攻防转换类型（化解/补击/借力/躲击/截击）？
- [ ] 攻防转换回合是否使用了长镜头？
- [ ] 轻功/腾空是否有借力点？落地是否完整展示？
- [ ] 力度表达是否通过环境反馈（而非皮肤凹陷）实现？
- [ ] 是否避免了"凭空悬浮"（除非剧本明确标注超自然）？
- [ ] 长镜头比率是否 ≥30%？
- [ ] 出招阶段是否使用长镜头（≥2s）完整展示招式

## 十、袁和平式武侠（v5.5 新增）

袁和平武侠动作设计的核心哲学：**不为"好看"设计动作，为"角色"设计动作。** 每个角色的打斗风格是其性格的外化。

### 10.1 因材施打

| 角色类型 | 动作特征 |
|---------|---------|
| 君子/侠客 | 招式精准、点到为止、收招克制 |
| 狂人/反派 | 招式狂野、不留余地、以伤换伤 |
| 女子/轻盈 | 以柔克刚、借力打力、飘忽不定 |
| 老者/宗师 | 以静制动、后发先至、一招制敌 |

### 10.2 攻防一体

袁和平式武侠的核心不是"谁先打到谁"，而是**"谁在攻防转换中更快一步"**。化解、补击、借力、躲击、截击——五法在武侠中同样适用。

### 10.3 钢丝的物理可信度

袁和平的钢丝哲学：**钢丝是增强，不是飞行。** 每次轻功必须有借力点（墙壁/水面/竹梢/树冠），角色从借力点弹起——钢丝增强跃起高度和滞空时间，但力学逻辑必须可信。

| 原则 | 袁和平式 | 避免 |
|------|---------|------|
| 借力点 | 必须有——墙壁/水面/竹梢 | 凭空起飞，无借力点 |
| 滞空 | 增强——0.5-1.5s | 长时间悬浮（>2s） |
| 落地 | 有缓冲——膝盖微弯，衣袂落下 | 轻飘飘落地，无视重力 |

### 10.4 武侠力度表达

武侠的"命中"不以血肉模糊为证据，而是：
- 轻击：衣袂被剑气划破
- 中击：身体被击退数步，地面留下擦痕
- 重击：撞断竹木/石柱，口中溢出鲜血
- 致命击：剑锋穿身而过，衣袂缓缓飘落

### 10.5 自检

- [ ] 每个角色的打斗风格是否是其性格的外化？
- [ ] 攻防是否在一体中完成？（非同回合交换）
- [ ] 轻功是否有借力点？（钢丝增强，不是飞行）
- [ ] 力度表达是否匹配武侠美学？（衣袂破损/竹木断裂/地面擦痕）
