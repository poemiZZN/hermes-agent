# 导演级运镜术语库（80 个运镜 Prompt）

> 供 `Basics-pro` 技能在填写「运镜」字段时参考选用。
> 来源：智智AI记《终于整理好了！80个运镜Prompt，直接拉高漫剧镜头感》（2026-08-18）
> **五大分类按剧情选用**：叙事定格（慢节奏/出场/对话）→ 氛围景别（环境/独处/铺垫）→ 运动镜头（登场/追逐/大场面）→ 情绪镜头（紧张/压迫/孤独，无需对白）→ 动作镜头（打斗/追逐/快切/高燃）。单集可多类组合使用。
> **v3.4 禁用**：❌ 节奏点爆发镜头。⚠️ 变速运镜仅限时间流逝意象镜头（正常→渐快→减速→正常）。慢动作仅限打斗高光。时间流逝优先用意象快切。
> **v3.7 新增**：§5 动作镜头从 16 个扩展至 26 个，新增交锋类（#17-#20）、冲击类（#21-#23）、逆转类（#24-#26），覆盖打击感/受击/武器碰撞/连击/POV 受击/子弹时间/地面缠斗/逆转翻盘/爆气冲击等打斗专属运镜。
> **光影联动**：以下运镜与光影系统强关联——低角压强镜头（配合高对比度硬光）、剪影决绝镜头（配合逆光）、变速运镜（配合时间流逝光影变化）。光影参数详见 SKILL.md 字段规范中的 6 维速查表。

## §1 基础叙事与定格镜头（8 个）

适用于人物出场、环境交代、普通对话、节奏较慢的剧情。

| # | 镜头名称 | 运镜 Prompt | 适配情节 |
|---|---------|------------|---------|
| 01 | **推镜头** | 缓慢推进，聚焦主体，压缩环境信息，增强情绪沉浸 | 人物觉醒、发现线索、情绪递进 |
| 02 | **拉镜头** | 镜头后撤，逐步交代空间关系，释放信息量 | 结局揭晓、关系疏离、命运展开 |
| 03 | **摇镜头** | 水平横向移动视线，引导观众浏览场景与人物关系 | 空间展示、多人对话、环境铺陈 |
| 04 | **移镜头** | 机位平行移动，保持主体节奏，形成流动叙事感 | 跟随行走、过程展示、日常叙事 |
| 05 | **跟镜头** | 持续跟随主体运动，保持行动临场感与代入感 | 追逐奔跑、主观行动、任务执行 |
| 06 | **升降镜头** | 垂直升降改变视角层级，强化气势与空间维度 | 登场亮相、场面揭示、权力关系 |
| 07 | **俯拍定格** | 高角度静止构图，强调秩序、孤立感与画面设计 | 群像调度、情绪停顿、场景总结 |
| 08 | **特写定格** | 静态特写锁定表情或物件，放大细节与象征意味 | 情绪爆点、关键道具、结尾余韵 |

### 叙事镜头 Prompt 示例

**推镜头：**
> 中近景，视线高度，镜头缓慢向前推进，聚焦坐在工位前看电脑的女人。人物轻轻抬眼，神情从平静变得凝重，背景逐渐虚化，突出人物情绪变化。

**摇镜头：**
> 中景，固定机位，镜头从桌面的文件和电脑屏幕缓慢水平摇向人物。女人坐在工位前沉默不语，镜头最终停在她的侧脸，表现环境信息和人物情绪。

## §2 氛围与景别镜头（12 个）

用于调整画面氛围和人物与镜头之间的距离。适合环境展示、人物独处、剧情铺垫。

| # | 镜头名称 | 运镜 Prompt | 适配情节 |
|---|---------|------------|---------|
| 01 | **特写** | 浅景深，面部占画面80%，眼神锐利，背景虚化，情绪聚焦 | 人物情绪爆发、秘密揭晓前夕 |
| 02 | **大特写** | 仅保留眼睛、嘴唇或手指细节，微表情突出，压迫感强 | 紧张对峙、关键线索出现 |
| 03 | **中近景** | 胸部以上构图，人物与环境轻度关联，自然视线高度 | 日常对白、关系升温时刻 |
| 04 | **中景** | 半身构图，动作与表情并重，叙事平衡，空间关系清楚 | 双人交流、剧情推进段落 |
| 05 | **全景** | 人物完整入镜，肢体语言明确，环境参与叙事 | 出场亮相、行动准备阶段 |
| 06 | **远景** | 人物在环境中占比小，空间感明显，氛围主导，留白丰富 | 孤独行走、命运转折前铺垫 |
| 07 | **超远景** | 宏大场景，人物极小，建立世界观，天际线感强 | 开场建立、旅程开启、史诗氛围 |
| 08 | **过肩镜头** | 前景肩部虚化，对话对象清晰，关系张力明显 | 谈判、审问、情感对峙 |
| 09 | **主观镜头** | 第一人称视角，视线驱动，沉浸感强，带轻微手持感 | 追逐、发现线索、惊悚遭遇 |
| 10 | **低角度镜头** | 机位仰拍，人物更具压迫感与权威感，透视夸张 | 反派登场、胜利瞬间、英雄塑造 |
| 11 | **高角度镜头** | 俯拍，角色显得脆弱渺小，信息一览无余 | 失败时刻、被围困、孤立无援 |
| 12 | **鸟瞰镜头** | 垂直俯视，图形化构图，调度关系清晰，强调设计感 | 群像调度、案发现场、空间展示 |

## §3 运动镜头（24 个）

适合直接用于 AI 视频。覆盖推/拉/摇/移/跟 + 环绕/变焦/手持/航拍/甩镜/滑轨/穿越/前景遮挡/长镜头调度。

| # | 镜头名称 | 运镜 Prompt | 适配情节 |

| 01 | **推镜** | 缓慢前推，聚焦主体，增强压迫与沉浸 | 人物觉醒、发现线索 |
| 02 | **拉镜** | 平稳后拉，逐渐揭示环境与关系 | 结局揭晓、孤独收尾 |
| 03 | **摇镜** | 水平摇动，跟随视线或展示空间 | 场景介绍、角色对峙 |
| 04 | **俯仰镜头** | 垂直上仰或下俯，强化高低关系 | 权力压制、情绪失落 |
| 05 | **移镜** | 机位横向移动，保持主体并拓展空间 | 人物出场、走位调度 |
| 06 | **跟镜** | 持续跟随主体运动，制造临场感 | 奔跑追逐、行动戏 |
| 07 | **升降镜头** | 机位上升或下降，形成立体空间层次 | 气势建立、环境揭示 |
| 08 | **环绕镜头** | 围绕主体旋转，突出情绪张力 | 告白时刻、心理波动 |
| 09 | **变焦镜头** | 焦距连续变化，压缩或拉伸空间感 | 惊讶反应、信息聚焦 |
| 10 | **手持镜头** | 轻微晃动，纪录感更强 | 冲突现场、危机时刻 |
| 11 | **航拍镜头** | 高空俯瞰大场景，建立宏大空间关系 | 开场建景、转场过渡 |
| 12 | **甩镜** | 快速摆动形成动态与切换感 | 激烈打斗、情绪爆发 |
| 13 | **滑轨镜头** | 平滑直线位移，画面稳定细腻 | 空间介绍、展示镜头 |
| 14 | **稳定器跟拍** | 低抖动跟随移动，兼顾流畅与速度 | 穿行场景、长镜头调度 |
| 15 | ⚠️ **变速运镜**（仅限意象镜头） | 正常→渐快→丝滑减速→正常，仅用于太阳升落/阴影变化等时间流逝意象 | 时间流逝空镜（太阳升落、烛火残尽等） |

| 17 | **穿越运镜** | 穿过门窗、人群或物体形成沉浸视角 | 梦境进入、场景衔接 |
| 18 | **低机位推进** | 贴近地面向前推进，强化力量与压迫 | 英雄出场、危险逼近 |

| 22 | **倾斜镜头（荷兰角）** | 画面带 3-15° 倾斜，制造失衡、不安与临场感。倾斜方向与攻击方向一致——A 从左侧攻击，画面向左倾斜 5° | 打斗交锋、精神崩溃、悬疑氛围 |
| 23 | **快速推进变焦** | 推进与变焦结合，形成强烈视觉冲击 | 真相揭露、危机降临 |
| 24 | **抽离镜头** | 镜头逐渐远离主体，留下余韵与空间感 | 结尾升华、情绪落幕 |

## §4 情绪镜头（20 个）

通过摄影运动帮助人物表达情绪。不以对白驱动，而是以表情+镜头运动对应。

| # | 镜头名称 | 运镜 Prompt | 适配情节 |
|---|---------|------------|---------|
| 01 | **推近压迫镜头** | 慢速推进，焦点锁定人物面部，背景逐渐压缩，眼神颤动 | 心理压迫、秘密揭晓前夕 |
| 02 | **后撤疏离镜头** | 镜头缓慢后拉，人物停留原地，空间感放大，环境吞没人像 | 失落、分手、关系疏远 |
| 03 | **环绕眩晕镜头** | 围绕主体360度环拍，轻微变焦制造失衡感，背景旋转虚化 | 震惊、告白、情绪失控 |
| 04 | **手持崩溃镜头** | 手持轻晃，近距离跟拍，环境剧烈移动 | 逃亡、争吵、精神濒临崩溃 |
| 05 | **低角压强镜头** | 低机位仰拍，人物轮廓强化，光影对比强烈 | 权力对峙、反派登场、强势宣言 |
| 06 | **俯拍孤立镜头** | 高机位垂直俯视，人物被环境包围，留白明显 | 孤独、无助、失败时刻 |
| 07 | **侧移窥视镜头** | 沿遮挡物横向移动，前景虚化遮掩主体，形成偷窥感 | 监视、秘密观察、危险逼近 |
| 08 | **定格凝视镜头** | 固定机位长时间停留，人物表情成为焦点，时间感拉长 | 沉默对峙、隐忍、悲伤酝酿 |
| 09 | **极速推进镜头** | 快速逼近主体，背景被迅速甩开，节奏突袭 | 惊觉、发现真相、危机来临 |
| 10 | **拉焦转移镜头** | 前后景焦点切换，注意力从一人转向另一物 | 线索出现、关系反转、暗示秘密 |
| 11 | **跟随沉浸镜头** | 稳定器贴身跟拍，步伐同步，代入角色行动 | 奔赴、寻找、任务执行 |
| 12 | **变焦窒息镜头** | 推拉变焦同步进行，主体比例稳定，背景空间扭曲 | 恐惧升级、危险降临、心理失衡 |
| 13 | **剪影决绝镜头** | 逆光拍摄，人物面部隐于黑影，轮廓边缘清晰 | 离别、牺牲、最终抉择 |
| 14 | **反打对峙镜头** | 正反打快速切换，视线方向精准对应，节奏加压 | 谈判、审问、激烈冲突 |
| 15 | **微距失控镜头** | 超近景拍摄眼睛、手指、嘴角等细节，捕捉细微颤动 | 紧张、欲言又止、情绪爆发前 |
| 16 | **长焦抽离镜头** | 远距离长焦观察，空间被压平，人物像被世界隔开 | 暗恋、旁观、无法靠近 |
| 17 | **穿越障碍镜头** | 从门框、人群、玻璃等障碍间推进，增强阻隔感与目的性 | 追寻、营救、突破困境 |
| 18 | **慢摇预兆镜头** | 缓慢平移或摇动，逐步揭示空间信息，制造悬念 | 异样出现、危机前奏、环境铺垫 |
| 19 | **升降命运镜头** | 镜头垂直升起或下降，人物关系与处境在空间中被重组 | 命运转折、结局揭示、格局拉开 |
| 20 | **空镜余韵镜头** | 人物离场后保留环境空镜，声音或风景延续情绪 | 失去之后、结尾回味、情绪收束 |

## §5 动作镜头（26 个）

用于动作明显、节奏快的剧情（打斗、追逐、危机、高燃登场）。分为三个子类：**通用动作**（#01-#16）、**交锋类**（#17-#20，近身攻击/武器碰撞）、**冲击类**（#21-#23，速度感/破坏力）、**逆转类**（#24-#26，局势反转/高燃）。

### 通用动作镜头

| # | 镜头名称 | 运镜 Prompt | 适配情节 |
|---|---------|------------|---------|
| 01 | **弧线跟进** | 镜头沿弧形轨迹逼近主体，兼顾空间展开与情绪聚焦 | 人物试探、关系升温 |
| 02 | **反向包抄镜头** | 镜头由主体背后绕至正面，制造局势翻转感 | 对峙升级、身份揭晓 |
| 03 | **侧向切入镜头** | 镜头自画面侧缘迅速切入主体，强化突发性 | 突然现身、危机闯入 |
| 04 | **压迫式逼近** | 长焦机位持续缩短人物呼吸空间，形成心理压强 | 审讯时刻、心理博弈 |
| 05 | **退让式让位镜头** | 镜头边退边让出前景空间，引出新信息主体 | 线索出现、第二人物登场 |
| 06 | **交叉穿行镜头** | 镜头在多人或障碍间连续穿行，保持叙事推进 | 群戏调度、追逐转场 |
| 07 | **贴地掠行镜头** | 超低机位贴地高速掠过，突出速度与冲击 | 车辆冲刺、战斗开场 |
| 08 | **顶视旋落镜头** | 镜头从顶视角旋转下落至人物层面，建立戏剧压差 | 命运转折、情绪崩塌 |
| 09 | **侧背尾随镜头** | 锁定人物侧后方同步移动，保留环境压迫感 | 潜行跟踪、秘密行动 |
| 10 | **突停凝视镜头** | 运动中骤然刹停并定格主体，放大情绪停顿 | 真相刺痛、内心震荡 |
| 11 | **回撤揭示镜头** | 从局部快速回撤，揭示完整局面或反转信息 | 陷阱曝光、局势逆转 |
| 12 | **双主体摆渡镜头** | 在两名角色之间往返移动，强调关系张力 | 谈判拉扯、情感试探 |
| 13 | **斜向俯冲镜头** | 以斜线轨迹快速俯冲进入场景，制造攻击性视觉 | 突袭降临、灾难逼近 |
| 14 | **纵深穿堂镜头** | 沿空间纵深连续穿过门廊通道，强化未知感与牵引 | 探秘进入、空间探索 |
| 15 | ~~**节奏点爆发镜头**~~ ❌禁用 | ~~在音乐或动作节拍瞬间加速冲刺~~ → 用快切替代 | ~~高燃出场、决战前奏~~ |
| 16 | **悬停审视镜头** | 短暂停驻并微调角度观察主体，形成冷静审视感 | 权力压制、危险评估 |

### 交锋类（近身攻击 / 武器碰撞）

| 17 | **打击冻结镜头** | 命中瞬间画面冻结 0.3-0.5s，主体与碰撞点居中，背景动态模糊骤停；写实版：画面微震 4-6px，命中点皮肤凹陷/衣料变形；特效版：冲击波扩散 | 拳/武器命中瞬间、致命一击 |
| 18 | **受击抛飞镜头** | 镜头锁定受击者，跟随身体向后抛飞轨迹，背景快速流动，落地时画面微震 | 重击将人打飞、撞墙、倒地 |
| 19 | **武器交锋镜头** | 两把武器沿对角线碰撞，大特写火花飞溅，镜头微震，金属余音视觉化 | 刀剑碰撞、锁刃、武器格挡 |
| 20 | **连击追踪镜头** | 稳定器快速跟随连续 2-3 次打击，焦点在攻击部位（拳/腿/武器）间跳跃，每次命中画面微震 | 组合拳、连续斩击、多段踢 |

### 冲击类（速度感 / 破坏力）

## 运镜选用决策指南

### 按剧情类型选运镜

| 剧情类型 | 首选分类 | 典型运镜 |
|---------|---------|---------|
| 人物出场 / 环境交代 | 叙事与定格 | 推镜、摇镜、升降镜头、俯拍定格 |
| 日常对话 / 对白 | 氛围与景别 | 中近景、过肩镜头、中景、主观镜头 |
| 情绪爆发 / 心理戏 | 情绪镜头 | 推近压迫、环绕眩晕、手持崩溃、定格凝视 |
| 追逐 / 打斗 / 动作 | 动作镜头（交锋类） | 打击冻结、受击抛飞、武器交锋、连击追踪 |
| 打斗高潮 / 绝招 / 逆转 | 动作镜头（冲击类+逆转类） | 子弹时间、第一人称受击、逆转翻盘、爆气冲击 |
| 地面格斗 / 近身缠斗 | 动作镜头（冲击类） | 地面缠斗、第一人称受击、打击冻结 |
| 场景切换 / 大场面 | 运动镜头 | 航拍、甩镜、穿越运镜、快切 |
| 结局 / 收尾 | 情绪镜头 + 叙事 | 空镜余韵、抽离镜头、后撤疏离、特写定格 |

### 运镜组合原则

1. **单镜 1-2 个运镜**：避免堆砌，如"微推 + 手持微抖 0.5Hz"
2. **运镜服务于情绪**：先确定本镜情绪基调，再从对应分类中选运镜
3. **动-静-动节奏**：连续动作镜之间插入静态镜头，避免视觉疲劳
4. **竖屏 9:16**：运镜幅度小，微推/微拉/手持微抖为主
5. **横屏 16:9**：运镜幅度可大，跟拍/轨道/慢摇/长焦压缩

### 运镜字段填写格式

```
运镜：（{运镜方式}＋{量化参数}，如：微推 ＋ 手持微抖 0.5Hz）
```

**示例：**
- 运镜：推近压迫镜头（慢速推进，焦点锁定人物面部，背景逐渐压缩）
- 运镜：环绕镜头（围绕主体 360° 环拍，轻微变焦制造失衡感）
- 运镜：贴地掠行镜头（超低机位贴地高速掠过，速度感 + 冲击力）
- 运镜：打击冻结镜头（命中瞬间画面冻结 0.4s，冲击波扩散，背景动态模糊骤停）
- 运镜：连击追踪镜头（稳定器快速跟随连续 3 次打击，焦点在拳→肘→膝间跳跃，每击画面微震）
- 运镜：子弹时间镜头（0.25× 慢动作环绕主体，碎片悬浮，180° 环拍）
