# 资产命名规范（Asset Naming Rules）

> 供 `Basics-pro` 技能在全部镜头生成时强制执行。
> v3.1 新增：杜绝因简称/别名/省略导致的 AI 生成时资产错乱。

---

## 一、核心原则

**所有场景、人物、道具在分镜中必须使用用户提供的完整资产名称，跨镜头、跨字段保持一致。任何字段中引用同一资产时，名称必须完全相同。**

---

## 二、资产命名格式

### 2.1 人物资产名称

```
{角色名} {服装/外观描述}
```

| 示例 | 说明 |
|------|------|
| `薇拉 女战士指挥官战甲` | 角色名 + 当前场景服装 |
| `卢卡斯 现代酒吧便装` | 不同场景不同服装视为不同资产 |
| `刽子手` | 单一名词即可唯一标识的角色 |
| `艾拉 女战士副官战甲` | 角色名 + 外观特征 |
| `围观女战士群` | 群体角色，无需服装描述 |

**规则：**
- 同一角色在不同场景穿不同服装时，必须使用不同的资产名称
- 如：`卢卡斯 现代酒吧便装`（第1集）≠ `卢卡斯 囚服`（第2集）
- 群体角色可省略服装描述（如 `围观女战士群`）

### 2.2 场景资产名称

```
{地点名} {时间/氛围描述}
```

| 示例 | 说明 |
|------|------|
| `塞尔加德处刑广场夜晚` | 地点 + 时间 |
| `酒店套房夜内` | 地点 + 时间 + 内外 |
| `古籍店黄昏内` | 地点 + 时间 + 内外 |

**规则：**
- 场景名称在分镜中作为场景字段的锚定名称
- 同一场景在不同时间（如日夜切换）视为不同资产

### 2.3 道具资产名称

```
{道具名}（与资产图文件名完全一致，不附加材质描述）
```

| 示例 | 说明 |
|------|------|
| `石斧` | 与资产图 `石斧.png` 完全一致 |
| `打火机` | 与资产图 `打火机.png` 完全一致 |
| `长剑` | 与资产图 `长剑.png` 完全一致 |
| `水晶吊坠` | 与资产图 `水晶吊坠.png` 完全一致 |

**规则：**
- 道具名称必须与用户提供的道具资产图文件名完全一致，**不加 `（）` 材质描述**
- 仅当道具**不在**用户资产图中时，才需附加材质/外观描述（如 `破旧木盾（边缘开裂，铁钉锈蚀）`）
- 道具字段每镜必写完整名称，不得使用「同上」
- 道具的材质/光影表现由「画面描述」字段负责，不通过道具名称传递

## 三、各字段资产引用规则

### 3.1 场景字段

**仅写完整场景资产名称，与资产图文件名一致。每镜必写完整名称，严禁使用「同上」。时间、内外、光线描述已拆分至独立字段「时间」和「画面描述」。**

| 正确 ✅ | 错误 ❌ |
|------|------|
| `塞尔加德处刑广场夜晚` | `同上` |
| `塞尔加德处刑广场夜晚` | `塞尔加德处刑广场夜晚 ／ 夜 ／ 外 ／ 火光摇曳` ❌ 时间/光线不应在场景字段 |

### 3.2 人物字段

**仅列名称，每镜必写完整资产名称，严禁使用「同上」。人物动作/状态描述统一合并至「人物站位」字段。**

| 正确 ✅ | 错误 ❌ |
|---------|---------|
| `薇拉 女战士指挥官战甲、刽子手、卢卡斯 现代酒吧便装` | `薇拉、刽子手、卢卡斯` |
| `薇拉 女战士指挥官战甲、刽子手、卢卡斯 现代酒吧便装` | `薇拉 女战士指挥官战甲（前景肩部虚化）、刽子手（高举石斧）` ❌ 动作描述不应在人物字段 |

### 3.3 道具字段

**仅列名称，每镜必写完整资产名称，不得使用「同上」。名称与资产图文件名一致，不加任何 `（）` 描述。道具的位置/状态合并至「人物站位」或「画面构图」字段。**

| 正确 ✅ | 错误 ❌ |
|---------|---------|
| `石斧、打火机` | `石斧、打火机（落于卢卡斯 现代酒吧便装脚边地面）` ❌ 位置描述不应在道具字段 |
| 仅当道具不在资产图中时：`破旧木盾（边缘开裂，铁钉锈蚀）` | 资产图中已有的道具加材质：`石斧（粗砺岩面）` ❌ |

### 3.4 人物站位字段

**引用人物时必须使用完整资产名称。本字段承担原「人物」和「道具」字段中 `（）` 内的动作/状态/位置描述，以及「行动者」标注。每镜中每个出场人物必须明确其朝向方向（如「朝向卢卡斯」「面向薇拉」「背对镜头」「面向镜头」）。若朝向目标未在当前镜头画面内，必须追加标注「（画面外X侧）」，避免AI生成时将目标错误地渲染在画面内。**

| 正确 ✅ | 错误 ❌ |
|---------|---------|
| `前景右侧薇拉 女战士指挥官战甲肩背虚化，背对镜头；中景刽子手居中高举石斧，朝向卢卡斯 现代酒吧便装；后景卢卡斯 现代酒吧便装跪地左侧，面向刽子手；薇拉 女战士指挥官战甲为行动者` | `前景右侧薇拉肩背虚化，中景刽子手居中，后景卢卡斯跪地左侧` |
| 目标未入画：`卢卡斯 现代酒吧便装居中，面向薇拉 女战士指挥官战甲（画面外左侧）` ✅ | `卢卡斯 现代酒吧便装居中，面向薇拉 女战士指挥官战甲` ❌ 薇拉未入画却未标注 |

### 3.5 画面构图字段

引用人物和道具时必须使用完整资产名称。

| 正确 ✅ | 错误 ❌ |
|---------|---------|
| `薇拉 女战士指挥官战甲肩部右侧前景虚化框定视点，刽子手石斧高举于画面中上1/3，卢卡斯 现代酒吧便装位于左下角` | `薇拉肩部右侧前景虚化框定视点，刽子手石斧高举于画面中上1/3，卢卡斯位于左下角` |

### 3.6 动作表演字段

引用人物时必须使用完整资产名称。

| 正确 ✅ | 错误 ❌ |
|---------|---------|
| `0-0.5s 薇拉 女战士指挥官战甲剑锋从右侧急速切入画面即将阻挡砍向卢卡斯 现代酒吧便装的石斧` | `0-0.5s 薇拉剑锋从右侧急速切入画面` |

### 3.7 画面描述字段

引用人物和道具时必须使用完整资产名称。

| 正确 ✅ | 错误 ❌ |
|---------|---------|
| `剑刃与石斧（粗砺岩面）碰撞瞬间火星四溅，冷蓝月光勾勒薇拉 女战士指挥官战甲剑刃边缘` | `剑刃与石斧碰撞瞬间火星四溅，冷蓝月光勾勒薇拉剑刃边缘` |

### 3.8 对白/台词字段

说话人必须使用完整资产名称。

| 正确 ✅ | 错误 ❌ |
|---------|---------|
| `薇拉 女战士指挥官战甲（威严·命令·约5.2音节/秒）："Hold it!"` | `薇拉（威严·命令）："Hold it!"` |

### 3.9 衔接注记字段

引用人物时必须使用完整资产名称。

| 正确 ✅ | 错误 ❌ |
|---------|---------|
| `下一镜首帧承接火星消散后刽子手的面部特写` | `下一镜首帧承接火星消散后刽子手的面部特写` |

## 四、禁止行为清单

| 类别 | 禁止行为 | 示例（❌ 错误） | 示例（✅ 正确） |
|------|---------|---------------|---------------|
| 简称 | 省略服装/外观描述 | `薇拉` | `薇拉 女战士指挥官战甲` |
| 别名 | 使用角色身份替代名称 | `指挥官` | `薇拉 女战士指挥官战甲` |
| 道具擅自加材质 | 资产图中已有道具，擅自附加 `（）` 材质描述 | `石斧（粗砺岩面）`、`打火机（金属外壳）` | `石斧`、`打火机` |
| 模糊指代 | 使用代词指代 | `那个女人`、`他` | `薇拉 女战士指挥官战甲` |
| 人物「同上」 | 人物字段使用「同上」 | `人物：同上` | `人物：薇拉 女战士指挥官战甲、刽子手、卢卡斯 现代酒吧便装` |
| 道具「同上」 | 道具字段使用「同上」 | `道具：同上` | `道具：石斧、打火机` |
| 场景「同上」 | 场景字段使用「同上」 | `场景：同上` | `场景：塞尔加德处刑广场夜晚 ／ 夜 ／ 外 ／ 火光摇曳，冷色月光` |
| 未入画目标未标注 | 朝向目标不在画面内却未标注「画面外」 | `面向薇拉 女战士指挥官战甲` | `面向薇拉 女战士指挥官战甲（画面外左侧）` |
| 跨字段不一致 | 人物字段写 `薇拉 女战士指挥官战甲`，动作表演写 `薇拉` | — | 所有字段名称完全一致 |

## 六、自检清单

生成全部镜头后，逐镜检查：

- [ ] 场景字段：是否每镜都写了完整场景资产名称？是否存在「同上」？
- [ ] 人物字段：是否每镜都写了完整人物资产名称（仅列名称，含服装/外观）？是否存在「同上」或简称/别名/模糊指代？
- [ ] 道具字段：是否每镜都写了完整道具资产名称（与资产图文件名一致，仅列名称，不加 `（）` 材质）？是否存在「同上」或擅自附加 `（）` 描述？
- [ ] 人物站位：引用人物时是否使用了完整资产名称？每个出场人物是否标注了朝向方向？朝向目标未入画时是否标注了「（画面外X侧）」？行动者标注是否在此字段？
- [ ] 画面构图：引用人物和道具时是否使用了完整资产名称？
- [ ] 动作表演：引用人物时是否使用了完整资产名称？引用道具时是否使用了完整道具资产名称？
- [ ] 画面描述：引用人物和道具时是否使用了完整资产名称？
- [ ] 对白/台词：说话人是否使用了完整人物资产名称？
- [ ] 衔接注记：引用人物时是否使用了完整资产名称？
- [ ] 跨镜头一致性：同一资产在所有镜头中的名称是否完全一致？
- [ ] 跨字段一致性：同一资产在同一镜头的不同字段中名称是否完全一致？
