# 爆款短剧公式类型库与拆解模板

本文档是六维拆解、骨架映射、四段式推演的详细参考。拆解与套用时按需读取。

## 一、核心爽感机制类型库

爆款短剧的情绪红利，通常由以下一种或多种机制叠加而成。拆解时先判定主机制，再标注辅助机制。

| 机制 | 情绪红利 | 典型套路 | 视觉名场面 |
|------|----------|----------|------------|
| 扮猪吃虎 | 憋屈→释放的落差爽 | 主角表面窝囊、实则深藏不露 | 被踩到临界点后轻描淡写碾压 |
| 阶层碾压 | 底层逆袭高位的复仇爽 | 穷/弱一方反杀权贵资本 | 身份揭晓，全场跪 |
| 绝境翻盘 | 命悬一线的求生爽 | 被逼入绝境后极限反转 | 反杀、绝处逢生 |
| 身份反转 | 认知错位的揭晓爽 | 众人看不起的人其实是真大佬 | 亮出真实身份/证件/权柄 |
| 打脸逆袭 | 即时报复的多巴胺爽 | 前脚被羞辱，后脚当面打脸 | 当众对质、证据甩脸 |
| 强强互撩 | 势均力敌的拉扯爽 | 双强情感博弈、极限拉扯 | 对峙、壁咚、反撩 |

判定标准：观众「爽」到底来自「谁打谁的脸」，以及「打脸靠什么」——是实力、身份、还是信息。

## 二、人设权力反差拆解模板

每个关键角色按四栏拆：

| 维度 | 主角 | 反派/高位者 | 打脸对象 |
|------|------|-------------|----------|
| 明面地位 | 低/被压制 | 高/施压 | 附和反派的帮凶 |
| 隐藏底牌 | 实力/身份/信息 | 把柄/弱点 | 无 |
| 压制关系 | 被谁压制 | 压制谁 | 站队谁 |
| 反转逻辑 | 何时、因何亮底牌 | 何时、因何崩盘 | 何时倒戈/被打脸 |

核心问题：**明面上谁碾压谁，暗面上谁碾压谁，落差有多大，反转在哪一刻爆发。**

## 三、信息差设计手法

信息差 = 观众与主角知情、反派不知情的隐藏信息。用于制造拉扯感、期待感、打脸铺垫。

常见手法：
- **身份隐藏**：主角的真实身份/财富/背景，反派蒙在鼓里。
- **能力隐藏**：主角有碾压级实力，但故意不出手。
- **预知/真相**：观众已知某事件真相，看反派如何一步步踩坑。
- **把柄在手**：主角握有反派致命证据，引而不发。
- **计中计**：主角早已布局，反派以为得逞实则是主角设的局。

每条信息差要标注：谁知道 / 谁不知道 / 何时揭晓 / 揭晓的爽感落点。

## 四、叙事节拍结构比例

竖屏短剧单集/单场的常用节奏配比（可微调，但反转与爆发必须占足权重）：

- 铺垫起因 ≈ 20%
- 受辱/施压 ≈ 25%
- 升级/蓄力 ≈ 15%
- 反转揭晓 ≈ 20%
- 爆发/打脸 ≈ 15%
- 收尾钩子 ≈ 5%

铁律：**冲突前置**（每集第一场即核心冲突）、**末尾留钩**（每集最后一句话/画面制造悬念）、**每 5-7 集一个爽点**（观众需要定期多巴胺）。

## 五、结尾钩子类型库

- **反转钩**：结尾一句话/一个画面翻转认知（"原来是你"型）。
- **悬念钩**：抛出未解之谜、未知威胁（谁在敲门、电话那头是谁）。
- **对立钩**：遗留对立矛盾，为下集冲突埋雷（反派放狠话、下战书）。
- **伏笔钩**：预埋一个看似无关实则关键的细节（一个道具、一句暗语）。
- **危机钩**：主角/盟友陷入新危机，制造追更焦虑。

钩子必须「一句话能说清」，且下集开场要兑现或推进，禁止空钩。

## 六、四段式完整示例（对标拆解后套壳的成品样式）

```
【第 1 集】
1. 铺垫起因：女主婚礼现场，婆家当众羞辱其出身，逼其签婚前协议放弃财产；全场看她笑话。
2. 冲突激化：婆婆把协议拍在桌上，未婚夫冷眼旁观，闺蜜落井下石。女主强忍，指尖掐进掌心。
3. 反转爆发：女主抬手撕碎协议，亮出手机——她才是对方家族最大债主，全场哗然，婆婆脸色惨白。
4. 结尾钩子：未婚夫颤抖着问"你到底是谁"，女主冷笑转身，门外一辆黑车停定，司机喊出她隐藏的真实姓氏。
```

## 七、骨架映射对位表（阶段二用）

| 原爆款结构 | 新故事落点 |
|-----------|-----------|
| 原主角（低位隐藏者） | 新主角 |
| 原反派/高位碾压者 | 新反派 |
| 原打脸对象 | 新打脸对象 |
| 受辱事件 | 新受辱事件 |
| 压制事件 | 新压制事件 |
| 反击节点 | 新反击节点 |
| 反转揭晓 | 新反转揭晓 |
| 视觉爆点 | 新视觉爆点（按新题材重设计） |

原则：**只移植结构，不照搬剧情、道具、台词。** 新剧要有新题材专属的信息差与视觉爆点。
