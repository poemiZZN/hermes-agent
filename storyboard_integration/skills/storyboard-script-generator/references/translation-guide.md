# 对白翻译指南（Dialogue Translation Guide）

> 供 `storyboard-script-generator` 技能在"第 3 步：对白翻译"时调用。

## 一、翻译原则

### 1.1 准确性优先
- 翻译必须忠实于中文原文的含义和情绪
- 不能遗漏、添加或改变原文的意思
- 专有名词（人名、地名）保持原文或用意译

### 1.2 口语化
- 使用目标语言的自然口语表达，而非书面语
- 符合角色身份和社会地位的语言风格
- 贵族说贵族的话，平民说平民的话，小孩说小孩的话

### 1.3 情绪一致
- 保持原文的情绪强度（愤怒就是愤怒，不是"有点不高兴"）
- 保持原文的语气（讽刺、温柔、命令、恳求等）
- 保持原文的节奏（短句急促、长句舒缓）

### 1.4 在地化
- 适当使用目标语言的俚语和惯用表达
- 符合目标语言文化的表达习惯
- 避免直译导致的文化隔阂

## 二、输出格式

每句对白按以下格式输出：

```
角色名（情绪·节奏·约X音节/秒）："目标语言原文" （中："中文原文"）
```

**字段说明：**
- **角色名**：说话的角色
- **情绪**：当前情绪状态（如：愤怒、温柔、困惑、恐惧、讽刺）
- **节奏**：语速（快/中速/慢/急促/缓慢）
- **约X音节/秒**：估算的音节速率，用于 AI 模型对口型
- **目标语言原文**：翻译后的对白
- **中文原文**：编剧提供的原始中文对白，仅供人类审阅

## 三、多语种对照示例

### 西班牙语
```
中文：塞拉菲娜（愤怒）："别碰我！"
→ 西班牙语：塞拉菲娜（惊怒，快，0.4s/字）：¡No me toques! （中："别碰我！"）

中文：陌生男伴（困惑）："塞拉菲娜，你怎么了？"
→ 西班牙语：陌生男伴（困惑，中速，0.4s/字）：Serafina, ¿qué te pasa? （中："塞拉菲娜，你怎么了？"）

中文：塞拉菲娜（坚定）："我一定要找到答案。"
→ 西班牙语：塞拉菲娜（坚定，中速，0.35s/字）：Tengo que encontrar la respuesta. （中："我一定要找到答案。"）
```

### 英语
```
中文：男主（愤怒）："你骗了我！"
→ 英语：男主（愤怒，快，0.3s/字）：You lied to me! （中："你骗了我！"）

中文：女主（悲伤）："我再也回不去了。"
→ 英语：女主（悲伤，慢，0.5s/字）：I can never go back. （中："我再也回不去了。"）
```

### 日语
```
中文：老人（感慨）："百年了，一切都变了。"
→ 日语：老人（感慨，慢，0.5s/字）：百年か…すべてが変わった。 （中："百年了，一切都变了。"）

中文：少女（惊讶）："这是什么？"
→ 日语：少女（惊讶，快，0.3s/字）：これは何？ （中："这是什么？"）
```

### 泰语
```
中文：母亲（温柔）："别怕，妈妈在。"
→ 泰语：母亲（温柔，慢，0.5s/字）：ไม่ต้องกลัว แม่อยู่ตรงนี้ （中："别怕，妈妈在。"）

中文：反派（威胁）："你会后悔的。"
→ 泰语：反派（威胁，慢，0.4s/字）：แกจะต้องเสียใจ （中："你会后悔的。"）
```

### 印尼语
```
中文：朋友（安慰）："一切都会好起来的。"
→ 印尼语：朋友（安慰，慢，0.5s/字）：Semua akan baik-baik saja. （中："一切都会好起来的。"）

中文：警察（命令）："不许动！"
→ 印尼语：警察（命令，快，0.3s/字）：Jangan bergerak! （中："不许动！"）
```

### 阿拉伯语
```
中文：父亲（严肃）："这是你的责任。"
→ 阿拉伯语：父亲（严肃，中速，0.4s/字）：هذه مسؤوليتك. （中："这是你的责任。"）

中文：女孩（哭泣）："我不想离开。"
→ 阿拉伯语：女孩（哭泣，慢，0.5s/字）：لا أريد الرحيل. （中："我不想离开。"）
```

## 四、翻译质量自检清单

生成对白翻译后，逐条检查：

- [ ] 翻译是否准确传达了中文原文的意思？
- [ ] 目标语言表达是否自然、口语化？
- [ ] 情绪和语气是否与原文一致？
- [ ] 是否符合角色的身份和说话风格？
- [ ] 是否使用了适当的俚语/惯用表达？
- [ ] 输出格式是否正确（角色名 + 情绪 + 节奏 + 原文 + 中文）？
- [ ] 是否在音频配置中声明了对白语言？

## 五、音频配置声明

在所有镜头的"音频配置（固定内容）"中，必须包含对白语言声明：

```
对话均为{目标语言}，适当使用{目标语言}俚语。
对白均为外语原声，中文翻译仅供人类审阅。
```

示例（西班牙语）：
```
对话均为西班牙语，适当使用西班牙俚语。
对白均为外语原声，中文翻译仅供人类审阅。
```

示例（英语）：
```
对话均为英语，适当使用英语俚语。
对白均为外语原声，中文翻译仅供人类审阅。
```
