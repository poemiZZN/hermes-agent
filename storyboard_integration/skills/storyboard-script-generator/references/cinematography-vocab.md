# 摄影词表与量化参数库（Cinematography Vocabulary）

> 供 `storyboard-director` 技能在生成分镜时调用。原则：用专业术语 + 量化单位，替代模糊形容词。

## 一、景别词表（Shot Size）

| 景别 | 取景范围 | 适用 |
|---|---|---|
| 大远景（ELS） | 人物极小，强调环境与空间 | 横屏开场、史诗感 |
| 远景（LS） | 全身 + 大量环境 | 群像、地形 |
| 全景（FS） | 人物全身 + 少量环境 | 动作、站位 |
| 中景（MS） | 腰以上 | 对话、互动 |
| 中近景（MCU） | 胸以上 | 表演、情绪 |
| 近景（CU） | 肩以上 | 表情 |
| 特写（CU） | 面部/局部 | 微表情、细节 |
| 大特写（BCU） | 眼/嘴/手等极小局部 | 竖屏情绪爆点 |

## 二、机位词表（Camera Angle / Position）

- 平视（Eye-level）：中性、平等
- 仰拍（Low angle）：人物显强/压迫感
- 俯拍（High angle）：人物显弱/被审视
- 过肩（OTS）：对话、关系
- 低机位（Ground level）：沉浸、宠物体/儿童视角
- 顶拍（Top-down）：俯瞰、仪式感
- 荷兰角（Dutch tilt）：失衡、紧张、 psychedelic
- 主观视角（POV）：代入、第一人称

## 三、运镜词表（Camera Movement，尽量量化）

| 运镜 | 量化写法举例 |
|---|---|
| 推（Dolly in / Push） | 微推 0.15m/s；快速推 0.6m/s |
| 拉（Pull out） | 慢拉 0.2m/s，露出环境 |
| 摇（Pan） | 横摇，角速度 8°/s |
| 移（Truck / Slide） | 侧移 0.3m/s |
| 跟（Follow） | 背后跟拍，步频同步 1.5 步/s |
| 升/降（Crane / Ped） | Tilt up/down，仰角 0→30° 用 1.2s |
| 手持微抖（Handheld） | 0.5–0.6Hz 微抖，幅度 ±2cm |
| 斯坦尼康（Steadicam） | 顺滑长跟，无抖动 |
| 环绕（Orbit） | 绕主体 90°，6s 完成 |
| 焦点变换（Rack focus） | 焦点由前景虚化转主体，0.4s |

## 四、量化参数范例（直接套用）

- **速度**：`0.2m/s`、`步频约 1.5 步/s`、`瞳孔 3mm→7mm（0.3s 内）`、`胸廓起伏每 1.6s 一次、幅度 3cm`
- **光学**：`f/1.4 极浅景深`、`85mm / T2.8`、`手持微抖 0.6Hz`、`景深 0.3m`
- **色温/颜色**：`色温 3200K 暖`、`#C8B040 冷黄`、`琥珀→蓝 过渡 0.3s`
- **声学**：`约 2.8kHz，持续 0.05s，混响 0.2s`、`声压 28dB`、`40Hz 低频风声`、`吞咽声 0.1s`

## 五、材质描写词库（Material）

- **皮肤**：SSS 半透明、真实毛孔、胡茬、眼周微血管、汗毛、眼下青影、泪膜反光
- **金属**：黄铜氧化暗铜色、划痕 0.05mm、冷钢反光、锈迹、磨损螺纹
- **布料**：棉麻磨损、油渍、褶皱受光梯度、皮革纹理、湿水反光
- **自然**：水面镜面反射、雾气体积光、沙石颗粒、植被露珠

## 六、光影描写词库（Lighting）

- 主光方向：顶光在眉弓下造锐利阴影；冷蓝侧光勾轮廓；窗光斜射
- 光型：丁达尔光柱（体积光）、伦勃朗光、蝴蝶光、硬光高反差、柔光低反差
- 明暗：禁止均匀照明——必须半明半暗（chiaroscuro）
- 质感：光在金属上的长条高光、在湿面上的镜面反射、透过百叶窗的条纹光

## 七、构图法（Composition）

三分法、中心构图、对角构图、框架构图（门窗框人）、前景遮挡、引导线、负空间、对称、留白（竖屏顶部/底部留白）。
