# 段落划分规则详解（Segment Division Rules）

> 供 `storyboard-script-generator` 技能在"第 2 步：段落划分"时调用。

## 一、核心原则（优先级从高到低）

### 原则 1：场景/剧情完整性 > 时长限制

段落划分的第一优先级是**保持剧情和场景的完整性**。一段连续的场景内剧情，绝不应该被生硬切断。

**判断标准**：以下情况视为"同一段剧情"，不应拆分：
- 同一场景内的连续对话（一问一答、多轮对话）
- 同一场景内的连续动作序列（如：进门→走到桌前→坐下→拿起杯子）
- 同一场景内的情绪递进（如：酝酿→爆发→收尾，见 emotion-library.md 的情绪曲线）
- 同一场景内的时间连续推进（如：黄昏→入夜）

### 原则 2：场景切换 = 自然分段点

每当剧本中出现以下变化，即为"自然分段点"：
- 场景地点变化（如：从酒店套房→电梯→豪车→古籍店）
- 时间跳跃（如：夜→黎明、闪回→现代）
- 剧情线切换（如：A 故事线→B 故事线）
- 情绪基调明显转变（如：温馨→紧张）

### 原则 3：模型时长上限

| 模型 | 单段多镜头累计时长上限 |
|------|------------------------|
| Seedance 2.0 | ≤ 15s |
| Seedance 2.5 | ≤ 30s |

## 二、段落超时拆分规则

### 2.1 前置检查：压缩优先

在决定拆分前，先问自己：
- 能否合并相邻的短镜头？（如：两个 2s 镜合并为一个 3.5s 镜）
- 能否精简冗余镜头？（如：去掉一个不必要的环境建立镜）
- 能否缩短个别镜头时长？（如：把 5s 空镜压缩到 3s）

**只有在压缩后仍超时的情况下，才执行拆分。**

### 2.2 拆分点选择

拆分点必须在以下"安全位置"：
1. **对白段落结束**：一轮对话说完，回应之前
2. **动作完成**：一个完整动作序列结束（如：推门→走出→关门 完成）
3. **情绪转折**：情绪从酝酿期进入爆发期之前（情绪曲线拐点）
4. **自然停顿**：剧本中有明确停顿/沉默/留白的位置

**禁止在以下位置拆分：**
- 对白进行中（一句话没说完）
- 动作进行中（一个动作没做完）
- 情绪爆发中途
- 悬念/紧张建立的最高点

### 2.3 第二段落衔接规则

当因超时被迫拆分时，第二段落必须以**衔接镜头**开头：

**衔接镜头类型（按优先级）：**

1. **环境空镜**（首选）
   - 全景/远景，展示当前场景的整体环境
   - 时长：2-3s
   - 示例：窗外雨景、室内静物、烛火摇曳、街道空镜
   - 必须与段落 1 的场景和氛围一致

2. **局部特写**（次选）
   - 关键道具特写、人物手部/眼部特写
   - 时长：2-3s
   - 示例：手背纹路、酒杯倾倒、门把手转动
   - 必须与段落 1 的尾帧有视觉或逻辑关联

3. **情绪延续镜**（备选）
   - 人物面部微表情特写，延续段落 1 的情绪状态
   - 时长：2-3s
   - 示例：人物凝视、垂首、抿唇

**衔接注记写法**：在段落 2 的第一个衔接镜头中，衔接注记必须写明：
```
衔接注记：本镜为段落衔接空镜，承接段落{1}尾帧的{场景/情绪/动作}；
{具体衔接元素，如：雨滴节奏延续、光影方向一致、情绪状态不跳变}；
下一镜正式切入段落{2}剧情。
```

### 2.4 拆分决策流程图

```
预估段落总时长 > 模型上限？
  ├─ 否 → 正常生成，不分段
  └─ 是 → 尝试压缩
      ├─ 可压缩到上限内 → 压缩后正常生成
      └─ 仍超时 → 寻找安全拆分点
          ├─ 找到安全拆分点 → 拆分
          │   ├─ 段落1：前半剧情（≤上限）
          │   └─ 段落2：衔接空镜/特写（2-3s）+ 后半剧情（≤上限-3s）
          └─ 找不到安全拆分点 → 重新评估镜头规划
              └─ 考虑：是否可以将部分内容移到下一段落？
```

## 三、实战案例

### 案例 1：同场景多剧情，无需拆分

```
场景：酒店套房，夜
剧情：塞拉菲娜与男伴亲密 → 突然推拒 → 手背纹路浮现 → 香槟塔倒塌
镜头：4 镜 × 3.5s = 14s
模型：Seedance 2.0（上限 15s）
决策：14s ≤ 15s，无需拆分，一个段落完成 ✓
```

### 案例 2：场景自然切换，自然分段

```
场景 A：酒店套房（4镜，14s）→ 场景 B：酒店电梯（2镜，7s）→ 场景 C：豪车后座（2镜，7s）
模型：Seedance 2.0（上限 15s）
决策：场景 A=段落1（14s），场景 B+C=段落2（14s）
说明：场景 B 和 C 虽然不同地点，但都是"离开酒店"的连续剧情线，可合并
```

### 案例 3：超时且必须拆分

```
场景：古籍店内，夜
剧情：塞拉菲娜入店 → 与店主对话 → 发现古籍 → 翻阅古籍 → 纹路共鸣反应
预估：6 镜 × 3.5s = 21s
模型：Seedance 2.0（上限 15s）
检查压缩：无法压缩（每镜都已是最短有效时长）
安全拆分点：发现古籍后、翻阅前（动作完成 + 情绪转折）
决策：
  段落1（4镜，14s）：入店 → 对话 → 发现古籍
  段落2（3镜，10.5s）：衔接空镜（古籍封面特写，3s）→ 翻阅古籍 → 纹路反应
  衔接注记：段落2首镜为古籍封面特写，封面纹路与段落1尾帧的手背纹路呼应，
  光影方向一致，暗示两者关联；下一镜切入翻阅动作。
```

## 四、段落内镜头规划模板

每个段落建议按以下模板组织（非强制，但推荐）：

| 位置 | 镜头类型 | 数量 | 单镜时长 | 累计 | 说明 |
|------|---------|------|---------|------|------|
| 第1镜 | 环境建立 | 0-1 | 2-4s | 0-4s | 全景/远景，交代空间；如上一段已建立可省略 |
| 第2镜 | 人物引入 | 1 | 3-4s | 3-8s | 中景/中近景，谁在哪儿、什么状态 |
| 第3-5镜 | 剧情推进 | 2-4 | 3-4s | 6-23s | 对切/过肩/特写，主要剧情载体 |
| 末镜 | 段落收尾 | 1 | 2-4s | 8-27s | 情绪定格/动作完成/关键道具，为转场铺垫 |

**时长控制建议：**
- 竖屏 9:16 + Seedance 2.0：每段 3-5 镜，总 10-15s
- 竖屏 9:16 + Seedance 2.5：每段 4-8 镜，总 15-30s
- 横屏 16:9 + Seedance 2.0：每段 3-4 镜，总 10-15s（单镜更长）
- 横屏 16:9 + Seedance 2.5：每段 4-6 镜，总 15-30s
