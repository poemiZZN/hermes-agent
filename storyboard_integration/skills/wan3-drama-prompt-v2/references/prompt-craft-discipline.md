# 提示词工程纪律（通用手法）

> 本文件收录**通用的提示词工程纪律**，全部已落到 wan3.0 口径（`@图片N` 指代 + 七大公式）。
>
> **纪律边界**：
> - 与 [`wan3-formulas.md`](wan3-formulas.md) 冲突时，**一律以公式文件为准**
> - 本文件是**补充手法**，不是替代公式；效果以实测为准，交付时不要当成硬承诺

---

## 1. 时间线连续纪律（补强 §6 多镜头公式）

多镜头公式给了「第N个镜头[a-b秒]」的外壳，但没规定**每段内部怎么写、段与段怎么接**。补这三条：

1. **每段四要素**：起始状态 + 可见动作 + 镜头拍法 + **结束状态**。
   「结束状态」是最常漏的一项，漏了下一段就没有落脚点，模型只能自己脑补，跨镜跳变基本从这里来。
2. **上段结束状态 = 下段起始状态**。写完通读一遍：如果第 2 段的开头无法从第 1 段的结尾自然接上，说明中间缺了一个动作，补上或合并。
3. **一段一主动作、一主运镜**。同一时间段里同时要求"固定机位 + 360 度环绕 + 推进"，模型会挑一个执行或三个都做半截。

**时间戳三条硬自检**：
- 从 0 秒起、段间不重叠、中间不留空
- 各段时长之和 **= `duration`**（硬要求，对不上会报错或被裁）
- 单段 **≥ 2s**，否则动作来不及展开

**段数卡尺**（按 wan3.0 `duration` 2–30s 换算）：

| duration | 建议镜头段数 | 说明 |
|---|---|---|
| 5s | 1（单镜头） | 只够一个主动作，写「生成单镜头」别切镜 |
| 8–10s | 2–3 | 安全区 |
| 15s | 3–4 | 4 镜是稳定上限 |
| 20–30s | 4 封顶，或拆任务 | 超 4 镜建议拆成多次任务，逐段生成后剪接 |

**节奏骨架**（仅用于原创内容的默认起手；反推已有成片时按真实切点，**不要套平均分段**）：

- **15s**：0–2 钩子（主体/商品/冲突立刻出现）→ 2–5 第一动作或卖点 → 5–9 推进或关系变化 → 9–12 高潮或效果证明 → 12–15 落点与收尾
- **30s**：0–3 钩子与关系建立 → 3–8 第一阶段 → 8–13 升级 → 13–18 变化或换位 → 18–24 高潮 → 24–28 结果 → 28–30 稳定收尾

**铺垫原则**（首镜铺满）：分镜 1（或单镜头的前 1/3）必须建立所有后续将出现的角色 / 道具 / 场景的视觉存在，后续分镜不得凭空出现新元素。新角色 / 新道具在首镜没出现过，后续突然冒出来 = 跨镜不一致的主要来源。如果剧本后半段确实需要新元素，要么在首镜前置交代（角色在背景中站立不动 / 道具在桌面上可见），要么拆成独立任务生成。

## 2. 素材职责声明（补强 §5 参考生公式）

参考生公式只给了「@参考对象」，没说**一个素材负责什么、不负责什么**。多素材场景下这是指代命中率的关键。

**四要素 = 素材编号 + 正向职责 + 生效时段 + 禁止迁移项**

wan3.0 写法：

```
@图片1 锁定人物五官、发型与服装，全片生效；画面背景与图中文字不参与生成。
@图片2 锁定商品外形、材质与比例结构，全片生效；商品结构与比例全程保持不变。
@视频1 只参考运镜方式与动作节奏；其中的人物、场景、品牌标识与声音均不迁移。
@音频1 作为音色参考；音色引用在台词句后紧跟「音色参考 @音频1」，不在开头写"提取音色特征"。
```

三条纪律：

- **禁止迁移项必须写成正向句** —— wan3.0 已废弃 `negative_prompt`，不写「不要参考图中的背景」，写「画面背景与图中文字不参与生成」
- 同一素材承担**超过两项职责就拆成两句**，一句只说一件事
- 多次引用时**每次都重复 @** 一次 —— 这与公式 §5「可在不同位置多次 @ 同一对象」一致，是提高命中率的推荐手法

## 3. 排除层的取舍（补强五层 / 六层结构的排除层）

排除层不是越多越好。堆到二三十条时，模型对每一条的注意力都被稀释。

- **只写 3–8 项**，且只写**这条提示词真实会踩的**风险。给生活方式广告加一堆打斗物理约束，纯属浪费额度。
- **先消矛盾，再写限制**。正文里「固定机位」和「环绕运镜」打架时，加十句约束也没用 —— 回去改正文。
- **常见互斥组合**（下笔前扫一遍）：

  | 互斥 A | 互斥 B |
  |---|---|
  | 固定镜头 | 持续环绕 / 持续推进 |
  | 自然纪录质感 | 每秒强转场 |
  | 浅景深近景特写 | 交代全景空间关系 |
  | 一镜到底 | 硬切转场 |
  | 商品正面 logo 全程朝向镜头 | 360 度环绕展示 |

- **优先级排序**（从这个顺序里挑最相关的 3–8 条）：身份 / 商品稳定 → 物理正确 → 摄影正确（机位与轴线）→ 文字与品牌 → 声音边界
- **注释层删除**：提示词中给人看的解释性文字——如「因为 X」「为了 Y」「重点于 Z」「目的是 W」「这里需要注意……」——一律删除。模型不需要知道你为什么这么写，只需要知道写什么。解释性文字会占用注意力额度并干扰对核心指令的解析。保留规则与描述，删掉理由。

## 4. 复杂动作的可追踪写法（补强 wan3.0 物理交互弱项）

**只在**打斗、追逐、抛接、液体喷射 / 倾倒、多人换位时追加；普通镜头写清动作即可，别过度工程化。

**五要素 = 谁发起 + 从哪里出发 + 沿什么路径 + 作用于谁 + 最后落在哪里**

镜头必须让动作关系可追踪：

- 发力 / 发射前，先让观众**看见发起者的起势动作**
- 飞行物**从发起者身边出现**，不凭空出现在画面中央
- 目标从**正确来向**受击或防守
- 多人换位用**一个双人广角**交代过程，别在特写里换位
- 物体飞行途中**不越轴、不突然反向**

> 与 SKILL.md 的高危动作流程配合：先走「检测→提醒→方案→用户决定」，用户选"硬跑"时再用五要素把动作写死。
> 五要素能提高动作**可读性**，但改变不了 wan3.0 物理交互穿帮的能力边界 —— 诊断到能力边界仍要明说。

## 5. 参考片反推（把成片还原成提示词）

用户丢一条成片说"照这个做一条 / 复刻这个"时的纪律。

**先看六项**：总时长 / 画幅 / 帧率、真实剪辑切点、每镜首帧与尾帧、人物服装商品场景、动作是否真实存在、口播字幕与环境声。

**输出六条规则**：

1. 用**真实切点**分段，不做平均分段
2. 只描述画面里**能确认**的动作，镜头外的一律不写
3. 区分**硬切**与无缝转场，按公式 §6 写在分镜内容开头
4. **不把推断写成事实**（"他应该是在找钥匙" → 不写）
5. **不为了"更精彩"添加**原片没有的抛接、旋转、特技、对白
6. 用户要加戏时**另建「创意延伸版」**，不覆盖直接反推版

**落到 wan3.0 时的形态选择**：有角色图 / 商品图 → §5 参考生；无素材纯复刻 → §2 进阶 + §6 多镜头；原片可直接作为输入 → 走 §7 视频编辑，比重新描述更省力也更稳。

## 6. 一镜到底的写法细则（补强「生成单镜头」控制词）

「**生成单镜头**」「**一镜到底**」是控制词，但控制词本身没给写法。补这四项：

- **摄影机连续路线**：从 A 点出发 → 经过 B → 绕过前景 C → 停在 D 构图
- **人物连续路线**：与摄影机的相对关系（跟随 / 交错 / 反向）
- **遮挡关系**：中途经过哪些前景遮挡（柱子、门框、走过的人）—— 遮挡是藏接缝的地方
- **速度变化**：哪一段加速、哪一段停住

写一镜到底时，**时间段只代表动作阶段，不代表切镜**，务必在结尾补一句：

```
全片为一个连续镜头，不硬切、不瞬移，机位运动连续。
```

## 7. 视频延长与智能编辑的要素补全（补强公式 §7）

公式 §7 给了骨架，这两项把要素写全：

**视频延长 = 原片末帧状态 + 新增时长 + 衔接动作 + 新增事件 + 结束状态 + 连续性约束**

> 公式要求"只写后续动态"，所以**末帧状态一句话点到即可**（用来对齐衔接点），不要展开重描述整个画面 —— 展开会让模型从头再演一遍。
> 需要换场景时，明确一个**可见转场载体**（推开的门、掠过的车窗、经过的柱子）和前后同方向运动，否则接缝硬。

**智能编辑 = 生效时段 + 定位方式 + 目标对象 + 从 A 变成 B + 保留项 + 声音要求**

> **定位方式**比名词更能锁住目标：「画面左侧的」「人物手中的」「桌面右上角的」
> **保留项**就是「其他保持不变」，但**点名要保的东西更稳**：「保持人物面部、动作、构图、背景光线与机位运动不变」
> **声音要求**：保留原声 / 去掉原声；改台词时必写「保持人物音色和语气」

## 8. 白膜转成片的粗细分类（补强公式 §5 白膜参考）

公式只给了一句写法，按素材精度分两类补细则：

**粗白膜**（只有几何体，用来定动作骨架、站位与运镜）——
必须写清**每个几何模型对应哪个角色或道具**的映射，以及四肢 / 翅膀 / 尾巴等完整动作链：

```
将 3D 预览视频转化为正式成片，预览视频中左侧的白模人形换成 @图片1 的男人，
右侧的白模人形换成 @图片2 的女人，中央的白色方块换成一张深色木质餐桌，
保持原有运镜、走位与两人相对距离，两人四肢动作与预览视频逐帧对应。
```

**细白膜**（已有完整模型，只做材质光影渲染）——
写渲染目标 + 分时段材质光影 + 场景 + 特效 + 全局一致性，并**显式声明辅助元素不进成片**：

```
成片中不出现轨迹线、坐标轴、相机锥体、网格地面与视窗界面元素，画面为完整实拍质感。
```

> 白膜的价值在于**运镜与走位已经确定**，提示词重点是"换成谁、换成什么材质"，不是重新设计镜头。

## 9. 最低质量线（交付前逐条自查）

- 前 **1–2 秒**必须出现主体 / 商品 / 冲突 / 强视觉动作，钩子别放到第 5 秒
- 人物、商品、场景**前后一致**
- 时间轴从 0 覆盖到结尾，**各段之和 = `duration`**
- 每段动作在分配时间内**做得完**（5s ≈ 1 个主动作；台词字数每秒 3–5 字，安全线 4 字/秒；超标 20% 以内原样保留，超过 20% 才拆段）
- 有 BGM 时写清类型 / 速度 / 乐器 / 情绪曲线 / 结尾方式，且与关键动作有节拍对应；不要 BGM 按控制词写「**无背景音乐**」
- 结尾有**明确落点**：动作落点，或稳定的英雄画面（商品正面定格 / 人物定格表情）

> ⚠️ BGM 的**标准公式只有「配乐 + 风格」两段**（见 [`wan3-formulas.md`](wan3-formulas.md) §4）。
> 上面的"速度 / 乐器 / 情绪曲线 / 关键节拍点"属于**扩展写法**，卡点精度以实测为准 —— 对客户不要承诺 wan3.0 能精确卡点。

## 10. 转场方式选择（按场景选多样转场，忌一律硬切）

> **🚨 核心口径**（对齐 SKILL.md §4 / §7 铁律9）：**按切点性质选转场，坚决避免一律硬切**。同场景连续动作用**运镜衔接（不切）**、同场景换机位直接**顺切**（可不写词）；跨场景 / 跨时空 / 情绪跳转要按性质从下面的词库里挑合适的手法——**硬切只是其中一种**（用于叙事反转、爆点、强节奏跳切）。**每镜开头都无脑填"硬切转场" = 严重错误**，把本该顺切或运镜连贯的镜头也塞进硬切，既单调又徒增跨镜一致性风险。

用法：每到一个切点，先判断"人物 / 场景 / 时间是否发生跳变"——三项都没变就用运镜或顺切；有跳变就来下面两张表按切点性质对号入座，挑一个**符合该场景情绪与逻辑**的手法（叠化、淡入淡出、闪白闪黑、匹配剪辑、遮挡 wipe、甩镜、光效过渡、雾遮罩、定格重音等都比一律硬切更有质感），并把转场逻辑写进那一镜的分镜内容里。目标是让承接方式**随剧情变化**，而不是逐镜复制同一个词。

### 10.1 按切点性质选转场（每个切点都来这张表挑，别一律硬切）

| 切点性质 | 首选 | 备选 / 备注 |
|---|---|---|
| 同场景同时间连续动作（救人→拨血污、抬手→撕信） | **不切，顺切或用运镜**（推 / 拉 / 跟随 / 环绕） | 默认就是这一类，**不写转场词**；也可写"光效过渡"（key light 移动、明暗渐变） |
| 同场景时间小跳（点烛→烛已燃过半） | 匹配剪辑（match cut） | 形状/位置对齐才稳；不稳退回叠化 |
| 跨景别同情绪（远景→近景看反应） | 硬切 或 快速推进 | 推进更沉浸；配"定格 0.3s 重音"留出"看清了"的节拍 |
| 视线引导（看→所见） | 硬切（顺视线切最稳） | 或摇镜顺视线摇过去不切 |
| 跨主体 / 跨空间 / 跨时间叙事跳 | 硬切 | 边界清晰，模型最易控 |
| 情绪温情的段落过渡 | 叠化 | wan3.0 叠化不稳，配 best-of-3 |
| 回忆闪回 / 时间倒叙 | 叠化 或 淡入淡出 | 模糊时间边界，暗示非线性叙事 |
| 段落起止 / 大时间跨度 | 淡出至黑 / 淡出至白 | 黑=终结感；白=温柔遗忘感；也可配 sound logo 单音 |
| 空间内转换（走廊→房间、山路→室内） | 遮挡转场（前景经过柱子/门框/人影/衣袖入画遮罩） | 门开门合本身就是天然 wipe |
| 悬念反转爆点 | 硬切 | 突兀感是叙事要的 |
| 动作连续但机位大跳 | 甩镜 或 硬切 | 甩镜有动感但难控，默认硬切 |
| 快节奏产品/情绪蒙太奇 | 快切两连 / 三连（1–1.5s 一镜） | 每镜自成完整画面状态；跨镜靠同色/同构图/同主体串起 |
| 环境雾气 / 白烟 / 水花 遮罩后浮现 | 雾遮罩转场（mist dissolve） | "在白雾散开的那一瞬间盘中浮现出 X" |
| 强情绪高潮收束 | 定格重音（freeze frame 0.3–0.5s）| 是转场的一半，剩下一半选硬切或淡出 |
| 一镜到底大幅调度 | 不切，用连续 orbit / 长跟拍 / 一镜多景别推拉 | 明写"镜头连续环绕/推进，不切镜" |
| 跟拍机位换角度（侧跟→正跟→尾跟） | 跟拍手法切换（tracking hand-off） | 主体运动方向必须连续，只换机位不换叙事时刻 |
| 屏幕/UI 触发转场（游戏、剪辑器风格） | 像素溶解 / 分辨率变化 / 光标点击后揭示 | 先描画 UI 元素与交互动作，再写"点击瞬间 X 变清晰" |
| 变装 / 换装 / 换场景（同一主体） | 门形 wipe（电梯门/幕布/衣物翻转） | 遮蔽期完成变化，打开时已换；比硬切自然 |
| 强节奏尾声定帧 | 定格 + 淡出 | 主体居中、留白充足；配 sound logo 收尾 |

### 10.2 转场词库（写出来时的落笔句式）

| 转场词 | 什么场景用 | 落笔示例 | wan3.0 稳定性 |
|---|---|---|---|
| 硬切转场 / Hard Cut | 跨主体/空间/时间叙事跳、反转爆点 | "第2个镜头[3-6秒]**硬切转场**，中景，……" | 稳，最可控的一种；但**只在真正的叙事跳变时用**，别逐镜复制 |
| 不切（运镜衔接） | 同场景同时间连续动作 | "第2个镜头[3-6秒]**镜头由中景连续推进至近景特写，不切镜**，……" | 稳，最建议做主力衔接 |
| 光效过渡 / Light Shift | 内在的时间/情绪推进 | "**光线由冷蓝转为暖黄**，key light 从画面左上缓缓移至画面正中，主体轮廓由剪影渐显" | 一般，建议明写光源移动路径 |
| 匹配剪辑 / Match Cut | 相似形状/位置/动作衔接两场景 | "手部特写切至同构图的另一只手，两只手在画面同一位置、同一角度" | 弱，形状对齐要素越具体越稳 |
| 叠化 / Cross Dissolve | 情绪温情、回忆入口 | "第2个镜头[5-9秒]**由前一镜画面缓慢叠化而来**，历时约 0.8 秒" | 弱，配 best-of-3 |
| 淡入 / 淡出至黑 | 段落起止、大时间跨度 | "画面**逐渐淡出至纯黑**，历时 0.5 秒，随后……" | 稳 |
| 淡出至白 | 温柔告别、梦境入口 | "画面**逐渐淡出至纯白**，白色停留 0.3 秒，切入下一场" | 稳 |
| 遮挡转场 / Wipe | 空间内位移、藏接缝 | "**画面前景由人影从右向左横穿**，人影完全遮住画面的一瞬间切至下一场" | 稳，前景元素越大越稳 |
| 门形 wipe | 变装/换场/剧情反转 | "**电梯门缓缓合拢**，闭合到画面全黑约 0.3 秒后再度打开，此时主体已换装、场景已变" | 稳，门/幕布/衣物翻转都算 |
| 雾遮罩 / Mist Dissolve | 白雾/白烟/水花后浮现新元素 | "**一小团柔和的白雾从画面上方散开笼罩住盘面**，就在白雾散开的那一瞬间，盘中凭空浮现出 X" | 稳，动作链写在同一段 |
| 定格重音 / Freeze Frame | 情绪高潮、"看清了"节拍 | "画面**定格 0.3 秒**，声音瞬间收小，随后……" | 稳，配 0.3–0.5s |
| 甩镜 / Whip Pan | 动作连续但机位大跳 | "**镜头快速横向甩动**产生轻微运动模糊，甩至下一场" | 弱，模型常做成"镜头晃"而非"甩"，慎用 |
| 快切两连 / 三连 | 快节奏产品/情绪蒙太奇 | "**快节奏剪辑三个特写镜头**：A / B / C，每个约 1.2 秒" | 稳，跨镜要有统一视觉主题串 |
| 一镜连续 orbit / 长跟拍 | 大幅调度、产品英雄镜 | "**镜头保持连续环绕**，从主体正面绕至侧面再至背面，全程不切" | 稳，明写"不切镜" |
| 跟拍手法切换 / Tracking Hand-off | 一段追逐/行进中换机位 | "**镜头切换到低角度正面跟拍**（tracking），主体运动方向不变" | 稳，主体运动方向要连续 |
| 像素溶解 / Pixel Dissolve | UI 风格、分辨率提升 | "**画面从马赛克像素块逐步溶解为清晰实拍**，历时 0.6 秒" | 中等，需先建立像素化首帧状态 |
| 屏幕点击揭示 | 游戏/交互广告 | "**白色光标滑入并点击 UI 按钮**，点击的瞬间画面主体从模糊变清晰" | 中等，UI 元素要先出现在画面内 |

### 10.3 五条纪律

- **按场景选转场、忌一律硬切是核心口径** —— 每个切点都按性质挑手法，让承接方式随剧情变化；硬切只是叙事跳变时的一种选择，不是默认槽位
- **同场景同时间的连续动作优先运镜 / 顺切而非切镜** —— 切了反而要额外写跨镜一致性约束，得不偿失
- **"不切 / 顺切"本身就是承接** —— 用运镜、光线、遮挡、动作衔接把两个时刻连起来，同样有节奏和信息量
- **叠化 / 甩镜 / 匹配剪辑在 wan3.0 不稳** —— 需要情绪过渡或形状衔接时用，配 best-of-3；淡入淡出、遮挡 wipe、闪白闪黑、定格重音相对稳
- **多样性自检**：一条多镜头里若每镜开头都写"硬切转场"，必是机械复制 —— 至少要区分"同场景运镜/顺切"与"跨场景多样转场"，回去按切点性质重新挑手法

> 反例：8 镜叙事里每镜都写"硬切转场"，其中"救人拖拽"→"拨血污"本是同场景同两人的连续动作，本该顺切或写"镜头从救人中景缓缓推进至男人面部特写"；而进入回忆那一镜本该用**叠化**、猛拉回现实那一镜本该用**闪白**——全填硬切既单调，又徒增跨镜一致性负担。
>
> 反例进阶：山间小路（户外）→ 土坯房内（室内）的空间跳，比起再写"硬切转场"，写成"少女架着男人走出画面，画面由山林绿色渐变至暖黄室内光"（光效过渡）或"镜头前景由门框从右向左横过，遮挡瞬间切至室内"（遮挡 wipe）更耐看，也更符合叙事的"进入内景"仪式感。

## 11. 复杂度预算与叙事骨架（防过载）

**复杂度预算**：写正文前先算一笔账。安全配置 = `1个场景 + 1个主角 + 1个关键物件 + 1条异常规律 + 1次反转`。以下每项属于**高风险变量**：
- 新增主要场景或地理跳跃
- 第三个以上可辨识人物或群众
- 角色/动物/车辆/道具发生结构变形
- 两人以上同步舞蹈、搏斗或复杂身体接触
- 快速追逐、连续腾跃或多次危险动作
- 多物体精确碰撞、复制或高速轨迹
- 长对白、持续口型或唱歌
- 镜面、多重倒影或画中画需精确同步
- 多次时间跳跃、世界重置或两个以上反转
- 无动机甩镜、绕拍、频繁换焦或连续跳切

普通 30 秒成片**最多保留两个高风险变量**。超过两个时，优先删除不会改变核心情绪和反转的变量。视觉奇观优先做成环境状态变化，而不是让人物和道具不断变形。

**一句话因果链**：写正文前先用一句话完成叙事骨架——
> `主角在固定场景执行任务 → 一个异常规律干扰任务 → 主角做出一次可见选择 → 结尾揭示同一物件或空间的真实含义`

如果一句话说不清，剧情仍然过载。不要继续加摄影、材质和负面词；先删减故事变量。

## 12. 连续性锁六类（跨镜一致性系统化）

提示词至少记录以下六类信息，跨镜头时在全局块统一声明一次：

| 类别 | 要记录的内容 |
|---|---|
| **角色** | 脸、年龄、发型、体型、主次关系、惯用手 |
| **服装** | 颜色、剪裁、鞋、帽、首饰、干湿与损坏状态 |
| **物件** | 数量、形状、材质、朝向、谁持有、是否已移动或打开 |
| **地理** | 入口、出口、左右位置、远近关系、运动轴线和摄影机不可跨越的方向 |
| **光线天气** | 主光方向、时间、雨雾、湿润程度和不可逆变化 |
| **动作状态** | 谁碰过什么、物件最终落点、是否已破裂、熄灭、落地或打开 |

> 专业运动、双人对打、车辆、球体或武器场景必须写出每次来因与去果。不得出现无来源来球、物体瞬移、左右手变化、跨轴、人数增殖或道具复制。
> 这六类与 SKILL.md §5.2 显式空间坐标、§5.3 跨镜头指代与空间管理配合使用。

## 13. 台词与情绪处理细则

### 13.1 台词内容缺失时的待填格式

原始要求要有对白、却未给出任何台词内容时，**一律不代拟台词**——台词是全片语义的承载，代拟等同于代写剧本，属最严重的编造。正文中该处写作固定格式：

```
台词（画内对白，{说话者}张口说话且口型与{语种}匹配，{在场其他角色}嘴部全程闭合不动）：待填台词，{N}–{M} 字
```

字数区间按每秒 3–5 字折算。该写法是"不保留 `{}` 占位符"的明文例外，仅适用于本情形。输出说明中须将其列为**阻断项**，说明使用者填入实际台词后方可提交，否则模型将自行编词。

双方对话而未指明由谁先开口时，改用：
```
台词（画内对白，{角色A全称}与{角色B全称}交替发言，各自发言时口型与{语种}匹配、同镜其余角色嘴部闭合）：待填台词，{N}–{M} 字，须逐句标注说话者
```

### 13.2 情绪表达三档处理

原文对情绪的要求分三档，处理方式不同：

| 档位 | 原文给出什么 | 处理方式 |
|---|---|---|
| **有方向** | 「越来越紧张」「从犹豫到坚定」 | 写为该方向的变化过程，起止两端取原文给出的词，中间不补动作细节 |
| **有强度** | 「情绪张力拉满」「情绪要浓烈一些」 | 原样保留该强度措辞，不删除；不自行设定具体强度 |
| **什么都没给** | 「情绪要有变化」「表情丰富一些」 | 仅写「表情在过程中发生变化」一类的中性表述，不设起止、不设趋势、不设强度，亦不得从场景或情节反推出方向 |

> 原文完全未提及情绪时，不主动补入情绪描写。面部微动作（眼神、眉毛、嘴角、呼吸、手部小动作）原文未给出的均属编造，不补入。

## 14. 表情铁律（阵营级表情锁定）

有阵营对立或角色立场明确的场景（施暴者 / 受害者、审问者 / 被审者、霸凌者 / 被霸凌者），须在全局约束中锁定各阵营的表情逻辑，防止模型随机生成错位表情（如受害者发笑、施暴者哭泣）。

**写法**：
```
@图片X 全程保持[痛苦/愤怒/恐惧]表情，严禁发笑；
@图片Y 全程保持[冷漠/嘲弄/得意]表情，严禁哭泣或恐惧表情。
```

**要点**：
- 锁定的是**表情类型**与**禁止表情**，不是微动作的每一帧——微动作（眨眼、吞咽）仍允许自然发生
- 与 §13.2 情绪三档配合使用：§13.2 管「情绪怎么变化」，本条管「什么表情绝对不能出现」
- 无阵营对立的普通场景不需要写本条；写了反而过度约束
